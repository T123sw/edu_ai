## 学习目标
本讲义旨在帮助学生建立关系数据模型的核心认知。学习完成后，学生应能：准确表述关系模型的基本组成要素；区分主键与普通属性的约束差异；理解查询操作作为集合变换的本质；能够识别数据库设计中的常见逻辑谬误。

## 准确概念与边界
关系模型（Relational Model）是基于集合论的数据组织方式。其核心边界在于逻辑层与物理层的分离。
1.  **关系（Relation）**：逻辑上表现为一张二维表，数学上定义为笛卡尔积的子集。表中的每一行称为元组（Tuple），每一列称为属性（Attribute）。
2.  **表（Table）**：关系的具体实现形式。关键边界在于：表中的行序无关紧要，列序无关紧要，且不允许存在完全重复的行。
3.  **主键（Primary Key）**：能唯一标识元组的最小属性集。必须满足两个约束：唯一性（Unique）和非空性（Not Null）。一个关系只能有一个主键。
4.  **查询（Query）**：对关系进行的集合运算，输入是关系，输出也是关系。查询语言（如 SQL）是声明式的，用户指定“想要什么”，而非“如何获取”。

## 机制与步骤
查询处理的逻辑机制通常遵循以下抽象步骤：
1.  **定位（FROM）**：确定操作的数据源关系。
2.  **筛选（WHERE）**：根据谓词逻辑 $P(t)$ 对元组 $t$ 进行选择操作，保留满足条件的行。
3.  **投影（SELECT）**：选择需要的属性列，形成新的关系结构。
4.  **连接（JOIN）**：若涉及多表，基于公共属性进行笛卡尔积后的筛选。

伪代码表示查询逻辑：
```text
FUNCTION Query(Relation R, Condition C, Columns L):
    Result = Empty Set
    FOR EACH tuple t IN R:
        IF Evaluate(t, C) IS TRUE:
            projected_t = Project(t, L)
            ADD projected_t TO Result
    RETURN Result
```

## 完整例子
假设有一个“学生信息表” `Students`，结构如下：

| 学号 (ID) | 姓名 (Name) | 年龄 (Age) | 专业 (Major) |
| :--- | :--- | :--- | :--- |
| 2023001 | 张三 | 20 | 计算机 |
| 2023002 | 李四 | 21 | 数学 |
| 2023003 | 王五 | 20 | 计算机 |

**主键**：`ID`。因为姓名可能重复，年龄和专业显然不唯一。
**查询任务**：找出所有计算机专业的学生姓名。
**SQL 实现**：
```sql
SELECT Name FROM Students WHERE Major = '计算机';
```
**执行结果**：
| 姓名 (Name) |
| :--- |
| 张三 |
| 王五 |

## 复杂度与权衡
在关系数据管理中，存在存储冗余与查询效率的权衡。
1.  **规范化（Normalization）**：通过拆分表减少数据冗余，保证数据一致性。例如将“专业”单独建表。但这会增加查询时的连接（JOIN）操作开销。
2.  **索引（Indexing）**：为特定列建立索引可将对全表的扫描复杂度从 $O(n)$ 降低至 $O(\log n)$ 或 $O(1)$。但索引会占用额外存储空间，并降低写入（INSERT/UPDATE）速度，因为每次写入都需维护索引树。
3.  **权衡策略**：读多写少的场景适合建立较多索引；写多读少或存储极度敏感的场景适合高度规范化且少索引。

## 常见误区
1.  **误区一：表行顺序有意义。** 纠正：关系是集合，除非使用 `ORDER BY`，否则数据库不保证返回行的顺序。
2.  **误区二：NULL 等于空字符串。** 纠正：`NULL` 表示“未知”或“不存在”，在逻辑运算中 `NULL = NULL` 的结果为未知（False），必须使用 `IS NULL` 判断。
3.  **误区三：主键必须是第一列。** 纠正：主键可以是任意列或列组合，物理存储顺序不影响逻辑主键定义。

## 自测题与答案
1.  **问**：若一个表中没有任意单列能唯一标识行，如何定义主键？
    **答**：可以使用多列组合成复合主键（Composite Key），只要组合值唯一即可。
2.  **问**：执行 `SELECT * FROM Students WHERE Age = NULL` 会返回结果吗？
    **答**：不会。任何与 NULL 的比较运算结果均为未知，应使用 `WHERE Age IS NULL`。
3.  **问**：关系模型中，允许两个元组完全相同吗？
    **答**：不允许。关系定义为集合，集合中的元素具有互异性。
