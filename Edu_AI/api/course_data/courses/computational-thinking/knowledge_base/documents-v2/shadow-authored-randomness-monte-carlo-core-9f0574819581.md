## 核心概念与边界
在计算思维中，**随机性**通常指不可预测的变化。然而，计算机是确定性机器，无法产生真正的随机数。我们使用的是**伪随机数生成器（PRNG）**，它通过确定性算法生成看似随机的数列。只要初始种子（Seed）相同，生成的序列就完全相同。这一特性对于调试和复现实验至关重要。

**蒙特卡洛方法（Monte Carlo Method）**是一类基于随机采样来解决确定性问题的算法总称。其核心边界在于：它不追求单次的精确解，而是通过大量重复实验，利用统计学规律逼近真实值。它适用于那些难以通过解析公式直接求解，但容易进行单次模拟的问题。

## 机制与步骤
蒙特卡洛方法的通用执行机制包含四个关键步骤：
1.  **定义域建模**：确定问题的输入空间及其概率分布。
2.  **随机采样**：从定义域中生成大量符合分布的随机输入样本。
3.  **确定性计算**：对每个样本执行确定的逻辑运算，得到输出结果。
4.  **统计聚合**：对所有输出结果进行统计分析（如求平均值、方差、频率），以此作为问题的近似解。

## 完整例子：估算圆周率 $\pi$
这是一个经典的蒙特卡洛应用。假设有一个边长为 2 的正方形，内部内切一个半径为 1 的圆。
正方形面积 $A_{square} = 2 \times 2 = 4$。
圆形面积 $A_{circle} = \pi \times 1^2 = \pi$。
若在正方形内随机投点，点落在圆内的概率 $P$ 为面积之比：
$$ P = \frac{A_{circle}}{A_{square}} = \frac{\pi}{4} $$
因此，$\pi = 4 \times P$。我们可以通过统计落在圆内的点数比例来估算 $\pi$。

### 参考代码（Python）
```python
import random
import math

def estimate_pi(num_samples):
    inside_circle = 0
    for _ in range(num_samples):
        x = random.uniform(-1, 1)
        y = random.uniform(-1, 1)
        if x**2 + y**2 <= 1:
            inside_circle += 1
    return 4 * inside_circle / num_samples

# 运行测试
samples = 100000
pi_est = estimate_pi(samples)
print(f"采样次数：{samples}, 估算值：{pi_est}, 误差：{abs(pi_est - math.pi)}")
```

## 复杂度与权衡
蒙特卡洛方法的误差收敛速度遵循大数定律，其标准误差与采样次数 $N$ 的平方根成反比，即 $O(1/\sqrt{N})$。这意味着若要将精度提高 10 倍，采样次数需要增加 100 倍。这是一种典型的**时间换精度**的权衡。在处理高维积分或复杂系统模拟时，尽管收敛慢，但相比传统数值方法，其计算复杂度往往不随维度指数级增长，因此具有独特优势。

## 常见误区
1.  **误区一：伪随机不可用。** 事实上，只要周期足够长且分布均匀，伪随机数在绝大多数模拟中足够有效，且具备可复现性。
2.  **误区二：样本越多越好。** 虽然增加样本能提高精度，但需考虑计算成本。当精度满足需求后，继续增加样本是资源浪费。
3.  **误区三：蒙特卡洛能解决所有问题。** 对于存在解析解的简单问题，使用蒙特卡洛是低效的；它主要用于解决“难解”问题。

## 自测题与答案
1.  **问**：为什么在调试蒙特卡洛程序时建议固定随机数种子？
    **答**：固定种子可以确保每次运行生成的随机序列相同，从而复现 Bug 或验证修改效果，排除随机性干扰。
2.  **问**：若采样次数 $N$ 从 100 增加到 10000，理论误差大约缩小为原来的多少？
    **答**：$\sqrt{10000/100} = \sqrt{100} = 10$，误差大约缩小为原来的 1/10。
3.  **问**：蒙特卡洛方法得到的结果是精确值吗？
    **答**：不是，它是基于概率统计的近似值，结果带有置信区间。
