## 准确概念与边界
**网络分层**是指将复杂的网络通信系统划分为若干个层次，每一层专注于特定的功能，并通过标准接口与相邻层交互。这种设计体现了计算思维中的“抽象”与“模块化”。常见的模型包括 OSI 七层模型与 TCP/IP 四层模型。在本课程中，我们主要关注 TCP/IP 模型中的网际层（Internet Layer）与传输层。

**IP 地址**是逻辑地址，用于在网络层标识设备。IPv4 地址长度为 32 位，通常采用点分十进制表示（如 $192.168.1.1$）。**子网掩码**用于区分 IP 地址中的“网络部分”与“主机部分”。掩码中为 1 的位对应网络号，为 0 的位对应主机号。

**边界说明**：本知识点聚焦于逻辑寻址与分层架构，不涉及物理层信号传输细节（如电压、光脉冲），也不深入探讨路由协议的具体算法（如 OSPF、BGP 的内部状态机）。

## 机制与步骤
数据在网络中传输的核心机制是**封装与解封装**。
1.  **发送端封装**：应用数据从上至下传递。每一层在数据前添加头部（Header），包含该层的控制信息（如源 IP、目的 IP、端口号）。
    *   传输层：添加端口信息，形成段（Segment）。
    *   网际层：添加 IP 地址，形成包（Packet）。
    *   链路层：添加 MAC 地址，形成帧（Frame）。
2.  **网络传输**：比特流通过物理介质传输。
3.  **接收端解封装**：数据从下至上传递。每一层读取并剥离对应的头部，将剩余数据交给上一层，直到应用层获得原始数据。

**IP 寻址计算机制**：
要判断两个 IP 是否在同一子网，需计算它们的网络号。公式如下：
$$ \text{NetworkID} = \text{IPAddress} \ \text{AND} \ \text{SubnetMask} $$
其中 AND 为按位与运算。若两个 IP 计算出的 NetworkID 相同，则它们位于同一局域网段，可直接通信；否则需通过网关转发。

## 完整例子
假设主机 A（$192.168.1.10$）向主机 B（$192.168.1.20$）发送数据，子网掩码均为 $255.255.255.0$。
1.  A 计算自己的网络号：$192.168.1.10 \ \text{AND} \ 255.255.255.0 = 192.168.1.0$。
2.  A 计算 B 的网络号：$192.168.1.20 \ \text{AND} \ 255.255.255.0 = 192.168.1.0$。
3.  结论：网络号相同，A 认为 B 在同一局域网，通过 ARP 协议获取 B 的 MAC 地址后直接发送帧。
若 B 的 IP 为 $192.168.2.20$，则网络号为 $192.168.2.0$，A 会将数据包发送给默认网关（路由器），由路由器进行跨网段转发。

## 代码实现
以下 Python 代码演示了如何验证两个 IP 是否在同一子网，不依赖第三方库，体现底层逻辑。

```python
def ip_to_int(ip_str):
    parts = [int(p) for p in ip_str.split('.')]
    return (parts[0] << 24) + (parts[1] << 16) + (parts[2] << 8) + parts[3]

def get_network_id(ip_str, mask_str):
    ip_int = ip_to_int(ip_str)
    mask_int = ip_to_int(mask_str)
    network_int = ip_int & mask_int
    # 转回点分十进制
    return '.'.join(str((network_int >> (8 * i)) & 255) for i in reversed(range(4)))

# 测试用例
ip1 = "192.168.1.10"
ip2 = "192.168.1.20"
mask = "255.255.255.0"

net1 = get_network_id(ip1, mask)
net2 = get_network_id(ip2, mask)

print(f"IP1 网络号：{net1}")
print(f"IP2 网络号：{net2}")
print(f"是否同网段：{net1 == net2}")
```

## 复杂度与权衡
分层模型的主要权衡在于**效率与灵活性**。
*   **优势**：各层独立演进，互不影响。例如，无线技术（链路层）的升级不需要修改网页浏览器（应用层）的代码。
*   **代价**：每一层的头部信息增加了数据传输的开销（Overhead）。对于极小的数据包，头部可能比有效载荷还大。此外，严格的分层可能导致跨层优化困难，例如某些实时应用需要链路层直接反馈拥塞信息，但标准模型中需逐层上传，增加延迟。

## 常见误区
1.  **误区**：IP 地址代表设备的物理位置。
    **正解**：IP 是逻辑拓扑位置，设备移动到新网络需更换 IP，而 MAC 地址通常绑定硬件不变。
2.  **误区**：互联网就是万维网（Web）。
    **正解**：互联网是基础设施（网络的网络），Web 是运行在其上的应用服务之一，其他还包括电子邮件、文件传输等。
3.  **误区**：子网掩码必须是 255.255.255.0。
    **正解**：掩码可以是任意连续的二进制 1，如 $255.255.255.128$（/25），用于更精细的子网划分。

## 自测题与答案
1.  **问**：若 IP 为 $10.0.0.5$，掩码为 $255.0.0.0$，网络号是多少？
    **答**：$10.0.0.0$。
2.  **问**：分层模型中，哪一层负责端到端的可靠性传输（如重传机制）？
    **答**：传输层（如 TCP 协议）。
3.  **问**：数据包在路由器转发时，哪一层地址会发生变化？
    **答**：链路层地址（MAC 地址）会变，网际层地址（IP 地址）通常不变（除非涉及 NAT）。
