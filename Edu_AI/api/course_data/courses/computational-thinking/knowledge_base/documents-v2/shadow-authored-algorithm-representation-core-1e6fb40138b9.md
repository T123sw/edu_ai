## 学习目标
本讲义旨在帮助学生掌握算法的三种基本表示方法：自然语言、流程图与伪代码。学习完成后，学生应能够：
1. 准确区分三种表示法的适用场景与优缺点。
2. 遵循标准规范绘制流程图，书写结构化伪代码。
3. 将具体问题转化为可执行的算法逻辑，并进行复杂度初步分析。

## 概念与边界
算法表示是计算思维的核心环节，旨在将解决问题的步骤形式化。
1. **自然语言**：使用人类日常语言描述步骤。优点是门槛低、易理解；缺点是容易产生歧义，难以表达循环与分支结构，不适合直接转换为代码。
2. **流程图**：使用标准化几何图形表示算法流程。优点是逻辑直观、便于检查死循环；缺点是绘制耗时，修改不便，复杂算法会导致图形庞大。常用符号包括：椭圆（起止）、矩形（处理）、菱形（判断）、平行四边形（输入输出）。
3. **伪代码**：介于自然语言与编程语言之间的文本描述。优点是结构清晰、易于修改、接近代码实现；缺点是缺乏统一标准，需约定关键字。

| 表示法 | 精确度 | 可读性 | 修改成本 | 适用阶段 |
| :--- | :--- | :--- | :--- | :--- |
| 自然语言 | 低 | 高 | 低 | 需求初步分析 |
| 流程图 | 中 | 中 | 高 | 逻辑结构梳理 |
| 伪代码 | 高 | 中 | 中 | 详细设计与编码前 |

## 机制与步骤
构建算法表示通常遵循“抽象 - 细化”过程。
1. **定义输入输出**：明确算法接收的数据及产生的结果。
2. **设计控制结构**：确定顺序、选择（if-else）与循环（while/for）结构。
3. **逐步细化**：将复杂步骤分解为原子操作。
4. **规范性检查**：确保流程图无死循环，伪代码缩进正确。

## 完整示例：计算 1 到 N 的累加和
**问题**：输入整数 $N$，计算 $S = \sum_{i=1}^{N} i$。

**流程图描述**：
1. [开始] -> 2. [输入 N] -> 3. [初始化 i=1, S=0] -> 4. <判断 i<=N?>
   - 是 -> 5. [S = S + i] -> 6. [i = i + 1] -> 回到 4
   - 否 -> 7. [输出 S] -> 8. [结束]

**伪代码**：
```text
算法 SumOneToN
输入：整数 N
输出：整数 S
开始
    S <- 0
    i <- 1
    当 i <= N 执行
        S <- S + i
        i <- i + 1
    结束当
    输出 S
结束
```

**可运行代码（Python）**：
```python
def sum_one_to_n(n):
    s = 0
    i = 1
    while i <= n:
        s += i
        i += 1
    return s

# 测试
print(sum_one_to_n(100))  # 输出 5050
```

## 复杂度与权衡
上述算法的时间复杂度为 $O(N)$，空间复杂度为 $O(1)$。若使用高斯公式 $S = \frac{N(N+1)}{2}$，复杂度可降为 $O(1)$。在选择表示法时，若侧重逻辑验证，流程图更佳；若侧重实现细节，伪代码更优。自然语言仅适用于非技术人员的沟通。

## 常见误区
1. **流程图闭环错误**：循环结构缺少终止条件或更新步骤，导致死循环。
2. **伪代码缩进混乱**：未能通过缩进体现代码块层级，导致逻辑歧义。
3. **变量未初始化**：在使用累加器或计数器前未赋初值。

## 自测题与答案
1. **问**：流程图中菱形框代表什么？
   **答**：代表判断或决策，通常有一个入口和两个出口（是/否）。
2. **问**：伪代码中"<-"符号的含义是什么？
   **答**：代表赋值操作，将右侧值存入左侧变量。
3. **问**：若 N=0，上述累加算法的输出是多少？
   **答**：0。因为初始化 S=0，循环条件 1<=0 不成立，直接输出 S。
