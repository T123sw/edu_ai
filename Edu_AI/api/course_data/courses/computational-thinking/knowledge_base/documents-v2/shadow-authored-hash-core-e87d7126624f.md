## 概念与边界
哈希映射（Hash Mapping）是一种通过哈希函数 $h(k)$ 将键（Key）转换为数组索引的数据存储技术。其核心目标是实现平均时间复杂度为 $O(1)$ 的查找、插入和删除操作。

**关键概念界定：**
- **哈希函数**：必须是一个确定性函数，即相同的输入永远产生相同的输出。形式化定义为 $h: U \rightarrow \{0, 1, ..., m-1\}$，其中 $U$ 是键的全集，$m$ 是哈希表槽位数量。
- **冲突（Collision）**：当两个不同的键 $k_1 \neq k_2$ 满足 $h(k_1) = h(k_2)$ 时，称为发生了冲突。根据鸽巢原理，只要键的空间大于槽位空间，冲突就不可避免。
- **负载因子（Load Factor）**：记为 $\alpha$，定义为 $\alpha = n / m$，其中 $n$ 是表中元素个数，$m$ 是槽位总数。$\alpha$ 衡量了哈希表的填充程度。

**边界条件：**
哈希映射不适用于需要范围查询（如“查找所有大于 10 的键”）或有序遍历的场景，此时平衡二叉搜索树更为合适。此外，哈希函数不具备可逆性，不能从索引反推原始键。

## 核心机制与步骤
处理冲突主要有两种机制，本讲义重点讲解**链地址法（Chaining）**。

1. **初始化**：创建一个大小为 $m$ 的数组，每个位置初始化为一个空链表。
2. **插入**：计算键的哈希值 $index = h(key)$。将该键值对作为新节点插入到数组第 $index$ 位置的链表中。
3. **查找**：计算 $index = h(key)$，遍历该位置的链表，比对键值是否相等。
4. **删除**：计算 $index = h(key)$，在对应链表中找到节点并移除。

## 完整示例
假设哈希表大小 $m=5$，哈希函数为 $h(k) = k \mod 5$。我们要插入序列 $[12, 22, 32, 7, 17]$。

| 步骤 | 操作键 | 哈希计算 | 索引 | 冲突情况 | 表状态（索引: 链表内容） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 12 | $12 \mod 5$ | 2 | 无 | 2: [12] |
| 2 | 22 | $22 \mod 5$ | 2 | 是 (与 12) | 2: [12, 22] |
| 3 | 32 | $32 \mod 5$ | 2 | 是 (与 12, 22) | 2: [12, 22, 32] |
| 4 | 7 | $7 \mod 5$ | 2 | 是 (与前述) | 2: [12, 22, 32, 7] |
| 5 | 17 | $17 \mod 5$ | 2 | 是 (与前述) | 2: [12, 22, 32, 7, 17] |

在此极端示例中，所有键都冲突在同一位置，查找复杂度退化为 $O(n)$。这说明了哈希函数分布均匀性的重要性。

## 代码实现
以下是基于链地址法的 Python 简易实现：

```python
class HashNode:
    def __init__(self, key, value):
        self.key = key
        self.value = value
        self.next = None

class HashTable:
    def __init__(self, size=10):
        self.size = size
        self.table = [None] * size
        self.count = 0

    def _hash(self, key):
        return hash(key) % self.size

    def put(self, key, value):
        index = self._hash(key)
        current = self.table[index]
        # 检查是否已存在
        while current:
            if current.key == key:
                current.value = value
                return
            current = current.next
        # 头插法新建节点
        new_node = HashNode(key, value)
        new_node.next = self.table[index]
        self.table[index] = new_node
        self.count += 1

    def get(self, key):
        index = self._hash(key)
        current = self.table[index]
        while current:
            if current.key == key:
                return current.value
            current = current.next
        return None
```

## 复杂度与权衡
- **时间复杂度**：
  - 平均情况：$O(1 + \alpha)$。当 $\alpha$ 为常数时，操作为 $O(1)$。
  - 最坏情况：$O(n)$。发生在所有键都哈希到同一位置时。
- **空间复杂度**：$O(m + n)$。需要存储数组槽位和所有节点。
- **权衡**：增大 $m$ 可以减小 $\alpha$，提高速度，但浪费空间；减小 $m$ 节省空间，但增加冲突概率，降低速度。通常当 $\alpha > 0.7$ 时建议扩容。

## 常见误区
1. **误区一**：“哈希函数可以保证唯一性。”
   - 纠正：哈希函数是将大空间映射到小空间，冲突是必然的，只能减少不能消除。
2. **误区二**：“哈希表查找永远比二叉树快。”
   - 纠正：在数据量极小或冲突严重时，哈希表性能可能不如二叉树，且哈希表不支持有序操作。
3. **误区三**：“负载因子可以大于 1。”
   - 纠正：在开放寻址法中 $\alpha$ 必须 $\le 1$；在链地址法中 $\alpha$ 可以大于 1，但过大会导致链表过长。

## 自测题与答案
1. **问**：若哈希表大小为 10，已存入 8 个元素，负载因子是多少？
   - **答**：$\alpha = 8/10 = 0.8$。
2. **问**：为什么哈希函数通常包含取模运算？
   - **答**：为了将任意大小的哈希值映射到固定的数组索引范围 $[0, m-1]$ 内。
3. **问**：在链地址法中，删除一个不存在的键需要遍历整个链表吗？
   - **答**：需要遍历该索引位置的整个链表，确认不存在后方可结束。
