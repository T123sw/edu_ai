## 学习目标
1. 理解变量作为“命名存储”的本质及其与内存地址的关联。
2. 掌握基本数据类型（整型、浮点型、布尔型）的区分与适用场景。
3. 能够正确构建表达式并理解运算符优先级与结合性。
4. 辨析赋值操作与数学等式的根本区别。

## 准确概念与边界
**变量（Variable）** 是计算机内存中具有特定名称的存储单元。在计算思维中，变量被视为数据的容器，其核心特征是“可变性”，即容器内的值可以在程序运行过程中被修改。变量的命名需遵循标识符规则，且应具有语义化特征。

**数据类型（Data Type）** 定义了变量所能存储值的集合以及对该值可执行的操作。例如，整型（int）用于计数，浮点型（float）用于度量。类型系统决定了内存分配的大小及解释方式。强类型语言禁止不同类型间的隐式运算，而弱类型语言则允许自动转换。

**表达式（Expression）** 是由变量、常量、运算符及括号组成的 syntactic 实体，其计算结果为一个值。表达式本身不改变程序状态，仅产生数据。

**赋值（Assignment）** 是将表达式计算结果存储到变量中的操作。在大多数编程语言中，赋值符号 `=` 表示“将右侧值存入左侧变量”，而非数学上的相等关系。

## 机制与步骤
变量使用的核心机制遵循“声明/初始化 -> 求值 -> 存储”流程。
1. **内存分配**：当变量被创建时，系统根据类型分配固定大小的内存空间。
2. **表达式求值**：编译器或解释器按照运算符优先级（如先乘除后加减）和结合性（通常为从左到右）计算表达式。
3. **赋值操作**：计算完成后，将结果二进制位写入变量对应的内存地址，覆盖旧值。

伪代码描述赋值过程：
```text
过程 赋值 (变量名, 表达式):
    值 <- 计算 (表达式)
    地址 <- 查找地址 (变量名)
    写入内存 (地址, 值)
结束过程
```

## 完整示例
以下 Python 代码展示了变量定义、类型差异及表达式计算：
```python
# 变量定义与初始化
count = 10          # 整型
price = 9.9         # 浮点型
is_valid = True     # 布尔型

# 表达式计算
total = count * price  # 整型与浮点型运算，结果为浮点型
discounted = total * 0.9

# 输出结果
print(f"总价：{total}, 折后：{discounted}")
```
在此例中，`count * price` 触发了隐式类型转换，整型 `10` 被提升为浮点型参与运算，体现了类型系统在表达式中的协调作用。

## 复杂度与权衡
使用动态类型（如 Python）编写表达式更灵活，开发效率高，但运行时需额外开销进行类型检查，且易引发类型错误。静态类型（如 C++）在编译期即可发现类型不匹配，运行效率高，但代码冗长。此外，浮点数运算存在精度损失问题，例如 $0.1 + 0.2 \neq 0.3$ 在二进制浮点表示中成立，涉及货币计算时需权衡使用定点数或整数模拟。

## 常见误区
1. **混淆赋值与相等**：`a = b` 是将 b 的值给 a，而 `a == b` 是判断两者是否相等。
2. **整数除法陷阱**：在许多语言中，`5 / 2` 结果为 `2` 而非 `2.5`，需显式转换为浮点型。
3. **链式赋值误解**：`a = b = c` 表示将 c 的值同时赋给 a 和 b，而非数学上的连等关系。
4. **变量未初始化**：使用未赋值的变量会导致未定义行为或运行时错误。

## 自测题与答案
1. **问**：若 `x = 5`，执行 `x = x + 1` 后，`x` 的值是多少？这符合数学逻辑吗？
   **答**：`x` 为 6。不符合数学逻辑，这是赋值操作，意为取 x 当前值加 1 后存回 x。
2. **问**：表达式 `3 + 4 * 2` 的结果是多少？为什么？
   **答**：结果是 11。因为乘法优先级高于加法，先计算 `4 * 2` 得 8，再加 3。
3. **问**：为何不建议用浮点型变量存储金额？
   **答**：因为二进制浮点数无法精确表示某些十进制小数，会导致精度丢失，产生计算误差。
