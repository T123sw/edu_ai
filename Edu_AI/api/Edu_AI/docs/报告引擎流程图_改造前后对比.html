三、关键差异对比

对比项 改造前 改造后
focus 评估通过后 直接 → confirmer → researcher → evaluator → confirmer
RAG / Web 工具 未使用（仅注册在 tool_registry） 由 LLM 自主决策调用
大纲生成 仅基于槽位信息 槽位 + research_context
正文生成 仅基于槽位 + 大纲 槽位 + 大纲 + research_context
软确认话术 固定模板 根据 research_decision 动态添加前缀
