CORE MECHANISM
核心机制：Continuous to Discrete
这就引出了第二部分，也是全模态最底层的技术难点：如何让只能处理离散文本的大模型，去理解高维连续的图像和声音？
TOKENIZATION NECESSITY
核心痛点：为什么必须“离散化” (Tokenization)？
万物皆可 Token 化，是 Any-to-Any 生成的前提。
连续特征 (Continuous)：适合做分类/理解，但难以进行自回归生成。
离散特征 (Discrete)：完美契合现有 LLM 的 Next-Token Prediction 机制。
结论：只有把图像和声音也切分、量化成离散的“词汇”（Token），才能复用大模型强大的自回归生成能力。

VISUAL TOKENIZATION
视觉离散化：VQ (向量量化) 与密码本机制
连续特征提取 → 在 Codebook 中寻找最相似的特征向量 → 输出索引 (Index)。这个索引即为一个 Visual Token。
模型内部训练一个包含几万个标准特征的“密码本”。
图像输入时，每个小图块去密码本里找最相似的标准向量，记录其编号（如“502”）。
最新进展：MAGVIT-v2 (无查找表量化 LFQ，解决密码本坍缩问题)。
哈尔滨工程大学 · 计算机学院

AUDIO TOKENIZATION
音频离散化：解耦与 RVQ (残差向量量化)
语义解耦：Semantic Token (提取说了什么) + Acoustic Token (提取情绪、音色、背景音)。
核心算法：RVQ (Residual Vector Quantization)。
级联压缩，极大地保留了高频声音细节。
解释了为什么 GPT-4o 连用户的呼吸声和笑声都能完美复刻。

META CHAMELEON
Meta Chameleon：彻底的纯早期融合
开源界的激进尝试：完全摒弃 CLIP/ViT，图像像素直接转化为离散 Token，与文本混合后输入第一层 Transformer。
革命性在于极其彻底的早期融合——完全杀死了外挂的视觉编码器。

创新点：引入 QK-Norm 等归一化技术，解决了不同模态混合时极其容易崩溃的训练不稳定性。

ANYGPT / VITA
AnyGPT / VITA：多路离散表征与并发输出
在字典中引入标准化的 <Modality_Start> 和 <Modality_End> 控制符。
模型只需预测下一个 Token，即可自然地实现一边输出文字，一边输出语音。

CHALLENGES & PLAN
底层挑战、瓶颈与个人规划
了解了 SOTA 架构，并不意味着我们可以高枕无忧。最后一部分，我们将深入探讨阻碍全模态大模型发展的底层瓶颈，并汇报我的科研规划。
MODALITY COMPETITION
学术痛点 1：模态竞争与梯度冲突 (Modality Competition)
Key Judgment
全模态目前最大的梦魇是“模态竞争”。加入了图像和音频后，模型原有的文本逻辑能力发生“灾难性遗忘”。
Mechanism
梯度冲突：文本数据和图像数据在底层反向传播时，抢夺同一批参数的更新方向。
“容量诅咒”：参数空间有限时的互相挤占。
如何设计更好的路由机制缓解这种“容量诅咒”，是目前的学术热点。
现象：多模态模型一旦变聪明了会看图听音，它的代码和数学推导能力就会不可逆地下降。
本质机理：梯度冲突 (Gradient Conflict)。高密度的文本特征与稀疏的视觉特征在反向传播时抢夺共享参数的更新方向。
研究热点：设计更好的路由机制缓解“容量诅咒”。

COMPUTATIONAL DISASTER
学术痛点 2：高维输入的 $O(N^2)$ 复杂度灾难
Key Judgment
Transformer 的自注意力机制是 $O(N^2)$ 的复杂度。把视频转成几十万个 Token 后，计算量会呈平方级爆炸。
Solutions
Token 动态合并与丢弃算法。
Mamba (状态空间模型) 替代部分 Transformer。
线性注意力机制。
这使得全模态模型的平民化部署几乎不可能。目前学术界的破局方向，一是探索 Token 合并算法，二是用具有线性复杂度的 Mamba 来替代部分 Transformer。
一段10秒的高清视频 ≈ 数十万 Tokens。
标准 Transformer 的计算复杂度为 $O(N^2)$，带来算力与显存的双重灾难。
破局方向：Mamba (状态空间模型)、线性注意力、Token 动态合并与丢弃算法。
