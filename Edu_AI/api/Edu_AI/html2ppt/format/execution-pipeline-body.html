EXECUTION PIPELINE
原理解析：工具调用的完整生命周期
1
意图解析与规划
用户输入自然语言指令，AI 客户端判断需要调用的外部能力，并提取参数槽位。
User: “帮我查最近的 Git 记录”
→ 匹配工具：git_log
2
发起标准 RPC 调用
客户端把参数封装为标准 JSON-RPC 报文，通过本地通道发送给对应服务。
{ "method": "tools/call",
"name": "git_log" }
3
资源访问与上下文回传
服务执行真实命令或查询，把结果整理成模型可读的文本、图片或结构化数据。
Result: [Commit 8a2b3]
→ LLM 生成摘要
