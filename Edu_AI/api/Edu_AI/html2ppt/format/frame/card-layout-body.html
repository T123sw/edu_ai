AI SKILLS PROFILE
AI Skills 的三类能力画像
卡片页不能只做三张海报，而要让每张卡同时承载职责、例子和课堂追问。
这样观众不仅知道“它是什么”，还能知道“它解决什么问题、如何和其他卡片串起来”。
Perception Layer
信息获取
连接搜索引擎、知识库、数据库和文件系统，为模型提供外部事实来源。
例子：网页检索、读取文档、查询数据库。
课堂追问：如果没有这层，模型为什么容易“编”出答案？
Reasoning Layer
逻辑计算
执行代码、统计分析、数据转换和公式推导，让模型获得可靠计算能力。
例子：运行脚本、做表格分析、调用公式链路。
课堂追问：哪些任务必须把“会想”变成“能算”？
Action Layer
交互执行
调用 API、发送通知、创建工单或更新系统状态，把建议转化为动作。
例子：发邮件、创建工单、同步业务系统状态。
课堂追问：执行能力为什么必须配套授权、审计和回滚机制？
课堂串联：Perception 负责取数，Reasoning 负责处理，Action 负责把结果变成外部动作。
