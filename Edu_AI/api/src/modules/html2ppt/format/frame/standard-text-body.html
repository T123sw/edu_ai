人工智能基础理论与核心演进
先用一句核心判断把观众注意力钉住，再让下面的卡片承担详细解释。
核心结论：文本页也要同时容纳定义、解释和教学抓手，而不是只放一句话加一张大白卡。
定义层回答“它是什么”，用 2 到 3 条短句交代边界、特征与对象。
解释层回答“为什么重要”，让观众看到它和上位概念、工程实践之间的关系。
迁移层回答“怎么讲给学生”，把例子、追问和课堂类比直接留在当前页。
TEACHING HANDLE
讲解顺序：先抛判断，再给定义，最后用可执行例子帮助记忆。
关键词：能力单元、输入输出、可复用、可组合。
追问：如果一个能力需要跨系统复用，它最小需要暴露哪些信息？
课堂例子：把“检索、计算、发邮件”拆成三个独立 Skill，会比从 API 细节开始讲更容易建立认知。
