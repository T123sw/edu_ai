COMPARATIVE ANALYSIS
把一个问题拆成两个对等视角
对比页要同时给出一句结论、两侧差异和底部映射表，避免只剩两块空白大面板。
View A
连续特征
更适合理解 / 不利生成
连续表示保留信息丰富，更适合分类、检索与表征学习。
它有利于保持语义细节，但不容易直接进入统一词表。
工程代价是生成链路和 token 化接口较难统一。
View B
离散特征
更适合统一建模 / 生成友好
离散 token 可以自然进入词表、嵌入层与 next-token prediction 流程。
它更适合统一训练、推理和多模态对齐接口。
代价是需要量化压缩，否则会带来表达损失。
本质
保留连续语义空间
收敛到统一离散表示
优势
理解与检索更细腻
生成与建模更统一
代价
接口不统一，难直接生成
需要量化压缩与对齐机制
