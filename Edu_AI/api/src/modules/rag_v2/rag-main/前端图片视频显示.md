✅ 当前方案总结
后端 (api.py)
检索时转换路径为 URL：

```html
image_url = f"http://localhost:8000/storage/images/abc.jpg"
context_parts.append(f"图片URL: {image_url}")
```

LLM 输出 Markdown 格式：

```html
![图片描述](http://localhost:8000/storage/images/abc.jpg)
<video src="http://localhost:8000/storage/videos/video.mp4" controls></video>
```
前端兼容性
Streamlit（当前）：

```
st.markdown(response, unsafe_allow_html=True)  # 自动渲染图片和视频
```
HTML（未来）：

```html
<!-- Markdown 渲染库会自动转换 -->
<img src="http://localhost:8000/storage/images/abc.jpg" />
<video src="http://localhost:8000/storage/videos/video.mp4" controls></video>
```
优势
✅ 前端无关：LLM 只输出标准 Markdown，任何前端都能渲染

✅ 路径正确：使用完整 HTTP URL，不依赖相对路径

✅ 易于迁移：换成 HTML 前端时，只需用 Markdown 渲染库（如 marked.js）

当前方案已经是最优解，无需修改！
