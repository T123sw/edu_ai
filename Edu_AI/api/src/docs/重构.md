### 🧠 为什么不用 Cursor 自动改？
Cursor 擅长的是“写一个具体的算法”或者“修改某个类里的几行逻辑”。
当你让它重构一个 1300 行的架构时，它会试图读取全量代码，然后输出全量代码。在这个过程中，它绝对会截断、遗漏、甚至把 V5.1 的新逻辑用 V4 的旧逻辑覆盖掉。

**所以，听我的：**
1. 自己新建文件。
2. 用鼠标选中 `service.py` 里的代码块，`Ctrl+X`，`Ctrl+V` 扔进新文件。
3. 修复红色的 `import` 报错。
4. 跑通一次测试。

等你完成这步“物理隔离”，系统就会变得无比清晰！接下来我们引入 **Planner + Executor** 的高级自治架构，就只需要在独立的 `report_agent.py` 里动刀子，绝对不会影响主干流程了！
