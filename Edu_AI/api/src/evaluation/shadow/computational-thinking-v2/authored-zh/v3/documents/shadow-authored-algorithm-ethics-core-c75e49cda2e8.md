## 学习目标
本讲义旨在使学生掌握算法公平性的基本定义、度量方法及伦理边界。学习完成后，学生应能够：1. 区分算法公平、透明与问责的核心概念；2. 使用数学公式量化群体公平性差异；3. 理解准确性与公平性之间的权衡关系；4. 识别常见的公平性误区并提出初步改进思路。

## 概念与边界
算法公平（Fairness）指算法决策在不同群体间不产生系统性歧视。它分为群体公平（如 demographic parity）和个体公平（相似个体应得到相似对待）。透明（Transparency）指算法决策过程可被理解，包括模型可解释性及数据来源公开。问责（Accountability）指当算法造成损害时，有明确的主体承担责任，包括设计者、部署者及使用者。三者边界在于：公平关注结果分布，透明关注过程可见，问责关注后果承担。仅靠透明无法保证公平，仅靠公平定义无法解决问责归属。

## 核心机制与度量
实现公平通常涉及三个阶段：预处理（修正训练数据偏差）、处理中（修改目标函数约束）、后处理（调整决策阈值）。最常用的群体公平度量是人口统计parity，其公式为：
$$ P(\hat{Y}=1 | A=0) = P(\hat{Y}=1 | A=1) $$
其中 $\hat{Y}$ 为预测结果，$A$ 为敏感属性（如性别）。若两者差异过大，则存在歧视。另一种常用指标是差异影响比（Disparate Impact Ratio, DIR）：
$$ DIR = \frac{P(\hat{Y}=1 | A=0)}{P(\hat{Y}=1 | A=1)} $$
通常认为 $0.8 \le DIR \le 1.25$ 为可接受范围。

## 示例：贷款审批中的差异影响
假设某银行使用算法审批贷款，敏感属性为性别（0 代表女性，1 代表男性）。我们需计算通过率差异。以下 Python 代码演示如何计算 DIR：

```python
import numpy as np

def calculate_dir(gender, decision):
    # gender: 0 或 1, decision: 0 拒绝 1 通过
    group_0_rate = np.mean(decision[gender == 0])
    group_1_rate = np.mean(decision[gender == 1])
    
    if group_1_rate == 0:
        return float('inf')
    
    dir_val = group_0_rate / group_1_rate
    return dir_val, group_0_rate, group_1_rate

# 模拟数据
g = np.array([0, 0, 0, 1, 1, 1, 1, 1])
d = np.array([1, 0, 1, 1, 1, 1, 1, 0])

ratio, r0, r1 = calculate_dir(g, d)
print(f"女性通过率：{r0:.2f}, 男性通过率：{r1:.2f}, DIR: {ratio:.2f}")
```
若输出 DIR 为 0.75，则低于 0.8 阈值，表明存在对女性的潜在不公平对待，需启动问责机制审查模型特征。

## 权衡与复杂性
公平性与准确性往往存在权衡（Trade-off）。在某些数据分布下，强行满足公平性约束会导致整体预测准确率下降。例如，若某群体历史数据中标签噪声较大，强制平衡通过率可能引入更多错误预测。此外，不同公平定义之间可能存在数学上的互斥，无法同时满足所有公平性指标。因此，工程实践中需根据具体场景设定优先级，而非追求绝对公平。

## 常见误区
1. **盲目去敏**：认为移除敏感属性（如性别列）即可消除歧视。事实上，代理变量（如邮编、消费习惯）可能隐含敏感信息，导致隐性歧视。
2. **公平即平等**：混淆机会平等与结果平等。算法应保障机会公平，而非强行拉平结果。
3. **技术中立论**：认为算法只是数学工具，无伦理属性。算法设计者的选择本身即蕴含价值判断。

## 自测题与答案
1. **问**：差异影响比 DIR 为 0.5 意味着什么？
   **答**：意味着受保护群体的通过率仅为对照群体的一半，存在显著歧视风险。
2. **问**：移除敏感属性列能否完全保证算法公平？
   **答**：不能。数据中其他特征可能与敏感属性高度相关，形成代理歧视。
3. **问**：公平性与准确性是否总是正相关？
   **答**：否。通常存在权衡关系，优化公平性约束可能会损失部分模型准确率。
