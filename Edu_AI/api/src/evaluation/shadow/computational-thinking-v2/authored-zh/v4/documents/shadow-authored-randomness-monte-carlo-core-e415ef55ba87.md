## 学习目标
1. 理解计算机中“随机数”的本质及其与真随机的区别。
2. 掌握蒙特卡洛方法的核心思想：通过大量随机采样求解确定性问题的数值解。
3. 能够独立编写程序，利用蒙特卡洛方法估算几何面积或积分值。
4. 理解采样数量与计算精度之间的权衡关系。

## 概念与边界
**随机数**：在计算思维中，计算机生成的通常是“伪随机数”。它们由确定性算法（如线性同余发生器）产生，看似无规律但可复现。真正的物理随机性（如放射性衰变）在常规编程中较少直接使用，除非涉及密码学安全。
**蒙特卡洛方法**：这是一种基于概率统计理论的数值计算方法。其核心边界在于：它不寻求解析解（公式推导出的精确值），而是通过构建概率模型，利用随机实验的频率来逼近问题的解。
**适用边界**：适用于高维积分、复杂系统模拟、难以用确定性算法求解的问题。不适用于需要绝对精确解或对实时性要求极高且无法承受大量采样的场景。

## 机制与步骤
蒙特卡洛方法的标准执行流程包含四个步骤：
1. **构造概率模型**：将待求解的确定性问题转化为一个概率统计问题。例如，将求面积转化为求点落入区域的概率。
2. **生成随机样本**：利用伪随机数生成器，产生符合特定分布（通常是均匀分布）的大量样本点。
3. **模拟实验**：对每个样本点执行判断或计算，记录满足条件的次数。
4. **统计估算**：根据大数定律，当样本量 $N$ 趋于无穷大时，频率收敛于概率。利用公式计算最终估算值。

## 完整示例：圆周率估算
**问题**：估算圆周率 $\pi$ 的值。
**原理**：考虑一个边长为 2 的正方形，其内切圆半径为 1。
正方形面积 $S_{square} = 2 \times 2 = 4$。
圆形面积 $S_{circle} = \pi \times 1^2 = \pi$。
若在正方形内随机投点，点落入圆内的概率 $P = \frac{S_{circle}}{S_{square}} = \frac{\pi}{4}$。
因此，$\pi = 4 \times P$。

**代码实现**：
```python
import random
import math

def estimate_pi(num_samples):
    inside_circle = 0
    for _ in range(num_samples):
        # 生成 [-1, 1] 之间的随机坐标
        x = random.uniform(-1, 1)
        y = random.uniform(-1, 1)
        # 判断是否在圆内 (x^2 + y^2 <= 1)
        if x**2 + y**2 <= 1:
            inside_circle += 1
    # 计算概率并推导 pi
    pi_estimate = 4 * (inside_circle / num_samples)
    return pi_estimate

# 运行示例
samples = 100000
result = estimate_pi(samples)
print(f"采样数：{samples}, 估算值：{result}, 误差：{abs(result - math.pi)}")
```

## 复杂度与权衡
蒙特卡洛方法的误差 $\epsilon$ 与采样次数 $N$ 的关系遵循统计规律：$\epsilon \propto \frac{1}{\sqrt{N}}$。
这意味着要将精度提高 10 倍，采样次数需要增加 100 倍。
**时间复杂度**：$O(N)$，线性增长。
**空间复杂度**：$O(1)$，若边生成边统计，无需存储所有样本。
**权衡**：在计算资源有限的情况下，需根据所需的精度位数决定 $N$ 的大小。对于低精度需求，该方法极快；对于高精度需求，计算成本可能过高。

## 常见误区
1. **误区一**：“随机数越多，结果一定越准。”
   **纠正**：虽然趋势如此，但由于随机波动，增加样本量偶尔可能导致短期误差变大，长期来看才收敛。
2. **误区二**：“伪随机数不能用于蒙特卡洛。”
   **纠正**：只要伪随机数生成器的周期足够长且分布均匀性良好，完全适用于科学计算。
3. **误区三**：“蒙特卡洛只能求面积。”
   **纠正**：它可以求定积分、期望值、复杂系统风险等任何能转化为期望值形式的问题。

## 自测题与答案
1. **问**：若要将蒙特卡洛模拟的误差减小为原来的 1/2，采样次数需变为原来的多少倍？
   **答**：4 倍。因为误差与 $\sqrt{N}$ 成反比。
2. **问**：在圆周率估算中，若随机点生成范围改为 $[0, 1]$ 的正方形，公式应如何调整？
   **答**：原理不变，仍为第一象限的 1/4 圆与正方形之比，公式仍为 $\pi = 4 \times (\text{圆内点数} / \text{总点数})$。
3. **问**：伪随机数生成器如果不设置种子（seed），每次运行程序结果会怎样？
   **答**：通常默认基于系统时间设置种子，每次运行结果不同；若硬编码种子，则结果可复现。
