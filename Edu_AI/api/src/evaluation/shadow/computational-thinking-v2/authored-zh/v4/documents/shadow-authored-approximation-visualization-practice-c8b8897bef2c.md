## 计算思维案例与实践：数值积分与流量估算

### 一、学习目标
1. 能够将连续的物理量变化问题转化为离散数值计算问题（ discretization）。
2. 掌握利用矩形法（Riemann Sum）进行数值积分的编程实现。
3. 通过可视化对比不同离散粒度下的近似效果，分析误差与计算成本的关系。

### 二、真实问题情境
某工程团队需要估算一个不规则水箱在特定时间段内的总进水量。已知进水流速 $v(t)$ 随时间变化，函数关系为 $v(t) = t^2 + 1$ (单位：升/分钟)，时间区间为 $t \in [0, 2]$ 分钟。由于传感器采样频率有限，无法获得连续曲线，只能通过离散采样点估算总量（即曲线下的面积）。

### 三、输入输出与材料
- **输入**：
    1. 流速函数 $v(t)$。
    2. 积分区间 $[a, b]$。
    3. 离散分割数 $N$（代表采样点数量或矩形个数）。
- **输出**：
    1. 估算的总水量值。
    2. 可视化图表：包含真实曲线、近似矩形条、误差随 $N$ 变化的趋势图。
- **材料**：Python 环境，`numpy` 用于计算，`matplotlib` 用于绘图。

### 四、分步任务
1. **任务一：构建离散模型**。将区间 $[0, 2]$ 等分为 $N$ 份，计算每份的宽度 $\Delta t = (b-a)/N$。使用左矩形公式计算总面积：$Area \approx \sum_{i=0}^{N-1} v(t_i) \cdot \Delta t$。
2. **任务二：可视化近似过程**。绘制 $v(t)$ 的真实曲线，并在其上叠加 $N=5$ 时的矩形条，直观展示“未被覆盖”的误差区域。
3. **任务三：误差分析**。分别计算 $N=5, 10, 50, 100$ 时的估算值，并与真实积分值（解析解 $\int_0^2 (t^2+1)dt = 14/3 \approx 4.6667$）对比，绘制误差随 $N$ 增大的下降曲线。

### 五、参考实现与推导
```python
import numpy as np
import matplotlib.pyplot as plt

def func(t): return t**2 + 1
true_val = 14/3  # 解析解

def riemann_left(N):
    a, b = 0, 2
    t = np.linspace(a, b, N+1)
    dt = (b - a) / N
    # 左矩形取前 N 个点
    area = np.sum(func(t[:-1]) * dt) 
    return area

# 测试不同 N
Ns = [5, 10, 50, 100]
errors = []
for n in Ns:
    est = riemann_left(n)
    errors.append(abs(est - true_val))

# 绘制误差趋势
plt.plot(Ns, errors, marker='s')
plt.xlabel("Number of Intervals (N)")
plt.ylabel("Absolute Error")
plt.title("Error Reduction with Increased Discretization")
plt.grid(True)
plt.show()
```

### 六、测试与边界情况
1. **边界测试**：当 $N=1$ 时，算法应退化为单个大矩形，误差最大。检查代码是否报错。
2. **大数测试**：当 $N=100000$ 时，计算时间是否显著增加？误差是否趋于稳定？
3. **函数突变**：若 $v(t)$ 在某点不连续（如阶梯函数），矩形法的误差收敛速度会变慢，需观察图表验证。
4. **负值处理**：若流速为负（排水），面积计算逻辑是否支持负值累加？（本例中 $v(t)>0$，但代码应具备通用性）。

### 八、拓展问题
1. **算法改进**：尝试使用“梯形法则”代替矩形法，观察同等 $N$ 下误差是否减小？推导梯形公式代码。

3. **实际约束**：若传感器每秒只能采样一次，即 $N$ 固定，如何通过数学修正公式减小系统误差？
