## 核心概念与边界
线性表是数据元素之间存在一对一关系的数据结构。栈、队列和双端队列是操作受限的线性表，其“受限”体现在插入和删除操作的位置上。

**栈（Stack）**：限定仅在表尾进行插入和删除操作的线性表。这一端被称为栈顶（Top），另一端为栈底（Bottom）。其核心特征是**后进先出**（Last In, First Out, LIFO）。想象一摞盘子，最后放上去的盘子必须最先拿走。任何不在栈顶进行的插入或删除都违反了栈的定义。

**队列（Queue）**：限定仅在表尾进行插入、在表头进行删除操作的线性表。插入端称为队尾（Rear），删除端称为队头（Front）。其核心特征是**先进先出**（First In, First Out, FIFO）。想象排队买票，先来的人先服务。若允许在中间插入元素，则退化为普通线性表。

**双端队列（Deque）**：两端都可以进行插入和删除操作的队列。它打破了栈和队列的单向限制，既可以实现 LIFO，也可以实现 FIFO，提供了更高的灵活性。

## 操作机制与示例
假设初始状态为空，我们对一个容量足够的结构执行以下操作序列：`插入 A` -> `插入 B` -> `删除` -> `插入 C` -> `删除` -> `删除`。

| 操作 | 栈 (Stack) 状态变化 | 队列 (Queue) 状态变化 | 双端队列 (Deque) 左侧删除 |
| :--- | :--- | :--- | :--- |
| 插入 A | [A] | [A] | [A] |
| 插入 B | [A, B] | [A, B] | [A, B] |
| 删除 | [A] (弹出 B) | [B] (弹出 A) | [B] (弹出 A) |
| 插入 C | [A, C] | [B, C] | [B, C] |
| 删除 | [A] (弹出 C) | [C] (弹出 B) | [C] (弹出 B) |
| 删除 | [] (弹出 A) | [] (弹出 C) | [] (弹出 C) |

通过上表可见，同样的操作序列，因结构约束不同，输出序列完全不同。栈输出为 B, C, A；队列输出为 A, B, C。

## 实现与复杂度分析
在 Python 中，原生 `list` 和 `collections.deque` 是主要实现工具。

1.  **栈的实现**：使用 `list` 即可。`append()` 为入栈，`pop()` 为出栈。
    *   时间复杂度：$O(1)$。
2.  **队列的实现**：推荐使用 `collections.deque`。`append()` 入队，`popleft()` 出队。
    *   若使用 `list` 实现队列，`pop(0)` 需要移动后续所有元素，时间复杂度为 $O(n)$，其中 $n$ 为队列长度。这在大数据量下是严重的性能隐患。
3.  **双端队列的实现**：必须使用 `collections.deque`。支持 `append()`, `pop()`, `appendleft()`, `popleft()`。
    *   两端操作复杂度均为 $O(1)$。

```python
from collections import deque

# 正确的队列用法
q = deque()
q.append(1)      # 入队
q.popleft()      # 出队，O(1)

# 错误的队列用法 (性能陷阱)
q_list = []
q_list.append(1)
q_list.pop(0)    # 出队，O(n)，不推荐用于队列
```

## 常见误区
1.  **混淆索引访问**：栈和队列通常不支持随机访问（如 `stack[i]`）。虽然 Python 的 `list` 支持，但在抽象数据类型（ADT）定义中，应仅通过顶/头尾操作访问，以保持逻辑封装性。
2.  **空结构操作**：对空栈执行 `pop` 或对空队列执行 `dequeue` 会引发异常（如 `IndexError`）。必须在操作前检查 `len(struct) > 0`。
3.  **误用 List 作队列**：如前所述，`list.pop(0)` 的线性复杂度会导致算法整体复杂度恶化，尤其在循环处理大量数据时。

## 自测题与答案
1.  **选择题**：若一个栈的输入序列为 1, 2, 3，则不可能的输出序列是？
    *   A. 3, 2, 1
    *   B. 1, 2, 3
    *   C. 3, 1, 2
    *   D. 2, 3, 1
    *   **答案**：C。解析：3 先出栈意味着 1, 2 已入栈且 2 在 1 之上，故 3 出栈后，下一个必须是 2，不能是 1。
2.  **判断题**：双端队列可以完全替代栈和队列的功能。
    *   **答案**：正确。双端队列功能超集，但为了代码语义清晰，特定场景建议使用专用结构名。
3.  **计算题**：若使用 `list` 实现队列处理 $n$ 个元素，总时间复杂度是多少？
    *   **答案**：$O(n^2)$。因为每个 `pop(0)` 是 $O(n)$，执行 $n$ 次即为 $O(n^2)$。
