## 计算思维核心讲义：近似计算、误差与可视化

### 一、学习目标
1. 理解为何在计算科学中“近似”是常态而非例外，掌握绝对误差与相对误差的定义及计算方法。
2. 能够区分截断误差与舍入误差，并理解它们对计算结果的不同影响。
3. 学会利用可视化手段展示迭代过程中的误差收敛趋势，从而评估算法的有效性。

### 二、准确概念与边界
在计算思维中，**近似计算**是指用有限步骤或有限精度表示无限过程或连续量的方法。**误差**是衡量近似质量的标尺。
- **绝对误差**：$E_a = |x - \hat{x}|$，其中 $x$ 为真实值，$\hat{x}$ 为近似值。它表示偏离的大小，但未考虑量级。
- **相对误差**：$E_r = \frac{|x - \hat{x}|}{|x|}$ (当 $x \neq 0$)。它消除了量纲影响，更适合衡量精度。
- **误差来源**：
    1. **截断误差**：由数学模型的近似引起（如用有限项级数代替无限级数）。
    2. **舍入误差**：由计算机浮点数表示有限精度引起（如 $\pi$ 无法精确存储）。

**边界说明**：当真实值 $x$ 接近 0 时，相对误差可能趋向无穷大，此时应慎用相对误差指标。此外，计算机浮点数存在机器精度（Machine Epsilon），误差无法无限减小。

### 三、机制与步骤：牛顿迭代法
以求解 $\sqrt{S}$ 为例，牛顿法通过迭代公式 $x_{n+1} = \frac{1}{2}(x_n + \frac{S}{x_n})$ 不断逼近真实值。
1. **初始化**：选择一个初始猜测值 $x_0$（通常为正数）。
2. **迭代更新**：代入公式计算下一代近似值。
3. **误差评估**：计算 $|x_{n+1}^2 - S|$ 或 $|x_{n+1} - x_n|$。
4. **终止条件**：当误差小于预设阈值 $\epsilon$ 或达到最大迭代次数时停止。

### 四、完整示例与代码
以下 Python 代码演示了计算 $\sqrt{2}$ 的过程，并记录每一步的相对误差用于可视化。

```python
import math
import matplotlib.pyplot as plt

def newton_sqrt(S, x0=1.0, max_iter=10):
    x = x0
    errors = []
    true_val = math.sqrt(S)
    
    print(f"{'Iter':<5} | {'Approx':<15} | {'Rel Error':<15}")
    for i in range(max_iter):
        rel_err = abs(x - true_val) / true_val
        errors.append(rel_err)
        print(f"{i:<5} | {x:<15.10f} | {rel_err:<15.10e}")
        x = 0.5 * (x + S / x)
    
    return errors

# 执行计算
errs = newton_sqrt(2.0)

# 可视化误差收敛
plt.semilogy(range(len(errs)), errs, marker='o')
plt.title("Convergence of Relative Error in Newton's Method")
plt.xlabel("Iteration Count")
plt.ylabel("Relative Error (Log Scale)")
plt.grid(True)
plt.show()
```

### 五、复杂度与权衡
- **时间复杂度**：牛顿法具有二次收敛性，误差平方级减少，通常只需极少迭代即可达到高精度。
- **权衡**：增加迭代次数可减少截断误差，但无法消除舍入误差。当近似值接近机器精度极限时，继续迭代可能导致误差震荡甚至增大。因此，需设定合理的终止阈值，避免无效计算。

### 六、常见误区
1. **误区一**：“迭代次数越多越好”。事实：受限于浮点数精度，超过一定次数后精度不再提升，反而浪费算力。
2. **误区二**：“绝对误差小就是精度高”。事实：若真实值为 $10^{-9}$，绝对误差 $10^{-10}$ 看似很小，但相对误差高达 10%，精度极差。
3. **误区三**：“可视化只是为了好看”。事实：对数坐标下的误差图能直观揭示收敛速率（线性或二次），是调试算法的关键工具。

### 七、自测题与答案
**Q1**: 若真实值为 100，近似值为 101，绝对误差与相对误差分别是多少？
**A1**: 绝对误差 $|100-101|=1$；相对误差 $1/100 = 0.01$ (即 1%)。

**Q2**: 在牛顿法迭代中，若发现误差曲线在某点后不再下降反而波动，最可能的原因是什么？
**A2**: 已达到计算机浮点数表示的精度极限（舍入误差主导），继续迭代无法获得更精确的真实值表示。
