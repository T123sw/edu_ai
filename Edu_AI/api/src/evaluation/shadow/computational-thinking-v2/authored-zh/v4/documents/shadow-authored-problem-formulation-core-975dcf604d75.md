## 学习目标
本讲义旨在帮助学生掌握将模糊的自然语言问题转化为计算机可处理的精确形式化描述的能力。学习完成后，学生应能够：
1. 准确识别问题中的输入变量、输出结果及约束条件。
2. 理解问题形式化的必要性，区分“问题定义”与“算法实现”。
3. 能够编写符合形式化规范的输入输出说明，并识别常见的定义错误。

## 核心概念与边界
**问题形式化**是指将现实世界中的需求转化为数学或逻辑语言的过程。计算机无法直接理解“大概”、“尽量”等模糊词汇，必须依赖精确的定义。
- **输入（Input）**：指问题解决前已知的数据集合。输入必须明确数据类型（如整数、字符串）、数据范围及来源。
- **输出（Output）**：指问题解决后期望得到的结果。输出必须具有确定性，对于相同的输入，形式化定义下的输出必须唯一。
- **约束（Constraints）**：指输入数据必须满足的前提条件，或问题解决过程中资源（时间、空间）的限制。约束分为“硬约束”（必须满足，否则问题无解）和“软约束”（优化目标）。

**边界界定**：问题形式化不同于算法设计。形式化关注“做什么”（What），算法关注“怎么做”（How）。例如，定义“求最大值”是形式化，而使用“遍历比较”是算法。若在定义阶段混淆二者，会导致解决方案缺乏通用性。

## 机制与步骤
将一个问题形式化通常遵循以下四个步骤：
1. **实体识别**：从描述中提取关键对象。例如在“计算运费”问题中，实体包括“重量”、“距离”、“费率”。
2. **变量定义**：为实体分配符号。设重量为 $w$，距离为 $d$，运费为 $c$。
3. **关系建模**：确定输入与输出之间的逻辑关系。例如 $c = f(w, d)$。
4. **约束声明**：明确变量的合法范围。例如 $w > 0$, $d \ge 0$。

## 完整示例：三角形面积计算
**问题描述**：给定三条线段长度，判断能否构成三角形，若能则计算面积。
**形式化定义**：
- **输入**：三个实数 $a, b, c$。
- **约束**：$a, b, c > 0$ 且满足三角不等式 ($a+b>c, a+c>b, b+c>a$)。
- **输出**：若满足约束，输出面积 $S$；否则输出错误标识（如 -1）。
- **逻辑**：使用海伦公式 $S = \sqrt{p(p-a)(p-b)(p-c)}$，其中 $p = \frac{a+b+c}{2}$。

**参考代码（Python）**：
```python
import math

def calculate_triangle_area(a, b, c):
    # 约束检查
    if a <= 0 or b <= 0 or c <= 0:
        return -1
    if (a + b <= c) or (a + c <= b) or (b + c <= a):
        return -1
    
    # 计算逻辑
    p = (a + b + c) / 2
    area = math.sqrt(p * (p - a) * (p - b) * (p - c))
    return area
```

## 复杂度与权衡
在形式化阶段，需考虑数据的精度与计算成本之间的权衡。例如，若输入为浮点数，判断相等性（$a == b$）可能因精度误差失效，形式化时应定义为 $|a - b| < \epsilon$。此外，约束条件越严格，程序的鲁棒性越强，但可能排除部分边缘合法用例，需在定义阶段明确“非法输入”的处理策略（是报错还是返回默认值）。

## 常见误区
1. **混淆打印与返回**：初学者常将 `print` 输出视为结果。形式化中，输出应是函数返回值，而非屏幕显示。
2. **忽略隐性约束**：如未定义除数不能为零，导致运行时错误。
3. **输入类型不明**：未说明输入是整数还是浮点数，导致除法运算出现预期外行为。

## 自测题与答案
1. **问**：在“判断闰年”问题中，输入是什么？约束是什么？
   **答**：输入是年份 $Y$（整数）；约束是 $Y > 0$（公元后）。
2. **问**：若函数定义为 $f(x) = 1/x$，形式化时必须补充什么约束？
   **答**：必须补充 $x \neq 0$。
3. **问**：输出可以是“随机数”吗？
   **答**：可以，但必须在形式化定义中明确声明“输出为符合特定分布的随机变量”，否则视为确定性错误。
