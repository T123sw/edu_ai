## 核心概念与边界
**算法公平（Fairness）** 指算法决策在不同群体或个人间不产生系统性歧视。主要分为群体公平（如人口统计 parity）与个体公平（相似个体得到相似对待）。边界在于：公平的定义依赖于具体场景，不存在 universally 适用的单一数学定义。
**算法透明（Transparency）** 指利益相关者能够理解算法的运作机制及决策依据。包括代码开源、模型可解释性（Interpretability）及决策理由的可访问性。边界在于：商业机密与完全透明之间存在冲突，且复杂模型（如深度学习）本质上存在“黑盒”特性。
**算法问责（Accountability）** 指当算法造成损害时，明确责任主体（开发者、部署者或用户）并进行补救的机制。边界在于：自动化决策链条中，责任分散可能导致“责任真空”。

## 机制与实施步骤
实现伦理算法通常遵循以下流程：
1. **数据审计**：检查训练数据是否存在历史偏见或代表性不足。
2. **约束优化**：在模型训练目标中加入公平性约束。
3. **后处理调整**：调整决策阈值以平衡不同群体的通过率。
4. **影响评估**：部署前进行差异化影响分析（Disparate Impact Analysis）。

## 完整示例与代码
以信贷审批为例，假设 $A$ 为敏感属性（如性别，0 或 1），$\hat{Y}$ 为预测结果（批准为 1，拒绝为 0）。
** demographic parity（人口统计 parity）** 要求批准率与敏感属性独立：
$$ P(\hat{Y}=1 | A=0) = P(\hat{Y}=1 | A=1) $$
差异度指标 $\Delta_{DP}$ 定义为：
$$ \Delta_{DP} = |P(\hat{Y}=1 | A=0) - P(\hat{Y}=1 | A=1)| $$
若 $\Delta_{DP} > 0.1$，通常认为存在显著偏见。

以下 Python 代码演示如何计算该指标：
```python
def calculate_demographic_parity(predictions, sensitive_attribute):
    """
    predictions: list of 0/1
    sensitive_attribute: list of 0/1
    """
    group_0 = [p for p, a in zip(predictions, sensitive_attribute) if a == 0]
    group_1 = [p for p, a in zip(predictions, sensitive_attribute) if a == 1]
    
    rate_0 = sum(group_0) / len(group_0) if group_0 else 0
    rate_1 = sum(group_1) / len(group_1) if group_1 else 0
    
    disparity = abs(rate_0 - rate_1)
    return disparity, rate_0, rate_1

# 模拟数据
preds = [1, 1, 0, 1, 0, 0, 1, 1]
sens =  [0, 0, 0, 0, 1, 1, 1, 1]
dp, r0, r1 = calculate_demographic_parity(preds, sens)
print(f"差异度：{dp:.2f}, 组 0 通过率：{r0:.2f}, 组 1 通过率：{r1:.2f}")
```

## 权衡与复杂度
公平性与准确性往往存在权衡（Trade-off）。强制满足公平性约束通常会降低模型在整体数据集上的准确率。这是因为历史数据中的标签本身可能包含偏见，修正偏见意味着违背部分历史“规律”。此外，增加公平性约束会增加优化问题的复杂度，可能导致训练时间增加或收敛困难。在实际工程中，需根据法律风险与社会影响确定可接受的公平性阈值。

## 常见误区
1. **误区一：去除敏感属性即可实现公平。**
   事实：其他特征（如邮编、消费习惯）可能与敏感属性高度相关（代理变量），去除显性属性无法消除隐性偏见。
2. **误区二：公平性是纯技术问题。**
   事实：公平性涉及社会学与法律定义，技术人员无法单独决定何种公平定义适用于特定场景。
3. **误区三：算法比人更客观。**
   事实：算法是历史数据的镜像，若数据包含人类偏见，算法会放大而非消除偏见。

## 自测题与答案
1. **问**：$\Delta_{DP} = 0$ 是否意味着算法完全公平？
   **答**：否。这只满足群体统计 parity，可能忽略了个体差异或真实资格率（Base Rate）的不同，需结合 Equalized Odds 等指标综合判断。
2. **问**：为何去除“性别”字段不能保证公平？
   **答**：因为存在代理变量（如“是否休过产假”、“居住区域”），模型仍可通过这些特征间接推断性别并产生歧视。
3. **问**：问责制的核心难点是什么？
   **答**：责任分散。当决策由数据提供者、算法开发者、部署平台共同完成时，难以定位单一责任主体。
