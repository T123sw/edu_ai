## 学习目标
1. 能够将现实世界的不确定性问题抽象为概率模型。
2. 掌握使用编程工具进行多变量蒙特卡洛模拟的流程。
3. 学会通过直方图和累积分布函数分析模拟结果的风险。

## 真实问题情境
在软件项目管理中，任务工期往往不是固定的。例如，开发一个模块可能需要 3 到 7 天，具体取决于技术难点。项目经理需要回答：“项目在 30 天内完工的概率是多少？”传统的关键路径法只能给出一个确定日期，而蒙特卡洛模拟可以给出完工概率分布，辅助决策者评估风险。

## 输入输出与材料
*   **输入材料**：任务列表，每个任务包含三个估计值：乐观时间（$a$）、最可能时间（$m$）、悲观时间（$b$）。假设任务间串行依赖。
*   **输出材料**：总工期的频率直方图、完工累积概率表。
*   **工具要求**：Python 环境，安装 `numpy` 和 `matplotlib` 库。

## 分步任务
1.  **模型抽象**：将每个任务的工期视为服从**三角分布**的随机变量。三角分布的概率密度函数在 $m$ 处最高，在 $a$ 和 $b$ 处为零。
2.  **数据准备**：定义一个包含 5 个串行任务的列表，每个任务设定不同的 $(a, m, b)$ 参数。
3.  **模拟循环**：编写程序循环 10000 次。在每次循环中，为每个任务生成一个随机工期，求和得到本次模拟的总工期。
4.  **可视化分析**：绘制总工期的直方图，并计算在特定天数（如 25 天、30 天）内完工的累积概率。
5.  **报告撰写**：根据模拟数据，给出建议的项目缓冲期。

## 参考实现与推导
三角分布采样可通过 numpy 实现。总工期 $T = \sum_{i=1}^{k} t_i$，其中 $t_i$ 是第 $i$ 个任务的随机工期。

```python
import numpy as np
import matplotlib.pyplot as plt

# 设置随机种子以保证结果可复现
np.random.seed(42)

# 定义 5 个任务的 (乐观，最可能，悲观) 工期
tasks = [
    (2, 3, 5),
    (3, 5, 8),
    (1, 2, 4),
    (4, 6, 10),
    (2, 3, 6)
]

num_simulations = 10000
total_durations = []

for _ in range(num_simulations):
    project_duration = 0
    for a, m, b in tasks:
        # 生成服从三角分布的随机工期
        duration = np.random.triangular(a, m, b)
        project_duration += duration
    total_durations.append(project_duration)

# 绘制直方图
plt.hist(total_durations, bins=50, density=True, alpha=0.7, color='skyblue')
plt.title('Project Duration Distribution (Monte Carlo)')
plt.xlabel('Days')
plt.ylabel('Probability Density')
plt.grid(axis='y', alpha=0.3)
plt.show()

# 计算 30 天内完工的概率
prob_30 = sum(1 for d in total_durations if d <= 30) / num_simulations
print(f"30 天内完工的概率：{prob_30:.2%}")
```

## 测试与边界情况
1.  **种子控制**：运行前必须设置 `np.random.seed()`，否则每次输出的概率值会有微小波动，导致无法验证代码正确性。
2.  **边界值测试**：检查输入参数是否满足 $a \le m \le b$。若 $a=b=m$，则退化为确定性任务，程序不应报错。
3.  **极端情况**：若模拟次数设为 0 或负数，程序应有保护机制或明确报错，避免除零错误。
4.  **数据合理性**：检查生成的随机工期是否始终落在 $[a, b]$ 区间内，可通过 `min(total_durations)` 和 `max` 验证。
