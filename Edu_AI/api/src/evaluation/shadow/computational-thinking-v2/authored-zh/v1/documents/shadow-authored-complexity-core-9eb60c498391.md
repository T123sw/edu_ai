## 学习目标
本讲义旨在帮助学生建立算法效率评估的量化标准。学习完成后，学生应能够：
1. 准确陈述时间复杂度与空间复杂度的定义。
2. 使用大 O 记号（Big O Notation）推导简单代码段的渐近复杂度。
3. 识别常见误区，理解复杂度分析在实际工程中的边界与权衡。

## 核心概念与边界
**时间复杂度**并非指程序运行的绝对秒数，而是描述算法执行步骤数量随输入规模 $n$ 增长的变化趋势。记作 $T(n)$。
**空间复杂度**指算法在运行过程中临时占用存储空间大小随输入规模 $n$ 的增长趋势，记作 $S(n)$。
**渐近分析**关注的是当 $n$ 趋向于无穷大时的主导项。大 O 记号 $O(g(n))$ 的数学定义为：若存在正常数 $c$ 和 $n_0$，使得对所有 $n \ge n_0$，都有 $0 \le T(n) \le c \cdot g(n)$，则称 $T(n)$ 的渐近上界为 $O(g(n))$。

边界说明：大 O 通常描述最坏情况（Worst Case），因为它提供了性能保证。但在某些场景（如快速排序），平均情况（Average Case）更具参考价值。复杂度分析忽略低阶项和常数系数，因为它们在 $n$ 极大时对增长趋势影响微弱，但在小规模数据下，常数项可能决定实际快慢。

## 分析机制与步骤
进行复杂度分析通常遵循以下三步法：
1. **识别基本操作**：确定算法中执行频率最高的语句，通常是循环体内的赋值、比较或算术运算。
2. **统计频度**：计算基本操作执行次数与输入规模 $n$ 的函数关系。
3. **化简阶数**：保留最高阶项，忽略常数系数，得到大 O 表示。

对于递归算法，需建立递推公式（如 $T(n) = 2T(n/2) + n$）并使用主定理求解。对于迭代算法，重点分析循环嵌套层数及循环变量的变化步长。

## 完整示例：嵌套循环分析
考虑以下 Python 代码段，计算其时间复杂度：
```python
def example_analysis(n):
    count = 0
    for i in range(n):          # 外层循环执行 n 次
        for j in range(i):      # 内层循环执行 i 次
            count += 1          # 基本操作
    return count
```
**推导过程**：
外层循环变量 $i$ 从 $0$ 遍历至 $n-1$。当 $i=0$ 时，内层循环执行 0 次；当 $i=1$ 时，执行 1 次；...；当 $i=n-1$ 时，执行 $n-1$ 次。
总操作次数为等差数列求和：$0 + 1 + 2 + ... + (n-1) = \frac{(n-1)n}{2} = \frac{1}{2}n^2 - \frac{1}{2}n$。
根据渐近分析规则，忽略系数 $\frac{1}{2}$ 和低阶项 $-\frac{1}{2}n$，最高阶项为 $n^2$。
**结论**：该算法的时间复杂度为 $O(n^2)$。空间复杂度为 $O(1)$，因为仅使用了 `count`, `i`, `j` 等固定数量的变量，不随 $n$ 增长。

## 复杂度与权衡
在实际系统设计中，时间与空间往往存在权衡（Time-Space Trade-off）。例如，使用哈希表（Hash Map）查找元素可将时间复杂度从 $O(n)$ 降至 $O(1)$，但需要额外 $O(n)$ 的空间存储哈希表。若内存受限，可能被迫选择时间复杂度较高但空间占用小的算法。此外，缓存友好性（Cache Locality）也会影响实际运行时间，即便两个算法大 O 复杂度相同，内存访问模式更连续的算法通常更快。

## 常见误区
1. **误区一：大 O 代表精确时间**。纠正：大 O 仅代表增长趋势，$O(n)$ 算法在 $n$ 较小时可能比 $O(1)$ 算法慢，因为后者可能有巨大的常数开销。
2. **误区二：忽略输入数据的分布**。纠正：某些算法（如插入排序）在数据基本有序时为 $O(n)$，完全无序时为 $O(n^2)$，需明确分析前提。
3. **误区三：递归一定慢**。纠正：递归本身不增加复杂度，关键在于递归树的结构。尾递归优化后可达到与迭代相同的空间效率。

## 自测题与答案
**题目 1**：分析代码 `while n > 1: n = n / 2` 的时间复杂度。
**答案 1**：$O(\log n)$。每次循环 $n$ 减半，执行次数为 $\log_2 n$。

**题目 2**：若算法 A 为 $O(n)$，算法 B 为 $O(n^2)$，是否意味着 A 永远比 B 快？
**答案 2**：否。当 $n$ 很小且 A 的常数系数极大时，B 可能更快。大 O 仅描述 $n$ 足够大时的趋势。
