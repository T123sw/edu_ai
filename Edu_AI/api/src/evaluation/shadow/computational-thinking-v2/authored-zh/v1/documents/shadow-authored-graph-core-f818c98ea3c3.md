## 学习目标
1. 准确理解图（Graph）的数学定义及其组成要素（顶点、边）。
2. 掌握邻接表（Adjacency List）存储结构的原理与构建方法。
3. 能够分析邻接表在不同操作下的时间与空间复杂度，并与邻接矩阵进行权衡。
4. 识别并纠正常见的图表示误区。

## 准确概念与边界
图是一种表示对象之间 pairwise 关系的数据结构，形式化定义为 $G = (V, E)$。其中 $V$ 是顶点（Vertex）的有限集合，$E$ 是边（Edge）的集合。边是顶点的有序对（有向图）或无序对（无向图）。
**邻接表**是一种链式存储结构。对于图中的每个顶点 $v \in V$，建立一个单链表或动态数组，将所有与 $v$ 相邻接的顶点存储在表中。若图有 $n$ 个顶点，则邻接表由一个大小为 $n$ 的数组头结点和若干链表组成。
**边界界定**：本知识点聚焦于“表示”而非“遍历”。邻接表适用于稀疏图（$|E| \ll |V|^2$），而不适用于需要频繁判断任意两点间是否存在边的稠密图场景。

## 机制与步骤
构建邻接表的核心机制是将“边列表”转化为“顶点到邻居的映射”。步骤如下：
1. 初始化一个包含 $|V|$ 个空列表的数组或字典。
2. 遍历每一条边 $(u, v)$。
3. 若为有向图，将 $v$ 加入 $u$ 的邻接表；若为无向图，需同时将 $v$ 加入 $u$ 的表，并将 $u$ 加入 $v$ 的表。
4. 处理权重（若有）：邻接表元素可存储元组 $(neighbor, weight)$。

## 完整例子
假设有一个无向图，顶点集 $V=\{0, 1, 2, 3\}$，边集 $E=\{(0,1), (0,2), (1,3), (2,3)\}$。
其邻接表表示如下（使用 Python 字典模拟）：
- 顶点 0: `[1, 2]`
- 顶点 1: `[0, 3]`
- 顶点 2: `[0, 3]`
- 顶点 3: `[1, 2]`
注意无向图中每条边在存储结构中出现了两次，分别属于两个端点。

## 代码实现
以下代码演示了如何从边列表构建邻接表，并支持有向/无向切换：

```python
def build_adjacency_list(edges, num_vertices, directed=False):
    """
    构建邻接表
    :param edges: 列表，元素为 (u, v) 或 (u, v, w)
    :param num_vertices: 顶点总数
    :param directed: 是否为有向图
    :return: 邻接表 (dict of lists)
    """
    adj = {i: [] for i in range(num_vertices)}
    for edge in edges:
        u, v = edge[0], edge[1]
        # 假设无边权，若有边权可存储为 (v, w)
        adj[u].append(v)
        if not directed:
            adj[v].append(u)
    return adj

# 测试数据
edges = [(0, 1), (0, 2), (1, 3), (2, 3)]
graph = build_adjacency_list(edges, 4, directed=False)
print(graph) 
# 输出：{0: [1, 2], 1: [0, 3], 2: [0, 3], 3: [1, 2]}
```

## 复杂度与权衡
- **空间复杂度**：邻接表存储所有顶点和所有边。对于无向图，边存储两次。总空间为 $O(|V| + |E|)$。相比之下，邻接矩阵固定为 $O(|V|^2)$。当图稀疏时，邻接表显著节省内存。
- **时间复杂度**：
    - 访问某顶点的所有邻居：$O(deg(v))$，其中 $deg(v)$ 为该顶点的度。
    - 判断两点 $u, v$ 间是否有边：需遍历 $u$ 的邻接表，最坏 $O(|V|)$，优于矩阵的 $O(1)$ 查找仅在稠密图中成立。
- **权衡**：若应用需频繁判断任意两点连通性，邻接矩阵更优；若需频繁遍历邻居或图规模大且稀疏，邻接表更优。

## 常见误区
1. **无向图单边存储**：错误地只在 $u$ 的表中存 $v$，导致从 $v$ 出发无法找到 $u$，破坏了无向图的对称性。
2. **顶点索引混淆**：顶点标识符（如姓名、ID）与数组下标（0 到 $n-1$）未建立映射，导致访问越界。
3. **自环处理**：若存在边 $(u, u)$，邻接表中 $u$ 的列表会包含自身，需根据业务逻辑决定是否允许。

## 自测题与答案
1. **问**：对于一个有 1000 个顶点、1000 条边的无向图，邻接表大约需要存储多少个整数项？
   **答**：约 2000 个项（每条边存两次）+ 1000 个头结点指针。
2. **问**：若要删除边 $(u, v)$，邻接表操作复杂度是多少？
   **答**：$O(deg(u))$，因为需要在 $u$ 的链表中查找并移除 $v$。
3. **问**：邻接表能否表示多重图（两点间多条边）？
   **答**：能，只需在邻接表中多次添加该邻居即可。
