## 准确概念与边界
**树（Tree）** 是由 $n$ ($n \ge 0$) 个结点构成的有限集合。当 $n=0$ 时称为空树。非空树具有以下特征：有且仅有一个特定的称为根（Root）的结点；其余结点可分为 $m$ ($m \ge 0$) 个互不相交的有限集合，每个集合本身又是一棵树。树强调的是层次关系，结点之间是一对多的关系。

**二叉树（Binary Tree）** 是树的一种特殊形式，其核心边界在于：每个结点最多有两个子树，且子树有左右之分，次序不能颠倒。即使某结点只有一个子结点，也必须明确是左子树还是右子树。这与普通树（子树无序）有本质区别。

**二叉搜索树（BST）** 是二叉树的应用形态，满足：若左子树不空，则左子树上所有结点的值均小于根结点的值；若右子树不空，则右子树上所有结点的值均大于根结点的值。

## 遍历机制与步骤
遍历是树结构的核心操作，指沿某条搜索路径寻访树中每个结点，使得每个结点均被访问一次且仅一次。根据访问根结点的顺序，深度优先遍历（DFS）分为三种：
1.  **前序遍历（Pre-order）**：访问根结点 -> 遍历左子树 -> 遍历右子树。
2.  **中序遍历（In-order）**：遍历左子树 -> 访问根结点 -> 遍历右子树。
3.  **后序遍历（Post-order）**：遍历左子树 -> 遍历右子树 -> 访问根结点。
4.  **层序遍历（Level-order）**：从上到下、从左到右逐层访问，通常借助队列实现。

递归是实现 DFS 遍历的自然机制。系统维护一个调用栈，每次递归调用将当前结点状态压栈，遇到空结点（基准情况）时返回，弹出栈帧恢复上一层状态。

## 完整例子
考虑如下二叉树结构：
```text
      A
     / \
    B   C
   /   / \
  D   E   F
```
- **前序遍历**：访问 A -> 左子树 B(D) -> 右子树 C(E,F)。序列：$A \rightarrow B \rightarrow D \rightarrow C \rightarrow E \rightarrow F$。
- **中序遍历**：左子树 D(B) -> 访问 A -> 右子树 E(C)F。序列：$D \rightarrow B \rightarrow A \rightarrow E \rightarrow C \rightarrow F$。
- **后序遍历**：左子树 D(B) -> 右子树 E(F)C -> 访问 A。序列：$D \rightarrow B \rightarrow E \rightarrow F \rightarrow C \rightarrow A$。
- **层序遍历**：第一层 A -> 第二层 B,C -> 第三层 D,E,F。序列：$A \rightarrow B \rightarrow C \rightarrow D \rightarrow E \rightarrow F$。

## 代码实现（Python）
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def inorder_traversal(root):
    if not root:
        return []
    # 递归公式：Inorder(T) = Inorder(T.left) + [root.val] + Inorder(T.right)
    return inorder_traversal(root.left) + [root.val] + inorder_traversal(root.right)

# 构建示例树
#       1
#      / \
#     2   3
#    /
#   4
root = TreeNode(1, TreeNode(2, TreeNode(4)), TreeNode(3))
print(inorder_traversal(root))  # 输出：[4, 2, 1, 3]
```

## 复杂度与权衡
对于包含 $n$ 个结点的二叉树：
- **时间复杂度**：无论何种遍历，每个结点访问一次，故时间复杂度均为 $O(n)$。
- **空间复杂度**：取决于递归调用栈的深度，即树的高度 $h$。
    - 最好情况（完全二叉树）：$h = \lfloor \log_2 n \rfloor + 1$，空间复杂度 $O(\log n)$。
    - 最坏情况（斜树）：$h = n$，空间复杂度 $O(n)$。
权衡在于递归代码简洁但依赖系统栈，迭代写法（使用显式栈或队列）可避免栈溢出但代码较复杂。

## 常见误区
1.  **混淆二叉树与度为 2 的树**：度为 2 的树要求至少有一个结点度为 2，且子树无序；二叉树允许度为 0 或 1，且子树有序。
2.  **认为中序遍历一定有序**：仅当二叉树是二叉搜索树（BST）时，中序遍历结果才单调递增。普通二叉树的中序遍历无顺序特征。
3.  **忽略空树处理**：递归基准情况必须明确处理 `root is None`，否则会导致运行时错误。

## 自测题与答案
1.  **问**：一棵有 10 个结点的二叉树，其最小高度是多少？
    **答**：$\lfloor \log_2 10 \rfloor + 1 = 4$。
2.  **问**：若某二叉树的前序遍历序列与中序遍历序列相同，该树具有什么结构特征？
    **答**：该树所有结点均无左子树（即右斜树）。
3.  **问**：在后序遍历中，根结点何时被访问？
    **答**：在其左子树和右子树均被遍历完成后最后访问。
