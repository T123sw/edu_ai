## 真实问题情境
某大学校园需要部署无人配送车。校园地图可简化为若干个“路口”和连接路口的“道路”。系统需要快速回答：“从当前路口 A 出发，可以直接到达哪些路口？”以及“哪个路口的连接道路最多（枢纽）？”。这是一个典型的图存储与基础查询问题。我们将路口抽象为顶点，道路抽象为边。

## 输入输出与材料
- **输入材料**：一份 CSV 格式的道路数据，每行表示一条双向道路，包含两个路口 ID。例如：`"A,B"`, `"B,C"`, `"A,C"`。
- **输出要求**：
    1. 构建好的邻接表结构。
    2. 指定路口的直接邻居列表。
    3. 度数最大的路口 ID 及其度数。
- **工具**：Python 3.x 环境。

## 分步任务
1. **数据建模**：确定顶点集合（路口 ID）和边集合（道路）。确认图为无向图。
2. **结构构建**：编写函数读取数据并生成邻接表。需处理顶点 ID 为非整数（如字符串）的情况。
3. **功能实现**：
    - 实现 `get_neighbors(graph, node)` 返回邻居列表。
    - 实现 `find_hub(graph)` 返回度数最大的节点。
4. **异常处理**：考虑输入数据中包含未定义的节点或重复边的情况。

## 参考实现与推导
以下代码展示了从字符串 ID 构建邻接表并查询枢纽的过程。推导逻辑是：利用字典的动态键特性处理非整数 ID，利用列表长度计算度数。

```python
def build_campus_graph(road_data):
    """
    :param road_data: 列表，元素为元组 ('A', 'B')
    :return: 邻接表 dict
    """
    graph = {}
    for u, v in road_data:
        if u not in graph: graph[u] = []
        if v not in graph: graph[v] = []
        # 避免重复添加同一条边（简单去重）
        if v not in graph[u]:
            graph[u].append(v)
            graph[v].append(u)
    return graph

def find_hub(graph):
    if not graph: return None, 0
    # 推导：度数即邻接表列表的长度
    hub = max(graph, key=lambda node: len(graph[node]))
    return hub, len(graph[hub])

# 模拟数据
roads = [('Gate', 'Lib'), ('Lib', 'Lab'), ('Gate', 'Lab'), ('Lab', 'Dorm')]
campus_graph = build_campus_graph(roads)
hub_node, hub_degree = find_hub(campus_graph)
print(f"枢纽路口：{hub_node}, 连接数：{hub_degree}")
```

## 测试与边界情况
为确保系统可靠，需设计以下测试用例覆盖边界：
| 测试场景 | 输入数据特征 | 预期行为 |
| :--- | :--- | :--- |
| 正常情况 | 连通图，多个节点 | 正确返回邻居和枢纽 |
| 孤立节点 | 存在节点无边连接 | 该节点邻接表为空，不被选为枢纽 |
| 重复边 | 输入包含 `('A','B'), ('A','B')` | 邻接表中 'B' 只出现一次（需去重逻辑） |
| 单节点图 | 仅一个节点，无边 | 返回该节点，度数为 0 |
| 不连通图 | 两组完全分离的节点 | 分别计算各部分，全局找最大度 |

特别注意：若输入数据中存在孤立的顶点（即在边列表中从未出现但属于地图范围），需要在初始化时显式声明顶点集，否则邻接表会丢失这些孤立点。本实现采用动态添加，仅包含有边的顶点。
