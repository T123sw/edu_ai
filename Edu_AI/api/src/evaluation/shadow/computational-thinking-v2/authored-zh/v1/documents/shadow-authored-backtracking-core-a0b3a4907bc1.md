## 概念与边界
回溯搜索（Backtracking Search）是一种通过尝试分步选择来解决问题的算法。它本质上是对状态空间树进行深度优先遍历。当发现当前部分解不满足约束条件时，算法放弃该步选择（即“回溯”），返回上一步尝试其他可能。

**核心边界界定：**
*   **与穷举的区别：** 回溯不是盲目的穷举。它利用约束条件在搜索过程中提前终止无效分支，这被称为“剪枝”。
*   **与动态规划的区别：** 回溯适用于求解所有解或特定可行解，且子问题重叠性不明显；动态规划适用于具有最优子结构且子问题重叠的问题。
*   **与贪心的区别：** 贪心算法只做当前最优选择且不回退；回溯允许“后悔”，即撤销选择并尝试其他路径。

## 核心机制
回溯算法的通用框架遵循“选择 - 探索 - 撤销”的三步循环。其逻辑结构可表示为：

1.  **终止条件**：判断当前路径是否达到目标深度或满足求解条件。
2.  **遍历选择列表**：对于当前状态，列出所有可能的选择。
3.  **约束检查（剪枝）**：若选择违反约束，则跳过（剪枝）。
4.  **做选择**：将选择加入路径，更新状态。
5.  **递归探索**：进入下一层决策。
6.  **撤销选择**：恢复状态，以便尝试下一个选择。

伪代码结构如下：
```python
def backtrack(路径，选择列表):
    if 满足终止条件:
        记录结果
        return
    for 选择 in 选择列表:
        if 不满足约束条件:  # 剪枝核心
            continue
        做选择
        backtrack(路径，选择列表)
        撤销选择
```

## 完整示例：组合总和问题
**问题描述**：给定一个无重复元素的正整数数组 `candidates` 和一个目标整数 `target`，找出所有可以使数字和为 `target` 的组合。每个数字可以无限次选取。

**状态空间分析**：决策树的每一层代表选择一个数字。分支代表可选的数字。若当前路径和超过 `target`，则该分支无需继续搜索。

**Python 实现**：
```python
def combination_sum(candidates, target):
    res = []
    path = []
    
    def dfs(start_index, current_sum):
        # 终止条件：和等于目标
        if current_sum == target:
            res.append(path[:])
            return
        # 剪枝：和超过目标，无需继续
        if current_sum > target:
            return
        
        for i in range(start_index, len(candidates)):
            num = candidates[i]
            # 做选择
            path.append(num)
            # 递归探索，注意 i 不变，因为可重复选取
            dfs(i, current_sum + num)
            # 撤销选择
            path.pop()
            
    dfs(0, 0)
    return res

# 测试
print(combination_sum([2, 3, 6, 7], 7)) 
# 输出：[[2, 2, 3], [7]]
```
在此代码中，`if current_sum > target: return` 即为典型的可行性剪枝。若没有此行，算法将继续递归直到栈溢出或遍历完所有无效组合。

## 复杂度与权衡
回溯算法的最坏时间复杂度通常是指数级的，记为 $O(b^d)$，其中 $b$ 是平均分支因子，$d$ 是树的最大深度。这是因为在最坏情况下，算法仍需遍历大部分状态空间。

**剪枝的权衡**：
*   **收益**：显著减少访问的节点数，降低平均运行时间。
*   **成本**：每次递归都需要额外的计算来检查约束条件。若约束检查过于复杂（例如 $O(n)$ 甚至更高），可能会抵消剪枝带来的收益。
*   **策略**：优先选择约束性强、分支少的变量进行探索（启发式搜索），可进一步优化效率。

## 常见误区
1.  **忘记撤销选择**：这是初学者最容易犯的错误。若在递归返回后不恢复状态（如 `path.pop()` 或恢复 visited 数组），会导致后续分支受到污染，产生错误结果。
2.  **剪枝条件错误**：过早剪枝可能漏掉合法解。例如在组合问题中，若数组未排序，不能简单地因为当前数过大就 break 循环，除非确信后续数更大。
3.  **混淆全局变量**：在递归中使用全局变量记录结果时，需注意引用传递问题。应将路径的副本（如 `path[:]`）存入结果集，否则结果集中的所有路径会随 `path` 变化而变化。

## 自测题与答案
1.  **问**：在 N 皇后问题中，若当前行放置皇后后，下一行所有位置均受攻击，算法应执行什么操作？
    **答**：执行回溯操作，返回上一行，移动上一行皇后的位置。
2.  **问**：若将示例代码中的 `dfs(i, ...)` 改为 `dfs(i + 1, ...)`，结果会有什么变化？
    **答**：每个数字最多只能被选取一次，因为索引强制向后移动，无法重复利用当前数字。
3.  **问**：剪枝是否影响算法找到解的正确性？
    **答**：不影响。剪枝仅去除不可能产生解的分支，合法解所在的分支不会被裁剪。
