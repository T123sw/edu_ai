关于与「**模式识别**」標題相近或相同的条目，請見「**[模式识别 (心理学)](/wiki/%E6%A8%A1%E5%BC%8F%E8%AF%86%E5%88%AB_(%E5%BF%83%E7%90%86%E5%AD%A6) "模式识别 (心理学)")**」。

**模式识别**（英語：Pattern recognition），就是通过[计算机](/wiki/%E7%94%B5%E5%AD%90%E8%AE%A1%E7%AE%97%E6%9C%BA "电子计算机")用[数学](/wiki/%E6%95%B0%E5%AD%A6 "数学")技术方法来研究模式的自动处理和判读。我们把[环境](/wiki/%E8%BF%90%E8%A1%8C%E7%8E%AF%E5%A2%83 "运行环境")与[客体](/wiki/%E5%AE%A2%E4%BD%93 "客体")统称为“模式”。随着计算机技术的发展，人类有可能研究复杂的信息处理过程。信息处理过程的一个重要形式是生命体对环境及客体的识别。对人类来说，特别重要的是对[光学](/wiki/%E5%85%89%E5%AD%A6 "光学")信息（通过[视觉](/wiki/%E8%A7%86%E8%A7%89 "视觉")器官来获得）和[声学](/wiki/%E5%A3%B0%E5%AD%A6 "声学")信息（通过听觉器官来获得）的识别。这是模式识别的两个重要方面。市场上可见到的代表性产品有[光学字符识别](/wiki/%E5%85%89%E5%AD%A6%E5%AD%97%E7%AC%A6%E8%AF%86%E5%88%AB "光学字符识别")、[语音识别](/wiki/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB "语音识别")系统。

计算机识别的显著特点是速度快、准确性高、效率高，在将来完全可以取代人工录入。

识别过程与人类的学习过程相似。以[光學字元識別](/wiki/%E5%85%89%E5%AD%B8%E5%AD%97%E5%85%83%E8%AD%98%E5%88%A5 "光學字元識別")之“[汉字识别](/w/index.php?title=%E6%B1%89%E5%AD%97%E8%AF%86%E5%88%AB&action=edit&redlink=1 "汉字识别（页面不存在）")”为例：首先将汉字图像进行处理，抽取主要表达特征并将特征与汉字的代码存在计算机中。就像老师教我们「这个字叫什么、如何写」记在[大脑](/wiki/%E5%A4%A7%E8%84%91 "大脑")中。这一过程叫做“[训练](/wiki/%E8%AE%AD%E7%BB%83 "训练")”。识别过程就是将输入的汉字图像经处理后与计算机中的所有字进行比较，找出最相近的字就是识别结果。这一过程叫做“[匹配](/wiki/%E5%8C%B9%E9%85%8D "匹配")”。
