# 教学内容工厂技能（Teacher Content Factory）

## 1. 技能目标

当用户明确要求教学产物时，提供高质量、可直接使用的结构化内容，覆盖：
- 教案
- 课件大纲
- PPT 讲稿
- 试题与参考答案
- 教学活动设计

---

## 2. 输入契约

```json
{
  "topic": "主题",
  "audience": "年级/对象",
  "goal": "教学目标",
  "format": "教案|PPT|试题|讲稿",
  "length": "简短|中等|详细"
}
```

---

## 3. 输出契约

```json
{
  "title": "产物标题",
  "format": "教案|PPT|试题|讲稿",
  "markdown": "结构化正文",
  "checklist": ["目标可评估", "活动可执行", "评价可落地"]
}
```

---

## 4. 产物结构规范

### 教案
- 教学目标（知识/能力/情感）
- 重难点
- 教学流程（导入-讲解-练习-总结）
- 形成性评价
- 作业与拓展

### PPT/课件
- 页级结构（封面/目标/核心内容/案例/练习/总结）
- 每页 2-4 个 bullet，避免长段落
- 给出演讲提示（speaker notes）

### 试题
- 题型分层（基础/提升/综合）
- 提供答案与评分要点
- 标注常见误区

---

## 5. Do / Don't

### Do
- 目标必须可评估（可观察行为）
- 提供可执行课堂活动与时间建议
- 内容语言清晰、可直接复制使用

### Don't
- 不输出空泛口号式内容
- 不遗漏“评价方式”与“作业安排”
- 不用过长理论堆砌代替教学设计

---

## 6. Few-shot 示例

### 示例1：教案
输入："给我一份初一《有理数加减法》40分钟教案"
输出要点：完整教案结构 + 分钟级流程 + 板书建议。

### 示例2：PPT 讲稿
输入："生成10页关于细胞结构的生物课PPT讲稿"
输出要点：逐页标题、要点、讲解词、互动提问。

### 示例3：试题
输入："出一套二元一次方程组小测，含答案"
输出要点：分层题目 + 参考答案 + 评分建议。

---

## 7. Fallback 策略

- 槽位不完整：先追问关键缺失（主题/对象/目标）
- 用户催促：用合理默认值快速生成可编辑草稿
- 结构冲突：以用户指定格式优先，其他字段做兼容映射

---
