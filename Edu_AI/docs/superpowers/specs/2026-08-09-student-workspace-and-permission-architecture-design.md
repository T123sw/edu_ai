## 1. 设计结论

学生端采用“同一应用、独立学生展示层、共享业务内核”的架构：

```text
统一登录与身份解析
├─ 教师工作区 Teacher Workspace
└─ 学生工作区 Student Workspace
       ↓
共享课程、课程成员、知识库、RAG、资源、任务、播放器和权限服务
```

本设计不复用历史 `src/pages/student/` 和 `src/components/student/` 界面。学生页面可以从当前教师主线页面复制一份作为开发起点，随后独立维护展示、交互和样式；认证、课程数据、API、权限、渲染器、播放器、任务协议和存储仍只有一套。

核心原则是：

1. 教师和学生使用同一个平台，但进入不同工作区；
2. 学生页面不是教师页面隐藏几个按钮后的结果；
3. 学生可以读取所属课程的课程事实，但不能修改课程事实；
4. 所有用户上传、深度研究和生成结果默认属于个人；
5. 只有教师可以把个人内容显式发布到课程；
6. 学生个人资料、生成物和对话默认不向教师或课程管理员公开；
7. 页面权限、工具权限、数据权限和后端接口权限必须一致；
8. 第一阶段只实现已有能力的正确组合与隔离，不增加没有完整数据闭环的占位功能。

## 2. 目标与非目标

### 2.1 目标

- 建立全新的学生工作区和学生路由；
- 形成稳定、简洁的学生一级导航；
- 让学生安全读取课程知识图谱、课程知识库和课程共享资源；
- 让学生使用被授权的AI问答、深度研究和资源生成工具；
- 确保学生上传、研究和生成结果只进入个人空间；
- 让教师发布的课程快照在学生端可读、可预览、可播放；
- 从前端、后端和存储三层阻止学生修改课程或发布课程内容；
- 清理旧学生界面和旧路由，避免长期维护两套学生端。

### 2.2 第一阶段非目标

以下能力只记录为后续方向，第一阶段不实现、不展示占位入口：

- 作业发布、提交、评分和班级管理；
- 错题本；
- 掌握度诊断；
- 间隔复习；
- 自动学习计划；
- 学习时长统计；
- 教师查看学生个人学习轨迹；
- 学生向课程发布资料或资源；
- 课程资源审批流；
- 学生间共享或协作编辑。

未来增加提交功能时，必须创建独立提交副本，不得直接公开学生个人原件、完整对话或个人知识库。

## 3. 已确认的产品决策

### 3.1 用户内容默认属于个人

以下内容无论由教师还是学生创建，都默认进入个人空间：

- 用户上传的文档、图片和视频；
- 用户发起的深度研究及研究结果；
- 报告、PPT、思维导图、练习题、闪卡、课堂小游戏和AI课堂；
- 生成过程中的配置快照、引用和中间结果。

个人内容只允许所有者读取和管理。课程负责人、其他教师和管理员不能因为具有课程管理能力而读取用户个人内容。

### 3.2 课程内容只能通过教师显式发布产生

教师可以把自己的个人资料复制到课程知识库，也可以把个人生成资源发布为课程资源快照。发布后：

- 个人原件继续保留且保持私有；
- 课程中产生独立副本、稳定ID和课程访问域；
- 修改个人原件不会静默修改课程副本；
- 学生可以读取课程副本，但不能更新、撤回或再次发布；
- 学生没有任何“加入课程知识库”或“发布到课程”的入口和接口权限。

### 3.3 学生课程角色为只读成员

学生作为课程 `viewer` 可以读取课程、课程知识和课程共享资源，但不能修改课程。学生使用个人生成工具的权限来自系统角色和工具白名单，不来自课程 `generate` 能力。

这一区分非常重要：

```text
课程读取权限 = 课程成员 viewer
个人工具权限 = 系统角色 student + 工具白名单
课程修改/发布权限 = 教师身份 + owner/editor 课程能力
```

因此学生可以读取课程资料作为个人生成来源，但个人生成任务不能写入课程资源。

## 4. 学生端信息架构

### 4.1 一级导航

学生端固定为六个一级入口：

```text
学习首页
AI问答
课程知识
个人知识库
AI课堂
资源管理
```

学生端不展示：

- 课程详情或课程设置；
- 课程成员管理；
- 数据管线；
- 课程知识库构建与索引管理；
- 知识图谱编辑；
- 教师工具目录；
- 系统运行配置。

### 4.2 当前课程上下文

AI问答、课程知识、AI课堂中的课程内容和资源管理中的课程共享依赖当前课程。页面顶部提供真实课程选择器，并将 `course_id` 写入URL。

规则：

- 从学习首页点击课程卡后，将该课程设置为当前课程并进入AI问答；
- 切换课程时，只切换课程相关数据；
- 个人知识库和个人生成资源不随课程切换；
- URL中的 `course_id` 是课程上下文的权威来源；
- 最近课程只能用于便捷进入，不能覆盖显式URL；
- 没有课程或无权访问时显示选择课程或无权限状态，不回退到不明确的旧课程。

## 5. 页面设计

### 5.1 学习首页

学习首页复制当前教师课程导航页作为起点，形成独立学生页面。

保留：

- 最近学习；
- 学生已加入的课程；
- 课程搜索；
- 课程卡片；
- 真实加载、空状态和失败状态。

修改：

- 删除创建课程、编辑课程和课程管理入口；
- 课程卡主操作改为“进入学习”；
- 点击课程后进入该课程的AI问答；
- 不展示随机进度、虚假学习时长和未落地推荐；
- 最近学习只使用真实的最近课程和最后访问路由。

不在首页重复展示最近个人资料、最近个人资源或快捷开始。

### 5.2 AI问答

AI问答复制当前教师端三栏工作区，建立独立学生页面：

```text
左侧：知识库与深度研究
中间：AI问答
右侧：学生生成工具
```

左侧保留当前已有结构：

- 课程知识库／个人知识库标签；
- 文档选择与全选；
- 文档预览；
- 个人资料上传；
- 知识库顶部的深度研究输入框；
- 深度研究进度、来源和失败反馈。

左侧删除：

- 增加到课程知识库；
- 重命名、删除或重建课程资料；
- 课程索引管理；
- 任何课程写操作。

中间问答保留课程RAG、个人RAG、Web检索、引用和对话能力。学生可以同时使用有权读取的课程资料和自己的个人资料。

右侧使用与教师端相同的生成流程容器，但加载学生工具目录。学生生成结果一律进入个人资源。

### 5.3 课程知识

课程知识复制现有课程知识页面，保留两个视图：

```text
知识图谱
课程知识库
```

学生可执行：

- 搜索、展开和折叠知识结构；
- 缩放、移动只读画布和查看节点详情；
- 打开课程文档、图片、表格、公式和视频；
- 从知识点进入带课程和节点上下文的AI问答；
- 查看文档来源与引用定位。

学生不可执行：

- 上传、删除、重命名或重新索引课程资料；
- 创建、删除、移动或修改知识节点；
- 修改课时、说明和关系；
- 将个人资料关联到课程节点；
- 构建或重建课程知识库。

学生页面不渲染这些操作，后端写接口仍必须返回 `403`。

### 5.4 个人知识库

个人知识库只展示当前学生自己的资料，支持：

- 上传文档、图片和视频；
- 查看解析与索引状态；
- 预览正文和媒体；
- 重命名和删除；
- 对失败的个人索引执行重试；
- 选择资料进入AI问答或资源生成。

深度研究入口不在个人知识库页面重复出现。深度研究仍位于AI问答左侧知识库顶部，研究结果完成后自动出现在个人知识库。

个人知识库不展示“加入课程知识库”。

### 5.5 AI课堂

AI课堂复制当前AI课堂页面，保留独立一级导航，并分为：

```text
我的AI课堂
课程AI课堂
```

我的AI课堂：

- 展示当前学生生成的个人AI课堂；
- 允许创建、播放、下载、重命名和删除个人AI课堂；
- 生成任务进入个人任务和个人资源；
- 不提供发布到课程。

课程AI课堂：

- 展示当前课程中由教师发布的AI课堂快照；
- 学生可以播放、暂停、翻页、答题、提问和下载允许的产物；
- 不允许修改、删除、撤回或重新发布。

学生生成AI课堂不能写入课程课堂列表。当前依赖课程 `generate` 能力和课程资源落库的实现必须改为“学生个人工具权限 + 个人资源落库”。

### 5.6 资源管理

资源管理使用两个一级标签：

```text
个人生成
课程共享
```

个人生成：

- 只展示当前学生的个人生成物；
- 支持按类型、课程来源、时间和关键词筛选；
- 支持预览、播放、下载、重命名和删除；
- 支持复制配置和重新生成；
- 不显示发布、更新发布或加入课程知识库。

课程共享：

- 只展示当前课程中由教师发布的课程资源快照；
- 支持预览、播放和下载；
- 不展示学生个人生成物；
- 不允许重命名、置顶、删除、撤回或管理；
- 切换课程后重新读取对应课程的共享资源。

## 6. 生成工具隔离

### 6.1 正式工具矩阵

| 工具 | 教师 | 学生 | 默认输出 |
|---|---:|---:|---|
| 报告 | 是 | 是 | 个人资源 |
| PPT | 是 | 是 | 个人资源 |
| 思维导图 | 是 | 是 | 个人资源 |
| 练习题 | 是 | 是 | 个人资源 |
| AI课堂 | 是 | 是 | 个人资源 |
| 教案 | 是 | 否 | 个人资源 |
| 教学博客 | 是 | 否 | 个人资源 |
| 闪卡 | 否 | 是 | 个人资源 |
| 课堂小游戏 | 否 | 是 | 个人资源 |

深度研究属于AI问答知识库模块，不属于资源生成工具目录。

### 6.2 生成流程

学生端复制并复用教师端已经稳定的生成流程，不重新发明第二套协议：

```text
选择工具
→ 选择有权读取的资料范围
→ 填写工具配置
→ 确认生成
→ 提交后台任务
→ 原子保存个人资源
→ 在资源管理“个人生成”中打开
```

允许的来源包括：

- 不使用知识库；
- 自动使用个人知识库；
- 自动使用当前课程知识库；
- 指定个人资料；
- 指定当前课程资料；
- 在权限允许的前提下组合个人和课程资料。

系统必须保存实际命中的文档、引用和配置快照。学生不能通过传入物理路径或伪造文档ID读取他人个人资料或其他课程资料。

### 6.3 工具注册表

后端工具注册表至少包含：

```text
ToolDefinition
- tool_id
- allowed_system_roles
- required_course_capabilities
- allowed_source_scopes
- output_scope
- publish_capability
```

前端获取经过身份过滤的工具目录。系统角色从认证令牌获取，不能信任客户端提交的 `actor_role`。即使学生绕过前端直接调用教案或教学博客接口，后端也必须返回 `403`；教师直接调用闪卡或课堂小游戏的新建接口同样被正式工具矩阵拒绝。

## 7. 权限模型

### 7.1 三层权限判断

```text
系统角色
  teacher / student / admin

课程角色
  owner / editor / viewer

资源所有权与访问域
  personal:<user_id> / course:<course_id>
```

一个请求必须同时满足所需的系统角色、课程能力和资源访问域。

### 7.2 学生课程权限

| 操作 | 学生权限 |
|---|---:|
| 查看所属课程 | 允许 |
| 查看课程知识图谱 | 允许 |
| 查看课程知识库和媒体 | 允许 |
| 使用课程资料进行问答 | 允许 |
| 使用课程资料生成个人资源 | 允许 |
| 查看教师发布的课程资源 | 允许 |
| 播放课程AI课堂 | 允许 |
| 修改课程信息 | 禁止 |
| 管理课程成员 | 禁止 |
| 上传、删除或重命名课程资料 | 禁止 |
| 修改知识图谱 | 禁止 |
| 管理课程资源 | 禁止 |
| 发布个人资料到课程 | 禁止 |
| 发布个人资源到课程 | 禁止 |

### 7.3 个人空间权限

- 个人知识库只允许所有者读写；
- 个人生成资源只允许所有者读写；
- 个人任务只允许所有者查看、取消和重试；
- 教师不能读取学生个人资料、生成物和对话；
- 课程负责人和系统管理员不能通过课程管理接口绕过个人隔离；
- 内部迁移或审计工具如需访问个人数据，必须使用显式内部权限和审计记录，不得复用公开HTTP接口。

## 8. 数据模型与访问域

### 8.1 个人知识文档

```text
KnowledgeDocument
- document_id
- library_type: personal
- owner_user_id
- course_id: null 或仅作来源上下文
- status
- active_index_version
- created_at / updated_at
```

索引访问域为 `personal:<user_id>`。

### 8.2 课程知识文档

```text
KnowledgeDocument
- document_id
- library_type: course
- course_id
- owner_user_id: null
- status
- active_index_version
- published_from_document_id: 可空
```

索引访问域为 `course:<course_id>`。只有课程成员可以读取。

### 8.3 个人生成资源

```text
PersonalMaterial
- material_id
- owner_user_id
- visibility: private
- material_type
- source_job_id
- source_snapshot
- artifact_manifest
- course_context_id: 可空
- created_at / updated_at
```

使用课程资料只会记录课程来源上下文，不会改变资源所有权和可见性。

### 8.4 课程共享资源

```text
CourseMaterialSnapshot
- material_id
- course_id
- visibility: course
- published_by
- published_from_material_id
- artifact_manifest
- version
- published_at
```

课程共享资源必须是教师显式发布的独立快照。学生个人资源不存在课程发布字段或发布接口能力。

- 页面状态编排；


## 10. 路由隔离

建议学生路由使用独立命名空间：

```text
#student-home

#student-ai
  ?course_id=...

#student-course-knowledge
  ?course_id=...
  &view=structure|documents

#student-personal-knowledge

#student-classroom
  ?course_id=...
  &space=mine|course

#student-resources
  ?course_id=...
  &space=mine|course
```

登录后的角色分流：

```text
teacher → 教师首页
student → #student-home
```

学生直接访问教师路由时，路由守卫必须阻止加载教师页面。教师直接访问学生路由时可以返回教师首页或明确的角色不匹配状态。路由守卫是用户体验层，后端接口仍必须独立鉴权。

## 11. 核心数据流

### 11.1 上传个人资料

```text
学生上传
→ 个人文档存储
→ personal:<user_id> 索引
→ 个人知识库可见
→ 可用于AI问答和个人生成
```

### 11.2 深度研究

```text
AI问答左侧输入研究主题
→ 搜索与抓取
→ 展示过程、来源和失败项
→ 研究结果写入个人知识库
→ 刷新个人资料列表
```

### 11.3 学生生成资源

```text
选择学生工具和资料
→ 校验系统角色、课程读取权和文档访问域
→ 创建个人后台任务
→ 原子保存个人资源
→ 资源管理“个人生成”可见
```

### 11.4 教师发布课程资源

```text
教师个人资源
→ 显式发布
→ 创建脱敏课程快照
→ 学生资源管理“课程共享”可见
```

### 11.5 学生生成AI课堂

```text
学生选择AI课堂工具
→ 读取有权访问的个人/课程资料
→ 创建个人课堂任务
→ 保存个人AI课堂和个人附件
→ “我的AI课堂”与“个人生成”可见
→ 不写入课程AI课堂或课程共享
```

## 12. 错误与状态设计

学生页面必须统一处理：

- 未登录：返回登录页；
- 不是课程成员：显示无权访问，不切换到其他课程；
- 学生调用课程写接口：后端返回稳定 `403`；
- 学生调用未授权工具：返回“当前角色不能使用此工具”；
- 个人资料不可用：显示具体文档和索引状态；
- 课程资料不可用：允许移除该来源或切换资料范围；
- 生成任务失败：保留配置并允许按权限重试；
- 资源保存失败：不得显示生成完全成功；
- 课程切换失败：保留当前页面，不混入上一课程的数据；
- 课程共享为空：显示“教师尚未发布课程资源”，不展示创建按钮；
- 个人空间为空：提供与当前页面直接相关的真实操作，不放未实现功能。

错误信息不得暴露物理路径、API密钥、内部堆栈或其他用户数据。

## 14. 测试与验收

### 14.1 权限自动化

必须覆盖：

1. 学生能够读取所属课程、课程知识和课程共享资源；
2. 学生对所有课程修改接口均得到 `403`；
3. 学生不能把个人文档加入课程知识库；
4. 学生不能发布个人资源到课程；
5. 教师、课程负责人和其他学生不能读取学生个人资料、任务、资源和对话；
6. 课程外用户不能读取课程资料和课程共享资源；
7. 文档ID、资源ID、媒体URL和下载接口均执行访问域校验；
8. 学生只能调用学生工具目录；
9. 教师不能新建闪卡或课堂小游戏；
10. 学生不能新建教案或教学博客；
11. AI课堂对教师和学生均可生成，但都默认保存为个人资源；
12. 学生AI课堂不会出现在课程公共课堂列表。

### 14.2 前端自动化

- 登录角色分流正确；
- 学生导航只有六个正式入口；
- 深度研究只位于AI问答知识库模块；
- 学生课程知识页面没有写操作；
- 资源管理正确请求 `mine/course` 空间；
- AI课堂正确请求 `mine/course` 空间；
- 学生工具目录与正式矩阵一致；
- 切换课程不会污染个人知识库和个人资源；
- 直接输入教师路由不会加载教师页面；
- 学生页面不导入教师业务组件。

### 14.3 端到端场景

1. 学生登录后进入学习首页；
2. 学生看到最近学习和所属课程；
3. 学生点击课程进入AI问答；
4. 学生在左侧切换课程知识库和个人知识库；
5. 学生发起深度研究，结果只进入个人知识库；
6. 学生阅读课程知识图谱和课程文档；
7. 学生生成闪卡、课堂小游戏和AI课堂；
8. 教师账号确认看不到学生个人生成物；
9. 教师发布一个课程资源；
10. 学生在课程共享中预览该资源；
11. 学生尝试直接调用发布和课程写接口，均被拒绝；
12. 学生切换课程，课程知识和课程共享同步变化；
13. 学生个人知识库和个人生成保持不变；
14. 教师工作区核心流程回归通过。

### 14.4 页面质量

至少验证 1024×768、1280×720、1366×768、1440×900 和 1920×1080：

- 页面无横向溢出；
- 学生导航和课程选择器可用；
- 三栏AI问答在窄屏正确切换为抽屉或标签；
- 知识图谱和文档预览可操作；
- 资源与AI课堂两个空间切换清晰；
- 键盘可以完成课程选择、文档选择、工具生成和资源预览；
- 空状态、失败状态和无权限状态均使用学生可理解的中文。

## 16. 完成定义

学生端第一阶段只有同时满足以下条件才算完成：

- 新学生工作区和六项一级导航正式启用；
- 学生页面与旧学生界面完全隔离；
- 页面展示层可以独立修改，同时稳定业务内核保持共享；
- 最近学习和课程列表使用真实数据；
- AI问答保留课程/个人知识库和深度研究；
- 课程知识完全只读；
- 个人知识库只包含学生个人资料；
- AI课堂区分我的课堂与课程课堂；
- 资源管理区分个人生成与课程共享；
- 正式工具矩阵在前端目录和后端接口中同时生效；
- 学生上传、研究和生成结果均只进入个人空间；
- 教师发布的课程快照可被学生读取；
- 学生无法通过页面或直接接口修改课程、发布内容或读取他人个人数据；
- 旧学生页面和旧路由清理干净；
- 教师现有工作区与正在进行的Agent优化不受影响；
- 权限、路由、端到端、响应式和教师回归验收全部通过。
