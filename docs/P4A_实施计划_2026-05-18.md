## 架构原则（修订）

```
用户输入
  │
  ├─ action_hint 有值（用户点按钮）
  │     → MainOrchestrator._dispatch_workflow()
  │     → WorkflowRuntime（ReportWorkflowRuntime 等）【保持不变】
  │
  └─ action_hint 无值（自然对话）
        → ReActAgent
        → 生成工具直接调生成引擎
        → WorkflowRuntime 完全不参与
```

**Workflow 只服务按钮路径，Agent 路径完全独立。**  
原 Phase 3（Workflow Fast-Path）取消，不再给 Workflow 开后门。

### 各模块职责边界

| 模块 | 职责 | 不做什么 |
|------|------|---------|
| `executor.py` | budget / capability / dedup 检查，计时，trace 写入 | 不知道工具名称的含义 |
| `registry.py` | `name → handler` 的映射表 | 不执行任何业务逻辑 |
| `schemas.py` | LLM 看到的工具描述 | 不包含执行逻辑 |

| `handlers/outline_parser.py` | Markdown 字符串 → 结构化数据（章节列表 / PptOutline） | 不做 LLM 调用 |
| `handlers/report.py` | 构造参数 + submit_callable_task + _run 闭包 | _run 内部才 import 引擎 |
| `handlers/quiz.py` | 同上 | 同上 |
| `handlers/ppt.py` | 同上，额外依赖 outline_parser | 同上 |
| `handlers/lesson_plan.py` | 同上 | 同上 |

### 调用链路（Phase 3 完成后）

```
ReActAgent._react_loop()
  └── execute_tool(name, args, ctx)              ← executor.py
        └── get_tool_handler(name)(name,args,ctx) ← registry.py
              ├── handle_rag_search               ← handlers/retrieval.py
              ├── handle_web_search               ← handlers/retrieval.py
              ├── handle_draft_outline            ← handlers/outline.py
              │     └── ctx.agent_gateway.chat()
              ├── handle_generate_report          ← handlers/report.py
              │     ├── outline_parser.parse_report_outline(md)
              │     └── submit_callable_task(_run)
              │           └── _run(): build_report_markdown(...)
              ├── handle_generate_ppt             ← handlers/ppt.py
              │     ├── outline_parser.parse_ppt_outline(md, topic)
              │     └── submit_callable_task(_run)
              │           └── _run(): PptContentMarkdownGenerator + Html2PptClient
              ├── handle_generate_lesson_plan     ← handlers/lesson_plan.py
              │     └── submit_callable_task(_run)
              │           └── _run(): LessonPlanGenerationEngine._generate_content(...)
              └── handle_generate_quiz            ← handlers/quiz.py
                    └── submit_callable_task(_run)
                          └── _run(): QuizGenerator.generate(...)
```

### 关键设计决策

**1. 引擎 import 放在 `_run()` 闭包内**  
`handlers/report.py` 不在模块级 import `build_report_markdown`，而是在 `_run()` 内部 import。避免 agent_tools 包 import 时触发引擎模块的所有副作用（LLM 客户端初始化等）。

**2. `outline_parser.py` 独立模块**  
报告需要 `[(chapter_title, [section_title])]` 格式；PPT 需要 `PptOutline` 对象。两者逻辑不同但都是"Markdown 字符串 → 结构化数据"，提取为独立模块便于单独测试，且不依赖任何领域对象（outline_parser 只 import `PptOutline` domain 对象）。

**3. stub 保留不删除**  
`generation_stub.py` 保留，`registry.py` 切换时只改 import，回退方便。Phase 4 验证通过后再考虑是否清理。

**4. `_run()` 内部异常不向外抛**  
每个 `_run()` 闭包用 `try/except` 包裹，失败时 `task_store.mark_failed()`，不中断 agent 对话。

### Task 3.1：报告生成引擎适配器（0.5天）

**文件**：`app/chat/runtime/agent_tools/handlers/generation_real.py`（新建）

`build_report_markdown` 需要的参数：
- `skill_manager`：封装 RAG/web 工具的 `SkillManager` 实例
- `slots`：`{"subject": ..., "focus": ..., "length_requirement": ..., "outline_text": ...}`
- `outline`：从 `confirmed_outline` markdown 解析出的章节列表（可选，None 则引擎自行生成）
- `mode`：`"fast"`（agent 已提供大纲，单次调用生成全文）

```python
# app/chat/runtime/agent_tools/handlers/generation_real.py

from __future__ import annotations
import os
from app.chat.tasks.background_runner import submit_callable_task
from app.chat.runtime.agent_tools.constants import TOOL_TO_WORKFLOW
from app.chat.runtime.agent_tools.result import error_result, ok_result


def handle_generate_report(name: str, args: dict, ctx) -> dict:
    subject = str(args.get("subject", "")).strip()
    confirmed_outline = str(args.get("confirmed_outline", "")).strip()
    focus = str(args.get("focus", "")).strip()
    length_hint = str(args.get("length_hint", "")).strip()

    def _run():
        from app.chat.agents.report_generation import build_report_markdown
        from app.chat.skill_manager import SkillManager
        skill_manager = SkillManager(
            rag_retriever=ctx.rag_retriever,
            web_retriever=ctx.web_retriever,
            capability=ctx.capability,
            request=ctx.request,
        )
        slots = {
            "subject": subject,
            "focus": focus,
            "length_requirement": length_hint,
            "outline_text": confirmed_outline,
        }
        # Parse Markdown outline → chapter list for structured generation
        outline = _parse_outline_chapters(confirmed_outline)
        body, checkpoint = build_report_markdown(
            skill_manager=skill_manager,
            slots=slots,
            outline=outline,
            mode="fast",
        )
        return {
            "status": "completed",
            "artifacts": [{
                "artifact_type": "report",
                "title": subject,
                "content": body,
                "generation_state": checkpoint,
            }],
        }

    task_id = submit_callable_task(fn=_run, workflow_type="report")
    return ok_result(name, f"已提交报告生成任务，task_id={task_id}", {"task_id": task_id, "workflow_type": "report"})


def _parse_outline_chapters(markdown: str) -> list[dict] | None:
    """宽松解析 Markdown → [{title, sections:[{title}]}]，失败返回 None。"""
    try:
        lines = markdown.strip().splitlines()
        chapters = []
        current: dict | None = None
        for line in lines:
            s = line.strip()
            if s.startswith("# "):
                if current:
                    chapters.append(current)
                current = {"title": s[2:].strip(), "sections": []}
            elif s.startswith("## ") and current is not None:
                current["sections"].append({"title": s[3:].strip()})
        if current:
            chapters.append(current)
        return chapters if chapters else None
    except Exception:
        return None
```

> **注意**：`SkillManager` 需要确认其构造签名（查 `app/chat/skill_manager.py`）。若签名不同，在此适配。

def handle_generate_quiz(name: str, args: dict, ctx) -> dict:
    subject = str(args.get("subject", "")).strip()

    difficulty = str(args.get("difficulty", "medium"))
    question_types = list(args.get("question_types") or [])

### Task 3.3：PPT 生成引擎适配器（0.5天）

PPT 分两步：生成 content markdown → html2ppt 转 PPTX。

```python
def handle_generate_ppt(name: str, args: dict, ctx) -> dict:
    topic = str(args.get("topic", "")).strip()
    confirmed_outline = str(args.get("confirmed_outline", "")).strip()
    slide_count = int(args.get("slide_count", 10))

    def _run():
        from app.chat.domain.ppt_outline import PptOutline
        from app.chat.workflows.ppt.content_markdown_generator import PptContentMarkdownGenerator
        from app.chat.workflows.ppt.html2ppt_client import Html2PptClient
        from app.chat.agents.report_generation import get_fallback_llm
        import os

        # 1. Markdown 大纲 → PptOutline
        ppt_outline = _markdown_to_ppt_outline(confirmed_outline, topic, slide_count)
        if ppt_outline is None:
            return {"status": "failed", "error": "大纲解析失败，无法生成 PPT"}

        # 2. 生成 content markdown
        generator = PptContentMarkdownGenerator(llm=get_fallback_llm())
        content_md, _meta = generator.generate(outline=ppt_outline)

        # 3. 提交 html2ppt job
        client = Html2PptClient(
            base_url=os.getenv("HTML2PPT_BASE_URL", "http://127.0.0.1:46080")
        )
        job = client.create_job(
            content_markdown=content_md,
            theme_id="default",
            metadata={"topic": topic, "slide_count": slide_count},
        )
        return {
            "status": "completed",
            "artifacts": [{"artifact_type": "ppt", "title": topic, "job_id": job.get("job_id")}],
        }

    task_id = submit_callable_task(fn=_run, workflow_type="ppt")
    return ok_result(name, f"已提交 PPT 生成任务，task_id={task_id}", {"task_id": task_id, "workflow_type": "ppt"})


def _markdown_to_ppt_outline(markdown: str, topic: str, slide_count: int):
    """Markdown 大纲 → PptOutline，失败返回 None。"""
    try:
        from app.chat.domain.ppt_outline import PptOutline
        lines = markdown.strip().splitlines()
        slides = []
        current_title = ""
        current_bullets: list[str] = []
        for line in lines:
            s = line.strip()
            if s.startswith("## ") or (s.startswith("# ") and not s.startswith("## ")):
                if current_title:
                    slides.append({"title": current_title, "bullets": current_bullets})
                current_title = s.lstrip("#").strip()
                current_bullets = []
            elif s.startswith("- ") or s.startswith("* "):
                current_bullets.append(s.lstrip("-* ").strip())
        if current_title:
            slides.append({"title": current_title, "bullets": current_bullets})
        if not slides:
            return None
        return PptOutline(topic=topic, slides=slides, slide_count=slide_count)
    except Exception:
        return None
```

> **注意**：`PptOutline` 构造参数需对照 `app/chat/domain/ppt_outline.py` 确认字段名。

## 禁止事项（Anti-Patterns）

| 禁止 | 原因 |
|------|------|
| agent 路径调用任何 WorkflowRuntime | 破坏架构分离，两套路径会产生干扰 |
| 修改 WorkflowRuntime 内部逻辑来适配 agent | 反向依赖，增加维护复杂度 |
| `generation_real.py` 中 import 循环 | 所有 workflow/engine import 放在函数 `_run()` 内部 |
| `submit_callable_task` 漏传 `workflow_type` | 任务查询接口依赖此字段分类 |
| 解析 Markdown 大纲失败时抛异常 | 应降级：返回 error_result，让 agent 告知用户重试 |
