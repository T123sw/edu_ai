# 换机器部署清单

> 目标：在另一台机器复刻出与本机一致的可运行环境。
> 最后更新：2026-06-30

`git clone` / `git pull` 只能同步**代码层**。要完整跑起来，还需手动处理
密钥、依赖、Docker、运行时数据这几层。按本清单逐项完成即可。

---

## 0. 拉取代码

```bash
git clone https://github.com/T123sw/edu_ai.git
cd edu_ai
# 或已有仓库
git pull origin main
```

代码、文档、`html2ppt`（已扁平化进主仓库）、`infra/searxng` 配置都会一并拿到，
与本机完全一致。

---

## 1. 配置 `.env`（含密钥，不在 git 里）

本机 `Edu_AI/.env` 含 `REMOTE_MODEL_API_KEY` 等密钥，**已被 .gitignore，不会进远程**。

用 U盘 / 网盘 / scp 把本机这个文件拷到新机器同位置：

```
Edu_AI/.env
```

图片搜索功能需要以下项（确认 `.env` 里有，没有就补）：

```bash
IMAGE_SEARCH_PROVIDER=searxng
SEARXNG_BASE_URL=http://localhost:8888
IMAGE_SEARCH_VLM_REVIEW=1          # 下载本地+base64 审查，默认开
# 以下有默认值，可不填
# IMAGE_SEARCH_TIMEOUT_S=8
# SEARCHED_IMAGE_MAX_BYTES=10485760
# REACT_MAX_STEPS=6
# REACT_TIMEOUT_SECONDS=40
```

## 2. Python 依赖

> 当前项目历史上用**系统全局 Python**。新机器建议建独立 venv 更干净。

```bash
cd Edu_AI/api/src

# （推荐）建独立 venv
python -m venv .venv
# Windows:  .venv\Scripts\activate
# Linux/Mac: source .venv/bin/activate

# 精确复刻（与本机版本完全一致）— 推荐
pip install -r requirements-lock.txt

# 或按范围装（拿兼容的较新小版本）
pip install -r requirements.txt

# 媒体相关（如需视频/音频处理）
pip install -r requirements-media.txt
```

> `requirements-lock.txt` 锁定了 30 个直接依赖的精确版本（取自本机可运行环境）。
> 完全锁定（含传递依赖）可在装完后 `pip freeze > full-lock.txt`。

playwright 还需装浏览器内核：

```bash
playwright install chromium
```

### 其他子模块依赖（按需）

| 模块 | 安装 |
|---|---|
| RAG v2 | 随后端主依赖一起装（`Edu_AI/api/src` 的 `requirements.txt`）；`rag_v2/rag-main` 独立工程已随 Phase 1 收口删除，无需单独装 |
| AI 讲师 | `cd Edu_AI/api/src/modules/AI_Lecturer && pip install -r requirements.txt`（离线版 `requirements-offline-py312.txt`） |
| EduAgent | `cd EduAgent && pip install -r requirements.txt` |

## 4. Docker 容器（SearXNG）

配置文件都在 git 里，**不用手写配置**，但要在新机器重新起容器
（容器是运行时实例，不跟 git 走，镜像会自动拉取）。

| 用途 | 命令 | 端口 |
|---|---|---|
| **图片搜索**（必须） | `cd infra/searxng && docker compose up -d` | 8888 |
| EduAgent 联网搜索（用 web_search 才需要） | `cd EduAgent && docker compose -f docker-compose.searxng.yml up -d` | 8090 |

验证 SearXNG：

```bash
curl 'http://localhost:8888/search?q=test&categories=images&format=json'
# 返回非空 JSON results 即正常
```

## 5. 运行时数据（不复制，重新生成）

以下目录是运行时产物，**已 .gitignore，不带到新机器**：

| 目录 | 内容 | 新机器处理 |
|---|---|---|
| `Edu_AI/api/src/storage/` | 对话记录、向量库、下载的图、缓存 | 从空白开始，自动重建 |
| `Edu_AI/api/course_data/` | 课程资料、生成的报告/PPT/教案 | 重新上传课程资料、重新生成 |

> 历史对话和已生成产物不会在新机器上。如确实要带，手动拷这两个目录
> （storage ~807M + course_data ~17M）。

## 速查：哪些靠 git、哪些手动

| 层 | 来源 |
|---|---|
| 代码 / 文档 / html2ppt 源码 / SearXNG 配置 | `git clone` ✅ 自动 |
| `.env` 密钥 | 手动拷 1 个文件 |
| Python / Node 依赖 | `pip install` + `npm install` |
| SearXNG 容器 | `docker compose up -d` |
| 运行时数据（storage / course_data） | 不带，重新生成 |
