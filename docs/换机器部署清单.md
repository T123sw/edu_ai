# 换机器部署清单

更新日期：2026-07-25

## 1. 准备主机

- Git 2.40+
- Python 3.12
- Node.js 20 / npm 10
- FFmpeg 与 ffprobe
- 足够运行 Playwright Chromium 的系统库

不需要 GPU、数字人模型权重或额外课件服务。

## 2. 克隆与安装

```bash
git clone <repository-url>
cd edu_ai
```

Windows：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
.\scripts\install-all.ps1
```

Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
bash scripts/install-all.sh
```

## 3. 配置

复制并填写：

- `Edu_AI/.env.example` → `Edu_AI/.env`
- `Edu_AI/api/src/.env.example` → `Edu_AI/api/src/.env`
- 可选：`EduAgent/config.toml.example` → `EduAgent/config.toml`

至少确认主 API、模型、Embedding、检索、MinerU Cloud、OpenMAIC 与课堂视频导出变量。真实密钥只保存在目标机器。

## 4. 启动

```bash
cd Edu_AI/api/src
python -m uvicorn app.main:app --host 0.0.0.0 --port 8001

cd Edu_AI
npm run dev -- --host 0.0.0.0 --port 5173
```

Windows 也可运行 `Edu_AI/api/src/start_api.bat`。

## 5. 发布验证

```bash
python -m pip check
python -m pytest tests/app tests/chat -q
npm test --prefix Edu_AI
npm run lint --prefix Edu_AI
npm run build --prefix Edu_AI
```

再执行一次真实 AI 课堂 PPTX 和 MP4 导出，检查 PPTX 可打开、MP4 为 H.264/AAC、SRT 为 UTF-8、时间线与成片时长一致。

## 6. 不迁移的本地产物

不要复制或提交 `.env`、`.venv*`、`node_modules/`、`dist/`、浏览器缓存、课程生成物、视频成品和真实密钥。
