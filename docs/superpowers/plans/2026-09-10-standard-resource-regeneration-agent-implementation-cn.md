# 知识点标准资源安全重生成与 Agent Skills 实施计划

日期：2026-09-10  
对应设计：[知识点标准资源安全重生成与 Agent Skills 设计](../specs/2026-09-10-standard-resource-regeneration-agent-design-cn.md)

## 阶段 1：先建立失败测试

1. 后端测试覆盖预检三种模式、只选择部分资源类型、空计划拒绝。
2. 覆盖批次幂等、活跃槽位冲突、知识图版本变化。
3. 覆盖 Job 结果与批次项材料版本绑定。
4. 覆盖审核版本/哈希错位返回冲突，以及批量审核只批准本批版本。
5. 前端测试覆盖动作摘要、选择计数和审核请求版本。

## 阶段 2：数据模型与事务安全

1. 扩展 SQLAlchemy 模型并增加 Alembic 迁移。
2. 批次仓储实现幂等读取、活跃槽位唯一键和结果版本记录。
3. 材料发布结果返回真实版本、内容哈希和生成批次。
4. 审核事务加入期望版本与哈希比较。

## 阶段 3：预检和 API

1. 在领域服务中按当前槽位状态生成动作计划。
2. 扩展创建请求，服务端重新计算并核对知识图版本。
3. 增加预检和最近批次接口；批次读写限制为课程管理者。
4. 保持旧创建请求的安全默认值。

## 阶段 4：Skill 与质量门

1. 新建 `edu-standard-resource-bundle/SKILL.md`。
2. 为每个知识点构建共享教学蓝图并写入三个任务的配置快照。
3. 学习指南、练习和 AI 课堂均启用必需审阅策略；课堂继续使用原生 OpenMAIC 结构。
4. 将退回理由和已批准版本事实传入修订任务。

## 阶段 5：前端交互

1. 增加资源类型和重生成模式选择。
2. 首次点击执行服务端预检，显示补齐、修订、重生成、保留和阻断数量。
3. 二次确认后创建批次；无执行项时不给出误导性提交。
4. 从最近批次恢复进度，审核携带版本和内容哈希。

## 阶段 6：验证

1. 运行标准资源后端测试和新增 API 测试。
2. 运行相关前端单元测试与生产构建。
3. 使用 Playwright 覆盖：部分已有资源预检、明确全量重生成、刷新恢复、版本冲突审核。
4. 记录命令、结果、环境限制和剩余风险到验收文档。
