# AI 课堂三栏学习工作台与资源上下文问答设计

日期：2026-09-01

状态：已实施；代码、自动化测试与响应式视口验收通过

关联设计：`2026-09-01-ai-classroom-curriculum-resource-tree-design-cn.md`

## 1. 背景

AI 课堂已经以课程目录组织节点和学习资料，但桌面端主体仍受居中最大宽度限制，超宽屏两侧存在大量空白；选中资源后的预览区也没有形成稳定的“学习内容 + 随堂问答”工作台。

本次改造在既有课程资源树、教师审核发布和学生学习进度能力之上完成两项升级：

1. 取消 AI 课堂主体的居中宽度上限，把课程目录放到页面内容区最左侧，并让学习空间使用全部剩余宽度；
2. 将桌面端固定为“课程与个人课堂目录 / 当前学习内容 / 当前内容问答”三栏，问答始终围绕中间正在展示的完整资源进行。

## 2. 已确认的产品决策

1. 页面左右保留约 20px 安全边距，不采用零边距贴浏览器边缘。
2. 左栏不再与主体一起居中，固定贴近页面内容区左侧。
3. 桌面端除左侧目录外，右侧固定分为中间学习区和右侧问答区。
4. 中间学习区承载视频播放、互动课堂、文档预览、习题作答及节点概览，不再为这些内容打开重复布局的新页面。
5. 右侧复用现有 AI 课堂实时问答的消息、输入和状态交互，但增加统一的“当前展示物”上下文适配。
6. 文档问答允许模型读取整份文档，而不是只读取当前可见页；习题问答允许模型读取完整题目、选项及关联材料。
7. 左栏底部增加“我的课堂”，仅展示当前课程下、当前登录用户个人生成的视频。
8. 教师审核与发布、学生学习进度继续保留，并随当前中间资源展示。
9. 不同资源使用独立的问答会话；切换资源不得把上一份资源的问答历史混入当前上下文。

## 3. 目标与非目标

### 3.1 目标

- 充分使用桌面横向空间，把中间学习内容设为页面视觉和操作中心。
- 保证课程导航、内容消费和 AI 问答同时可见，减少页面跳转和上下文丢失。
- 为课程发布资源和用户个人生成视频提供清晰但互不混淆的入口。
- 为视频、文档和习题提供统一、可审计且权限安全的资源上下文问答协议。
- 保持教师与学生在同一页面骨架上使用各自权限范围内的管理或学习能力。

### 3.2 非目标

- 不在本次改造中重做问答消息气泡、语音回答、中断恢复或播放器渲染器。
- 不把“我的课堂”扩展成跨课程个人资源中心。
- 不允许问答自动读取当前课程的全部资料；默认上下文只限中间当前展示物。
- 不把习题问答变成直接代答或自动提交系统。
- 不改变既有资源审核、发布版本和学生学习完成口径。
- 不在第一阶段增加用户可拖拽的栏宽调整功能。

## 4. 方案比较与选择

### 4.1 方案 A：在现有 AI 课堂页内建立统一三栏工作台（采用）

保留课程目录页作为唯一入口，在同一页面内组合资源目录、中间类型化查看器和上下文问答。现有播放器、文档查看器、习题组件及问答组件作为能力被嵌入工作台。

优点：切换资源连续，目录和问答始终可见；现有深链接、审核状态和学习进度可以继续使用。缺点：需要把原本只服务互动课堂的问答控制器抽象为通用资源上下文问答。

### 4.2 方案 B：每种资源进入独立详情页

目录点击后跳转到视频页、文档页或习题页，各页面分别放置问答。

优点：页面职责局部简单。缺点：频繁跳转，目录位置与问答历史难以保持，不符合固定三栏要求。

### 4.3 方案 C：在目录页嵌入现有播放器完整页面

使用嵌套页面快速复用播放器和问答。

优点：初始改动少。缺点：产生重复导航、重复滚动和不可控的响应式嵌套，也难以统一文档与习题上下文。

因此采用方案 A。

## 5. 信息架构

```text
AI课堂
├─ 左栏：导航（约 340px）
│  ├─ 课程目录（主滚动区）
│  │  └─ 章 / 节 / 节点 / 发布资源
│  └─ 我的课堂（底部区域）
│     └─ 当前课程 + 当前用户生成的视频
├─ 中栏：学习内容（弹性占满）
│  ├─ 节点概览
│  ├─ 视频 / 互动课堂
│  ├─ 完整文档预览
│  └─ 习题作答
└─ 右栏：当前内容问答（约 380px）
   ├─ 当前上下文标识
   ├─ 独立问答记录
   └─ 输入、发送、停止与错误恢复
```

“课程目录”表达教师发布的规范课程学习路径；“我的课堂”表达登录用户在当前课程中的私人生成成果。两者视觉上属于同一左栏，但使用独立标题、数据来源和可见性规则。

## 6. 桌面布局

### 6.1 外层

- 移除工具栏和主体的 `1560px` 居中最大宽度限制。
- 页面使用全宽布局，左右安全边距建议为 `clamp(16px, 1.25vw, 24px)`。
- 工具栏与三栏主体共享相同左右边界。
- 主体高度继续基于视口和课程顶部导航计算，三栏分别管理内部滚动，不让整个页面因长目录或长问答无限增长。

### 6.2 三栏尺寸

推荐桌面列定义：

```css
grid-template-columns:
  clamp(310px, 18vw, 360px)
  minmax(520px, 1fr)
  clamp(340px, 21vw, 420px);
```

- 左栏稳定、紧凑，不因超宽屏无限增宽。
- 中栏获得所有剩余空间，是优先扩展区域。
- 右栏保持适合连续阅读问答的宽度，不挤占主要学习内容。
- 栏间距建议为 14–16px。

示意：

```text
┌──────────────┬───────────────────────────────────┬──────────────────┐
│ 课程目录     │ 当前学习内容                      │ AI 随堂问答      │
│ 章 / 节      │                                   │ 围绕：当前资源   │
│ 节点资源     │ 视频 / 文档 / 习题                │                  │
│              │                                   │ 问答记录         │
│              │                                   │                  │
├──────────────┤                                   ├──────────────────┤
│ 我的课堂     │ 教师：审核发布                    │ 输入问题  [发送] │
│ 个人视频     │ 学生：进度与作答状态              │                  │
└──────────────┴───────────────────────────────────┴──────────────────┘
```

## 7. 左栏：课程目录与我的课堂

### 7.1 课程目录

- 沿用现有章、节、节点和节点资源树，不改变目录排序、选中与搜索规则。
- 课程目录占据左栏主要高度并独立滚动。
- 搜索继续覆盖章节、小节、节点和课程发布资源；不默认搜索“我的课堂”，避免混淆公开课程内容与个人内容。
- 教师继续看到审核状态；学生继续看到个人学习进度。

### 7.2 我的课堂

- 固定放在左栏底部，以分隔线和独立标题与课程目录区分。
- 数据范围必须同时满足：当前课程、当前登录用户、个人生成、视频或可播放课堂类型。
- 默认展示紧凑列表；数量较多时区域内部滚动，不挤走课程目录标题和当前选中路径。
- 每项至少显示标题、生成时间或更新时间、生成/可播放/失败状态。
- 点击可播放视频后，中间区直接切换到该视频，右侧问答同步绑定该个人视频。
- 个人视频默认仅本人可见，不因出现在课堂页而进入课程发布目录。
- 教师若要将个人成果发布为课程资源，仍通过既有审核发布流程处理，不在列表点击时自动共享。
- 空状态显示“还没有个人生成的视频”，教师或具备生成权限的用户可看到生成入口；无生成权限的学生只看到说明。

## 8. 中栏：统一学习内容区

中栏由统一资源查看器按当前选择分发，不同资源使用同一外壳、面包屑和状态区。

### 8.1 未选择资源

显示节点或课程概览。右侧问答进入未绑定状态，说明“选择一份资料后即可围绕内容提问”，不得静默使用整门课程作为上下文。

### 8.2 视频与互动课堂

- 在中栏直接展示播放器或互动课堂场景，不再要求离开三栏工作台。
- 保留播放、暂停、字幕、场景切换、习题互动、全屏和学习记录。
- 全屏时只放大中间课堂内容；退出全屏后恢复原三栏、目录选中项和问答记录。
- 现有“提问时暂停、回答后继续”仅在支持中断恢复的互动课堂中启用；普通视频问答不应伪造播放中断状态。

### 8.3 文档

- PDF、Markdown、文本及已有安全转换结果在中栏完整预览。
- 当前页码、滚动位置可作为问题的辅助上下文，但模型可检索整份文档。
- 文档加载或解析失败时保留安全下载入口；问答区明确显示上下文暂不可用，不能假装已读取全文。
- 学生学习进度继续遵循打开后“学习中”、明确完成阅读后“已完成”的现有规则。

### 8.4 习题

- 中栏展示完整题目、选项、材料、作答状态和反馈。
- 问答可读取整份习题内容及关联材料，但默认不得把标准答案直接写进用户正在作答的题目。
- 学生提问时，回答优先采用提示、概念解释和解题步骤；是否展示最终答案继续受现有作答/提交状态规则约束。
- 教师预览可查看答案配置，不产生学生作答记录。

### 8.5 教师与学生状态区

- 教师中栏保留版本、待审核状态、批准并发布、退回修改等操作。
- 学生中栏保留资源级学习进度、完成阅读、答题提交及同步状态。
- 右侧问答不得遮挡或替代审核、发布和进度操作。

## 9. 右栏：当前展示物问答

### 9.1 复用边界

复用现有 `ClassroomQaPanel` 的以下体验：

- 用户与 AI 消息展示；
- 空状态、发送状态、错误状态和重试；
- 输入长度限制、快捷发送和自动跟随最新消息；
- 互动课堂中的暂停、回答语音播放、停止回答和恢复授课。

组件需要从“只接受互动课堂中断控制器”演进为“通用问答面板 + 可选播放中断能力”。文档、习题和普通视频使用相同问答视觉，但不显示无意义的“继续授课”操作。

### 9.2 当前上下文标识

右栏顶部必须显示：

- 当前资源标题；
- 资源类型；
- 上下文状态：准备中、可提问、不可用或已更新。

文案示例：`正在围绕《问题形式化与输入输出学习指南》问答 · 已读取完整文档`。

### 9.3 会话隔离

问答会话键至少包含：

```text
user_id + course_id + resource_kind + resource_id + resource_version
```

- 同一资源版本返回时恢复对应问答记录。
- 切换资源立即切换会话，不把上一资源历史发送给模型。
- 新版本发布后使用新会话键；旧版本问答记录保留但不参与新版本回答。
- 未选择资源、资源无权访问或上下文构建失败时禁止发送。

## 10. 上下文数据协议

前端发送稳定资源引用，不直接拼装或上传整份文档文本：

```text
course_id
resource_kind
resource_id
resource_version
context_scope = full_resource
optional_anchor = scene_id | page_number | question_id
conversation_id
```

服务端按登录用户和课程角色重新校验资源权限，并从受信任的数据源构建模型上下文。

### 10.1 视频与互动课堂

上下文包含课堂标题、场景、讲解文本、字幕或转写、当前场景和已发生的课堂问答。当前场景作为优先定位，完整课堂内容作为可检索范围。

### 10.2 文档

上下文范围为当前资源版本的完整解析文档。长文档通过服务端全文检索、分块与引用组合进入模型，不能依赖浏览器当前可见页，也不能因为模型上下文窗口有限而悄悄截断为开头若干页。

回答应尽可能携带页码、章节或段落来源；当前页码仅提高相关内容优先级。

### 10.3 习题

上下文包含完整题目、选项、题干材料、知识点关联及用户当前作答状态。学生权限下，标准答案和解析是否进入可见回答由现有提交状态和教学策略控制；模型内部即使可用，也不得绕过产品规则泄露答案。

### 10.4 个人视频

个人视频使用其课堂脚本、场景、字幕或转写作为上下文。访问控制必须验证资源所有者；其他用户即使猜到资源 ID 也不得读取内容或问答记录。

## 11. 数据流

### 11.1 选择课程资源

```text
点击目录资源
  -> 更新深链接和当前选择
  -> 中栏加载对应查看器
  -> 右栏根据资源引用建立或恢复独立会话
  -> 服务端校验权限并准备完整资源上下文
  -> 上下文就绪后允许提问
```

### 11.2 切换资源

```text
资源 A 问答中
  -> 用户选择资源 B
  -> 取消或隔离 A 的未完成响应
  -> 中栏展示 B
  -> 右栏切换到 B 的会话与上下文状态
  -> 返回 A 时恢复 A 的记录
```

### 11.3 个人视频

```text
个人生成任务完成
  -> 视频归档到当前课程下的个人资源
  -> 我的课堂刷新列表
  -> 点击视频
  -> 中栏播放 + 右栏绑定该视频上下文
```

## 12. 响应式规则

### 12.1 大屏（建议不低于 1280px）

- 固定三栏同时可见。
- 左栏和右栏固定在推荐宽度范围，中栏弹性扩展。

### 12.2 中等屏（约 960–1279px）

- 左栏改为课程目录抽屉，中栏和右栏保持双栏。
- 顶部保留明确的“课程目录”入口。
- 选择资源后自动关闭目录抽屉。

### 12.3 小屏（低于约 960px）

- 中栏优先占满宽度。
- 课程目录与问答分别通过抽屉或页内切换打开，不能同时覆盖中栏。
- 当前资源标题和问答未读/进行中状态保留在紧凑工具栏。
- 抽屉打开后正确管理焦点，关闭后返回触发按钮。

具体断点应在真实 1024、1280、1440、1920 和超宽屏下验证后确定，不以某一张截图尺寸硬编码。

## 13. 路由与状态恢复

在现有 `node_id`、`resource_id` 基础上支持个人视频目标，并保持链接可复制：

```text
#teacher-classroom-studio?course_id=<courseId>&node_id=<nodeId>&resource_id=<resourceId>
#student-classroom?course_id=<courseId>&node_id=<nodeId>&resource_id=<resourceId>
#teacher-classroom-studio?course_id=<courseId>&personal_classroom_id=<id>
```

- 课程资源与个人视频参数互斥，出现冲突时拒绝含糊定位并回到安全默认状态。
- 刷新后恢复中栏当前资源、左栏选中项和对应问答会话。
- 学生不得通过个人课堂参数访问教师或其他用户的视频。
- 资源被删除、撤回或更新时，保留页面骨架并给出明确状态，不展示陈旧正文。

## 14. 权限与安全

- 课程目录继续在服务端过滤学生不可见版本。
- “我的课堂”接口只返回当前用户在当前课程下的个人视频。
- 问答服务端必须重新校验课程成员关系、资源可见性、资源版本和个人资源所有权。
- 前端传来的全文、答案或资源标题不作为权限和上下文事实来源。
- 文档解析内容、课堂字幕和习题答案不得出现在无权访问用户的错误信息、日志或问答来源中。
- 切换资源时的迟到流式响应只能写入原资源会话，不能显示到新资源面板。
- 文档预览继续清理不受信任 HTML 和危险链接。
- 问答对学生展示习题答案时必须遵守现有提交与反馈策略。

## 15. 加载、空状态与错误恢复

- 首次加载用三栏骨架表达最终结构，避免双栏到三栏的明显跳动。
- 中栏加载资源时，左栏仍可操作；右栏显示“正在准备当前内容”。
- 问答上下文准备失败不阻断资源学习，中栏继续可用，并提供单独重试。
- “我的课堂”加载失败不阻断课程目录，底部区域显示局部重试。
- 个人视频生成中显示任务状态，不允许点击为可播放资源。
- 资源切换失败时保留上一份成功内容或进入明确错误态，不能让中栏标题与正文指向不同资源。
- 问答请求失败保留用户问题和当前资源绑定，重试不得重复创建可见消息。

## 16. 可访问性与交互约束

- 三栏使用语义化导航、主内容和补充问答区域；问答区使用合适的 `aria-label`。
- 键盘焦点顺序为工具栏、左栏、中栏、右栏，抽屉打开时限制焦点范围。
- 当前目录资源、当前个人视频和当前问答上下文必须有非颜色选中标识。
- 所有可点击项使用按钮或链接，不使用无语义点击容器。
- 长标题允许换行或在可访问名称中保留全文。
- 栏内滚动区域需要可见滚动反馈，并避免滚动链误带动整页。
- 尊重减少动态效果设置；资源切换不使用大幅位移动画。

## 17. 建议组件边界

| 组件或模块 | 职责 |
| --- | --- |
| `ClassroomStudioPage` | 解析路由、加载目录和个人课堂、协调当前资源 |
| `ClassroomWorkspaceLayout` | 三栏结构、响应式抽屉和栏内滚动 |
| `CurriculumResourceTree` | 课程目录、课程资源选择与角色状态 |
| `MyClassroomList` | 当前课程的个人生成视频列表与状态 |
| `CourseResourceViewer` | 中栏类型分发及教师/学生状态区 |
| `ContextualClassroomQaPanel` | 通用问答 UI、当前上下文标识和会话切换 |
| `ClassroomPlaybackQaAdapter` | 互动课堂暂停、回答和恢复能力 |
| `ResourceQaContextController` | 资源引用、上下文就绪状态、请求取消与会话隔离 |

问答 UI 与上下文来源必须分离：面板只负责消息交互，控制器负责资源权限、上下文引用和流式生命周期，播放器适配器只负责可选的中断恢复。

## 18. 测试策略

### 18.1 单元与组件测试

- 超宽屏取消 `1560px` 居中限制，左栏贴近安全边距，中栏占用剩余宽度。
- 三栏宽度、最小中栏宽度及中小屏抽屉切换正确。
- “我的课堂”只显示当前课程、当前用户的个人视频。
- 课程目录搜索不错误混入个人视频。
- 视频、文档、习题和个人视频正确分发到中栏。
- 资源切换同步更新右栏标题、上下文状态和会话记录。
- 文档请求使用 `full_resource`，不退化为仅当前页。
- 习题问答包含完整题目引用且遵守答案展示策略。
- 普通视频和文档问答不显示“继续授课”；互动课堂继续支持中断恢复。
- 教师审核发布和学生学习进度在三栏下无回归。

### 18.2 服务与权限测试

- 跨课程、跨用户、未发布版本和被撤回资源的问答上下文访问被拒绝。
- 个人视频列表和问答严格校验所有者。
- 文档全文检索覆盖后半部分命中，证明不是只读取开头或当前页。
- 习题答案在学生未满足展示条件时不会由问答泄露。
- 资源版本更新后新旧会话隔离。
- 迟到流式响应不会污染当前已切换资源的会话。

### 18.3 端到端验收

1. 在 1920px 及超宽屏中，目录位于页面左侧安全边距内，AI 课堂使用几乎全部可用宽度。
2. 桌面端同时看到课程目录、中间学习区和右侧问答区。
3. 左栏底部“我的课堂”只显示当前用户在当前课程生成的视频。
4. 点击课程视频或个人视频后，中栏直接播放，右栏显示对应视频上下文。
5. 点击文档后中栏直接预览；针对未显示页的内容提问仍能得到有来源的回答。
6. 点击习题后中栏可作答，右栏能解释整份习题且不违反答案展示规则。
7. 切换两份资源时，问答标题、上下文和历史互不混杂；切回后恢复原记录。
8. 教师仍能在中栏完成审核和发布，学生仍能看到并更新学习进度。
9. 中等屏目录变为抽屉，小屏问答也变为抽屉，中间内容始终优先可用。
10. 问答上下文加载失败时，视频、文档或习题仍可正常学习。

## 20. 建议实施分片

1. **全宽三栏骨架**：移除居中上限，建立桌面三栏和中小屏抽屉规则。
2. **中栏类型化学习体验**：把现有视频/课堂、文档和习题查看能力稳定嵌入统一外壳。
3. **我的课堂**：增加当前课程个人视频读模型、列表、状态和中栏播放定位。
4. **通用资源上下文问答**：拆分问答 UI 与播放器中断控制，增加资源会话与完整上下文协议。
5. **角色功能与加固**：验证教师审核发布、学生进度、权限、错误恢复、响应式和端到端场景。

## 21. 完成定义

只有满足以下全部条件，才能宣称本次改造完成：

1. AI 课堂不再以 `1560px` 宽度居中，左侧目录和右侧学习工作台充分使用页面宽度。
2. 桌面端课程目录、中间学习内容和当前内容问答稳定同时可见。
3. “我的课堂”准确保存并展示当前课程中当前用户个人生成的视频。
4. 视频、完整文档和完整习题均能成为右侧问答的明确上下文。
5. 不同资源及不同版本的问答会话相互隔离，切换和迟到响应行为正确。
6. 教师审核发布、学生学习进度、互动课堂中断恢复和现有权限体系无回归。
7. 中小屏降级、键盘操作、错误隔离和真实浏览器验收全部通过。
