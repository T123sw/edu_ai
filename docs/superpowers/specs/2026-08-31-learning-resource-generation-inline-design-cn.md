# 学习资源生成入口交互修正设计

日期：2026-08-31

## 目标

将“学习资源生成”从独立配置页改为课程知识页内展开配置。入口继续位于“更新知识库”旁边，点击后 URL 不变化，并在当前知识库卡片下方显示现有的标准学习资源配置能力。

## 交互

- “学习资源生成”使用按钮，不再使用链接。
- 点击按钮后，在操作区下方展开配置面板；再次点击或点击“收起”关闭面板。
- 学习资源配置面板与“更新知识库”配置向导互斥，同一时间只展示一个配置面板。
- 展开学习资源配置时收起知识库配置向导；打开知识库配置向导时收起学习资源配置。
- 面板沿用当前页布局，使用 `role="dialog"` 与 `aria-modal="false"` 表示内嵌配置区域。
- 学生端继续只读展示已发布资源，不显示生成入口。

## 实现边界

- `CourseKnowledgeBuildCard` 管理两个配置面板的开关状态。
- 新建轻量内嵌面板组件，提供标题、说明、收起按钮并复用 `StandardLearningResources`。
- 删除 `learning-resource-generation` 独立路由、页面及其样式。
- 不修改资源生成、进度轮询、审核、重试和后台任务协议。

## 验收

- 课程知识页能看到“学习资源生成”按钮。
- 点击按钮后 URL 不变，页面下方出现知识点选择与生成按钮。
- 学习资源配置和知识库配置不会同时显示。
- 配置面板可收起。
- 独立路由不再注册，原有学生只读资源仍保留。
