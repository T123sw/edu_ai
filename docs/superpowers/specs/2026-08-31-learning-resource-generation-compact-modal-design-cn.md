# 学习资源生成紧凑弹窗设计

日期：2026-08-31

## 1. 背景与目标

当前学习资源配置在课程知识页内展开，并同时呈现全部章节、全部叶子知识点以及每个知识点的三类资源卡片。随着知识点数量增加，配置区域会形成很长的页面，扫描、选择和生成操作都变得困难。

本次改造把入口调整为紧凑弹窗，优先服务“快速选择知识点并批量生成”。资源预览和审核仍然可用，但改为按需展示，不再默认铺开所有详情。

## 2. 范围

本次只调整教师端学习资源生成入口和配置界面的信息架构、布局与交互：

- “学习资源生成”按钮打开模态弹窗。
- 弹窗提供章节折叠、紧凑知识点行、批量选择、状态摘要和固定操作栏。
- 单个知识点的三类资源详情按需展开。
- 保留现有生成、后台执行、进度查询、失败重试、预览和审核接口。
- 学生端已发布资源的阅读界面保持不变。

不调整资源类型、生成提示词、后端任务协议、审核规则和数据模型。

## 3. 弹窗结构

### 3.1 外层弹窗

- 点击“学习资源生成”后打开居中的模态弹窗，课程知识页不再向下增长。
- 桌面端宽度为视口的约 80%，最大宽度 1080px；最大高度为视口的 82%。
- 弹窗分为固定标题栏、可滚动内容区和固定底部操作栏。
- 标题栏显示“学习资源生成”、简短说明和关闭按钮。
- 内容滚动只发生在弹窗主体，标题、选择统计和提交按钮保持可见。
- 点击关闭按钮、按 Escape 或完成取消操作都可关闭弹窗；关闭后焦点返回入口按钮。
- 生成任务提交后允许关闭弹窗，后台任务继续运行。

### 3.2 章节与知识点列表

- 章节使用折叠分组，首次打开时只展开第一个章节。
- 章节标题显示章节名称、知识点数量和已选择数量。
- 每个知识点使用单行布局，包含复选框、知识点名称、简化路径、资源状态摘要和“查看详情”操作。
- 路径最多显示一行，超出时截断，并通过原生标题提示完整路径。
- 三类资源状态使用短标签或图标摘要展示，例如“课堂 未生成、指南 待审核、练习 已发布”。状态不能只依赖颜色区分。
- “全选当前章节”和“选择全部知识点”均可用；再次操作可取消对应范围的选择。

### 3.3 按需详情

- 默认不展示资源卡片。
- 点击某个知识点的“查看详情”后，仅在该知识点下方展开三类资源详情。
- 同一时间最多展开一个知识点详情；打开新的详情时自动收起先前详情。
- 详情继续提供现有的内容预览、批准发布、退回修改和版本提示。
- 收起详情不会改变当前选择状态。

### 3.4 固定操作栏

- 左侧持续显示“已选择 X 个知识点，将生成 Y 项资源”，其中 `Y = X × 3`。
- 右侧提供“取消”和“开始生成”按钮。
- 未选择知识点或正在提交时禁用“开始生成”。
- 提交成功后显示明确反馈，说明任务已进入后台；教师可以关闭弹窗并通过后台任务查看进度。
- 提交失败时保留选择结果，并在操作栏上方显示可读错误信息。

## 4. 组件边界与状态

- `CourseKnowledgeBuildCard` 只负责入口按钮和弹窗开关，不再承载长配置内容。
- `LearningResourceGenerationPanel` 调整为真正的模态弹窗外壳，负责标题、关闭、焦点管理和固定布局。
- `StandardLearningResources` 增加教师生成用的紧凑模式；学生只读模式保持现有呈现。
- 紧凑模式管理章节展开、当前详情知识点和知识点选择状态。
- 生成批次、轮询、重试和审核仍调用现有 API，不复制请求逻辑。
- 关闭弹窗会清理纯界面状态；已经提交的后台任务不被取消。

## 5. 响应式与可访问性

- 1440px 及以上保持最大宽度 1080px。
- 1024px 至 1439px 使用视口宽度减去安全边距，知识点状态标签允许紧凑换行。
- 720px 以下弹窗接近全屏，知识点行分为标题行与状态行，底部按钮仍保持可见。
- 弹窗使用可访问的 `dialog` 语义、焦点圈定、Escape 关闭和关闭后焦点恢复。
- 所有复选框都有可读标签；所有操作支持键盘访问并保留明显焦点样式。
- 正文保持足够对比度与 1.5 以上行高；长路径使用截断而不是横向滚动。
- 遵循 `prefers-reduced-motion`，不使用会造成布局位移的悬停动画。

## 6. 错误与后台任务状态

- 目录加载失败时在弹窗内容区显示错误和重试入口，固定操作栏保持可见但禁止提交。
- 批次提交失败时保留已选知识点，允许直接重试。
- 批次运行中显示紧凑进度条和成功、失败数量；失败项继续使用现有重试能力。
- 弹窗关闭不取消后台任务；再次打开时继续展示接口能够恢复的最新目录和资源状态。
- 审核失败只影响当前详情，错误信息显示在对应详情区域或弹窗顶部。

## 7. 测试与验收

- 点击入口打开模态弹窗，课程知识页高度不因配置内容增长。
- 弹窗标题、内容和底部操作栏在滚动时保持正确分区。
- 首次只展开第一个章节，其余章节折叠。
- 每个知识点默认只显示单行摘要，不呈现三张完整卡片。
- 同一时间最多展开一个知识点详情。
- 章节选择、全选、取消选择和底部数量计算正确。
- 提交后后台任务继续执行，关闭弹窗不会取消任务。
- 生成失败保留选择，审核和失败重试能力不回归。
- 学生只读资源页面保持原有内容和权限。
- 在 1440px、1024px 和窄屏尺寸验证无页面横向滚动，键盘焦点和 Escape 关闭正常。

## 8. 非目标

- 不新增资源类型或生成参数。
- 不改变每个知识点生成三类资源的规则。
- 不把资源生成改为同步请求。
- 不重做学生端资源阅读页面。
- 不修改课程知识树或知识库更新向导。
