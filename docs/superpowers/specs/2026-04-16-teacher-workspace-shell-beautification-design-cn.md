# 教师问答工作台整体美化设计

## 1. 设计目标

本次设计面向教师问答工作台的整体外壳升级，目标不是重做三栏内部功能，也不是引入新的复杂交互，而是在保留当前信息架构与业务流程的前提下，让页面更像一个成熟、稳定、可长期使用的教师工作台。

本次设计确认的核心目标如下：

1. 保留当前清晰的三栏式工作台结构，不改变左侧知识源、中间问答、右侧生成工坊的功能分工。
2. 让页面整体从“基本规整”提升为“更有专业感、更有秩序、更有主次”的现代工作台。
3. 强化顶部课程语境表达，使用户进入页面后能立即知道当前基于哪门课程、围绕哪个知识点开展工作。
4. 在视觉上让中间问答区更自然地成为主任务区域，同时让左右两栏保持清楚但不过度抢眼。
5. 控制改动边界，只做页面级整体美化，不下沉重做三栏内部深层布局。

## 2. 项目上下文

结合项目既有设计上下文，本次升级继续遵循以下原则：

- 用户是处在课程语境中的教师，而不是泛聊天用户。
- 界面应体现专业、可信、清晰、低认知负担。
- 整体风格应为浅色优先、结构稳定、工作台导向，而不是展示型 AI 界面。
- 课程语境优先于聊天语境。
- 重点是帮助教师组织知识、推进问答、沉淀产出，而不是强化视觉噱头。

## 3. 当前问题

当前页面已经完成第一轮基础整理，但仍存在以下问题：

1. 页面整体虽然更规整，但工作台气质仍然偏平，升级感不够明显。
2. 顶部上下文栏已出现，但更像信息条，尚未成为清晰的“课程工作语境锚点”。
3. 三栏虽然分工明确，但整体仍接近“三块并排容器”，主次关系不够稳定。
4. 中间问答区是实际主任务区，但外层衬托和聚焦力度仍然不足。
5. 页面背景、面板边界、阴影与留白层次还偏保守，没有把“专业工作台”感做起来。

## 4. 范围界定

### 4.1 本次范围

本次设计与实现只包含以下内容：

1. `AIWorkspace.tsx` 的页面级整体外壳美化。
2. `AiStudioPage.css` 的工作台通用样式升级。
3. 顶部上下文栏的质感优化。
4. 三栏主工作区的背景、外层容器、边界、阴影、留白、比例和主次关系优化。
5. 中间主区的聚焦增强。

### 4.2 不在本次范围

以下内容不纳入本轮：

1. `SourcePanel`、`ChatPanel`、`StudioPanel` 内部深层结构重排。
2. 三栏内部按钮组、筛选器、列表项、表单区的大改版。
3. 新的业务功能、新的工作流入口或新的状态中心。
4. 状态管理、接口调用或页面数据流的重构。

## 5. 目标体验

教师进入页面后，应先感知到这是一个明确处于课程上下文中的工作台，而不是普通聊天页。

理想体验如下：

1. 第一眼知道当前课程与当前知识点。
2. 第一层视觉感受是“专业、清晰、稳定”。
3. 第二层视觉关注自然落到中间问答区。
4. 左右两栏清晰可辨，但只作为支撑区而不是主角。
5. 页面整体更适合长时间使用，不依赖花哨效果制造“高级感”。

## 6. 设计方案

### 6.1 整体风格方向

本次采用“分层型工作台”方向：

1. 保留三栏清晰结构。
2. 通过背景层次、外层容器、上下节奏和边界精度建立更成熟的工作台观感。
3. 避免过度装饰、强玻璃感、强渐变和泛 AI 化视觉语言。
4. 用秩序感和主次关系体现升级，而不是用夸张视觉差异。

### 6.2 页面背景

页面背景调整为更克制的浅灰蓝中性色基底，但整体浓度很轻。

目标：

1. 让白色工作区更容易被识别出来。
2. 降低页面“纯白平铺”造成的单薄感。
3. 维持轻量、耐看的教学平台气质。

页面背景应体现微弱层次，而不是明显视觉装饰。

### 6.3 顶部上下文栏

顶部上下文栏保留极简原则，但需要更像“课程工作条”，而不只是普通白色信息条。

内容依旧只保留两项：

1. 当前课程
2. 当前知识点

设计要求：

1. 不加入资料数、对话数、产物数、RAG 状态、Web 状态等附加信息。
2. 不加入筛选、切换、管理类复杂操作。
3. 通过更稳的边界、更精确的留白和更清楚的信息权重，让这一栏成为页面顶部的语境锚点。
4. 当前课程的视觉权重高于当前知识点，但两者仍保持一体化阅读关系。

### 6.4 三栏关系

本次不把三栏融合成一个大壳，而是保留清楚的三栏结构。

但三栏的关系将从“并列三块”调整为“有主有辅的工作台”：

1. 中间栏是主工作区。
2. 左右栏是辅助区。
3. 三栏视觉语言统一，但视觉分量不完全相同。

设计要求：

1. 中间栏拥有最干净的背景对比和最稳的边界。
2. 左右栏保留清晰容器感，但存在感略低于中间栏。
3. 三栏间距、外层衬底和页面边缘留白需要统一节奏。

### 6.5 中间主区聚焦

中间聊天区的聚焦不依赖新增模块，而依赖外层关系优化。

主要通过以下手段实现：

1. 中间区域周边背景更干净。
2. 中间面板边界更明确。
3. 中间面板与左右栏之间形成更稳定的主次对比。
4. 外层包裹区让中间工作流更像页面的“工作现场”。

### 6.6 面板质感

三栏面板统一升级为更利落、更产品化的工作台容器。

具体方向：

1. 圆角适度收紧并统一。
2. 边框更轻，但需要更准确。
3. 阴影更浅、更柔和，避免漂浮感。
4. 面板外层与页面背景形成更自然的层级，不使用强模糊和玻璃拟态。

### 6.7 配色策略

本次色彩策略为“克制但不发灰”。

规则如下：

1. 以浅中性色为主体。
2. 保留现有蓝色作为主强调色，但缩小其使用范围。
3. 强调色只服务于关键交互、激活态和重要状态。
4. 避免整页大面积蓝紫渐变、发光或未来感配色。

### 6.8 留白与节奏

页面不靠大块空白制造高级感，而靠秩序感制造专业感。

重点处理：

1. 顶部上下文栏与三栏主区之间的垂直节奏。
2. 三栏之间的水平间距。
3. 页面四周边距与内容呼吸感。
4. 外层容器与面板内边距的比例关系。

## 7. 实现边界

建议实现主要落在以下文件：

- `Edu_AI/src/stitch/pages/AIWorkspace.tsx`
- `Edu_AI/src/pages/teacher/AiStudioPage.css`

其中：

1. `AIWorkspace.tsx` 负责页面级结构、顶部上下文栏与主区外层容器关系。
2. `AiStudioPage.css` 负责工作台的共享视觉语言，包括背景、上下文栏、三栏间距与面板样式。

除非为适配页面级样式必须增加极少量容器类名，否则不应扩大到三栏内部业务组件的大改。

## 8. 响应式原则

本次整体美化不能破坏现有响应式降级逻辑。

要求如下：

1. 桌面端继续保持三栏结构。
2. 中屏下仍优先保障中间主区的可用性。
3. 小屏下继续沿用当前“侧栏隐藏、中栏优先”的降级逻辑。
4. 顶部上下文栏在窄屏下允许换行，但不能变成信息堆叠区。

## 9. 验收标准

### 9.1 视觉验收

1. 页面整体观感比当前版本更成熟、更稳定。
2. 顶部上下文栏更像工作台语境条，而不是普通信息条。
3. 三栏仍然清晰分开，但中间主区聚焦更明显。
4. 页面背景、外层容器、边框、阴影和留白形成清楚层次。
5. 整体更像教学工作台，而不是通用聊天页。

### 9.2 行为验收

1. 左右栏折叠与展开不受影响。
2. 预览态引发的栏宽变化不受影响。
3. 小屏降级行为不受影响。
4. 顶部上下文缺省时页面仍可正常工作。

### 9.3 回归关注点

1. 页面级样式调整不能破坏 `SourcePanel`、`ChatPanel`、`StudioPanel` 的既有功能。
2. 文本在长课程名和长知识点名场景下不能溢出遮挡。
3. 外层容器和面板高度关系不能破坏现有滚动逻辑。

## 10. 成功标准

本轮完成后，应达到以下结果：

1. 教师进入页面后会先明确课程语境，再进入工作流。
2. 页面整体从“已规整”提升到“有专业工作台质感”。
3. 中间问答区成为更自然的页面视觉中心。
4. 三栏结构仍然清楚，不因统一风格而失去辨识度。
5. 本轮改动范围仍然克制，为后续三栏内部精细化优化保留空间。
