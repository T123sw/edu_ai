日期：2026-09-07｜状态：A 已实施，前端模拟 API 验收通过；真实后端及组合验收待 B 执行。

先读[并行执行约定](../plans/2026-09-07-frontend-experience-parallel-handoff-cn.md)。配套：[计划](../plans/2026-09-07-home-resume-plan-cn.md)、[验收](../acceptance/2026-09-07-home-resume-acceptance-cn.md)。

## 目标与确认要求

首页最上端直接显示上次使用的课程名称，配一个“继续备课”或“继续学习”按钮。保持紧凑，不做大型卡片、统计或待办列表。课程名称不能只在 tooltip 中出现。

```text
上次备课：数据结构 · 数组                   [继续备课 →]
上次学习：数据结构 · 数组                   [继续学习 →]
```

两行分别出现在师生端；知识点为有真实记录时的次要信息，课程名称必需。小屏可以自然换行，但只有一个继续操作。

## 本轮实施决策

以下是为可执行性确定的工程默认值，不是已存在能力：

- 本设备持久化，按认证主体和角色隔离，不增加跨设备同步接口。
- 恢复到最近成功进入的课程工作页面，并保留已经由该页面支持的知识点、资料等定位参数。
- 对话恢复仅使用已有有效的会话恢复能力；不承诺恢复未发送文字、未保存编辑、播放秒数或新增后端会话能力。
- 没有记录时隐藏入口。课程已删除／失权时清除失效记录并隐藏。
- 课程有效而资料或知识点已删除时，降级到同课程工作入口，明确提示原位置不可用；不能打开其他同名资料。
- 网络失败不等于失权：保留记录，提供简洁重试状态，不用一次失败清空历史。
- 退出账号不泄露上一账号名称；旧无账号归属的历史记录不自动导入新账号。

## 页面与状态

教师主页 `HomeDashboard.tsx`：主内容首项放紧凑 ResumeEntry，再呈现现有课程列表。
学生主页 `StudentHome.tsx`：同样置顶，移除重复的旧“最近学习”展示；加入课程等内容保持原功能。

入口状态：无记录 → 隐藏；验证中 → 紧凑加载态；有效 → 名称＋按钮；临时读取失败 → 重试；明确失效 → 清理／降级。

“课程名称”使用当前有权访问的课程元数据，不能以 localStorage 中缓存的名字作为可信数据。

## 位置记录契约

建议新增独立模块 `frontend/src/stitch/resume/`，导出读取、记录、校验和解析函数，以及 ResumeEntry、ResumeTracker。

```ts
type ResumeRecord = {
  version: 1;
  courseId: string;
  route: string;
  scopeId?: string;
  materialId?: string;
  materialType?: string;
  conversationId?: string;
  visitedAt: string;
};
```

账号键由已验证用户身份＋角色确定；若现有会话仅有 username，则将其作为当前系统账号键，不新增或猜测用户 ID。不存 token、聊天正文或任意 URL。字段名属于建议内部结构，可按现有路由适配，外部 hash 继续遵循已有 course_id、scopeType、scopeId 等参数。

- 只保存允许的师生业务路由和受支持的定位参数；通过现有 roleRouteResolver／路由构造器生成目标，不重放任意 hash。
- 首页、登录、设置、开发页、临时弹窗等不更新记录。
- 等课程权限与目标加载成功后记录，失败访问不能覆盖有效位置。
- 切换知识点时即使路由名不变也应更新记录。
- storage 不可用或内容损坏时应用仍能正常工作。

## 边界与非目标

不重构认证体系，不修改知识点语义，不新增 Agent 修改逻辑。恢复知识点后由 Agent B 的范围解析接管；不要维护第二套知识点状态。

## 完成定义

师生两个入口、账号隔离、真实课程名称、有效定位恢复及失效处理均完成，并满足配套验收。只有教师端或只有按钮外观不算交付。


## 实现补充

实际记录使用 `version/courseId/route/params/visitedAt`；`params` 按页面限定白名单，知识点名称不持久化。超长课程名最多显示两行，完整文本保留在可访问内容及标题属性中。课堂现有 `replaceState` 写入同样被跟踪，恢复时将现有 `teacher-classroom-studio` 写入规范化为 App 支持的 `classroom-studio`。

知识目录树的内部选中项尚无可靠 URL 恢复协议，本次仅恢复知识目录页面；知识点精确恢复支持 AI 工作区的 `scopeType/scopeId`，课堂目录支持 `node_id/resource_id`。资料页支持 `material_type/material_id`。不新增会话、未保存输入或播放进度恢复能力。完整交接见配套验收文档。
