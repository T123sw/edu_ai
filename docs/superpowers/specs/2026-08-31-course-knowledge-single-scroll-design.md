# 课程知识页单一滚动容器设计

## 背景

课程知识页右侧内容区已经设置纵向滚动，但课程知识库文档列表又使用 `flex: 1` 和 `overflow-y: auto` 创建了第二个滚动容器。课程资料数量增加后，文档列表只能占用剩余高度，最终被压缩到几乎不可见。

## 目标

- 课程资料和课程知识库共用右侧内容区的一条纵向滚动条。
- 课程资料按实际内容高度展示。
- 课程知识库在课程资料后自然排布，不再被剩余高度压缩。
- 保持左侧知识节点列表的独立滚动方式不变。
- 保持窄屏布局行为不变。

## 方案

保留 `.knowledge-library__content` 作为右侧唯一纵向滚动容器。移除 `.knowledge-library__documents` 的伸展和内部纵向滚动能力，使文档列表恢复普通文档流：

```css
.knowledge-library__content {
  overflow-y: auto;
}

.knowledge-library__documents {
  flex: none;
  overflow-y: visible;
}
```

课程资料区、知识库标题栏和文档列表均成为同一滚动内容的一部分。上传按钮随知识库标题栏正常滚动，不新增悬浮或折叠行为。

## 测试

- 增加样式回归断言，确认右侧内容区保留 `overflow-y: auto`。
- 增加样式回归断言，确认文档列表使用 `flex: none` 和 `overflow-y: visible`。
- 运行课程知识页浏览器回归，确认桌面与窄屏布局没有横向溢出或入口丢失。

## 非目标

- 不调整课程资料行高或默认折叠状态。
- 不修改知识节点树的滚动方式。
- 不改变资料上传、预览、删除或审核功能。
