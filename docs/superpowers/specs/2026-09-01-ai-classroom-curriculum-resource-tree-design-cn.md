# AI 课堂课程目录化、教师审核发布与学生学习进度设计

日期：2026-09-01

状态：已实现并通过自动化验收

## 1. 背景

当前课程工作区将“AI课堂”“课程知识”“资源管理”和“学习任务”拆成多个入口。AI 课堂页面主要围绕“创建课堂”和“已生成课件列表”组织，标准学习资源则分散在课程知识页面中。教师需要跨页面完成资源查看、审核和发布，学生也缺少一个能够沿课程目录连续学习的稳定入口。

本次改造把“AI课堂”从平铺课件列表升级为课程目录式学习空间：左侧展示按章节、小节展开的课程目录，每个叶子知识点下面直接列出与该节点关联的 AI 课堂、报告或学习指南、文档和练习；右侧展示当前选中的节点或资源。

教师和学生消费同一棵课程资源树，但承担不同任务：

- 教师查看全部资源版本，完成预览、审核和发布；
- 学生只查看已发布版本，完成学习并查看个人学习进度。

## 2. 已确认的产品决策

1. AI 课堂页面以课程目录为一级组织方式，不再以课件生成时间或资源平铺列表为一级结构。
2. 章节、小节和叶子知识点沿用课程知识图谱的层级和稳定节点 ID，不另建一套人工目录。
3. 每个叶子节点下面挂载该节点的学习资料，资源属于知识节点，不直接属于页面栏目。
4. 教师端和学生端共用同一目录及资源关联关系，不复制两套数据。
5. 教师端目录表达资源生产状态，核心操作是预览、批准发布和退回修改。
6. 学生端目录表达个人学习状态，只显示当前已发布版本。
7. 点击 AI 课堂或教学视频进入现有互动课堂播放器；点击文档、报告或学习指南在当前页面直接预览；点击练习在当前页面进入作答视图。
8. 第一阶段沿用现有“审核通过即形成学生可见发布版本”的原子操作，界面统一称为“批准并发布”。
9. 已发布版本存在新草稿或待审核版本时，学生继续学习旧的已发布版本，直到新版本批准发布。
10. 资源进度按资源版本保存；目录中的小节和课程进度是对当前已发布资源的汇总，不覆盖资源级原始证据。

## 3. 目标与非目标

### 3.1 目标

- 为教师和学生提供一致、可理解的课程目录式资源入口。
- 让教师不离开目录上下文即可找到待审核资源、预览内容并完成发布。
- 让学生清楚看到“学到哪里、这一节有哪些材料、哪些已经完成”。
- 复用现有标准资源、审核接口、已发布版本、AI 课堂播放器和版本化学习记录。
- 消除 AI 课堂页、课程知识页中标准学习资源的重复展示和入口歧义。
- 保留深链接，使学习任务、通知或分析页面能够直接定位到具体知识节点和资源。

### 3.2 非目标

- 不重做 AI 课堂播放器、实时问答、LessonTimeline 或课堂导出能力。
- 不把课堂练习升级为正式考试，也不改变正式测评的评分和复核规则。
- 不在第一阶段增加定时发布、多人会签、审批流配置或已发布版本撤回。
- 不用页面停留时长推断学生已经读懂文档。
- 不把教师审核状态和学生学习状态合并为同一状态字段。
- 不移除独立“学习任务”领域；任务仍可引用课程资源及其版本化学习证据。

## 4. 方案比较与选择

### 4.1 方案 A：统一课程资源树，按角色投影不同状态（采用）

课程知识目录作为唯一骨架，资源挂在叶子节点下。教师查询返回全部可管理资源及审核状态；学生查询只返回已发布版本并附带本人进度。

优点：数据一致、不会产生目录漂移，能够复用现有标准资源目录和权限体系；教师与学生讨论“1.1 节的练习”时指向同一对象。缺点：前端需要将审核、预览、播放器跳转和进度汇总整合到一个页面状态模型中。

### 4.2 方案 B：教师审核页与学生学习页分别维护目录

教师继续使用资源管理或课程知识页面，学生新建独立学习目录页。

优点：改动局部。缺点：两套目录和资源排序容易不一致，教师难以准确预览学生看到的结构，也不能满足“把审核功能拿过来”的目标。

### 4.3 方案 C：保留平铺 AI 课堂列表，只增加章节筛选

在现有 AI 课堂页上增加章节筛选器，不把资料真正放入目录节点。

优点：实现成本较低。缺点：目录仍不是学习主线，文档和练习继续分散，无法形成完整课程学习空间。

因此采用方案 A。

## 5. 信息架构

```text
课程工作区
└─ AI课堂
   ├─ 左侧：课程资源目录
   │  ├─ 第一章
   │  │  ├─ 1.1 小节
   │  │  │  ├─ AI课堂 / 教学视频
   │  │  │  ├─ 学习指南 / 报告 / 文档
   │  │  │  └─ 练习
   │  │  └─ 1.2 小节
   │  └─ 第二章
   └─ 右侧：节点概览或资源内容
      ├─ AI课堂入口与摘要
      ├─ 文档预览器
      ├─ 练习作答器
      └─ 教师审核区 / 学生进度区
```

页面继续使用现有课程顶部导航，“AI课堂”是课程资源学习的规范入口。课程知识页专注知识库、教材和知识结构，不再为学生重复渲染完整标准学习资源目录。学习任务中的资源链接也跳转到该入口并自动定位资源。

## 6. 页面布局

### 6.1 桌面端

页面使用左右双栏布局：

- 左栏宽度使用 `clamp(300px, 28vw, 420px)`，是可独立滚动的大目录；
- 右栏占据剩余空间，是主要预览和操作区；
- 页面顶部保留紧凑工具栏，显示课程资源概况、搜索和教师操作；
- 右栏内容滚动不改变左栏当前选中项；
- 刷新或从播放器返回后恢复上次选中的节点与资源。

示意：

```text
┌──────────────────────────────────────────────────────────────┐
│ AI课堂          搜索课程资料                 [生成学习资源] │
├───────────────────┬──────────────────────────────────────────┤
│ 第一章            │ 1.1 节 · 课程导论                        │
│  ▾ 1.1 课程导论   │                                          │
│    ▶ AI课堂       │ 当前资源标题                             │
│    ▤ 学习指南     │ 资源预览 / 课堂入口 / 练习作答           │
│    ✓ 练习         │                                          │
│  ▸ 1.2 基础概念   │ 教师：审核与发布                         │
│ 第二章            │ 学生：学习状态与继续学习                 │
└───────────────────┴──────────────────────────────────────────┘
```

### 6.2 小屏端

- 目录变为页面顶部的“课程目录”抽屉；
- 选择资源后自动关闭抽屉并展示内容；
- 当前路径以面包屑保留在内容区顶部；
- 教师审核操作固定在内容底部安全区，但不得遮挡正文；
- 返回操作优先回到原目录位置，而不是课程首页。

## 7. 左侧目录行为

### 7.1 层级与展开

- 目录按知识图谱顺序展示章、节和叶子知识点。
- 叶子节点展开后展示资源；没有资源的节点仍可见，教师看到“尚未生成”，学生看到“暂无已发布资料”。
- 默认展开当前选中资源的祖先路径。
- 首次进入时展开第一章，但不自动启动视频或练习。
- 目录支持按资源标题和知识节点标题搜索；搜索结果保留完整路径，避免同名小节无法区分。

### 7.2 教师目录状态

教师看到全部标准资源槽位和已有版本：

- `未生成`
- `生成中`
- `待审核`
- `已发布`
- `已退回`
- `生成失败`
- `已发布 · 有新版本待审核`

章节和小节显示状态汇总，例如“待审核 2 · 已发布 4”。状态必须使用文字或文字加图标，不能只依赖颜色。

### 7.3 学生目录状态

学生只看到已发布资源，并看到本人对已发布版本的学习状态：

- `未开始`
- `学习中`
- `已完成`
- `待同步`

小节显示“已完成 2/3”，课程顶部显示“已完成 8/12”。该数字称为“学习覆盖”，不包装成知识掌握率或综合得分。

## 8. 右侧内容区

### 8.1 未选择资源

选择章节或小节但未选择资源时，右侧显示节点概览：

- 节点标题和完整目录路径；
- 本节资料数量及类型；
- 教师：待审核数量、最近更新和“生成学习资源”入口；
- 学生：完成数量、最近学习资源和“继续学习”入口。

### 8.2 AI 课堂或教学视频

- 点击资源后，右侧先显示课堂标题、场景数、版本、简介和学习或审核状态；
- 学生点击“开始学习/继续学习”后进入现有全屏互动课堂播放器；
- 教师点击“预览课堂”进入同一播放器，但预览行为不得写入学生学习进度；
- 播放器返回地址携带节点和资源定位参数，以恢复目录上下文；
- 若资源包含导出的 MP4，它仍是同一 AI 课堂版本的附属产物，不另建重复资源节点。

### 8.3 报告、学习指南和文档

- Markdown、结构化报告和纯文本在右侧直接渲染；
- PDF 使用内嵌预览；浏览器无法预览时提供明确的“下载查看”；
- DOCX 优先使用服务端转换后的安全预览，不在客户端执行不受信任脚本；
- 内容区保留目录标题、资源版本和更新时间；
- 学生打开资源后记为“学习中”，由学生明确点击“完成阅读”形成完成事实，不按停留时长自动完成。

### 8.4 练习

- 练习在右侧显示题目、提交状态和学习反馈；
- 学生第一次有效提交后进入“学习中”；
- 所有必答题至少提交一次后资源标记为“已完成”；
- 正确率单独显示，不作为资源完成门槛；
- 教师预览时可以查看题目和答案配置，但不产生学生作答记录。

### 8.5 不支持的资源类型

右侧显示资源标题、类型、版本和安全下载入口。不得因为预览器不支持而隐藏已发布资源，也不得把下载成功误记为学习完成。

## 9. 教师审核与发布

### 9.1 审核入口

教师选择待审核资源后，在内容区顶部看到状态，在内容区底部看到审核操作：

- `批准并发布`
- `退回修改`

退回修改必须填写简短原因；批准发布可填写可选说明。提交期间禁用重复操作。

### 9.2 原子发布规则

第一阶段沿用现有标准资源审核语义：

```text
待审核版本
  ├─ 批准并发布 -> 冻结 approved_version -> 学生可见
  └─ 退回修改   -> 标记 rejected       -> 学生不可见
```

批准操作必须在服务端事务内同时完成：

1. 校验教师课程管理权限；
2. 校验提交版本仍是当前待审核版本；
3. 对 AI 课堂编译并冻结版本化学习清单；
4. 更新 `approved_version`；
5. 记录审核人、时间和决定；
6. 使学生目录读取到新的已发布版本。

### 9.3 新旧版本并存

- 已发布 v2、当前待审核 v3 时，教师默认预览 v3，并可切换查看 v2；
- 学生继续读取 v2，学习进度不会被 v3 草稿影响；
- v3 批准发布后，新学习会话读取 v3；v2 的历史学习证据保留；
- 目录不得只显示“已发布”而隐藏存在待审核新版本的事实。

### 9.4 生成入口

教师保留“生成学习资源”能力，但它从页面主角变为目录上下文操作：

- 页面工具栏可批量选择叶子节点生成标准资源；
- 小节概览可对当前节点发起生成或失败重试；
- 学生不显示生成、重试、审核和版本切换入口；
- 生成任务继续使用现有后台任务与轮询机制。

## 10. 学生学习进度

### 10.1 资源级口径

| 资源类型 | 开始条件 | 完成条件 | 版本隔离 |
| --- | --- | --- | --- |
| AI课堂 | 产生有效播放、作答或演示行为 | 普通讲解覆盖不低于 80%，且全部必答题已提交 | 是 |
| 报告/指南/文档 | 首次成功打开可读内容 | 学生点击“完成阅读”并由服务端记录 | 是 |
| 练习 | 首次有效提交 | 全部必答题至少提交一次 | 是 |
| 仅下载资源 | 首次打开或下载记为已开始 | 默认不自动完成；需显式完成动作 | 是 |

资源完成只表示完成规定学习行为，不表示正确、通过、掌握或获得成绩。

### 10.2 小节与课程汇总

```text
当前已发布资源数 = 学生当前可见的资源版本数量
已完成资源数     = 其中本人状态为 completed 的资源数量
学习覆盖         = 已完成资源数 / 当前已发布资源数
```

- 没有已发布资源的小节显示“暂无资料”，不显示 0%。
- 资源发布新版本后，旧版本证据继续保留，但新版本需要重新形成完成事实。
- 教师新增资源后，小节的“已完成 x/y”分母会增加；这表示当前课程内容覆盖变化，不代表历史学习记录回退。
- 汇总只用于导航提示，不替代资源级的讲解覆盖、题目提交、正确率和完成时间。

### 10.3 继续学习

“继续学习”按以下顺序选择：

1. 最近一次处于学习中的资源；
2. 当前小节第一个未开始资源；
3. 后续小节第一个未开始资源；
4. 全部完成时返回课程完成概览。

系统只选择目标，不自动播放媒体或自动提交练习。

## 11. 路由与页面状态

AI 课堂页面使用可复制的深链接参数：

```text
#teacher-classroom-studio?course_id=<courseId>&node_id=<nodeId>&resource_id=<resourceId>
#student-classroom?course_id=<courseId>&node_id=<nodeId>&resource_id=<resourceId>
```

要求：

- `node_id` 和 `resource_id` 合法时直接展开并选中目标；
- 资源属于其他节点或课程时拒绝定位，不泄露标题；
- 学生访问未发布版本时返回目录并提示“该资料尚未发布或已更新”；
- 只有 `node_id` 时打开节点概览；
- 没有定位参数时恢复本地最近选择，无法恢复则显示课程概览；
- 学习任务、通知和教师分析统一构造该深链接，不再跳到旧的重复资源视图。

## 12. 前端组件边界

建议将现有 `ClassroomStudioPage` 从生成页拆成以下职责明确的组件：

| 组件 | 单一职责 |
| --- | --- |
| `CourseClassroomCatalogPage` | 加载目录读模型、解析路由选择、协调角色视图 |
| `CurriculumResourceTree` | 展示章、节、资源和状态摘要，不加载资源正文 |
| `CurriculumNodeOverview` | 展示所选节点的资源与进度或审核概览 |
| `CourseResourceViewer` | 按资源类型分发到课堂、文档或练习视图 |
| `TeacherResourceReviewPanel` | 版本切换、审核提交和反馈 |
| `StudentResourceProgressPanel` | 展示资源级进度、同步状态和继续学习动作 |
| `CourseResourceGenerationDialog` | 复用现有标准资源批量生成和重试能力 |
| `courseResourcePresentation` | 集中处理状态文案、图标、排序和深链接构造 |

`CurriculumResourceTree` 不直接调用审核或学习接口；它只消费已经组合好的目录读模型并发出选择事件。审核、预览和学习进度分别由独立组件管理，避免一个页面同时承担目录、内容解析、业务写入和统计计算。

## 13. 服务端读模型与接口

### 13.1 复用能力

现有能力继续作为事实来源：

- 标准资源目录与叶子节点关联；
- `current_version`、`approved_version` 和 `review_status`；
- 标准资源审核接口；
- AI 课堂版本化 `ResourceLearningManifest`；
- 学生资源学习进度和教师资源学习分析；
- 课程角色与 owner/editor 权限。

### 13.2 目录读模型

建议提供角色安全的聚合接口，避免前端自行拼接多个接口后产生短暂越权或状态不一致：

```text
GET /api/courses/{course_id}/classroom-catalog
```

教师返回：

- 完整知识目录；
- 每个叶子节点的资源槽位；
- 当前版本、已发布版本和审核状态；
- 生成任务摘要；
- 节点级待审核和已发布数量。

学生返回：

- 完整可导航目录；
- 仅已发布资源版本；
- 本人资源级学习进度；
- 节点级已完成数量和当前已发布总数。

学生响应不得先返回未发布资源再由前端隐藏。教师进度分析也不得混入学生目录响应。

### 13.3 通用非课堂资源进度

现有 AI 课堂学习记录继续使用精细时间线证据。报告、文档和练习增加轻量版本化资源进度，但不得伪造时间线百分比：

```text
student_id + course_id + resource_id + resource_version
  -> status: not_started | in_progress | completed
  -> completion_basis: explicit_read | required_questions_submitted
  -> started_at
  -> completed_at
  -> last_activity_at
```

完成写入由类型化接口校验；客户端不能直接提交任意完成百分比。

## 14. 数据流

### 14.1 教师批准发布

```text
选择待审核资源
  -> 加载当前版本完整预览
  -> 教师点击“批准并发布”
  -> 服务端校验角色与版本
  -> 冻结发布版本及学习清单
  -> 刷新目录读模型
  -> 教师目录显示已发布
  -> 学生目录开始返回该版本
```

### 14.2 学生学习

```text
打开 AI课堂目录
  -> 服务端只返回已发布版本 + 本人进度
  -> 选择资源
  -> 按类型进入课堂、预览或练习
  -> 写入版本化学习事实
  -> 服务端投影资源状态
  -> 刷新资源、小节与课程学习覆盖
```

## 15. 权限与安全

- owner/editor 可以生成、预览、审核和查看本课程资源分析；viewer 权限按现有课程权限策略只读。
- 学生只能读取课程中当前已发布资源，并且只能读取和写入自己的学习记录。
- 教师预览不得创建学生学习会话或污染课程完成统计。
- 学生不能通过修改 URL 读取待审核、已退回或其他课程资源。
- 文档预览必须清理不受信任 HTML，禁用内联脚本和危险 URL 协议。
- 审核提交必须包含被审核版本，防止教师在旧页面上误批准后来生成的新版本。
- 所有写操作保持幂等；刷新、重复点击或网络重试不能重复发布或重复累计进度。

## 16. 加载、空状态与错误处理

### 16.1 加载

- 首次加载展示与目录层级相近的骨架，不闪现空目录。
- 切换节点不清空整个页面，只让右侧内容区进入加载状态。
- 学习进度加载失败时仍允许访问已发布资源，但明确显示“进度暂时无法同步”。

### 16.2 空状态

- 教师无知识目录：提示先完成课程知识构建，不显示无效生成按钮。
- 教师节点无资源：显示资源槽位和生成入口。
- 学生课程无已发布资源：显示“教师尚未发布学习资料”，不暴露待审核数量。
- 搜索无结果：保留搜索词并提供清除操作。

### 16.3 错误

- 审核版本冲突：刷新当前资源，提示版本已经变化，要求重新预览后操作。
- 审核失败：保留预览和退回原因，允许重试。
- 文档预览失败：降级为下载入口，不把失败记为完成。
- 播放器资源不存在：返回目录并保留节点上下文。
- 进度补传失败：显示“待同步”，本地保留幂等事件，恢复后补传。
- 目录部分节点异常：隔离到对应节点，不阻断其他章节学习。

## 17. 可访问性与视觉约束

- 目录使用树形导航语义，章节展开按钮提供 `aria-expanded`；选中资源提供 `aria-current` 或等价可感知状态。
- 目录、内容区和审核操作都可通过键盘完成。
- 状态不只使用颜色，至少包含简短文字。
- 焦点进入全屏课堂并返回后，应回到原资源项。
- 长标题允许换行，不以省略号隐藏唯一辨识信息；必要时显示完整路径。
- 动画只用于展开和状态反馈，并尊重减少动态效果设置。

## 18. 兼容与迁移

1. 现有标准资源的 `leaf_id`、三类资源槽位和版本信息直接生成新目录读模型，不迁移内容本体。
2. 现有 AI 课堂已发布版本及学习进度继续有效。
3. 原 AI 课堂平铺列表入口改为新目录页；旧深链接仍能进入播放器。
4. 课程知识页中的学生标准资源列表移除后，旧定位链接重定向到新 AI 课堂目录。
5. 独立资源管理继续管理个人资源和课程共享范围，不与“按知识节点学习”的入口重复。
6. 学习任务保持独立；任务引用资源时跳到新目录并继续复用同版本学习证据。

## 19. 测试策略

### 19.1 单元测试

- 知识目录到章、节、资源树的稳定转换与排序。
- 教师审核状态和学生学习状态文案映射。
- 学生目录过滤未发布版本。
- 小节与课程学习覆盖的零资源、增量发布和版本更新口径。
- 深链接解析、非法资源拒绝和返回位置恢复。
- 各资源类型到播放器、预览器和练习器的分发。

### 19.2 组件测试

- 目录展开、折叠、搜索、选择和键盘导航。
- 教师能够预览待审核资源并批准或退回。
- 审核按钮不会触发课堂跳转，重复提交被禁用。
- 学生看不到生成、审核、版本切换和教师分析。
- 文档预览、显式完成阅读和练习全部提交后的状态刷新。
- 教师课堂预览不产生学生学习进度。

### 19.3 服务与权限测试

- 教师与学生目录响应字段和资源范围隔离。
- 学生直接访问待审核、已退回或跨课程资源时被拒绝。
- 审核时版本冲突、幂等重试和事务一致性。
- 新版本发布后旧版本证据保留、学生读取切换正确。
- 非课堂资源完成依据由服务端校验，客户端不能伪造百分比。

### 19.4 端到端验收

1. 教师进入 AI 课堂后看到按课程章节展开的目录，而不是平铺课件列表。
2. 1.1 节下面同时展示 AI 课堂、学习指南和练习，并可继续扩展报告或文档类型。
3. 教师点击待审核 AI 课堂能进入预览，返回后仍定位在 1.1 节。
4. 教师批准并发布资源后，状态立即变为已发布，学生刷新后可见。
5. 教师退回资源并填写原因后，学生不可见该版本。
6. 已发布 v2 且 v3 待审核时，学生继续学习 v2，教师明确看到版本并存状态。
7. 学生点击 AI 课堂进入现有互动播放器，学习进度按版本持续保存。
8. 学生点击文档直接预览，打开后为学习中，显式完成阅读后为已完成。
9. 学生完成练习全部必答题后为已完成，答错不阻止形成学习完成事实。
10. 学生目录显示资源、小节和课程覆盖，且不把覆盖描述为掌握率。
11. 学习任务中的资源链接能够直接定位到目录节点和资源。
12. 刷新、重新登录、小屏切换和短暂断网后，选择位置与已持久化进度保持一致。

## 21. 建议实施分片

## 22. 完成定义

只有满足以下全部条件，才能宣称本次改造完成：

1. AI 课堂首页已经由平铺列表改为课程目录式资源空间。
2. 教师能够沿目录完成资源预览、审核和发布，不需要跳转到课程知识页寻找审核入口。
3. 学生只看到已发布资源，并能沿同一目录查看本人资源级和节点级学习状态。
4. AI 课堂、文档和练习都进入符合其类型的学习体验。
5. 新旧资源版本、教师审核状态和学生学习状态在数据及 UI 中保持隔离。
6. 学习任务、资源管理和课程知识页面与新入口职责清晰，没有重复主入口。
7. 权限、幂等、刷新恢复、错误降级、响应式和可访问性通过自动化与真实端到端验证。
8. 现有 AI 课堂播放、实时问答、PPTX/视频导出、正式测评和学习证据链路无 P0/P1 回归。
