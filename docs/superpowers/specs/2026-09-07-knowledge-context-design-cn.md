## 不可改变的产品规则

课程按知识点组织。用户处于“数据结构 › 数组”时说“为当前课程生成资料／报告”，默认围绕“数组”生成，课程名称表达归属。不得因为出现“课程”二字就扩展为整门课程。

当前知识点缺失、失效、无法唯一定位或意图不明确时，Agent 必须澄清，用户回答前不得启动该生成任务。目标明确时直接继续，避免重复确认。显式整门课程／跨知识点请求应独立识别；范围不清时仍先澄清。

## UI 设计

```text
当前讨论：数据结构 › 数组                     切换
当前讨论：数据结构 › 尚未选择知识点           选择知识点
```

- 放在工作台对话区域上方，课程名和知识点直接可见。
- 切换器使用当前课程知识点树和搜索；同名节点展示章节路径。
- 从知识点入口进入自动带入；首页继续入口恢复的 scopeId 走相同解析。
- 选择知识点表达讨论范围，与左栏勾选来源文档是两个不同概念，不能由勾选文档隐式改写知识点。
- 用户要求“换到链表”且唯一定位时同步界面；临时指定另一个对象不永久改默认范围。
- 无知识点时仍可浏览和普通聊天；仅依赖明确范围的工作进入澄清，不把所有聊天都禁用。

## 可信上下文

沿用现有 `course_id`、`scope_type`、`scope_id`，URL 使用现有 workspaceScope 解析器。服务端依认证身份查课程和知识图谱，解析有效知识点及路径。客户端 scopeLabel 只作展示提示，不能作为事实来源。

建议 B 提供独立的上下文模块，向 Agent 及 C 暴露以下语义（内部名称可适配，字段含义固定）：

```text
ResolvedWorkspaceContext
  course_id, course_title
  scope_type, scope_id, scope_title, scope_path
  resolution: resolved | needs_clarification | invalid
```

`course` 是已有协议中的状态，不等于用户已明确要求整门课程。需要解析用户本轮意图后决定能否执行。

上下文必须贯穿：请求规范化 → 服务端校验 → 当前主运行时／工具配置 → 检索与生成参数 → 保存归属 → 返回界面。不能只在聊天文字前拼一句课程名称。

显式来源文档选择保留原 source_mode 语义；知识点上下文决定主题与归属，不能把个人资料选中误当成切换课程。若来源与任务范围冲突且影响意图，应澄清。

## 澄清状态

```text
收到请求 → 解析可信范围及本轮意图
          ├─ 明确 → 执行
          ├─ 不明确 → awaiting_clarification → 用户补充 → 重新校验 → 执行
          └─ 无权／失效 → 明确错误，不执行
```

澄清保留原问题、操作类型、候选范围、选中来源和必要引用，按认证主体＋会话绑定。补充“数组”时，继续原先的报告生成请求，不把它当成普通百科问答。

选择项由用户有权访问的知识点生成，提供节点路径；亦接受自由文本。选择项数量适中，可搜索更多。相同名不能擅自选第一个。

语义上需要响应 `needs_clarification`、问题、候选对象及待处理操作标识。优先映射已有响应／事件结构；确需新增字段，由 B 维护前后端一致的类型，并为旧响应保留兼容解析。此处状态名是目标契约，不声称现有 API 已提供。

## 切换及异步隔离

- 请求发出时冻结课程、知识点、会话和引用快照。
- 切换后清理不兼容的选中资料和待操作引用；旧任务继续属于原范围，其迟到结果不得替换当前范围。
- 用户切换范围期间有待澄清任务时，取消旧待操作并提示，或让用户明确恢复原操作；不可自动迁入新课程。
- 不只依赖提示词：执行生成／保存工具前再次校验范围，缺失应停止并转澄清。

## 与资料修改的区别

C 已唯一定位且用户有权修改的资料，其原始课程／知识点／版本是修改目标。不能因当前页面未选知识点就重复追问已确定资料，也不能把已确定报告迁移到当前页面的另一个知识点。

C 在确定目标之前缺少范围时可使用 B 的澄清能力。一次请求只保留一个待处理操作；B 负责统一调度，避免范围澄清和修改澄清各跑一遍。

## 既有代码线索

`workspaceScope.ts`、`AIWorkspace.tsx`、`ChatPanel.tsx`、`services/teacher/chatV2.ts` 已有 scope 参数；后端 `request_normalizer.py`、`context_builder.py`、`react_agent.py` 及 generation context 模块需核对真实主调用链。生成工厂的 scope 透传也须检查，不能遗漏按钮入口。

## 非目标

不进行页面整体改版、认证重构、知识图谱算法变更；不修改 A 的历史记录模块，不实现 C 的版本存储。B 负责共享入口集成与最终组合回归。
