# 自主学习前端 V1

依据本轮用户确认的简化方案实施，取代 docs/README.md 中独立路线确认页、全局任务入口和综合资源库的旧提议。

## 范围

- 首页是课堂入口：品牌、大输入框、最近课堂、共享课堂。提交需求直接进入课堂，无独立路线确认步骤。
- 课堂为三栏：按学习顺序组织生成资源的目录、内容阅读/播放区域、知道学习位置的 Agent。
- 工作台为次级制作空间：额外资源生成、课程知识来源、后台任务控制。只有这里出现任务列表、取消和重试。
- 资源中心只存储工作台生成的资源，支持筛选、查看、重命名、下载、删除。
- 师生共用全部学习页面。学生不出现学习文件上传；教师拥有共享课堂上传发布入口。
- 不出现学习任务、班级、课程码和学生分析等旧产品入口。

## 交互阶段边界

保留真实登录，开发环境额外提供显式交互预览，不伪造业务 token。新业务数据通过独立本地模型驱动；页面明确标注本地演示，生成、检索、Agent 和发布均不声称已接后端。视频使用可播放的分镜演示，不冒充真实生成视频。

学习状态按账号隔离并持久化到浏览器；共享内容单独保存，学习时创建个人状态。内容切换使用 URL，浏览器前进后退有效。对话记录绑定原资源，异步回答不改变当前资源。工作台资源与课堂资源分开。网络和存储失败不能伪装为服务端保存成功。
