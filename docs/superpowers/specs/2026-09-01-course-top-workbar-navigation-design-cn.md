# 课程顶部工作栏导航设计

日期：2026-09-01  
状态：已完成方案讨论，待规格复核

## 1. 背景与目标

当前课程工作区使用固定左侧栏承载课程概览、学习任务、问答与生成、课程知识、AI 课堂、个人资源和课程设置。该结构持续占用横向空间，并把课程级入口、低频设置入口和默认落地页混在同一导航层级。

本次调整的目标是：

1. 完全移除课程工作区的全局左侧栏，让知识结构、课堂场景和资源列表获得完整横向空间。
2. 将高频课程功能集中到顶部工作栏，并固定名称与顺序。
3. 将课程概览降级为进入课程时的默认落地页，不提供再次进入的导航入口。
4. 当前课程名称只表达上下文，不承担课程切换功能。
5. 将低频的课程设置收纳到当前课程展开栏，并按教师与学生权限区分。

## 2. 已确认的信息架构

### 2.1 桌面端顶部工作栏

顶部工作栏采用单行结构：

```text
Edu AI ｜ 当前课程名称⌄ ｜ 工作台  课程知识  AI课堂  资源管理  学习任务 ｜ 后台任务  个人中心
```

五个主入口的名称和顺序固定为：

1. 工作台
2. 课程知识
3. AI课堂
4. 资源管理
5. 学习任务

对应现有能力的名称调整：

- “问答与生成”改为“工作台”。
- “个人资源”改为“资源管理”。
- “AI 课堂”在导航中统一显示为“AI课堂”。

这些名称应由统一的课程导航定义提供，页面标题、教师导航和学生导航不得各自维护不同文案。

### 2.2 当前课程展开栏

当前课程名称不提供课程切换、课程搜索或最近课程列表。

- 教师：课程名称显示展开提示，展开栏中提供“课程设置”。
- 学生：课程名称只作为不可交互的上下文文本，不显示展开提示，也不显示课程设置。
- 展开栏不得提供课程概览入口。

点击展开栏之外的区域、按下 Escape 或发生路由变化时，应关闭展开栏。展开触发器需要暴露正确的 `aria-expanded` 状态，并支持键盘操作。

### 2.3 课程概览

课程概览页面保留，但从持久导航中移除。

- 用户从全部课程列表进入某门课程时，默认进入该课程概览。
- 用户离开概览进入任一工作页面后，顶部工作栏、课程名称展开栏和其他全局入口均不提供返回概览的路径。
- 概览中的功能卡片仍可作为首次进入课程时的任务起点。
- 概览不参与顶部工作栏的选中状态。

### 2.4 离开课程

Edu AI 品牌入口保留为返回角色对应的全部课程首页的方式。它只负责离开当前课程，不返回课程概览。

原左侧栏中的“返回全部课程”入口和顶部重复面包屑不再保留。

## 3. 页面布局

课程壳层由固定侧栏加内容区改为纵向布局：

```text
课程壳层
├── 顶部工作栏
└── 当前页面内容
```

顶部工作栏包含四个明确区域：

1. 品牌区：Edu AI，点击返回全部课程。
2. 课程上下文区：当前课程名称；仅教师可展开课程设置。
3. 主工作导航区：五个固定顺序的功能入口。
4. 账户操作区：后台任务、个人中心，以及页面按需注入的操作。

课程壳层不再提供任何左侧导航、移动端左侧抽屉或常驻目录。具体页面需要知识目录、资源分类、场景列表等结构时，由页面在自己的内容区域内实现局部面板；该局部面板不得重新演变为跨页面的全局课程导航。

## 4. 导航与选中规则

顶部入口与现有路由的对应关系保持不变，只调整呈现方式和名称：

| 顶部入口 | 主路由 | 同组路由 |
| --- | --- | --- |
| 工作台 | `ai` | `ai` |
| 课程知识 | `knowledge` | `knowledge`、`graph` |
| AI课堂 | `classroom-studio` | `classroom-studio` |
| 资源管理 | `resources` | `resources` |
| 学习任务 | `learning` | `learning` |

路由进入同组页面时，对应入口显示选中状态。课程概览 `course-detail` 和课程设置 `edit` 不选中五个主入口中的任何一项。

教师和学生复用同一份入口顺序与主名称；权限差异通过路由映射和课程设置的可见性处理，不再使用“AI问答”“个人资源”等学生专属导航名称。

## 5. 视觉与交互

- 顶部工作栏保持浅色、低噪声风格，与现有蓝色品牌体系一致。
- 当前入口同时使用文字颜色、背景或底部指示条表达选中状态，不能只依赖颜色细微变化。
- 所有可点击元素提供悬停、键盘焦点和按下反馈，交互反馈不得造成布局位移。
- 课程名称过长时单行截断，并通过原生标题或等效无障碍说明展示完整名称。
- 页面标题和页面操作可放在工作栏下方的页面头部，不能挤压五个主入口的稳定顺序。
- “AI课堂”作为产品导航标签不插入空格；正文中的自然语言不强制改写。

## 6. 响应式行为

### 6.1 宽屏与常规桌面

五个主入口保持单行完整展示。账户操作区优先保留图标和必要状态，课程名称允许截断。

### 6.2 中等宽度

按以下顺序释放空间：

1. 隐藏后台任务和个人中心的辅助文字，保留图标与可访问名称。
2. 收紧导航项水平间距。
3. 截断课程名称。

不得改变五个入口的顺序。

### 6.3 移动端

移动端可使用顶部菜单承载五个课程入口，但不得恢复左侧常驻栏或从左侧滑出的课程导航抽屉。课程设置继续遵守教师可见、学生隐藏的权限规则。

## 7. 组件边界

实施时保持以下职责边界：

- `courseNavigation`：提供统一名称、固定顺序、路由分组和权限元数据。
- `CourseShell`：负责顶部工作栏、当前课程展开栏、角色差异和课程页面容器。
- 具体课程页面：负责自身页面头部、操作按钮和局部目录或面板。
- 角色路由解析：继续负责教师与学生目标路由映射，不在视觉组件中复制 URL 规则。

本次不重构具体页面内部布局，也不改变课程、任务、知识、课堂或资源的数据流。

## 8. 测试与验收

自动化测试至少覆盖：

1. 统一导航定义只返回五个顶部入口，名称和顺序完全符合规格。
2. `course-detail` 和 `edit` 仍被识别为课程工作区路由，但不出现在顶部主导航。
3. 教师可看到当前课程展开触发器和课程设置；学生看不到展开触发器与课程设置。
4. 顶部工作栏不渲染课程侧栏、“返回全部课程”和旧移动端左侧抽屉。
5. 教师与学生均使用“工作台”“资源管理”等统一文案。
6. `knowledge` 与 `graph` 均选中“课程知识”。
7. 点击 Edu AI 返回角色对应的全部课程首页。

视觉验收覆盖 1440px、1024px、768px 和 375px 宽度，确认：

- 页面左侧没有全局侧栏占位。
- 五个入口在桌面端顺序稳定。
- 中等宽度没有水平溢出或相互遮挡。
- 移动端没有恢复左侧课程导航。
- 教师展开栏可正常关闭，学生没有空菜单或无意义箭头。

## 9. 非目标

本次不包含：

- 当前课程切换器。
- 从工作页面返回课程概览的入口。
- 具体页面内部目录和面板的统一设计。
- 后端接口、权限模型或课程数据结构调整。
- 对课程概览内容本身的重构。
