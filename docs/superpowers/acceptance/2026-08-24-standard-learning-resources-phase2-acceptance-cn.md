## 1. 验收范围

本阶段实现叶子知识点标准资源、教师审核、阅读型/测评型学习任务、不可变资源快照和基于资源完成事件的学习进度。使用当前“数据库”课程的六个叶子知识点作为最小验证结构。旧课程共享资源仅标记为 `legacy_shared`，待真实数据库迁移后再核对和清理；分层 RAG 不在本阶段范围内。

## 2. 功能验收清单

- [x] `ACC-STRUCT-01` 测试脚本只允许默认测试课程，其他课程必须显式确认。

### C. 学习任务与学习证据

## 4. 运行态验收路径

1. 教师进入“课程知识”，确认三个章节、六个叶子知识点及每点三个标准资源槽位。
2. 选择一个叶子知识点发起生成，观察批次状态和失败项重试。
3. 预览生成结果，分别验证驳回原因必填、单项通过和批量通过。
4. 创建阅读任务，选择已通过标准资源或教师个人资源，直接发布。
5. 学生打开任务快照，完成资源；教师端确认进度和 `activity_evidenced` 证据。
6. 创建测评任务，确认没有有效测评时仍不能发布。
