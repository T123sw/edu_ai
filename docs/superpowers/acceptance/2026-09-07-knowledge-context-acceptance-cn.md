## 数据与证据层次

## 通过标准

确定性测试必须证明未明确时不执行；真实模型冒烟至少覆盖 B02、B03→B04、B05，不能仅检查回答中出现“数组”。B02 需要成果正文与归属证据，B03 需要零生成副作用证据。真实模型不可用时标记“待真实模型验证”，不得标记完整验收通过。

前端核对 1366px 和 390px 范围栏、长路径、选择器键盘操作；不根据历史截图宣称新 UI 通过。
