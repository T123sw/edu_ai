# 实验教学事实层整理

2026-10-17。**后续状态：生产后端已于 13:40:48 UTC 重启，新事实层在线生效。** 9 轮真实线上问答验证主要状态、错误依据、计数和历史定位正确，仍发现一处字段语义推演错误；见[重启后复验与未解决问题](../2026-10-17-experiment-facts-restart/README.md)。下面保留此前实现及隔离验证记录；原 verification.json 是重启前的历史快照。现有 edu-experiment/1、/2 实验无需重新生成。

## 具体改变

新增 `facts.py`，在冻结证据与教学模型之间做确定性的事实整理，输出 `edu-experiment-facts/1`。不新增模型调用、审查阶段或实验生成门槛。

| 内容 | 整理后的含义 |
| --- | --- |
| 当前状态 | 阶段、当前任务、步骤索引、尝试编号、状态快照；字段带名称/单位/是否存在。新增提问保存步骤索引和页面判定，旧冻结记录缺少的值保留未知 |
| 所问操作 | 操作人、动作、输入、任务、操作前和尝试后状态、结构化数值变化；数字增减直接计算，历史问题与当前画面分开 |
| 判定 | 关联真正的动作及判定事件；区分单次操作与整个尝试。pending、pass、fail、unknown、awaiting_review 不混算 |
| 错误依据 | 新协议引用动作 facts 的 expected/chosen；旧协议对记录状态执行原任务条件，列出实际值、要求和未满足条件。只有失败文字而没有依据时标为 unavailable，不编造用户的心理误解 |
| 恢复状态 | 失败之后是否有恢复记录、恢复到哪个快照、是否等于操作起点；兼容两个协议在不同时间更新 attempt_id 的行为 |
| 统计 | 程序统计演示步骤、语义动作、判定、失败、符合页面预期的选择，以及各阶段和任务的计数；初始化、重复点击、反馈、回滚、动画采样分别计数，不加进教学步骤 |
| 历史后续 | 所问动作之后、下次初始化/重置/切换前的实际动作数量和有限明细；明确不含所问动作本身，不把它当未来预测 |
| 不可靠文字 | 页面 message/lastAction/feedback 等文字移入 reference_only；设计说明及历史回答也单列。保留原始快照，不把生成的文字升级成已验证因果结论 |
| 缺失信息 | 未上报结构化结束原因时标未知；没有测量有效性标记时，不把数值 0 当作未测量的证明，也不把字段存在当作测量已验证 |

上下文先给历史对话，再给事实，实际用户问题放在最后。教学 Skill 使用明确口径，解释“尚未完成”时优先说明未满足的条件，用户未要求预测时不列举多步未来数值。Skill 保留对旧事实格式的兼容，避免正式进程重启前无法读旧结构。

新增只读工具 `get_fact_summary`、`list_operations`、`get_operation`，沿用原 owner/实验/冻结上下文授权。原始事件、快照、尝试和差异查询继续保留。新工具可分页读取全部动作，未载入的历史明确标注；统计覆盖整个冻结记录，不依赖最近几条聊天。

## 验证

- **64 项后端回归通过**：包括 20 项事实层测试及原有实验/教学测试。覆盖控件与语义动作重复、v1 多命令演示/回看重建、无动作直接提交、整次尝试判定、跨任务初始化、回滚、未知/开放评价、历史分页、参数名 control、同名任务与阶段、页面文字隔离及数值变化。
- 最后一轮 **6 个真实模型案例**：冒泡错误原因、交换后状态、历史操作、精确统计、自由探索和非算法的摩擦实验。统计正确为演示 6 步、第一任务 7 次动作/1 次失败/6 次选择匹配预期；历史指定操作之后为 5 次，比较对象也匹配记录。
- 隔离真实 HTTP 路由＋真实模型 **2 轮连续问答**：新字段持久化、错误恢复说明、回复旧问题同时读取新状态、SSE 与查询结果一致。最后两轮均完成，约 2.91/2.28 秒，无生产业务写入。
- 55 条真实事件的事实投影重复 100 次，平均约 **0.413 ms**（本机样本，不是服务 SLA）。语法编译与 Skill 校验通过。没有前端改动，因此不新增构建或页面布局验收。

## 仍需区分的边界

事实整理已验证，不等于所有生成解释都正确。实测过程中曾出现模型自行补出错误后续比较、混淆同名任务与阶段、把判定加算成动作等问题；经增加直接事实摘要、分阶段计数、数值变化与明确的后续动作记录，关键统计与历史动作复验正确。

最终 HTTP 复验前仍有一次未经请求的多步推演错误，随后收紧教学提示，最后连续问答没有复现。非算法回答对“0 是否初始占位”的表述仍可能不够严谨；源数据没有测量有效性标记时，本实现只能把未知明确提供给模型，不能补造真实测量结论。没有增加额外模型审阅，也未修改生成实验的错误页面文字。

此前发现的“回答中刷新后 pending 等到约 120 秒才可重试”问题不在本次事实层修改中，尚未修复。上线后应分别复验事实新格式与该既有状态问题。
