# 课程准备 Agent：研究与学习路径阶段验收

日期：2026-09-17。对应用户要求：先推进接收意图、正确搜索资料、汇总并生成学习路径。

## 交付范围

实现独立的 `research_learning_path` 阶段：意图提炼 → 检索 → 正文分段读取 → 带原文引用的研究汇总 → 学习路径 → 独立审阅。它是 P2/P3 的优先切片；不是整课资源制作或课程交付，返回始终带 `course_ready=false`。

- `ResearchAgent` 按阶段挂载六个强类型工具，模型每轮只允许一个完整 function call。截断、纯文本、未知工具、畸形 JSON、多工具并发响应均不执行。
- 用户原话、目标、时间、基础和排除项进入 Brief；需求关联原话。网页只作为资料，不赋予工具权限。
- 搜索候选和已读正文分离。每次最多保存 5000 字符节选，可指定偏移继续读后文；每段单独保留 source_id、URL、提取时间、偏移和正文 SHA-256。引用必须是该节选实际存在的原文。
- 路径包含目标、先修、分钟数、学习活动、自测、需求及证据关联。服务端检查先修顺序、覆盖、时长与引用关系；独立模型上下文检查语义和教学合理性，最多两次审阅修正。
- SQL 保存任务工作记忆与全部检查点；在模型/检索/读取之前预扣次数。最多 30 次决策、6 次搜索、8 次正文读取，总期限 600 秒（包含排队），150 秒执行租约，最多 3 次崩溃回收。连续 3 次工具错误停止，保留失败原因。
- 失败提交及定位到节点/引用的错误一并进入下一轮上下文，供定向修复；不通过清空参数或放松引用检查来伪造成功。
- 所有接口从登录身份解析数据库用户，校验当前启用状态。owner + request_id 唯一约束处理重复提交；取消和租约回收隔离旧执行器，不能覆盖已取消任务。

## 文件与运行方式

入口：`backend/src/app/api/course_research.py`；循环与契约：`backend/src/app/course_preparation/research_*.py`；模型适配：`model_adapter.py`；受控提示词：`prompts/`。

迁移：`backend/src/alembic/versions/20260917_0025_course_research_runs.py`，接在既有学习流程迁移 `20260917_0024` 后，不改写其内容。新增 `course_research_runs` 表。迁移升级/降级仅在隔离测试库验证，**未对业务数据库执行迁移**。

启用步骤（后端正常运行环境）：

1. 在 `backend/src` 执行 `python -m alembic upgrade head`，应用当前工作区已审核的迁移链。
2. 配置 PostgreSQL `DATABASE_URL`、可用 LLM 配置、`TAVILY_API_KEY`（检索和正文提取），设置 `COURSE_RESEARCH_ENABLED=true`，重启后端。
3. 新接口通过现有登录 Bearer token 访问。功能开关默认关闭；未配置迁移时不自动建表。每个后端进程启动一个专用研究 worker，多进程通过 PostgreSQL 行锁互斥领取。

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| POST | `/api/course-preparations/research-runs` | 202，提交或幂等回放 |
| GET | `/api/course-preparations/research-runs/{run_id}` | 阶段、真实调用进度、终态与结果 |
| POST | `/api/course-preparations/research-runs/{run_id}/cancel` | 取消排队或运行任务 |

最小提交体：

```json
{
  "request_id": "6449032d-8ab7-4b88-9ac7-5f3b26038573",
  "goal": "面向只学过函数和条件判断的Python初学者，用45分钟理解递归的终止条件与调用过程，能手写阶乘并识别无限递归。不要讲动态规划。",
  "overrides": {"total_minutes": 45}

```

同一次网络重试保持 request_id，新的需求或失败后新尝试使用新 UUID。终态结果包含 `brief`、`research_summary`、`learning_path`、`sources`、`review`。节点生成稳定 node_id 与 prerequisite_ids；资料列表不返回完整网页正文或内部工具轨迹。

## 明确的阶段边界

- 当前只支持新学习需求和开放网络。上传、自有知识库、已有课程补充/修改明确拒绝，等待后续接入。
- 当前记忆是本任务的 SQL 工作记忆；跨课程长期偏好、共享记忆 epoch/删除生命周期尚未接入，不写已掌握、成绩或学习完成。
- 复用已有用户模型配置修订；显式绑定修订不可用时失败。环境默认配置未形成不可变修订，服务重启后可能使用更新的环境值。
- 当前预算约束调用次数与期限；没有供应商账单级 token/费用结算。上下文用保守 UTF-8 字节上界检查，默认窗口配置 128000，支持 `COURSE_RESEARCH_CONTEXT_TOKENS`，超限失败而非静默删掉证据。
- 当前专用阶段 worker 尚未并入完整准备任务的通用事件流、子任务与 outbox；不将本切片标为完整 P2/P3 已完成。
- 未接首页 UI、资源生成、课程 manifest 提交或学习 Agent 交接。真实供应商 smoke 和隔离库 API 测试通过不等于业务环境已部署。
- 工具校验能保证引用存在和结构一致；单个模型样例不能证明所有学科事实与教学质量均可靠，后续应增加跨主题评测。

## 最终验证记录

最终自动化结果：**113 passed，2 skipped**（16.34 秒）。两项跳过仅为 SQLite 不具备 PostgreSQL 行锁语义的并发场景，其 PostgreSQL 版本均通过。另有 3 条第三方依赖弃用提示；本阶段代码编译与变更格式检查通过。

真实供应商最终样例：2026-09-17，耗时 **50.5 秒**，12 次模型决策、2 次搜索、4 次正文读取，来自 3 个不同网页。生成 7 条带来源的研究结论、5 个学习节点，独立审阅 `pass`。两次供应商返回多工具调用被严格拒绝，重试后继续；没有执行不完整或未挂载工具。

| 学习节点 | 分钟 | 先修 |
| --- | --- | --- |
| 递归直觉：更小的同类问题 | 6 | 无 |
| 终止条件与递归步骤 | 9 | 递归直觉 |
| 阶乘调用展开与逐层返回 | 12 | 终止条件与递归步骤 |

共 45 分钟。路径遵守初学者基础与“不讲动态规划”的排除项，最后节点明确区分“递归深度超限”现象与具体原因。

来源包含 Berkeley Python Numerical Methods、freeCodeCamp 入门教程、Rollbar 的错误示例。源网站质量、默认值与教学翻译的限制随路径明确保留，不声称已核对未读取的官方规范。

[样例产物 JSON](artifacts/2026-09-17-course-research-path-sample.json)保留真实需求、研究结论、路径、审阅、来源 URL/哈希/偏移及调用数量，不分发网页正文与原文引文。完整本机 smoke 检查点位于 `/tmp/course-research-live-final.json`；归档前再次用服务端校验器验证全部引文确实存在、需求原话匹配、路径覆盖、先修与总时长。

## 查看逐步日志与中间产物

真实验证脚本支持 `--log-dir <新目录>`。每次使用新目录，避免覆盖先前运行证据：

```bash
python -m scripts.smoke_course_research \
  --goal '面向只学过函数和条件判断的Python初学者，用45分钟理解递归的终止条件与调用过程，能手写阶乘并识别无限递归。不要讲动态规划。' \
  --minutes 45 \
  --output /tmp/research-observed/final-checkpoint.json \
  --log-dir /tmp/research-observed
```

- `report.html`：运行时持续更新的可展开报告，查看阶段、来源正文、汇总、路径与审阅。
- `events.jsonl`：按时间追加的模型请求、工具选择/参数、查询、候选与正文读取记录；不记录密钥、认证请求头或模型隐藏推理。
- `NNN-call-NN-阶段.json`：每次预算预扣和工具返回后的不可覆盖检查点，包含该时刻完整工作状态。
- `brief.json`、`summary.json`、`path.json`、`review.json`：最新阶段产物；以报告的终态和审阅结果判断路径是否通过。

这是 Agent 主体链路的真实供应商验证，入口为命令行；不代表前端、登录接口和业务数据库部署全链路验证。日志只在指定的本地目录生成，保留用户需求与已读网页节选，不开启全局 HTTP 请求体日志。

2026-09-17 逐步日志复测发现：读取额度已用尽时仍挂载 fetch_source，模型会继续请求读取并使任务失败。已将剩余额度显式传入模型，并按预算动态卸载检索/读取工具；读取耗尽后保留汇总工具，核心证据不足仍按原门禁失败。新增两项预算挂载回归，主体循环和协议适配测试共 36 项通过。失败与修复后运行分别保留在 `artifacts/course-research-e2e/20260917-run-01/` 和 `20260917-run-02/`，不覆盖失败记录。
