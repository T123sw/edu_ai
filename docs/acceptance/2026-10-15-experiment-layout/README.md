# 实验三栏与内部排布

本次按用户要求整理整体视觉与信息层级，保留三阶段教学和现有操作协议。

- 左栏保留实验标题与阶段导航，保存状态弱化展示，同步、导出和新一轮实验收进记录管理。
- 中栏图形优先，参数、操作和统计跟随；移除重复页头，公式默认折叠，探索建议按需展开。实验高度随内容伸展，减少内外双重滚动。
- 右栏优先呈现当前操作反馈，背景与操作记录可展开，问题记录区独立。
- 统一系统字体、控件尺寸、绿色主操作及轻量分隔；保留图形本身的状态颜色、绘图和算法。
- 手机仍使用步骤、实验、讲解三个面板，切换显示后重绘画布；统计紧凑排列，控件自然换行。

历史三页实验在展示时追加布局层，不修改保存的 HTML、revision、运行记录或答案规则。对可识别的 canvas/大 SVG 页面整理容器；不明确的布局保留原结构。新生成页面的接入约定补充布局建议与可选区域标记，不增加生成校验门槛。旧 v1 实验沿用原内部页面，仅共用更新后的外层。

验证使用生产快速排序与冒泡排序页面的只读副本，在本地模拟保存接口，覆盖 320/390/768/1024/1440px 的三个阶段、可见画布、内外无横向溢出、公式展开不改变状态、演示前进/回看、练习反馈、探索参数及刷新恢复。另复用 v1/v2 两套浏览器回归验证阶段切换、错误重试、问题上下文与保存冲突。测试没有写入生产用户学习记录，也没有重新调用模型生成实验。

发布以当前线上 PBL 工具栏版本的源码快照为基线，先复现相同入口哈希，仅叠加本次五个前端文件。发布记录和具体结果见同目录 JSON；发布前的中间截图、诊断保存在私有 `.runtime/experiment-layout/`。接入约定逐请求读取，前端更新不需要后端重启。
