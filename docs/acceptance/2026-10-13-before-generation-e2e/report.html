上下文预算

48,000 原来是固定的 UTF-8 JSON 字节上限，既不是 48,000 个汉字，也不是 48,000 个 token。现改为软目标：优先去重；必需要求、结论与定位超出时按需扩展，默认最多 96,000 字节。可选正文不会触发扩容。完整请求（含提示词、工具、历史、输出余量）仍经过 128,000 保守上界检查，实际 token 消耗由接口 usage 记账。

当前实际调用模型配置为 deepseek-v4-flash，直连 DeepSeek 官方 API。官方平台说明标注支持 1M token 上下文；本轮没有做百万 token 极限测试，模型容量不等于应用预算。
