1. **习题审阅与恢复未稳定通过。** HTTP 样本的判断题和简答题没有选项，模型却返回 `option_checks=[0]`，触发 `quiz_review_option_coverage_incomplete`。有限重审后来发现第 3 题对“用户”干扰项的解释缺失，转为 `RESOURCE_CONTENT_REJECTED`；此时 `production_repairs=2`，整课以 `QUALITY_GATE_FAILED` 结束。候选正文摘要保持 `425afd5281a9803195def78fd71c09117e0c3dc11e62233535c6e4d5a8762ff5`，证明重审没有偷换正文，但不能说明内容修复最终成功。
