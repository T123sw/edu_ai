快速排序按“选择基准 → 完成一次分区 → 处理子区间 → 完整实验”展开；摩擦实验按“观察基线 → 改变摩擦系数 → 改变初速度 → 完整实验”展开。每步只开放当前动作和参数，正确、错误、无变化、无效及禁止操作均返回解释；操作完成由实际状态判断。支持单步、播放、暂停、重试、快照恢复，以及独立的自由探索状态。

MAIC-UI 保持原生科学建模和页面生成，新增可信 SDK 管理动作、模型与反馈。服务端重放同一确定性引擎，另用 Python 校验排序/分区和摩擦数值。引擎按内容摘要固定，历史会话恢复需要保留 `.runtime/practice-guidance/replay-*.mjs`。会话、操作批次回执、观察与问答分别持久化；断网草稿、丢失回执重试和多页面冲突均有显式处理。问答使用已保存的当前步骤和尝试数据。

本版领域适配仅包含快速排序和恒定滑动摩擦。其他主题保持原生完整实验；旧实验不自动转换，重新生成受支持主题后使用新协议。指导步骤由这两种领域适配器提供，尚未实现任意主题的自动可靠分步。

验证结果见 [verification.json](verification.json)：后端 20 项、状态模型 6 项、分步浏览器 3 项、旧版浏览器 5 项通过；1 项可选旧样例跳过。另有真实接口桌面/手机共 4 个完整流程，PostgreSQL 独立 schema 的迁移升级/回退、并发冲突和重复回执检查。校验器回归 7 项、类型、局部 lint 和隔离生产构建通过。API 验收使用实际路由及存储逻辑，但鉴权和辅导回答模拟；没有创建生产学习记录。
