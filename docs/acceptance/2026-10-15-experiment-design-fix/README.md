## 原因

任务停在 experiment_design，尚未进入 MAIC-UI 页面生成。日志显示模型同时填写 explicit_submit 和自动提交动作，第一次修复后仍触发「显式提交不能另设自动提交动作」。旧 JSON Schema 没有表达字段互斥，修复错误仅指向整个对象，公开错误却让用户调整主题。原始失败输出当时未保存，不能推测其他具体内容。

## 改动

- 用 submission 判别联合表达两种任务类型；手动提交字段仅允许 null/省略。对手动提交中不生效的字符串 submit_action 做可追踪清理，不更改动作、判定或任务顺序。
- Condition 路径在 Schema 中声明根，字段校验返回具体位置；补充完整路径例子，区别 state_fields 相对路径，保持危险属性禁止访问。
- 接受常规大小写/下划线动作 ID；初始观察允许空 commands，断言仍必需。浏览器仍检查整个演示的真实状态变化。
- 设计尝试的原始输出、调整与具体错误按账号隔离保存。失败提示说明模型设计冲突，不再要求用户改变实验主题。
