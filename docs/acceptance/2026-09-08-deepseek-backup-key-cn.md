# DeepSeek 备用密钥

配置文件 `.env` 新增 `DEEPSEEK_API_KEY_BACKUP`，默认留空；主密钥仍为 `DEEPSEEK_API_KEY`。填入备用值后重启后端生效。真实密钥不提交到 Git，示例文件只包含空配置项。

普通对话 Harness、资料阅读与修改使用的模型客户端、生成模型网关均接入同一请求级切换机制。主密钥返回 HTTP 402 时，使用备用密钥重发当前 completion 请求，模型和请求内容保持不变。不会重跑 Agent 回合或已执行工具；只有收到成功响应后才向下游发送正文流。备用密钥仍失败时返回其错误，不循环切换。其他 HTTP 状态保留原行为；备用值为空或与当前密钥相同时不启用。备用密钥仅用于配置中的 DeepSeek 接口，不发送到其他服务商。

Harness 子进程通过仅监听 127.0.0.1、随机令牌认证的本机转发端口调用。日志仅记录主密钥返回 402 和切换事件，不记录密钥或请求正文。

验证：65 项隔离检查通过，包含真实本机 HTTP 主/备请求、流式传输、两把密钥均失败、非余额错误、空配置、目标服务隔离、本机鉴权，以及模型客户端、生成网关和 Harness 接入。没有提供备用密钥，因此未执行真实外部备用账户验证；本次部署不会自行恢复服务商余额。
