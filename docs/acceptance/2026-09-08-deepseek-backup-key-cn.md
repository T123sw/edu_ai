# DeepSeek 备用密钥

配置文件 `.env` 新增 `DEEPSEEK_API_KEY_BACKUP`，默认留空；主密钥仍为 `DEEPSEEK_API_KEY`。填入备用值后重启后端和 OpenMAIC sidecar 生效。真实密钥不提交到 Git，示例文件只包含空配置项。

普通对话 Harness、资料阅读与修改使用的模型客户端、生成模型网关均接入同一请求级切换机制。主密钥返回 HTTP 402 时，使用备用密钥重发当前 completion 请求，模型和请求内容保持不变。不会重跑 Agent 回合或已执行工具；只有收到成功响应后才向下游发送正文流。备用密钥仍失败时返回其错误，不循环切换。其他 HTTP 状态保留原行为；备用值为空或与当前密钥相同时不启用。备用密钥仅用于配置中的 DeepSeek 接口，不发送到其他服务商。

Harness 子进程通过仅监听 127.0.0.1、随机令牌认证的本机转发端口调用。日志仅记录主密钥返回 402 和切换事件，不记录密钥或请求正文。

2026-09-11 补充：当 `ANSWER_LLM_API_BASE`、`QWEN_BASE_URL`、`OPENROUTER_BASE_URL`
等历史角色配置或运行时配置也指向同一个 DeepSeek 地址时，其 Key 不再改变调用顺序。
服务器访问该地址时统一使用 `DEEPSEEK_API_KEY`，仅在其返回 HTTP 402 后使用
`DEEPSEEK_API_KEY_BACKUP`。指向其他供应方地址的 Key 保持各自配置。

任务调用链审计结果：

| 任务 | DeepSeek 调用入口 | 处理结果 |
| --- | --- | --- |
| 报告、教案、博客、题目、闪卡、思维导图、游戏 | `ChatModelGateway` / 报告模型客户端 | 统一主 Key，HTTP 402 时备用 |
| 课堂生成 | OpenMAIC sidecar | 读取同一组环境变量，HTTP 402 时备用 |
| 课程知识构建、计划构建、教材翻译、知识图谱生成 | RAG 模型调用与专用适配器 | 直连入口已接入统一策略 |
| 资料修改 | 报告模型客户端 | 统一主 Key，HTTP 402 时备用 |
| 文档索引、视频导入、课堂视频导出、教材解析 | 不调用 chat completion | 不读取 DeepSeek Key |

验证：后端 47 项主备策略、任务接入和配置存储隔离检查通过，包含真实本机 HTTP 主/备请求、流式传输、两把密钥均失败、非余额错误、空配置、目标服务隔离、本机鉴权，以及生成网关、Harness、RAG、教材和知识图谱接入。OpenMAIC sidecar 214 个测试文件、1775 项测试全部通过，生产构建通过。真实外部探测显示当前主 Key 可用、备用 Key 返回 HTTP 402；切换机制已就绪，但备用账户仍需补充额度后才能承担故障切换。
