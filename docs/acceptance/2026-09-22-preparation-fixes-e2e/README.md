## 修复内容

- 习题审阅曾在 `{"value": ...}` 外层包装处连续出现缺闭合/多余括号。带明确 schema 的审阅工具现在直接提交该 schema 的顶层对象，提示与工具保持一致。保留原有 JSON/schema 严格校验、完整题目/选项核对及最多两次协议纠正，不本地拼补模型 JSON，不提高 token 或父预算。三轮接口均交付，本轮七门正常课程的资源审阅回执未发现非法 JSON；其他阶段的有限纠正单独保留在 [传输检查](transport-check.json)。
- 首次会话 404 来自 `enter` 与挂载时 `refresh` 并发。前端共用在途初始化，确认创建成功后才读取历史；未知会话/节点及越权访问的 404 语义保持不变。
- 字幕改放在幻灯片画布下方；流程框为标签和详细说明分配足够空间，保留 18px 最小基础字号。浏览器增加字幕/画布不相交和实际文字边界检查。见 [最终桌面截图](desktop-subtitles.png)。
- 空的报告定位标签转换为真实 DOM 锚点，其他原始 HTML 继续转义，代码示例保持原文；不启用任意 raw HTML。见 [最终窄屏截图](narrow-report.png)。
- 首次修复后的两次浏览器测试又暴露加载超时：多组固定间隔轮询在慢请求时叠加，课堂刷新重复读取账号下所有课程。现复用串行轮询，上一轮完成后再计时；课堂只更新当前课程和独立后台任务列表。两个视口的 12 次真实资源回读均通过，约 1.5–3.7 秒，无接口错误，详见 [回读记录](resource-replay.json)。这是定向回读，不冒充新建课程端到端。
- 同步移除报告和通用资源审阅提示中残留的“学习时长显式上限”说法。学习时长继续只指导内容量；首轮估算 38.15 分钟、参考 20 分钟，仍正常交付，未改小估算。
