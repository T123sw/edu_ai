## 质量边界与未通过项

独立复核发现已被模型核对放行的三道题仍错误，而且作为成功检查点被重试保留：

- 第 7 题二分查找：目标 83 实际比较 3 次，模型给出 4 次，并把第 11 个元素误读为 75。
- 第 8 题快速排序：按其解析中的交换步骤得到 `[19,23,31,35,47,56,74,68]`，与所选 B 不一致。
- 第 26 题完全二叉树：0 起始编号 1024 位于左子树；对应子树中排在它之前的叶子有 18 个，模型答右子树、0 个。

见[独立计算反例](independent-quality-audit.json)。自动完整性成功不等于答案正确；本样本不作为可直接用于正式考试的合格试卷。当前页面仅生成与预览，`exam_ready=false`。下一步质量工作应针对独立求解和可执行算法核验设计通用机制，不能用这三道样题的硬编码答案冒充通用修复。

计时作答、提交、评分、自动识别教材/试卷及多卷选择仍未实现，本轮没有把这些规划能力描述为已交付。
