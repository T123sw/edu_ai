# 互动实验页面展示优化

2026-10-13，已发布至当前 Nginx 前端。针对用户截图 `image copy 12.png` 的实验区过窄、重复卡片层级及双层滚动问题进行调整。

- 顶部编号步骤与当前任务，实验为主体，右侧固定 AI 实验伙伴。
- 生成页面按实际内容自适应高度；专注模式扩大实验宽度，退出支持 Escape，保留 iframe 和当前操作状态。
- 结果以指标展示，观察笔记与历史记录分开排版；AI 回答支持 Markdown，手机端单列并提供问 AI 入口。
- 展示适配在前端包装生成 HTML，未改写已保存的实验算法与内容。

## 验证

- TypeScript、修改文件 ESLint、Vite 生产构建通过。
- Playwright 3 项通过：1440 / 390 像素的生成入口、参数操作、保存、AI 引导、刷新恢复；真实快速排序 HTML 在 1920 / 1440 / 390 下的布局检查。
- 验证 iframe 无额外纵向滚动、页面无横向溢出，切换步骤和专注模式保留参数，iframe 内 Escape 可退出，非 iframe 来源的尺寸消息被忽略。
- 发布后使用 Nginx 实际静态资源复验真实 HTML 的三种宽度，1 项通过；HTTP 首页与本轮构建一致。
- 浏览器验证使用真实已生成的快速排序 HTML，但认证、实验详情、保存与 AI API 使用模拟响应。本轮未新建模型生成任务，不代表重验了模型生成或 AI 回答质量。
