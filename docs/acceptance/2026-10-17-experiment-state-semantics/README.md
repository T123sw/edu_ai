## 修复内容

原问题的根因是把轮末复位后的局部标记当作整轮历史。新增可选 `snapshot._teaching`，版本 `edu-state-evidence/1`，复用现有快照传输：

- fields 保存字段的含义、时间范围和重置时机。
- transition 保存最近一次实际事件、重置前后值和原因；相同事件的重复采样不算新操作。
- completion 保存本次实际命中的结束分支及当时依据；初始化、更换输入和重置清空上次原因，恢复保留原证据。

新增通用解析器 `state_evidence.py`；缺失、未知版本或格式不完整均降级为未知，不阻断生成或问答，不增加模型调用、审查、前端协议或必填生成字段。原始快照仍可查询，整理结果注明页面上报、不代表独立科学认证。

事实包和 `get_fact_summary` 同时提供当前状态语义与 `recorded_completions`，保留重置之前各次完成原因及当时数值，避免比较两次运行时套用当前原因。列表保留最近 4 项，带总数、截断标记与快照定位。不会从 done、false、0 或生成文案反推历史原因。

实验设计 Skill 的页面指令直接包含[状态证据规范](../../../backend/src/app/practice/skills/design-experiment/references/state-evidence.md)，后置讲解也优先读重置前事实。教学 Skill 明确：终态不能证明整段历史；缺少语义时承认未知，不补造第四轮或测量过程；pending 和匹配预期分别描述。

实测还发现旧记录触发多次查询后可能超过 8 次而让整条问答失败。现保持 8 次实际查询/最多 4 轮模型的预算，超额查询返回“未执行”，随后关闭工具，要求用已有证据回答并说明未知；不通过扩大无限重试解决。

## 冒泡样例更新

仅修改既有专用验收实验 `practice_792ef220f0ee56f7576d4417540dc83f` 的探索页：记录实际比较/交换计数、字段语义、每次比较、轮末重置与两种完成原因。演示、练习算法保持原版本，包装版本号统一更新。

- 逆序 `[4,3,2,1]`：6 次比较、6 次交换，最后一轮发生交换；因为未排序区只剩一个元素而结束。
- 有序 `[1,2,3,4]`：3 次比较、0 次交换，因完整一轮无交换而结束。
- 重复值 `[2,2,1,3]`：6 次比较、2 次交换，最终 `[1,2,2,3]`。当两个结束条件同时成立时，文案采用区间完成，避免把跑满轮次称为提前结束。
