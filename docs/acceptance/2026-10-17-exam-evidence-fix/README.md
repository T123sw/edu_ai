## 修复内容

- **输入隔离与内容修复**：独立解题只接收新题的数据；自包含新题的内容修复使用冻结文本模型，原卷图片继续用于读卷、首次生成与原题对照。修复指令要求真正改正选项、答案、子题及解释，避免只修 JSON 或继续沿用错误答案。
- **计算证据**：计算器支持实际结果命名绑定、字典、受限容器方法、双层推导式、白名单命名参数及受限排序 key。不执行任意 Python。嵌套结果、复制与算法轨迹也计入分配预算，补充资源边界回归。
- **数据结构核验**：支持堆、拓扑顺序、线性探测哈希、Dijkstra、完全二叉树；单选检查全部选项。树题生成前提供程序算出的新实例与祖先子树；答案核验要求对应子题的实际声明与计算结果一致，区分空间叶序和全局编号，用真实结构生成解释。
- **误判修正**：审查意见的数值证据也需核验；未基于对应树结构的错误计算先修正证据。符号复杂度题允许数学论证，堆题不因提及完全二叉树而进入目标结点检查。明确单选布尔检查的正反方向，并支持从 1 编号的树题。
- **填空改编**：固定定义、公式或判断条件类填空，要求围绕具体状态和操作设计新问题，避免仅改变量名或故事背景。最后遗留的链表填空题已定向复测通过，新整卷第 15、16 题均在首轮通过。
- **故障恢复**：短暂连接、限流及服务端异常采用有限重试；取消继续传播。某题传输重试耗尽后记录失败并继续后续题目，已通过检查点保留。完整性或质量检查失败时仍不发布残缺试卷。
- **可复现迁移**：源码准备脚本正确记录累计补丁新增模块，验证并升级已知历史补丁，拒绝覆盖未知修改。保留完整上游源码、Explore/Plan/Quiz、图像能力、两次内容修复及检查点机制。

资料链路仍为考试专用上传 → MinerU 解析 → 出题，无知识库入库/索引。正式测试账号的知识库和知识文档记录均为 0。隔离测试还阻断了知识库入口并观察后端 Embedding 请求；此项不是生产全网流量抓取。
