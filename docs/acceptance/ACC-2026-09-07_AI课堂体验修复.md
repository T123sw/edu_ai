# AI 课堂体验修复（2026-09-07）

对应截图 image copy 13–16 的七项反馈。

- 首次进入、小节节点共用学习路径组件：主题区、课堂/指南/练习三张卡片、生成入口。
- 字幕由实际语音执行器驱动，浏览器朗读与阅读等待按句推进；已有整段音频按播放进度与句长分配字幕。后者没有逐字时间戳，因此句子切换时间为估算。
- 问答面板删除顶部资源范围横幅与副标题，保留内部资源、题目焦点绑定。
- 审核与发布位于播放器/练习上方；退回时展开原因输入。
- 教师试答与学生答题使用同一组件，教师本地对照参考答案，不写学生学习记录。
- 学生单选提交字母、多选提交数组；仅提交已发布版本，支持文字输入，编辑后重置提交幂等键。兼容多选标准答案 AC/A,C/数组，旧 manifest 同样在评分时规范化。
- 课堂问答由后端读取真实内容，当前页与中断句优先；增加播放版本传递，复用播放器权限与快照读取，按版本筛选用于回答的历史问答。
- 提交后刷新目录不再卸载当前习题，避免成功提示和已填写答案被刷新清空。
- 修复教师目录选择写入旧 teacher-classroom-studio 路由的问题。
