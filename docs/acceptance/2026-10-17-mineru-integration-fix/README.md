## 修复结果

- 通用资料解析和模拟考试共享 provider 配置解析与构造逻辑。考试快照冻结本地/云端选择、地址、密钥和本地超时；旧云端考试快照保持原选择，新任务使用当前本地配置。取消以 revision ID 为唯一键的解析器缓存，避免不同配置复用客户端。
- 本地适配器改用 MinerU 4.x `/v1/tasks`，请求自包含 ZIP，读取正文、middle_json、structured_content 和图片。从解析器实际页记录生成页覆盖证据，保留空白页、版面、图片、表格和公式，不使用输入页数伪造解析完成。
- 解析取消、期限、任务回执和远端 DELETE 已接入；缺失图片、重复/非法页码、失败任务和异常归档均不能作为成功结果返回。
- 修正本地任务回执被标为云端的问题；为课程解析缓存增加适配器版本，旧本地缺陷结果下次访问时重新解析，原资料版本和权限检查保留。
- 系统配置验证改用本地 `/v1/health`，RAG 日志不再把本地服务误报成云端。

## 实际验证

使用真实本地 MinerU 4.0.12，调用项目适配器和资料服务；所有业务存储验证使用临时 SQLite。不是 pypdf 替代解析；pypdf 仅生成夹具和独立检查原 PDF 页数。

| 样本/流程 | 结果 |
| --- | --- |
| 原两页排序试卷 | 2,074 字符、17 个布局块、无完整性缺陷，3.94 秒 |
| 两页扫描试卷（柱图＋表格） | 373 字符、9 个布局块、2 个图片资产、无完整性缺陷，5.46 秒 |
| 中间加入空白页的三页 PDF | 空白页覆盖保留，无完整性缺陷，5.39 秒 |
| 课程核心资料 `DocumentStore.read` | primary 资料通过，两个图片资产可经权限/哈希检查读取 |
| 考试 `GenerationSources` 默认入口 | 使用 `mineru-local`，17 个布局块保留，通过严格页覆盖校验 |
| 真实任务取消 | 本地抛出 `CANCELED`，服务端查询任务状态也为 `canceled` |
| 本地解析→DeepTutor→私有结果保存 | 首次 26.27 秒，1/2 题通过；一次重试 10.16 秒后 2/2 并保存成功 |

出题首轮失败来自计算答案问题：`0.40 × 4 × 15 / 13` 应约为 1.85，模型给出 1.92，被现有校验拦截。重试后链路成功，但存在近似原题、快速排序分区算法假设未明确等质量限制；本次不宣称整卷质量或图题生成验收完成，`exam_ready=false` 保持不变。扫描件仍有个别 OCR 空格错误，本次通过指产物与完整性接口接通。

专项回归 **121 passed、6 skipped、2 warnings**：涵盖本地/云端协议、配置快照、考试、课程资料缓存与权限、取消、配置 API、知识库解析和图片接入。6 个跳过项是未配置隔离 PostgreSQL 的双后端用例；SQLite 对应项通过。

扩大检查时记录过两项失败：新增缓存测试直接比较内存 tuple 与 JSON list，已修正为比较序列化后的值；另一个 RAG 存储测试硬编码要求 `backend/src/storage`，与环境指定存储根目录不符，未修改该测试来迁就本次改动，最终仅选取相关 RAG 解析/图片用例。隔离入口补齐 RAG 从环境读取的路径，防止测试导入时使用生产路径。
