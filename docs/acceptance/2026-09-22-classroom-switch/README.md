# AI 课堂默认生成与前端开关

新建课程默认为每个知识点生成报告、习题和 AI 课堂。首页输入框下方提供默认开启的「AI 课堂」开关；关闭后生成报告和习题。需求文字和模型推断都不能覆盖开关。局部补充、资源修订和已持久化的生成规格保持原有范围。

`overrides.include_classroom` 是严格布尔值，省略时为 true。需求整理保存的 `required_resource_types` 与实际资源生成都由程序应用此设置；路径和整课审阅提示也明确该优先级。默认值的请求摘要兼容旧请求，关闭开关会改变摘要，避免复用不同请求的幂等结果。前端切换后提交会使用新的请求编号。

学习时长仍只用于指导内容量。本次未改动学习时长、生成模型、内容质量标准或数据库结构。
