## 1. 循环不变量：正确性与终止性

- 定义循环不变量：在每次迭代开始和结束时都为真的条件，与循环条件（guard）的区别

- 引入 Cornell CS2112 四步法：建立（Initialization）、保持（Preservation）、后置（Postcondition）、终止（Termination）

- 讨论不变量的强弱：过弱导致无法证明后置条件，过强导致无法建立或保持

- 说明本报告两种变体的不变量均不要求目标存在，与 Cornell 讲义（假设 k∈a）的差异

- 检查题：给定循环与候选条件，判断是否为不变量并说明理由


### 循环不变量基础与二分查找框架

循环不变量是在每次迭代开始和结束时都为真的条件。对于二分查找，它描述搜索区间内元素与目标值的关系。本单元介绍如何用不变量指导循环设计，并区分循环条件与不变量：不变量在循环退出时仍成立，而循环条件决定何时停止。

目标：能解释两种变体的循环不变量及其在退出时的含义

示例（教学设计）：以数组a=[1,3,5,7]，目标x=5为例，初始l=0,r=3，不变量为a[:l]均小于x且a[r+1:]均大于x（闭区间），循环中每次更新保持此性质。

易错点：误认为循环条件（如l<=r）是不变量的一部分，实际上循环条件在退出时为假，不变量必须独立于循环条件成立。

自检：给定一个循环，让学生判断某条件是否为不变量（在循环前后均成立），并解释为何循环条件不是不变量。

依据：资料 1

## 2. 闭区间变体：查找任一匹配下标

- 代码框架：l=0, r=n-1, while l<=r, m=(l+r)//2

- 返回值契约：a[m]==x 立即返回 m；循环退出返回 -1（表示不存在）

- 不变量：0<=l<=r+1<=n，a[:l] 均 <x，a[r+1:] 均 >x

- 更新规则：a[m]<x 则 l=m+1（排除 m），a[m]>x 则 r=m-1（排除 m）

- 示例：a=[1,3,5,7], x=5 返回 2；x=4 返回 -1（逐步模拟）

- 边界示例：空数组返回 -1；单元素 a=[5], x=5 返回 0；重复值 a=[1,3,3,5], x=3 返回任一匹配下标（不保证最左）；目标大于所有元素 a=[1,3], x=9 返回 -1

- 常见错误：更新分支漏 +1 或过度 +1 导致死循环或漏检；将 -1 与半开区间的 n 混淆

- 终止性：每次未返回的迭代使候选长度 r-l+1 严格减小且不小于0；循环退出时 l=r+1，结合不变量说明目标不存在。

- 检查题：手动模拟给定数组与目标，写出每步 l,r,m、候选长度并验证返回值


### 闭区间变体：查找任一匹配下标

闭区间变体使用l=0, r=n-1，循环条件l<=r。不变量为0<=l<=r+1<=n，a[:l]均小于x，a[r+1:]均大于x。当a[m]==x时立即返回m；若a[m]<x则l=m+1，否则r=m-1。循环退出返回-1表示不存在。此变体适用于查找任意匹配下标，目标可不存在。

目标：能写出闭区间变体的二分查找代码，并正确返回匹配下标或-1；能解释两种变体的循环不变量及其在退出时的含义；能处理空数组、单元素、重复值、目标不存在等边界情况

示例（教学设计）：a=[1,3,5,7]，x=5：l=0,r=3,m=1,a[1]=3<5→l=2；m=2,a[2]=5==5→返回2。x=4：l=0,r=3,m=1→l=2；m=2,a[2]=5>4→r=1；l=2>r=1退出，返回-1。

易错点：将返回-1与半开区间的插入点n混淆，或认为闭区间变体也能返回插入点。本节选定的闭区间实现只返回匹配下标或-1，不提供插入位置；这不是所有闭区间算法的普遍限制。

自检：给定有序数组和目标，手动模拟闭区间变体，写出每一步的l,r,m，并验证最终返回值。

依据：资料 1

## 3. 半开区间变体：bisect_left 左插入点语义

- 代码框架：l=0, r=n, while l<r, m=(l+r)//2

- 返回值契约：退出返回 l（左插入点 ip），确认存在须 l<n 且 a[l]==x

- 不变量：0<=l<=r<=n，a[:l] 均 <x，a[r:] 均 >=x

- 更新规则：a[m]<x 则 l=m+1，否则 r=m（注意 r=m 而非 m-1）

- 终止性：每次迭代使 r-l 严格减小；退出时 l=r，由两侧分区条件推出返回值是首个不小于目标的位置（允许等于n）。

- 与 Python 官方 bisect 文档分区性质对应：a[lo:ip] 均 <x，a[ip:hi] 均 >=x

- 示例：a=[1,3,5,7], x=5 返回 2；x=4 返回 2；x=8 返回 4（逐步模拟）

- 边界示例：空数组返回 0；单元素 a=[5], x=5 返回 0；重复值 a=[1,3,3,5], x=3 返回 1（最左）；目标大于所有元素 a=[1,3], x=9 返回 2

- 常见错误：将插入点直接当作匹配下标（未检查存在性）；误在循环退出后直接访问 a[l]；循环内部 l<r 保证 l<=m<r<=n，a[m] 可安全访问；把 n 与 -1 混淆


### 半开区间变体：左插入点语义

半开区间变体（bisect_left）使用l=0, r=n，循环条件l<r。不变量为0<=l<=r<=n，a[:l]均小于x，a[r:]均大于等于x。当a[m]<x时l=m+1，否则r=m。退出时l==r，返回l作为左插入点。确认存在需检查l<n且a[l]==x，插入点可等于n。

目标：能写出半开区间变体（bisect_left语义）的代码，并正确返回左插入点；能处理空数组、单元素、重复值、目标不存在等边界情况

示例（教学设计）：a=[1,3,5,7]，x=5：l=0,r=4,m=2,a[2]=5>=5→r=2；m=1,a[1]=3<5→l=2；l==r=2，返回2。x=4：l=0,r=4,m=2,a[2]=5>=4→r=2；m=1,a[1]=3<4→l=2；返回2。x=8：l=0,r=4,m=2→l=3；m=3,a[3]=7<8→l=4；返回4（等于n）。

易错点：认为半开区间变体直接返回匹配下标，忽略它返回的是插入点，需额外检查存在性。

自检：给定数组和目标，计算bisect_left结果，并验证分区性质：a[:ip]均<x，a[ip:]均>=x。

依据：资料 1

## 4. 边界情况系统化处理与两种变体对比

- 空数组：闭区间 l=0,r=-1 循环不执行返回 -1；半开区间 l=0,r=0 返回 0

- 单元素：闭区间检查 a[0]==x；半开区间返回 0 或 1

- 重复值：闭区间返回任一匹配下标（不保证最左）；半开区间返回最左匹配索引

- 目标不存在：闭区间返回 -1；半开区间返回插入点（可为 n）

- 目标大于所有元素：闭区间返回 -1；半开区间返回 n（须先检查 l<n 再访问 a[l]）

- 对比两种变体的返回值契约：-1 表示不存在 vs n 表示右端插入点，不可混为一谈

- 强调两种变体不是简单的区间记号切换，而是返回语义的根本不同

- 检查题：设计测试用例覆盖上述边界，分别用两种变体实现并验证输出


### 边界情况处理：空数组、单元素、重复值、目标不存在

空数组：闭区间l=0,r=-1，循环不执行返回-1；半开区间l=0,r=0，返回0。单元素：闭区间检查a[0]是否等于x；半开区间返回0或1。重复值：闭区间返回任一匹配下标（不保证最左），半开区间返回最左匹配的索引。目标大于所有元素：闭区间返回-1，半开区间返回n。

目标：能处理空数组、单元素、重复值、目标不存在等边界情况；能识别并修复常见错误（如死循环、越界、混淆返回值）

示例（教学设计）：a=[]，x=5：闭区间返回-1，半开区间返回0。a=[5]，x=5：闭区间返回0，半开区间返回0。a=[1,3,3,5]，x=3：按本节向下取整模板，闭区间返回1，半开区间也返回1；另取a=[1,2,2,2,3]、x=2，闭区间首轮返回2，半开区间返回1，说明任一匹配与最左匹配的差异。a=[1,3]，x=9：闭区间返回-1，半开区间返回2。

易错点：忽略空数组导致访问a[0]越界，或认为半开区间返回值总是有效索引，未检查l<n就访问a[l]。

自检：编写测试用例覆盖空数组、单元素、重复值、目标不存在，验证两种变体的输出。

依据：资料 1

## 5. 常见错误调试与可检验学习目标

- m 计算：Python 中 (l+r)//2 必须取整，虽无溢出但浮点索引会报错

- 更新分支错误：漏 +1（如 l=m）导致死循环；过度 +1（如 r=m-1 在半开区间）导致漏检

- 死循环分析：以 a=[1], x=2 为例展示 l=m 不 +1 的无限循环

- 越界问题：循环内由 l<r 和向下取整保证 m<n；循环退出后 l 可能为 n，访问 a[l] 前须先检查 l<n

- 返回值混淆：-1（不存在）与 n（右端插入点）语义不同

- 调试策略：用 assert 检查不变量；用边界测试用例（空、单元素、重复、不存在）验证

- 学习目标：能写出两种变体代码并解释不变量；能处理所有边界情况；能识别并修复常见错误

- 检查题：给出含错误的二分查找代码，找出错误并修复，运行测试用例验证


### 常见错误与调试策略

常见错误包括：m计算未取整（Python中(l+r)//2需用整数除法）；更新分支漏+1或过度+1导致死循环或漏检；半开区间循环退出后未检查l<n就访问a[l]可能越界（循环内由l<r保证m<n）；混淆-1与n。调试策略：用断言检查不变量，用边界测试用例验证。

目标：能识别并修复常见错误（如死循环、越界、混淆返回值）

示例（教学设计）：错误代码：l=0,r=n; while l<r: m=(l+r)//2; if a[m]<x: l=m; else: r=m-1。当a[m]<x时l=m不+1，若l=m且m<r，可能死循环（如a=[1],x=2，l=0,r=1,m=0,a[0]<2→l=0，无限循环）。完整修复需同时改为：小于目标时l=m+1，否则r=m。只修复左分支后，右分支r=m-1仍可能跳过合法的左插入点。

易错点：认为Python中l+r不会溢出就无需关注m计算，但忘记取整会导致浮点数索引错误。

自检：给出有错误的二分查找代码，让学生找出错误并修复，然后运行测试用例验证。

依据：资料 1
