# 实验助手“回答或继续问”点击反馈修复

已发布前端，无需重新生成实验或重启后端。

## 原因与调整

正式页面复现：点击后焦点仍在按钮，输入框位于 y=1024–1124，而视口高度只有 1000，见 [复现记录](before.json)。原逻辑仅选择回复对象；最新回答完成时本来就会自动选中，再点同一条不会产生可见变化。

按钮现在在用户点击时同步聚焦输入框并滚动到可见位置，保留草稿，增加选中样式和 aria-pressed；“改问当前操作”同样定位输入框。模型完成回答不会自动抢夺输入焦点。

## 验证

- 发布预览和正式页面各 12 项检查通过：1440、390、320px，各覆盖选择最新回答、重复选择、选择旧回答及键盘 Enter。均检查输入框焦点、可见位置、草稿保留、选中状态和页面无横向溢出。选择本身不发送模型请求；切回当前操作同样保留草稿。见 [预览](preview-results.json)、[正式页面](online-results.json) 和 [手机截图](online-390.png)。手机采用 Chromium 窄屏模拟，未声称真机软键盘验证。
- 从正式页面点击历史回答后发送一次真实追问，前端请求和服务端保存的 reply_to 均与所选历史消息一致；回答正常完成，首段 1.786 秒，总计 2.250 秒。见 [真实问答](real-qa.json)。使用已有专用测试实验，不操作其他用户实验。
- 新旧实验协议桌面/手机共 4 项浏览器回归通过，其中新增重复点击定位与草稿保留断言，见 [回归日志](regression.log)。
- 实验模块专用 TypeScript 检查、组件 ESLint 和正式构建通过。最初尝试全仓 tsconfig 检查时遇到已存在的测试导入和其他模块类型错误，因此没有宣称全仓类型检查通过。

基于与正式入口哈希一致的 `/tmp/edu-exam-fixes-source`，只叠加两个实验前端文件构建。发布前校验旧入口、备份，安装新资源后原子替换入口；保留旧资源，核对 Nginx 入口和全部发布文件哈希。见 [发布清单](deployment.json)。
