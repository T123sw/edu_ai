## 可复现的问题

旧检查器把全部参数同时改到最大值（数字以外的输入也一律改成数字），随后只等待 1400ms，再对比开始/结束快照。这会改变动画速度或破坏数组输入，并漏掉延迟/短暂的中间结果。

确定性回放：一个正常延迟 1800ms 更新结果的页面，旧检查判失败，新检查通过。同主题另一次真实模型生成的快速排序页面在旧检查下也能通过，说明模型生成具有差异；该页面不是原任务的失败候选。

## 修改

- 默认参数运行一次；参数逐项测试，数值在默认值附近按 step 调整，保留合法范围；CSV 数组保留数组格式，不把自由文本强制变成数字。
- 观察最多 8 秒并捕获 report 事件，中间结果变化也会被记录。
- 仍要求参数操作产生结果变化，仍拦截 JS 错误、无结果、无控件、横向溢出等；没有跳过验证。
- 检查输出增加控件值、操作前后快照和尝试记录，模型修复可使用具体证据。
