## 实现

- 设计 Skill 要求算法从初始输入执行至真实终止，缩小输入规模而不截断过程；删除 12 步演示与 5 个任务的格式上限，不规定练习题数。
- 一个实践任务可包含完成整个算法的连续操作。正确中间操作返回 pending 并反馈，只有实际完成才 pass；fail 恢复本次操作前状态，保留已有进度。最后一个任务通过后不再调用下一任务初始化，保留最终结果并锁定操作；重置可重新开始最后一个任务。
- 探索页配置不传入 demo_initial、demo_result 或教学任务，使用页面自身的初始参数。说明文字不进入参数解析。生成约定要求页内输入错误提示，避免沙箱拦截 alert。
- 设计 Skill、页面接口约定放入 system 指令，原始 HTML 作为算法和绘图参考，防止原探索页的自动单步控件覆盖人工判断要求。
- TeachingPlan 增加少量 demo_result 目标结果字段。本地运行全部演示后检查实际结果，拦住仅设置完成标志的页面；不约束容易与算法变体相关的过程计数。练习检查实际 EduStage.perform 调用并拒绝“单步/下一步/自动完成”按钮替代判断。最终拼装后的三个页面再做本地接入检查，无新增模型审查调用。
