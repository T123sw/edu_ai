# Agent Memory V2 扩展评测报告

> 日期：2026-08-31
>
> 分支：`feature/agent-memory-v2-langmem`
>
> 结论：第一阶段后端验收通过；真实 LangMem 仍应保持后台候选层定位。

## 1. 评测范围

本轮把原有 15 条抽取样本和 10 条检索样本扩展为：

- 130 条确定性候选抽取压力样本：70 条明确长期偏好，60 条普通问句、保护事实、引用/否定和临时偏好。
- 100 条检索压力样本：每条包含同用户同课程高相似干扰、跨用户精确匹配和跨课程精确匹配。
- 12 条真实 LangMem 难例：6 条应写入，6 条应拒绝或返回空结果。
- 真实 PostgreSQL E2E：LangMem 抽取、policy、持久化、跨会话召回和探针清理。

所有 LangMem 指标均按“经过项目 policy 后的最终写入结果”统计，不把模型原始候选冒充最终质量。

## 4. 本轮修复

- 将 LangMem 的空 schema 插入解释为 `empty/no_candidates`，不再误报 provider error。
- 将 `"None"`、`"null"` 和 `"n/a"` 等可选字段输出归一化为空值。
- 偏好、画像和纠正候选必须在用户原话中包含显式、长期表达证据。
- 引用、否定、临时要求和受保护学习事实统一由 policy 拒写。
- 保留 `source_span` 必须逐字存在于用户消息中的校验。

## 6. 限制与下一步

- 真实 LangMem 仅 12 条人工难例，样本仍小，不能代表生产分布。
- 最终轮只有一次运行，尚未形成多次重复试验的置信区间。
- 当前 embedding 默认关闭，检索压力集主要验证文本排序和权限隔离。
- 尚未使用匿名化真实用户对话验证长对话、错别字、方言、多语言和长期矛盾演化。

上线灰度前建议采集至少 300 条匿名化对话，按相同数据集重复运行 3 次，并以 Precision、Recall、画像轴准确率、错误率、P95 延迟和人工偏好一致率作为下一道闸门。
