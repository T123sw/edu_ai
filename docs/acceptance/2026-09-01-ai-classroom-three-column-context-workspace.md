## 1. 验收范围

## 2. 自动化验收

### 2.1 后端目标测试

执行资源问答、课堂问答、学生课堂权限和课程目录目标测试：

```text
55 passed, 0 failed, 3 warnings
```

三项摘要警告来自 `pkg_resources`/FastAPI 旧事件接口的弃用提示；pytest 结束后另有 Windows 临时目录清理警告，均未改变退出码和测试结果。

覆盖结论：

- 文档和习题使用完整资源上下文；
- 学生只能访问批准版本，教师编辑角色访问当前可见版本；
- 习题答案在不应展示时会从上下文中清除；
- 资源 ID、版本、角色和所有者共同隔离问答会话；
- 问答音频使用受保护路径；
- 课堂全文检索可命中后续场景；
- 个人课堂与课程课堂权限未回归。

### 2.2 前端完整测试与构建

```text
npm test: 435 passed, 0 failed
npm run build: success
```

覆盖结论：

- 课程资源和个人课堂 URL 目标互斥；
- 静态资源问答不会触发课堂播放中断；
- 资源 A 的迟到回答不能污染资源 B；
- 教师审核面板和学生进度组件仍由中栏资源查看器承载；
- 目录、问答抽屉具备语义、Escape 关闭和焦点恢复合同；
- 960px、1280px 两级响应式合同和独立滚动通过。
