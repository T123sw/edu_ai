# SCRIPT — n5-tradeoff-self-attention

**Voice:** 中文女声（host 语音提供方，zh）
**Voice settings:** 默认语速，稳定、清晰、不作夸张起伏
**Voice direction:** 教师讲解。克制、以对比和判断为主；数字与公式读得稍慢，句间留自然停顿；不做营销式渲染，不提问作答。

## Line 1 — 开场：一个取舍问题 (Frame 1)

**Time:** 0.0 – 22.0s
**Delivery:** 承接前两节，直接抛出问题；最后一句点出三个角度时放慢。

    前面我们看清了 Transformer 的整体结构，也拆开了缩放点积注意力。这一节只回答一个问题：既然循环网络已经能做序列到序列的任务，为什么还要换成自注意力？那句常听到的“完全并行”，又在什么范围内成立？判断不靠直觉，靠三个可量化的角度：每层计算复杂度、最少顺序操作数、以及任意两个位置之间的最大路径长度。

## Line 2 — 循环的固有串行性 (Frame 2)

**Time:** 22.0 – 48.0s
**Delivery:** 描述机制，语气平稳；"代价不只是慢"处略作强调。

    先看被替换的一方。循环模型沿符号位置分解计算：每一步的隐藏状态，都由前一个隐藏状态和当前位置的输入共同决定。对齐到计算时间上，位置 t 必须等位置 t 减一算完，这就形成一条长度等于序列长度的依赖链。代价不只是慢：一个训练样本内部无法并行，只能在样本之间批处理，序列越长，可并行的批量越受显存限制。

## Line 3 — 三个衡量角度 (Frame 3)

**Time:** 48.0 – 72.0s
**Delivery:** 三个角度逐一交代，像在黑板上写下三个列标题。

    那怎么公平地比较不同的层类型？原论文给了三个角度。第一，每层的计算复杂度，一层要花多少计算量。第二，可以并行化的计算量，用最少顺序操作数衡量，也就是把所有位置并行算完需要几个串行步骤。第三，长程依赖的最大路径长度，信号从一个位置走到另一个位置要穿过多少层；路径越短，长程依赖越容易学。

## Line 4 — 第一列：每层计算复杂度 (Frame 4)

**Time:** 72.0 – 100.0s
**Delivery:** 逐行读数，公式读成中文量级；不要赶。

    先填第一列，每层计算复杂度。自注意力是 n 平方乘 d 的量级：n 个位置两两打分，得到一个 n 乘 n 的注意力矩阵，每个元素是一次长度为 d 的点积。循环层是 n 乘 d 平方：n 个时间步，每步把 d 维输入乘上 d 乘 d 的权重矩阵。卷积层是 k 乘 n 乘 d 平方：核宽 k，深度可分离卷积能压小后面的项，但单个卷积核宽小于序列长度时，连不上所有位置对。

## Line 5 — 第二、三列：顺序操作数与路径长度 (Frame 5)

**Time:** 100.0 – 136.0s
**Delivery:** 两列连着讲，节奏可以稍快，但每个数值都落在对应的行上。

    第二列，最少顺序操作数。自注意力是常数级：所有位置同时打分、同时加权求和，一层只要常数个串行步骤。循环是 n 级：第 t 步必须等第 t 减一步，顺序步数等于序列长度。卷积也是常数级，每个输出只依赖固定窗口内的输入。第三列，最大路径长度。自注意力是常数：任意两个位置一步直达。循环是 n：信息要沿链一步步传。卷积是对数级：以 k 为底、n 的对数，需要 n 除以 k 层连续卷积，或者用膨胀卷积压到对数层。

## Line 6 — 条件：n < d (Frame 6)

**Time:** 136.0 – 166.0s
**Delivery:** "必须说清的条件"处停顿半拍；数字念清楚，语速不变。

    这里有个必须说清的条件。比较 n 平方乘 d 和 n 乘 d 平方，同时约掉 n 和 d，剩下就是 n 与 d 比大小：当序列长度 n 小于表示维度 d 时，自注意力每层反而更省。这在句子上通常成立。原论文用 word piece 和 byte pair 表示，句子长度只有几十，而模型维度是五百一十二。比如 n 取四十、d 取五百一十二，n 平方乘 d 约八十二万，n 乘 d 平方约一千万，差一个数量级。

## Line 7 — 代价与受限自注意力 (Frame 7)

**Time:** 166.0 – 194.0s
**Delivery:** 讲代价时不夸大；最后一句"账没有消失，只是换了位置"放慢，作为本段落点。

    代价也要摆在同一张表上。自注意力的复杂度对 n 是平方的：序列翻倍，每层计算量和注意力矩阵的内存都变成四倍，长序列下这就是瓶颈。原论文给出一条缓解路径：每个位置只看邻域 r 以内的位置，就是受限自注意力。复杂度从 n 平方乘 d 降到 r 乘 n 乘 d，代价是最大路径长度从常数升到 n 除以 r。账没有消失，只是换了位置。

## Line 8 — 完全并行的边界 (Frame 8)

**Time:** 194.0 – 236.0s
**Delivery:** 全片最重要的一段。训练与推理两侧对比要清楚；"一次前向"和"m 次顺序前向"重读。

    现在说那句最容易误解的“完全并行”。它只对编码器，以及训练时的解码器成立。训练用教师强制：解码器输入是真实目标句右移一位的结果，因果掩码保证位置 i 只能看到位置一到 i，于是所有位置的预测能在一次前向里同时算出。推理时没有真实答案，第 i 个词元必须等第 i 减一个选出来，才能作为输入。生成 m 个词元，仍然需要 m 次顺序前向。

## Line 9 — 结论与工程佐证 (Frame 9)

**Time:** 236.0 – 264.0s
**Delivery:** 收束、清楚；最后一句是留给学生的判断句，语气平实不煽动。

    把这些放在一起，判断就清楚了。自注意力用常数个顺序操作，换来常数级的路径长度，代价是每层随 n 平方增长的复杂度；“完全并行”只覆盖编码器和训练时的解码器，不覆盖自回归生成。工程上的回报是真实的：原论文的模型在八块 P100 上训练十二小时，就达到了新的翻译质量最优。所以下次有人问 Transformer 为什么快，先问他一句：你说的是训练，还是生成？
