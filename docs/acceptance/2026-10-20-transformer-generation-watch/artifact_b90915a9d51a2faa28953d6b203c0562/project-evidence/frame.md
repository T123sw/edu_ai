# frame.md — 设计真源（课程视觉合同）

本文件是品牌真源：颜色、字体、字号、间距、组件与构图规则。故事板块拥有内容，本文件拥有外观。帧内的可见文字不得照抄本文件。

## 画布与安全区

- 画布 1920 × 1080，16:9。根元素使用 `width/height: 100%`，画布尺寸由 `data-width` / `data-height` 声明。
- 外边距 96px（左右）。内容竖直区域：`y = 104` 到 `y = 876`。
- **字幕保留带**：`y > 900` 的区域留空（底部约 17%）。任何元素（标题、卡片、图示标签、箭头、页脚）都不得越过 876。即使本片最后没有字幕轨，也保持这条底线一致性。
- 每帧左下角可有页码点阵，基线 `y = 852`，高度 ≤ 10px；这不是必须元素。

## 字体（已随项目提供，禁止另找字体）

在**每个**子组合的 `<template>` 内部声明一次 @font-face，路径相对装配后的项目根：

```css
@font-face {
  font-family: "Noto Sans SC";
  font-style: normal;
  font-weight: 100 900;
  font-display: block;
  src: url("assets/fonts/NotoSansSC-Variable.ttf") format("truetype");
}
```

- 全片唯一字体族：`"Noto Sans SC"`（中文与拉丁共用，字重 100–900 可变）。不得出现任何其他 font-family 名称（系统 CJK 字体、monospace 都不可用）。
- 公式、维度符号、`d_model`、`LayerNorm(x + Sublayer(x))` 也用该字体，用字重与 `font-variant-numeric: tabular-nums` 区分层级，不要引入等宽族。
- 数字强调用 `font-variant-numeric: tabular-nums`。

## 字号阶梯（硬下限）

| 用途 | 字号 | 字重 |
| --- | --- | --- |
| 封面主标题 | 92–104px | 800 |
| 帧标题 / 主陈述 | 56–64px | 700 |
| 正文说明 | 36–40px | 400–500 |
| 图示标签、卡片内文 | 28–32px | 500 |
| 维度/数字标签、角标 | 28–32px | 700 |
| 页脚 / kicker | 28px | 600，字距 +0.08em |

- 正文不得小于 32px，图示标签不得小于 28px，标题不得小于 48px。
- 一屏文字量受控：标题 ≤ 18 字，单行说明 ≤ 26 字。**密集框图拆成多步呈现，不缩字号。**
- 行高：标题 1.18，正文 1.55，标签 1.35。

## 颜色令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| canvas | `#0f172a` | 帧背景（全片统一） |
| canvas-deep | `#0b1222` | 背景渐变的暗端 |
| surface | `#18243c` | 卡片/面板底色 |
| surface-2 | `#1f2f4d` | 高亮面板、选中格 |
| ink | `#f8fafc` | 主文字 |
| ink-muted | `#a9b6ca` | 次级说明、轴标签 |
| stroke | `rgba(248,250,252,0.16)` | 描边、网格线 |
| accent | `#38bdf8` | 强调色：编码器侧、主箭头、要点 |
| accent-2 | `#a78bfa` | 解码器侧、交叉注意力 |
| accent-3 | `#fbbf24` | 掩码 / 禁止 / 提醒 |
| ok | `#34d399` | 中间表示 z、通过/合法 |
| danger | `#fb7185` | 非法连接、越界 |

- 只用上表色值。所有文字对比度必须 ≥ 4.5:1：ink/ink-muted 在 canvas/surface 上均满足；accent 系仅用于大字号或 ≥28px 的标签。
- 背景使用 `radial-gradient` 或极低透明度（≤0.10）的装饰网格，不得压过内容。

## 组件

1. **kicker（帧首角标）**：28px，字距宽，`accent` 色，前面一条 40×3px 短线。
2. **headline（帧标题）**：56–64px / 700，`ink`，左对齐于 96px 边距，位于 `y≈150`。
3. **block（框）**：圆角 16px，`surface` 底，1.5px `stroke` 描边；内部标题 32px / 700，副标签 28px / 500 `ink-muted`。编码器相关块描边带 `accent` 提示，解码器相关块用 `accent-2`。
4. **stack-chips（堆叠示意）**：3–4 个 28px 高的横条叠成 "N=6" 的层叠暗示，偏移 10px，最上层实体块标 "×6"。不要画六层完整细节。
5. **arrow（数据流箭头）**：2.5–3px 线宽，箭头头部三角；主链 `accent`，交叉注意力用 `accent-2` 虚线（`stroke-dasharray` 视觉，不靠动画）。
6. **chip（标签药丸）**：`surface-2` 底，圆角 999px，内边距 8×18，文字 28px。
7. **formula plate（公式板）**：`canvas-deep` 底 + `accent` 左侧 4px 竖条，文字 34–40px，字重 600。
8. **matrix（掩码矩阵）**：4×4 单元格 96×96，gap 10px；合法格 `surface-2` + `ok` 描边，非法格 `danger` 填充 0.18 透明度 + `−∞` 文字 30px；行列标签 28px `ink-muted`。
9. **tokens（序列小格）**：64×64 圆角 12 格，内放单字符/向量标记，标签在下方 28px。
10. **step list（数据流清单）**：行高 56px，序号圆点 34px `accent`，条目 32px。

## 构图规则

- 每帧一条主视线：从左到右（数据流）或从上到下（层级堆叠），不要两条竞争。
- 主元素高度锚定在 `y≈0.22–0.34 × 1080`；支撑细节向下铺开。横向内容居中于 96–1824 区间。
- 主元素在 `t ≤ 0.5s` 内可见（用 `fromTo` 入场，不用 CSS 隐藏态）。
- 每帧的揭示必须铺满整个时长，按旁白节奏依次到达；禁止在 25% 处一次性铺满整屏。
- 背景装饰（网格、光晕）为 `class="clip"` 的全时长底层元素；背景色不得画在 `#root` 上。

## 结构提示（论文图 1 的骨架）

- 左侧竖直栈 = 编码器（`accent`），右侧竖直栈 = 解码器（`accent-2`），中间水平通道 = 表示 `z`（`ok`）。
- 编码器层 = 2 个子层块；解码器层 = 3 个子层块（掩码自注意力 / 交叉注意力 / 前馈）。
- 每个子层块外侧画残差旁路弧线 + `LayerNorm` 小标签；统一维度 `d_model = 512` 作为贯通的尺寸标注。
- 掩码帧使用 matrix 组件，上三角整片 `−∞`；与右移一位配合时用两行 token 序列错位演示。

## 动画语法（遵从规律，不发明）

- 一个 paused GSAP 时间线，注册在 `window.__timelines["<frame_id>"]`。
- 入场 `fromTo`，位移用 `x` / `y` / `scale` / `opacity`，不使用 `width` / `height` / `top` / `left` 补间。
- 揭示节奏：标题先到（0–0.6s），块/节点按旁白逐块到达（每块 0.35–0.5s），箭头/连线最后接通。
- 缓动：`power3.out` 入场，`power2.inOut` 位移，`back.out(1.6)` 只用于单个关键 chip 落位。
- 禁用 CSS `transition`、`repeat: -1`（有限 root 时长下也只允许有限次数）、`Math.random`、`Date.now`。
