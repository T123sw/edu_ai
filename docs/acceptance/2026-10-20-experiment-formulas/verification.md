# 实验原理与公式解析修复

## 复现与原因

只读检查当前冒泡排序实验 `practice_71abf36edf8b5ed8c95e126ea98a2d9e`，演示和探索两页的参考区均有 8 处未解析公式，包括 `\(a[i] > a[i+1]\)` 和 `\(\frac{n(n-1)}{2}\)`。

原生 PostProcessor 通过 HTML 是否包含 `katex` 判断是否注入初始化脚本。该实验只有 `.katex-display` 样式，也满足这一判断，导致漏掉初始化。宿主虽已内嵌 KaTeX 资源，但没有统一调用解析器。原生依赖保持固定版本，未修改。

## 修复范围

展示层在布局整理后统一解析原理参考区，已有实验无需重新生成或修改存储内容。采用 KaTeX 默认分隔符，覆盖 `\(...\)`、`\[...\]`、`$$...$$` 和其默认数学环境。原生后处理已将单美元符号公式转换为括号分隔符。

跳过已渲染公式、代码和输入控件；观察参考内容变化并重新解析新增公式，解析期间断开观察避免自身更新循环。保留 `trust: false`，不修改实验状态、事件和生成流程。

## 验证

- 复现原页面显示 LaTeX 源码，修复后两页各渲染 8 处公式且无 `.katex-error`；分式实图检查通过。
- 独立浏览器回归覆盖 CSS 含 KaTeX 但未初始化、行内和块级公式、预先渲染内容保持一致、动态修改、反复展开收起及代码/输入/参考区外文本保留。
- 隔离发布包类型检查、Vite 构建通过；15 项浏览器回归通过，包含实际冒泡排序、摩擦力、旧实验恢复、两阶段流程及 320–1440 宽度布局。
- 当前冒泡排序桌面和手机测试在 Nginx 发布入口再次验证；浏览器 API 全部使用本地模拟响应，没有写入生产学习数据。结果见 `published-browser.log`，发布信息见 `release.json`。
- 仅叠加 `presentation.ts` 和 `frameMath.js` 到最新课程共享会话前端快照；不需要重启后端。
