## 验证结果与限制

后端最终综合回归：**410 passed / 7 skipped，350.76 秒**，见 [完整输出](integrated-agent/20260917T144926865351Z-pytest.txt) 和 [命令/环境/哈希](integrated-agent/20260917T144926865351Z-run.json)。7 个 skip 为 6 个 SQLite 不支持的并发/进程场景、1 个未启用的旧 LangMem 自动提取 live 集成；相应 PostgreSQL 并发场景与旧记忆 PostgreSQL 集成实际运行。LangMem 自动提取不是本学习 Agent 默认写入路径，未将其 skip 计为通过。轮询修复的请求内来源去重、跨请求重新授权、撤权拒绝均包含在本次综合回归。

浏览器：安静学习/会话 11 项通过；真实即时检查 1 项、偏好编辑删除 1 项、教学观察 1 项、真实延迟通知 1 项通过。最终全资料浏览器曾多次失败，记录依次保存在 final-interview/browser-*.txt。限制检查题并发和取消旧读取后单节点闭环通过，但连续切换仍复现，正式构建也复现，因此不能把问题归咎于开发服务器。进一步测得轮次列表单次请求约 12.6 秒，而前端每秒重复发送并积压；列表又对同源历史轮次重复读取和授权。最终修复为串行轮询（空闲 5 秒、活动 1 秒、切换时取消）及每次列表请求内按准确资料版本去重校验，不跨请求缓存权限。正式构建下两项完整浏览器验收通过（52.6 秒 + 42.5 秒，总计约 98.5 秒），全部 12 份资源均有打开截图；保持代码不变，第二次独立浏览器会话也通过（43.6 秒 + 49.8 秒，总计约 96 秒）。两次都是完整登录、真实模型答疑、作答刷新、课堂播放及全部 12 份资料打开。
