# 我有 Python 开发基础，目标是应聘 AI Agent 开发岗位，希望在120分钟内建立适合工作面试的实践认知。请安排4个循序渐进的知识点：Agent循环与模型/应用职责边界；工具调用与失败恢复；记忆与上下文管理；评估与可观测性。请搜索并实际阅读可信资料，汇总依据后生成可执行的学习路径。每个节点需要学习报告、理解练习和可播放的讲解课堂，包含具体案例与面试自测。内容以入门到能够解释设计取舍为准，不要求完成大型项目。

预计 120 分钟；课程版本 1。

## 1. Agent 循环与模型/应用职责边界（30 分钟）

- 能用自己的话解释 Agent 不是单一循环，而是 L1 工具调用循环、L2 任务循环、L3 编排循环三层嵌套结构
- 能清晰说出模型与应用的职责边界：模型只提议动作，应用负责校验参数、执行权限并决定如何处理输出
- 能在面试中解释为什么把执行与校验放在应用层而非模型层（确定性 vs 非确定性）

## 2. 工具调用与失败恢复（30 分钟）

- 能描述工具调用协议：模型产出结构化 JSON 载荷（工具名+参数），应用接收、校验、执行并返回结果作为新上下文
- 能区分瞬时故障与持久故障，并说明各自的处理策略（指数退避 vs 熔断器）
- 能解释为什么模型应始终知道工具失败，而不是用幻觉内容填补缺口
