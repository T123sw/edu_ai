## 0. 执行结论

- 八类生成工厂按钮已统一调用 `/api/chat/v2/stream`，没有触发旧 direct 或课堂直达接口；用户原文与内部 `action_hint` 分离。
- 工厂请求新增 `entry_mode=generation_factory`，不携带当前会话 ID，不插入聊天气泡，也不写会话历史或长期记忆；普通对话仍保留大纲确认。
- 工厂请求在模型规划前即创建真实的 `preparing` 后台任务；任务中心立即可见，正式生成沿用同一任务 ID，准备失败也落在该任务记录中。
- 报告、教案、博客和 AI 课堂可在同一 Agent 轮次完成内部规划并直接提交，用户不再确认工厂入口的大纲或方案。
- 配置弹窗已收敛为一个自然语言输入框、每类动态浅色示例和折叠资料范围；空输入、placeholder、键盘焦点、草稿和窄屏引导均有自动化证据。
- Agent 创建的八类资源使用显式 `review_policy=required`；普通资源和课堂都在发布前校验独立审阅与内容摘要绑定。
- 真实模型已验证报告/教案/博客/课堂方案，以及教案、博客、习题、闪卡、导图、游戏的完整任务和材料回读。课堂完整任务首次在独立审阅的空修改处失败并被正确阻止发布；适配层已修复且回归测试通过。真实重试生成完成后，外部模型主备密钥均返回 HTTP 402，审阅未能完成，证据保留在重试目录。
- 六档浏览器受影响矩阵共 70/70 通过，覆盖 1920、1440、1366、1280、1024 和 390 宽度，前端构建通过。完整桌面 E2E 基线为 92/122 通过、28 失败、2 跳过，失败分布在既有课堂、知识向导、学习闭环、学生工作区和视觉快照等模块；本功能矩阵与完整基线分开记录。前端全量为 481/483，两项失败是本轮开始前已存在的源码静态断言。后端全量运行 47 分钟到 68% 后因已累计 122 个失败标记而停止；本功能定向集 55/55 通过。
- 当前结论为“有条件通过”：核心入口、请求、质量策略和响应式可交付；尚未逐项完成人工播放/通关截图、所有权限攻击场景及本文每组精确数字的真实模型复跑。

## 2. 签收总门槛

以下条件必须全部成立：

1. 八类资源按钮均从生成工厂进入 Chat V2 Agent 流。
2. 生成工厂提交时不调用逐资源 direct API 或课堂直接生成 API。
3. 极简弹窗默认只呈现自然语言需求和折叠的资料范围，不再显示大型结构化表单。
4. placeholder 不进入请求、历史、工作记忆或产物要求。
5. Agent 正确接收按钮资源类型，并从用户文字理解具体约束。
6. 工厂入口直接生成，普通对话保持差异化确认；两者使用同一质量审阅门槛。
7. 权限、来源范围、幂等、并发和恢复验证通过。
8. 自动化回归、生产构建、浏览器 E2E 和真实模型样本都有可追溯证据。

任何一项失败，整体状态不得标为“通过”。
