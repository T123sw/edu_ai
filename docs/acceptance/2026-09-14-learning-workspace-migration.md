# 自主学习课程工作区迁移

## 实现

- 首页不显示顶部导航；已登录用户的“我的课堂”读取 `/api/courses`，按最近使用／更新时间排序。
- 进入具体课程后，顶部依次显示 AI 课堂、工作台、资源中心。每个链接保留 `course_id`，教师和学生使用各自原有路由。
- 新工作区入口 `?workspace=1` 直接复用 `ClassroomStudioPage`、`AIWorkspacePage`、`CourseResourcesPage`，以及原有认证、课程权限、后台任务和资源 API。没有 iframe 或替代接口。
- 页面使用统一的淡紫浅色主题；原有课堂目录／阅读／问答三栏、工作台面板和资源目录／预览布局保留。手机顶部的三个入口直接显示在第二行。
- 返回全部课程进入自主学习首页；`?legacy=1` 保持原版导航和主题。原课程知识和学习任务仍可从教师课程菜单进入。
- 本地交互预览同步补齐三个顶部入口，工作台、资源中心与课堂之间保留 `classroom` 参数。

## 范围

本次迁移的是已有真实课程的三个工作页面。首页目标输入、示例课堂和共享发布的本地演示流程沿用前一版，并未在本次接入模型生成或服务器发布。

## 验证

- `pnpm check:self-learning`：自主学习入口类型与 ESLint 检查。
- 对修改的原版应用、课程壳、路由文件单独运行 ESLint。
- `pnpm build`：生产构建。
- `tests/self-learning/workspace.spec.ts`：用现有 API fixtures 验证教师／学生登录、从首页进入课程、三个页面切换、课程上下文、刷新与返回首页，覆盖 1440、1024、390 宽度。
- 原有自主学习交互测试覆盖本地预览和新导航兼容性。

API fixtures 只用于自动化测试；真实服务器上的模型生成和 TTS 未在本次执行。

验证结果：类型检查、修改文件 ESLint 与生产构建通过；24 项原自主学习交互测试通过，教师／学生三个尺寸共 6 项迁移测试通过。原模块在开发服务器首次加载和刷新时需要加载较多依赖，迁移测试在这些位置等待导航出现后再验证，最长等待 20 秒。
