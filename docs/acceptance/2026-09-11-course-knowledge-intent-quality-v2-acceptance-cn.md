## 1. 总体验收规则

以下五组强制条件必须全部通过：

1. 教师硬要求不遗漏、不软化，歧义能提出有效澄清；
2. 来源策略实际影响查询、筛选、全文获取和发布判定；
3. 案例、练习等交付物按类型和数量真实存在，不能以网页数量替代；
4. 每条要求可追溯到证据、产物和质量结论；
5. 任一硬要求不满足时不得发布、不得显示满分。

模拟测试、离线评测和真实外网 E2E 都必须执行。真实外网短时波动可以重试，但不能跳过或用 fixture 冒充。

## 3. 离线需求理解评测

至少 60 个标注样例，按字段统计 precision、recall 和 hardness accuracy：

- 新建课程：对象、基础、课时、难度、语言和目标；
- 增量补充：包含、排除、保留和指定节点；
- 来源：只允许、必须、优先、禁止、时效和语言；
- 产物：概念、案例、实验、练习、答案、解析和数量；
- 歧义：深一点、资料好一点、适合学生、最近内容等；
- 冲突：8 课时覆盖完整研究生内容、只用某站但又要求另一官方站；
- 安全：课程描述、网页或教材中的提示注入。

强制阈值：

- hard requirement recall = 100%；
- hard/preference hardness accuracy = 100%；
- 结构化字段整体 F1 ≥ 0.95；
- 关键歧义识别率 ≥ 0.90；
- 不应澄清的清晰样例误阻塞率 ≤ 0.05。

## 4. 来源质量测试

### 4.1 确定性 provider 场景

1. required domain 有结果：只选择符合域名且正文合格的来源；
2. required domain 无结果：构建阻塞；
3. preferred domain 无结果、社区有结果：进入教师决策；
4. A/B 来源已满足：停止继续搜索 C/D 来源；
5. 搜索摘要相关但全文无关：拒绝；
6. canonical URL 不同但正文相同：只保留一份；
7. `.org` 聚合站：不能仅凭后缀进入 A；
8. 网页提示注入：作为不可信文本清洗，不改变构建要求；
9. Tavily 失败：标记 basic fallback，关键事实不通过全文门禁；
10. rerank 失败：告警和指标可见，不能静默宣称高质量排序。

### 4.2 真实外网抽检

每次发布候选至少人工抽检：

- top-5 查询相关率 ≥ 80%；
- 可访问页面全文抽取成功率 ≥ 90%；
- 指定官方域名命中与系统统计一致；
- 来源标题、组织、URL、时间和正文可追溯；
- 默认模式无 D 级来源发布。

外网指标按运行日期记录，不能跨日期复用旧结论。

## 5. 教学产物测试

对每种产物执行 schema、数量和内容检查：

- concept：定义、机制、边界和误区；
- case：背景、步骤、输入、输出、验证和解释；
- exercise：题目、答案、解析、评分点、难度和目标；
- lab：环境、步骤、预期结果和故障排查；
- comparison：统一维度、适用条件和反例。

数量使用产物记录统计，不搜索关键词猜测。任何未通过内容审查的产物不计入教师要求数量。
