## 待修问题

1. **习题题型映射缺失（优先）**：生成器返回 `choice / blank / short / judge`，课堂控件使用 `single_choice / multiple_choice / short_answer / true_false`。实际单选题出现 4 个复选框；判断题出现文本框；题型标签均降级成“练习”。作答仍能保存和批改，但操作语义错误。见[真实页面](quiz-before.png)及[作答记录](quiz-answer.json)。本次单选由确定性规则判分，填空、简答和判断调用模型，均判断正确；简答使用自行表述的同义答案。
2. **习题资源弹窗丢失换行**：预览直接在 h3 放题干，代码行挤为一段，课堂作答页保留换行。见[手机预览](preview-quiz-390.png)。应统一题干 Markdown 渲染与必要的段落样式。
3. **情景案例首次生成失败**：`STUDIO_CONTENT_INVALID`，模型结构修复后仍不合格；手动重试恢复。未保存首次模型原始输出，无法确定具体是哪条结构规则。额外诊断调用通过，因此不能宣称已修复稳定性问题。见[失败任务](job-scenario.json)和[重试任务](scenario-retry.json)。建议补充明确的分支约束提示和可追溯的校验失败原因。
4. **播客时长偏长**：约 3 分钟配置生成 243.048 秒，超出约 35%；当前页面说明时长为近似目标，属于待优化项。可按配音实际语速调整文字预算。

- 每工具一个主题样本，不能推断长期成功率。播客验证了真实解码/播放/下载，未进行人工听感评价。
- 生成报告示例已运行并比较输出；其余语义作抽查，不代表全面学科准确性认证。
- 初版测试脚本的控件标签、旧路由和弹窗关闭定位已修正；这些不是产品故障。
- 额外诊断调用受 dotenv 覆盖隔离参数影响，曾在独立测试账号中保存 `diagnostic` 案例，已定点删除。最终案例验收固定为浏览器重试生成的 `job_a81bcc56c7594abc`，不使用诊断样本替代端到端结果。
- 测试资源保留在独立账号，未改动日常用户课程、答案或资源。凭据只保存在仓库外的权限受限文件中。
