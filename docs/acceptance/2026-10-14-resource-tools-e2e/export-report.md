# 验收·学习报告·Python 变量绑定与列表浅拷贝

## 一、结论

1. Python 变量是绑定到对象上的名字。`a = [1, 2]` 后，`a` 指向一个列表对象。
2. 当执行 `b = a` 时，`a` 与 `b` 引用同一个列表对象，这是**别名**。此后通过 `b.append(3)` 修改列表，`a` 看到的内容也会改变。
3. 当执行 `b = a.copy()` 时，会创建该列表的**浅拷贝**。修改外层列表时，`a` 与 `b` 不再互相影响。
4. 浅拷贝只复制外层容器，嵌套列表等内部可变对象仍可能被共享。
5. 整数是不可变对象。重新赋值会改变变量名指向的对象，不会原地修改原整数对象。
6. 判断行为差异时，关键要区分：当前是**别名**、**浅拷贝**，还是**重新赋值**。

## 二、依据与关键概念

### 1. 变量绑定对象

Python 中的变量不是“盒子”，而是指向对象的名字。  
`a = [1, 2]` 表示名字 `a` 绑定到一个列表对象。  
`b = a` 不创建新列表，只是让 `b` 也绑定到同一个列表对象。

### 2. 整数不可变

整数属于不可变对象。  
如果 `x = 1`，之后写 `y = x`，再写 `y = 2`，这不是把原来的整数 `1` 改成 `2`，而是让 `y` 重新绑定到整数 `2`。  
因此 `x` 仍然绑定到 `1`。

### 3. 列表别名

文档给定示例范围：

```python
a = [1, 2]
b = a
b.append(3)
```

因为 `b = a` 后 `a` 与 `b` 引用同一列表，所以 `b.append(3)` 也改变 `a` 所见内容。  
结果中 `a` 和 `b` 都会看到 `[1, 2, 3]`。

### 4. 列表浅拷贝

文档给定示例范围：

```python
b = a.copy()
```

`a.copy()` 创建浅拷贝。  
浅拷贝会创建一个新的外层列表，因此对 `b` 外层执行 `append`，通常不会改变 `a` 的外层内容。  
但如果列表中包含嵌套列表，嵌套列表仍会被共享。

### 5. 别名与重新赋值的区别

- **别名**：`b = a`，两个名字指向同一个对象。修改对象内容，双方都可见。
- **浅拷贝**：`b = a.copy()`，外层列表是新对象，但嵌套对象仍可能共享。
- **重新赋值**：`b = ...`，只是让 `b` 指向新对象，不影响 `a` 原来指向的对象。

## 三、对比表：别名、浅拷贝、重新赋值

| 方式 | 代码示意 | 引用关系 | 修改 `b` 对 `a` 的影响 | 关键判断 |
|---|---|---|---|---|
| 别名 | `b = a` | `a` 与 `b` 引用同一列表对象 | `b.append(3)` 会改变 `a` 所见内容 | 两个名字指向同一对象 |
| 浅拷贝 | `b = a.copy()` | 外层列表是新对象，嵌套列表仍共享 | `b.append(3)` 不改变 `a` 外层；但修改嵌套列表可能影响 `a` | 外层独立，内部不一定独立 |
| 重新赋值 | `b = [1, 2, 3]` 或 `b = 2` | `b` 重新绑定到新对象 | 通常不改变 `a` 原来指向的对象 | 变量名换了指向，不是原地修改 |

## 四、代码示例与输出说明

```python
# 1. 别名：b 与 a 指向同一列表
a = [1, 2]
b = a
b.append(3)
print("别名：", a, b)

# 2. 浅拷贝：外层独立
c = [1, 2]
d = c.copy()
d.append(3)
print("浅拷贝：", c, d)

# 3. 浅拷贝嵌套共享
e = [1, 2, [9]]
f = e.copy()
f[2].append(10)
print("浅拷贝嵌套共享：", e, f)

# 4. 整数不可变与重新赋值
x = 1
y = x
y = 2
print("整数不可变/重新赋值：", x, y)
```

输出说明：

```text
别名： [1, 2, 3] [1, 2, 3]
浅拷贝： [1, 2] [1, 2, 3]
浅拷贝嵌套共享： [1, 2, [9, 10]] [1, 2, [9, 10]]
整数不可变/重新赋值： 1 2
```

逐项解释：

1. **别名**：`b = a` 后，`b.append(3)` 修改的是同一个列表，因此 `a` 和 `b` 都变为 `[1, 2, 3]`。
2. **浅拷贝**：`d = c.copy()` 后，`d.append(3)` 只修改新外层列表，因此 `c` 仍为 `[1, 2]`，`d` 为 `[1, 2, 3]`。
3. **浅拷贝嵌套共享**：`f = e.copy()` 只复制外层列表。`f[2]` 与 `e[2]` 仍指向同一个嵌套列表，所以 `f[2].append(10)` 后，`e` 和 `f` 都看到 `[9, 10]`。
4. **整数不可变/重新赋值**：`y = x` 后，`y` 先指向 `1`；`y = 2` 让 `y` 重新绑定到 `2`，`x` 仍为 `1`。

## 五、面向自主学习者的可执行建议

1. **看到赋值先问一句**：`b = a` 是让两个名字指向同一对象，还是创建了新对象？  
   如果是同一对象，修改内容会互相影响。

2. **需要独立外层列表时使用 `copy()`**：  
   例如 `b = a.copy()`，可以避免 `b.append(...)` 影响 `a` 的外层内容。

3. **遇到嵌套列表要额外小心**：  
   `copy()` 是浅拷贝，嵌套列表仍共享。若修改嵌套列表，原列表也可能被影响。

4. **练习判断别名与重新赋值**：  
   对同一段代码，分别写出 `a` 和 `b` 的最终结果，并说明是“同一对象被修改”还是“变量重新绑定到新对象”。

5. **用最小示例验证**：  
   优先使用两三个元素的列表和整数做实验，观察 `append`、`copy()` 和重新赋值后的输出差异。
