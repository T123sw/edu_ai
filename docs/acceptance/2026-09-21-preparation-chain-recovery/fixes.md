# 备课链路故障修复与复验

本文记录本次故障诊断中累计提交的修复；端到端结论见 README，代码修复不等于所有真实场景已通过。

## 故障与修复

- 取消后模型预留无法结清：为已发出的父任务模型调用保存仅服务端持有的结算凭据，允许原调用完成费用结算，仍禁止取消后的业务内容提交。
- 有限修复没有带上具体失败原因：保存并恢复报告/习题的精确格式反馈，正文摘要不变；内容、审阅格式和供应商故障分别限制恢复轮数。
- 课堂映射只落在首句旁白：默认核对整场景，允许对被拒绝映射做有限定位修订，重新独立核验，正文不变。
- 原生模型输出被截断或工具参数 JSON 无效：整批工具不执行，最多两次模型纠错，计量所有实际请求，保留原始教学内容和证据。
- 缺失可交付学习检查、时长超限逐个出现：交付前收集全部已知检查覆盖、需求覆盖及各节点/整课时长错误，一次给出精确修订反馈；不伪造问题映射、不降低质量门槛。
- 原生 Skill/工具封装后超过窗口：以最终供应商请求计算保守窗口占用，只缩小输出预留，不丢输入、不提高硬预算；审阅中去除重复的旧修订正文。
- 合法报告锚点被拒绝：识别二至六级标题内及独立行上的单/双引号锚点，保留原文和 ID；代码块锚点不算章节。
- 课堂修订上下文膨胀：不再把字体、颜色、类型、ID、媒体地址列为可修改教学字段；格式纠错只传具体错误片段，不累计整段失败输出。
- 会话响应超时被报成通用响应大小错误：明确分类为可有限恢复的供应商超时，保留结算；真正大小上限仍受控。

- 节点和整课重复分配削减量：先处理节点再校核整课，使用投影目标，实际内容必须重新生成、审阅和估算；不修改已存估算。真实复验又发现只削减最长课堂会要求 10.5→约1.5 分钟，模型未遵守，现改为同节点可修订资源按比例共同缩减，保留资料不擅自改写。
- 修订上限仅存在自然语言：程序派生的正有限小数分钟上限进入新资源规格的 teaching_context；报告/习题按新正文重新估算，课堂按新分镜估算，显式单资源硬上限始终校核；本轮后续修复将程序派生目标单列为指导字段，由最终节点/整课总量门禁决定可否交付。默认单资源配额仍为 null，不将节点时间复制到每份资源。
- 本阶段超时误判父预算耗尽、有效结果等待收尾被丢弃：区分供应商阶段截止与父预算；已接收结果可完成本地关闭，父截止、取消、租约仍严格检查。
- 测验旁白标点被误判为泄题：统一新旁白连接规则，兼容旧的额外句号形式，保留答案泄露检查。
- JSON 内再串行化 JSON 导致模型输出语法错误：结构化内容阶段挂载原生对象提交工具，完整对象交给程序无损序列化，旧纯文本工具保留兼容。
- 已加载 Skill 又被模型重复调用：内容阶段先验证原生 Skill 正文及摘要，再隐藏重复加载工具；保留原生 SDK、完整 Skill 和阶段提交工具。
- 课堂映射审阅输出冗长：模型逐个编号审阅每个真实绑定，服务端恢复原始 ID/定位；严格拒绝遗漏、重复、未知及布尔编号，保留全部独立判定。
- 课程计划纠错误交单个节点：工具描述、原生 Skill 和错误回执均明确要求一次重交完整 title/summary/nodes/limitations 对象；不提高连续错误或预算上限。

- 研究恢复重交已有结论被误计为连续错误：相同 ID、正文与引文通过校验后返回已保存回执，不重复写入、不失效已有汇总、不清除真正错误计数；仍消耗动作预算，有限循环保护不取消。
- 习题审阅逐字摘录被模型改写：备课习题提供完整解析的稳定片段编号，由模型选择连续范围，服务端原样恢复摘录；仍独立核验每个选项真假及解析推理，缺失原文必须不通过。旧调用者的逐字摘录仍受原有匹配校验，已存审计格式保持兼容。

- 报告/习题首次生成格式错误直接终止：在原有最多三版生成边界内携带具体格式反馈，错误候选不污染有效正文；格式和元数据始终重新校验。
- 报告/习题审阅重复或新增需求映射：统一按原始绑定编号输出审阅，由服务端恢复完整 ID/定位，编号必须完整且唯一；并未自动将语义审阅设为通过。

- 报告/习题缩减三次仍超时：反馈实际字数、思考秒数、剩余可读字数，并保留上次被拒绝草稿供下一次有限纠错。按现有实际内容公式校验，不调小已保存的估算。指定时限的备课测验允许删除冗余题，保留题目 ID 与顺序、同步映射/估算并重新独立审阅；其他局部修改仍保持完整题目身份。
- 课堂超时只有错误代码：明确实际总秒数、上限、所需缩减秒数，生成器输入显式总秒数上限；允许真实删减工作量。耗尽重试后仍保存具体错误。

- 结构合法但工作量超时被误判不可恢复契约错误：使用明确的时长异常类型，交回既有内容修订流程；仍只有两轮内容恢复和原父预算，其他结构、身份及权限错误的门禁不放宽。

- 交付约束被当作正文教学要求：需求提取将节点数、总时长、资源类型、来源策略和排除项放入对应约束字段；教学 requirements 只保留知识、顺序和活动。新增可选节点数及用户原文引句，并校验最终路径节点数；旧任务不要求重生成。
- 学习端拒绝合法多选答案：仅对 multiple_choice 的完整选项标签串解析 A,B,C / ABC 等格式，仍拒绝说明性文字和未知选项。
- 学习侧统一显示五分钟：读取准备链路的 estimated/measured/unknown 数据，未知显示待估，估算明确显示“约”；不把估算称为实际学习时间。
- 习题刷新缺少自己的答案回显、播放器未加载练习样式：显示已保存的只读作答并复用练习样式；浏览器检查同题、同选项、批改结果和刷新持久化。
- 私有课堂误走旧课程课件接口返回404：通过学习端授权版本接口读取后传入播放器，版本必须严格相符，继续使用既有学习位置回传。

- 临时资源配额未回收其他资源腾出的时间：按已完成同节点资料的估算和整课余额重新分配，仅调整服务端派生的配额，追踪原始上限来源；用户显式单资源上限、节点上限、整课上限和两轮恢复次数保持不变。未知时长或来源不明时不放宽。

- 联合修订目标被误当成用户单资源硬上限：单独记录 resource_repair_target_minutes；沿用三次写作，前两次要求参考目标，最后一次仍严格校核显式单资源上限，并把真实估算的候选交给独立审阅及节点/整课总时长门禁。不自动交付超时课程、不调低估算、不增加次数或预算；旧未设置字段的上下文序列化不变。


- Flash 同轮提交多份资源：供应商响应交给 SDK 前校验整批调用；多份正文提交进入既有最多两次格式纠错，任何一份都不先执行。其他研究阶段仍允许合法多动作。
- 临时预算预留冲突：区分真实已消耗额度不足与并发调用的在途预留，后者在原阶段截止内等待并重新校验租约、取消和父预算；不持有数据库事务等待，不发出未获预算的请求。
- 少量剩余时长触发整节点重写：首轮联合修订后，如果单份可改资源保留至少一半工作量即可吸收缺口，仅修订该资源，其他已审阅正文和回执不变。最终节点/整课硬门禁仍适用。
- 初稿过长：针对短入门节点、同时有报告/习题/课堂且用户没有明确篇幅题量要求的情况，提示先写紧凑但充分的内容；显式用户要求和必要目标优先。真实复验仍出现超时，不能据提示词修改宣称已经解决。
- 浏览器验收不识别合法简答题：用例支持 input/textarea，检查提交后同题、同答案与刷新回读；选择题的已选与禁用检查保留。
- 审查结构仅放在提示词：将独立审查的 JSON Schema 同步到原生 MCP 提交工具，保留必填字段、禁止额外字段及正确的 $defs 引用。报告、习题的真实 SDK 协议回归验证工具结构，业务语义和覆盖门禁不变。

- 审查 schema 声明仍被模型忽略：在 native provider 将整批响应交给 SDK 前校验实际参数，缺字段/额外字段进入既有最多两次格式纠错，给出具体路径；工具桥再次校验。只接收完整审查，保留真实 blocking_issues，不提高阶段期限或父预算。
- 习题正文被再次 JSON 编码成字符串：读取元数据前先验证 content 对象及 questions 对象数组，返回可操作的类型错误；不自动解析或接受错误正文，仍在原有最多三次写作内重交并独立审阅。
