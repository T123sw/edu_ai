## 真实课例

题目：**神经元为什么需要偏置**。真实配置模型 DeepSeek 与本地 Qwen TTS，隔离存储；不是固定模板或伪造音频。

- 两段配音分别 17.016、19.416 秒，总长 **36.432 秒**。
- 原生检查通过；原生渲染的 MP4 同时包含视频流和音频流，见 [ffprobe](probe.json)、[原生检查](native-check.json)、[完整语义内容](content.json)。
- 初始模型响应出现 JSON 格式错误、事件使用局部时间的问题；实际结构反馈触发修复后通过，没有额外模型内容审查。
- 真实工程浏览器播放检测到非零 WebAudio 输出；**25.000 秒定位 seg2**；桌面/移动视口无溢出，无外部 CDN 请求。
- 父页面访问、同源其他 API 请求、外域请求均被隔离策略拒绝；见 [浏览器证据](browser-real-evidence.json)、[桌面](browser-real-desktop.png)、[移动视口](browser-real-mobile.png)。
- 完整可查看产物放在 `/home/zxqs_ep/data/main-review/hyperframes-implementation/`：`lesson.mp4`、`lesson.srt`、`project.zip`。

后端另用该真实课例，在隔离 SQLite 中接收第 25 秒的问题，随后保存新版本，再执行回答；断言模型输入和引用仍为旧版本的 seg2。此处回答模型为测试替身，接收、持久化、授权、上下文、版本选择和引用逻辑为实际实现。浏览器用实际 Player/工程/音频，但课程、认证、播放会话 API 使用测试替身；真实 API 鉴权另有后端集成测试。移动测试为 Chromium 320/390px 视口和 autoplay 失败事件模拟，未声称完成实体手机兼容验收。
