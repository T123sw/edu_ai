## 1. 功能范围

验收覆盖同源课堂的无头场景回放、实测 `LessonTimeline`、旁白混音、分段拼接、
1080p MP4、UTF-8 SRT、后端异步任务、登录下载和课堂页交互。

不验收视频 B 的虚拟帧钟、逐帧动画、Remotion/渲染农场，也不把系统语音音色听感
作为自动化门禁。

## 4. 失败与安全用例

| 场景 | 预期与结果 |
| --- | --- |
| 渲染路由超时/失败 | 任务失败，不发布半成品 |
| FFmpeg 缺失或返回非零 | 错误进入 job message，staging 清理 |
| 无效产物文件名/路径穿越 | 固定白名单拒绝 |
| 未登录或无课堂权限下载 | 认证/授权层拒绝 |
| 重复点击 | 前端单飞锁阻止并行提交 |
| 临时 `audioUrl` | 不写入持久时间线 |
