# 互动实验三栏前端验收

2026-10-13，已发布至当前 Nginx 前端。

## 范围

按用户要求，本轮只完成前端整理：左侧步骤、中间交互/观察记录、右侧本步任务参考与问答。桌面三栏独立滚动，手机使用三个面板切换。步骤选择不表示完成或掌握。

此前提前添加、未部署的操作生命周期和辅导后端代码已撤回。本轮没有自动发问、操作结束识别或新的 Agent/Skills 实现；后续设计见[计划](../../architecture/2026-10-13-practice-skills-plan-cn.md)。

## 验证

- TypeScript、修改组件 ESLint、Vite 生产构建通过。
- 3 项 Playwright 通过：桌面/手机完整已有交互流程，以及真实生成的快速排序 HTML 在 1920、1440、390 宽度下的布局。
- 验证三栏相邻、输入框在可见范围、页面无整体横纵溢出；实验内无重复纵向滚动。
- 切步骤、专注视图、观察页签和手机面板保留 iframe 参数；未保存笔记、未发送问题保留。观察保存、已有问答和刷新恢复通过。
- 验证切步骤/操作/保存不会自动调用问答接口；主动提问仍传入当前步骤和结果。
- 发布后使用 Nginx 静态资源复验真实 HTML，1 项通过；HTTP 首页与本轮构建一致。

实验 HTML 来自已生成的快速排序；认证、保存、问答及详情 API 为浏览器测试模拟响应。本轮没有重新生成模型内容或验收自动教学闭环。
