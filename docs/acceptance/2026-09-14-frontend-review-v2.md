# 前端改版验收（2026-09-14）

本轮按用户要求只实施前端。AI 课堂与资源中心在现有前端项目内重做；原工作台继续复用，以独立预览入口提供本地交互。后端联调必须在用户确认前端之后进行。

## 预览入口

- `http://localhost:5173/?review=1`：教师示例首页。
- `http://localhost:5173/?review=1&role=student`：独立学生示例数据。
- `http://localhost:5173/?review=1#/classroom/sample-agent`：AI 课堂。
- `http://localhost:5173/?review=1#/resources?classroom=sample-agent`：资源中心。
- 工作台从课堂内顶部导航进入，地址自动携带课程、知识点与资料引用。

沿用已有预览域名时，在该域名后使用相同查询参数和 hash 即可。原 `?legacy=1`、真实课程 `?workspace=1` 和前版本地预览入口保留。

## 页面和交互

首页移除顶部三个导航及介绍副标题，右上角保留头像；学习需求输入采用更明显的多行提示与换行说明。进入课堂后显示 AI 课堂、工作台、资源中心三个顶部导航。

AI 课堂保留目录、学习内容、学习 Agent 三栏，支持章节展开、桌面侧栏收起、手机端面板切换。已有播放、报告阅读位置、练习、笔记与本地续学交互保留。

资源中心采用资源列表与阅读预览两栏，区分课程资料与我的作品。支持搜索、类型/知识点筛选、置顶、重命名、删除、报告下载、引用到工作台、选择知识点加入学习目录，以及回到对应课堂内容。加入学习目录创建独立副本并防止重复加入；删除原作品保留学习副本和学习记录。

工作台保留原知识源、对话和生成工厂布局及工具配置入口。通过独立 document 加载原工作台样式，课程导航与新页面保持淡紫浅色风格。带入资料经“引用到对话”显式加入对话。

可体验的完整路径：进入示例课堂 → 工作台 → 教学报告 → 填写需求并生成 → 完成提示/资源中心 → 查看作品 → 加入本节学习 → 在课堂学习 → 刷新恢复。

## 当前模拟范围

- 工作台普通对话为固定示例回复，教学报告提供本地生成成功/失败及资源流转演示。输入“模拟失败”可触发失败状态。
- 其他七类工具保留配置交互，并明确提示当前演示支持教学报告，尚无真实生成。
- 资料上传与解析、检索、模型生成、真实音视频、权限与发布均未联调；课堂播放器使用已有分镜示例。
- `frontendReview/api.ts` 仅在明确的 review 工作台入口拦截 API 请求并在浏览器内响应。预览身份不读写原认证数据，资源、学习记录、会话及工作台 UI 使用独立本地存储键。

## 验证入口

- `pnpm check:self-learning`：新学习页面类型与 ESLint 检查。
- `pnpm exec eslint src/frontendReview src/context/AuthContext.tsx`：预览适配与身份隔离检查。
- `node --import tsx --test src/selfLearning/model.test.ts src/selfLearning/library.test.ts`：学习数据及副本语义。
- `pnpm exec playwright test -c playwright.self-learning.config.ts frontend.spec.ts review.spec.ts`：1440、1024、390 宽度下的前版回归及新闭环；包含无后端请求、原登录数据不变、重命名、置顶、搜索空态、删除原作品后课堂副本仍可读。
- `pnpm build`：生产构建。

生产构建仍有旧依赖的大包提示；AuthContext 保留已有 Fast Refresh 导出警告。全仓旧模块 TypeScript 问题不属于本轮类型检查范围。

本次结果：27 项三视口浏览器测试、7 项数据测试通过；补充作品引用的知识点上下文断言后，3 项闭环测试再次通过。新页面类型检查、相关 ESLint（0 错误）与生产构建通过。预览服务已在 5173 端口启动。

## 后续界面反馈：最近学习与常驻 Agent

首页不再展示独立“我的课堂”区。最近学习统一收纳自己生成的课堂与已开始学习的共享课堂，提供全部、自己生成、共享课堂筛选及来源标记；按最近进入/学习时间排序。发现共享课堂继续作为加入新课堂的入口。

课堂右侧 Agent 默认常驻，不再提供桌面收起按钮，也不需要先点击节点启动对话。小屏继续使用常驻的 Agent 面板入口，切换面板不卸载会话。切换知识点自动保存和恢复对应消息；同知识点内切换报告、视频、练习沿用同一会话。消息追加时捕获知识点，防止异步回复写入刚切换的新会话。未发送草稿在本次课堂页面的知识点切换之间保留，刷新后不恢复草稿。

新增全局学习记忆展开区，汇总本课堂所有知识点的完成数量、练习反馈和用户自评。完成学习不自动判定掌握；“我已理解”明确显示为“自评已理解”。自评可清除，练习反馈始终单独保留。共享课堂开始学习时不继承发布者的会话、学习记录或自评。

`learningMemory.ts` 提供后续联调边界：当前知识点最近 12 条消息与各知识点的简短学习事实，不混入其他知识点完整聊天。旧消息按资源所属知识点读取，无需清空原预览数据。当前仍为固定示例回答与本地记忆，尚未实现模型总结、语义检索或服务端长期记忆。

新增 `conversations.spec.ts` 验证来源筛选、常驻对话、知识点会话和草稿隔离、同知识点内跨资源续聊、自评与消息刷新恢复；`learningMemory.test.ts` 验证旧消息读取、上下文范围、掌握与完成分离、共享学习者数据隔离。

本轮调整验证：33 项三视口浏览器测试与 9 项数据测试通过；新页面 TypeScript/ESLint 和生产构建通过。人工截图检查后进一步限制记忆展开区高度，以保留小屏对话阅读空间。

## 普通入口工作台修复

用户截图确认普通入口仍显示早期 `Studio` 简化表单。前次仅修复登录页预览链接，没有覆盖普通登录页内的导航。本次从学习 App 的实际路由修复：普通登录、早期 `?preview`、新版 `?review` 统一进入原 AIWorkspace；现存 `#/studio?classroom=...` 自动交接，不再显示简化表单。资源中心统一为新 ResourceCenter。

普通/早期预览入口通过 sessionStorage 中的上下文标识记录学习数据 owner、角色及返回查询参数，不复制课堂、不修改认证数据。原工作台模拟适配器读写该学习空间的数据，返回课堂和资源中心恢复原入口。适配器仅在工作台 document 内启用，生成与知识源仍为本地模拟。

`review.spec.ts` 扩展覆盖新版预览、早期学生预览、教师普通登录旧 Studio 地址、学生普通登录四类入口，每类验证三个视口下的生成、资源管理、加入学习和返回恢复。已移除仅断言旧简化表单的两项过期浏览器测试，由上述实际原工作台流程替代。

验证结果：12 项工作台入口与资源闭环测试通过；24 项课堂、首页及知识点会话回归测试通过。学习前端类型检查、相关 ESLint 和生产构建通过。原 review 身份的工作台会话/UI 存储键保持兼容，普通登录数据按各自学习 owner 隔离。

## 资源归属与工作台精简

按后续截图反馈，删除工作台顶部“从课堂带来的资料”栏，不再自动携带课堂当前资源引用。课程与知识点范围继续沿用；从个人作品点击“引用到工作台”时，引用交给原对话输入区，不新增顶部栏。

资源中心取消课程资料/我的作品双空间，只展示个人生成资源。保留作品搜索、筛选、置顶、重命名、下载和加入学习等操作；课程内容与学习副本仍在 AI 课堂中。旧 `space=course` 及课程资源 ID 不再显示课程资料，课堂工具栏移除原来指向该列表的“本节资料”链接。相关 12 项入口和资源流转测试通过。
