# 教学资源统一接入模型规划流程

> 历史验收记录：统一大纲确认的设计已在 [2026-09-09 质量自检](2026-09-09-resource-quality-audit-cn.md) 中修正。当前资源交互和质量标准以新记录为准。

## 实现范围

教师对话中的教案、教学博客、习题、闪卡、思维导图、互动游戏和 AI 课堂，接入报告所用 Harness 运行时。普通文本请求和显式 generate.* 提示直接交给模型；未增加用户意图、语言、主题或确认口令的关键词路由。

模型选择资料归属与资源类型、规划检索和内容组织、判断澄清/修改/暂停/继续，再调用类型明确的工具。代码保留权限、有效引用、证据范围、已展示版本、后续轮次及幂等性约束。课件仍由 OpenMAIC 生成原生 Stage/Scene/Action，不引入第二条 PPT 生成链路。

右侧配置表单的直接生成 API 保留现有显式配置通路；本次统一的是与报告一致的对话生成流程。已有文档修改继续使用修改稿预览及确认保存。图片/视频输入的理解不在此次新增范围。

## 完整流程

1. 模型按课程目录选择知识点或课程归档，记录工作记忆。
2. RAG/Web 开启必须实际调用，关闭由模型判断；证据在原权限范围内流转。
3. organize_resource_content 组织并审阅内容，draft_resource_outline 保存方案。教案等允许在不同教学环节复用同一内容模块，模型决定顺序与分组。
4. 返回保存的方案后结束本轮；用户后续确认时模型调用 submit_resource。修改方案使旧展示/确认失效；中断沿用同一版本和幂等键恢复。
5. 教案/博客生成 Markdown；习题/闪卡/导图生成原生结构；游戏使用现有模板生成可运行 HTML。后台独立模型审阅六类标准，最多两次内容修订，版本绑定审阅通过后才保存。
6. AI 课堂复用 durable classroom_generate 和 OpenMAIC。课堂内容先审阅，文字缺陷使用精确原文修改并复审；保留场景与动作身份。修改讲解使旧音频失效，按模型传入的语音设置重新合成；未经审阅不落库交付。Harness 已有目录规划，不再进入旧课堂关键词选知识图谱片段的流程。
7. find_resource_jobs 跨对话发现当前用户当前课程任务，query_resource_job 回读真实产物并核对审阅版本；取消只限当前会话。查询回答不覆盖为生成通知。课堂使用统一资源引用，最近生成入口可打开播放器。

## 实测发现并修复

- 报告模块“恰好一次且按顺序”约束不适用于复习/评价等教案活动。非报告允许重复引用和自主安排顺序，仍检查索引有效及完整覆盖。
- 课程级工作区必须省略 scope_id 或传 null。工具 schema 和错误消息明确这一契约，模型可修正参数，不能将参数错误说成课程不存在。
- 同课程资源页的 hash 目标变化原来没有触发重新读取，导致打开下一份结果仍显示上一份。已监听目标变化并验证教案→闪卡切换。
- 课堂结果引用补充 material_type/material_id，课堂语音开关贯穿保存前的音频处理。

## 验证

验收脚本：scripts/verify-harness-resources.py。使用独立 FastAPI 服务、合成教师与课程、隔离文件/SQLite、真实模型 SDK 和真实后台 worker；HTTP 从首轮请求经过方案展示、后续英文确认、任务查询、资源 API 回读，再由模型读取并回答。课堂调用真实 OpenMAIC 服务。浏览器仅将 API 转发到隔离服务，没有伪造资源响应；验证原生预览与交互。

最终结果：

- 七类资源全部通过真实 HTTP 对话 → 方案 → 后续英文确认 → durable worker → 模型生成/审阅 → 保存 → API 回读 → 模型查询。习题中途明确“先不要生成”未提交，后续英文确认才提交。
- 七类真实产物均在浏览器打开；3道习题能查看解析，4张闪卡能翻面，游戏4组拖拽配对能提交并得到全部正确反馈，三页课堂可切换到第二页。
- 课堂最后的语音设置修复复用了同一真实 OpenMAIC 产物，重新执行保存前审阅与处理，未重复生成场景；再次读取确认没有 audioUrl，并验证真实播放器。证据中保留初次完整链路以及 finalization_verified/no_tts_verified 标记。
- 后端在隔离 JSON/SQLite 配置下 **121 项通过**；新增浏览器 **8 项通过**；前端生产构建通过，保留现有包体积警告。
- 主服务已加载修改，健康接口 200。主系统显式 generate.flashcard 提示配合“只解释、不要创建资源”，模型返回普通回答、没有提交任务，证明动作提示不替代当前用户意图。

补充运行的旧浏览器套件存在三个与本次代码无关的旧期待：恢复旧版按钮和两项旧工厂表单交互超时；没有用这些用例宣称全仓浏览器测试通过。本轮新增场景及实际产物检查全部通过。最初课堂知识图谱隔离测试在读取本机 PostgreSQL 配置时失败，修改前基线亦复现；使用正确隔离持久化配置后该组通过。

模型审阅不是人工审阅或全面事实核验；无效输出和修订耗尽如实失败，不能以固定规则把语义错误强行标记为成功。
