# 文档引用与连续读改

右侧预览收窄为桌面约 34vw（最高 700px），中等窗口约 43%，抽屉最高 600px。

教师私人生成资料的预览在“导出”旁提供“引用”。点击将《文件名》插入输入框并保留原草稿，不自动发送。请求携带原课程、文档 ID、版本和服务端内容哈希；聊天消息不展示这些标识，也不展示“正在修改”引用状态条。删除尚未发送的文件名引用会清除绑定；发送后的连续追问沿用当前文档，新对话清除引用。

复用 edu-artifact-revision 技能的原文问答和局部修改能力。引用本身不授权写入；明确提出修改意见后保存新版本。基准版本或内容哈希不符时返回冲突，不能静默换成最新内容执行。手输名称的修改请求即使只匹配一个候选，也先确认目标；候选序号续接原操作。仍沿用原有私有资料归属、鉴权和类型校验，不扩大修改权限。

验证：106 项后端回归、15 项浏览器检查、5 项前端单元检查、前端构建通过。浏览器验证文件名插入、隐藏 ID/hash 传参、连续追问、删除草稿引用，以及不同窗口尺寸的原位预览。真实模型在独立样本文档上使用带哈希引用完成问答和局部修改：读取保持 v1，修改保存 v2，其余文字不变。复现脚本为 backend/src/tests/chat/artifact_revision_skill_live_smoke.py，使用临时存储，不修改用户资料。
