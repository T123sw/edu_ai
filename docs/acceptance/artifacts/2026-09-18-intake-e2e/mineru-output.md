练习要求与参考资料：最小计算器 Agent

练习目标：用 Python 制作命令行助手，让模型选择 add(a,b) 工具并将计算结果回答给用户。只需单次工具调用，不要求多轮记忆或自主规划。

验收要求：保留用户问题、模型工具调用参数、工具执行结果、最终回答这四项可读日志。用“计算 12 加 30”作为成功例，用“参数 b 缺失”作为失败例。

工具定义：add 的输入 schema 是 object，a 和 b 必须为 number，required 包含 a 和 b；函数实现返回 a+b。工具描述要说明用途和参数含义。

调用流程：先把用户问题与工具 schema 发给模型。收到工具调用时读取 name、arguments 和 call\_id，校验名称和 JSON 参数，执行 add；然后把结果与相同 call\_id 作为工具消息发回模型，取得最终回答。模型请求工具不等于工具已经执行。

安全与失败：只允许执行已注册的 add 函数，不执行模型输出的任意代码。参数缺失或类型不符时，不运行函数，返回结构化错误，例如 code=INVALID\_ARGUMENT、message=b is required。模型可提示用户补齐参数，不得编造计算结果。

参考伪代码：若 name != add 则返回 UNKNOWN\_TOOL；若 a 或 b 不是数字则返回 INVALID\_ARGUMENT；否则执行 add(a,b)，记录结果并交回模型。成功用例期望结果为 42；缺失 b 的用例期望工具未执行且返回错误。

范围：这份材料只讲模型与工具之间的最小循环，不包含真实供应商 SDK 的安装、鉴权或完整可运行接口示例。若需要真实 API 程序，这部分材料还需要补充；不能假装附件已经给出。
