# Agent 读取权限与跨对话记忆约定

日期：2026-09-08。用户已确认的产品基线；实施状态见末节。此文约束后续开发，不代表全部能力已上线。

## 读取范围

会话组织交流，认证身份和资源授权决定可读范围。所有自动上下文注入与工具读取均由后端检查；模型参数、历史消息、记忆不能扩大权限。

| 数据 | 范围与读取规则 |
| --- | --- |
| 当前对话 | 当前用户拥有的会话；近期消息自动读取，旧内容按需检索 |
| 其他对话 | 同用户、当前课程；按问题检索相关片段并保留来源，不自动合并全文 |
| 报告与任务 | 同用户、当前课程可跨对话发现；真实状态来自任务库，产物还须校验当前读取权限与审阅版本 |
| 全局个人偏好 | 当前用户；明确的全局偏好可跨课程使用 |
| 课程个人偏好 | 当前用户、指定课程；不传播到其他课程或其他成员 |
| 课程资料与共享产物 | 按当前资源授权读取；同课程不意味着可读其他人的私聊 |
| 他人私聊与私人记忆 | 普通 Agent 不开放；教师或管理员角色本身不自动扩大范围 |
| 密钥、连接串、任意服务器文件 | 教学 Agent 不开放，只提供受控业务工具 |

跨课程历史和任务仅在用户明确指定目标课程后读取，并重新检查该课程权限；默认不搜索全部课程。没有实现对应工具时如实说明能力范围，不用模型提供的课程 ID 绕过。

## 任务定位与事实

优先使用明确任务或报告引用；否则结合主题、知识点与来源会话寻找候选。多个合理候选需消歧，不自动选择最新项。分页结果不是完整集合，当前会话无任务也不是全课程无任务。

区分找到候选、候选不唯一、未找到关联、查询不可用与任务真实状态。未找到或读取失败不能推出未完成、从未提交，更不能触发重建。声称已核实必须有业务查询依据。

读取后保存任务、来源对话、大纲版本与产物引用。引用不是授权，每次使用重新检查；产物状态不得从旧链接快照推断。旧数据缺少来源时尝试通过经过身份过滤的持久化记录恢复，不能猜测。

## 记忆生命周期

任务库是执行状态的权威来源；历史文本和摘要只提供线索。一次性要求保存为任务约束，稳定且有明确来源的个人偏好才进入长期记忆。当前要求优先于历史偏好，任何偏好均不得覆盖业务权限。

长期偏好应支持查看、更正、删除，携带来源和作用域；删除要使派生索引、缓存、摘要失效，不能从旧摘要恢复。引用文本、模型推断和用户自述不自动成为身份、成绩或学习完成记录。

## 读取与操作

跨对话读取允许解释进度和展示有权访问的产物，不自动获得修改、重新生成、取消或发布授权。操作须有当前请求明确指向的对象并满足业务权限。其他会话的大纲及其确认不复制到当前会话；历史命令不重放。

## 本轮实施与待办

本轮实现报告路径：同用户同课程任务摘要自动读取、分页发现工具、跨对话任务及正文读取、只读关联、旧来源恢复、权限重新检查、与操作权限隔离。正文继续使用任务提交时的章节快照和绑定当前正文的审阅记录验证。

本轮未实现通用跨对话消息检索、显式跨课程检索入口、长期记忆管理及删除传播、跨对话修改/取消的授权流程。这些遵守本契约，后续分别实现与验收，不能将报告路径修复宣传为完整记忆系统完成。

验收覆盖：旧会话空任务而另一会话报告已完成；多候选不自动关联；同用户其他课程及他人任务不可读；权限撤销后旧链接失效；失败与空结果区分；不返回全文历史、内部配置或凭据；只读链接不能取消任务；正文变化使旧审阅失效；旧报告可恢复来源；重启后保留只读引用。
