# 模型负责决策与工作记忆改造计划

目标：普通对话与报告的 Harness 主入口不再用用户文本匹配决定意图、澄清、确认、切题或下一步。模型依据当前请求、工作记忆、版本化产物与真实工具结果规划调用。

1. 主入口仅校验身份、课程、显式工作区，不执行旧关键词预路由或文本修订拦截。
2. 提供工作区选择与工作记忆工具；模型选择目录归属并记录具体主题、目标、用户事实、计划与阻塞原因。
3. 按用户 / 课程 / 对话保存 Harness 状态，兼容迁移旧的知识点分片；产物与检索证据保留原范围。
4. 移除固定确认口令。submit_report 由模型基于用户意图决定调用；代码保留当前版本、权限、资料范围、幂等校验，并持久化决策来源和提交结果。
5. 同步根角色、Skill 和大纲渲染；用户大纲仅章节和短要点，内部组织供正文生成使用。
6. 验证中英文自然推进、否定 / 修改 / 换题由模型规划，代码不检查这些词；回归隔离、版本、防重、状态迁移及浏览器连续对话。真实模型测试在诊断会话运行，不重放用户已有请求。

范围：当前支持的普通文本对话与报告 Harness 入口。图片 / 视频、显式引用的旧资料编辑和其他生成工厂入口仍是独立已有路径，不能宣称全站所有工作流已迁移。

实施状态：上述普通文本对话与报告改造已完成，137 项后端回归、6 项浏览器用例通过，中英文自然推进均完成实际报告落库。详见 [验收记录](../acceptance/2026-09-08-model-owned-planning-cn.md)。
