# 学习 Agent 当前上下文能力检查

检查日期：2026-10-13。范围是课程学习页右侧的学习 Agent，不包含独立 AI 工作台对话助手。

实施更新：下文保留检查时的状态。随后已实现 PPT 的“当前页语义内容＋本页完整讲稿＋讲解位置”方案，支持区分正在看的页与最近讲解的页；详情见 [PPT 上下文实现说明](2026-10-13-learning-agent-ppt-context-cn.md)。文档选区、单题绑定和互动实时状态仍按下文记录。

**结论：基本问答和资料上下文链路已经实现，但对当前界面的感知不完整。它能依据当前资料片段回答，不能保证准确理解所有“这里”“这道题”“为什么变成这样”的提问。**

## 当前如何工作

用户发送问题时，前端固定本次的课程、知识点、资料 ID、资料版本、阅读位置和选中文字。后端校验资料归属，读取指定版本，并把资料片段、选中文字、课程目标和本知识点近期对话交给模型。启用相关能力时，还会按预算加入偏好、学习摘要和学习事实。

模型可以通过工具继续读取资料、搜索本课程资源、读取学习摘要和搜索本人本课程的历史对话。它没有直接读取整个屏幕或任意网页状态的能力，也不会默认获得工作区全部资料全文。

## 能否知道用户在根据什么提问

| 提问场景 | 当前能力 |
| --- | --- |
| 围绕当前打开的资料提问 | 能绑定到资料及其版本，自动读取一部分正文 |
| 选中普通文字后提问 | 能收到选中文字；与原文唯一匹配时能定位周边正文 |
| 滚动到文档中部，问“这里是什么意思” | 无法准确定位；当前实现可能仍提供文档开头片段 |
| 看着某页课堂幻灯片提问 | 场景信息上报后，能读取该场景的存储数据；长内容会截断 |
| 调整模拟参数后问“为什么变成这样” | 能读取原始场景内容，但没有接收到当前参数、计算结果等运行状态 |
| 做练习时问“我这题为什么错了” | 可以读取练习资料和部分学习结果摘要，但提问没有绑定当前题号、所选答案和本次作答记录 |
| 发送问题后切换知识点 | 已发送的上下文固定，答案仍归属原知识点会话 |

## 已发现的缺口

1. **阅读位置没有转换成正文位置。** 前端文档定位主要是滚动像素 `scroll_top`，后端明确不把它当作正文字符位置。未选中文字时，初始片段从正文开头截取。最小复现确认：传入末尾滚动位置，返回的仍是开头片段。

2. **选中文字与原始 Markdown 可能对不上。** 例如页面显示“变量保存数据”，源文件却是“变量**保存**数据”。当前精确字符串匹配会失败。模型仍收到选中文字，但可能缺少正确的周边段落；这一情况已用最小样例复现。

3. **交互模拟缺少运行状态回传。** 学习提问只带场景 ID，没有模拟中的当前角度、速度、结果、错误等。已有互动事件记录不等于把这些状态提供给学习 Agent。

4. **练习缺少具体提问对象。** 题目组件里的选项和答案未进入阅读快照。学习摘要中的完成、自评或检查判断，也不能替代“当前第几题、用户选了什么、为什么被判错”的上下文。

5. **返回资料时存在沿用旧选区的风险。** 阅读快照按资料版本缓存；重新打开文档时，握手没有立即发送新的文档快照，可能暂时沿用上次选区。这是代码检查发现的风险，尚未用真实浏览器复现。

## 优先补齐的内容

- 文档：发送当前可见段落的稳定标识和文本，并处理 Markdown 与显示文字的映射。
- 模拟：发送当前参数、结果和最近一次操作。
- 练习：发送题目 ID、作答记录 ID、用户答案和反馈。
- 切换资料：清除旧选区，等待新资料上下文就绪；输入框旁显示本次引用对象。

## 验证范围与代码依据

本轮检查时后端服务运行中，进程启动环境中的五个新版学习开关均已开启。已运行后端上下文、会话、模型适配测试，结果为 35 项通过、20 项 PostgreSQL 参数化用例因未配置隔离测试数据库而跳过；前端阅读消息、会话与学习状态测试 9 项通过。最初测试受业务环境开关影响，隔离测试环境后通过，未修改业务开关。

这些结果验证当前源码的基础机制，不代表所有回答质量已验证。本轮没有新增真实模型问答、生产页面浏览器端到端验证或 PostgreSQL 并发验收；没有修改 Agent 代码或部署。
