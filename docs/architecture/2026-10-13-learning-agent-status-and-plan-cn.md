# 学习 Agent 功能现状与优化计划

当前目标是围绕已有学习材料，提供提示、追问和解释，帮助学生逐步理解。下一步聚焦引导式问答，暂不扩展习题生成和复习安排。

**已实现的功能**

- 识别当前课程、知识点、学习目标和阅读资料。
- 围绕选中的报告段落、具体习题或 PPT 当前页进行问答，支持查看回答来源。
- 根据场景提供提示、解释或完整解答，并结合用户引用的实际作答进行讲解。
- 保存对话、讨论重点和学习困难，支持纠正记录、刷新恢复及失败重试。

**当前状态**

基础问答与上下文能力已完成相关验证，但连续多轮引导的稳定性仍需专项验收。代码已提交并推送，最新功能尚未完成部署。

**下一步优化计划**

- 根据学生答对、答错或“不知道”的反馈调整提示，避免重复追问和过早给出答案。
- 保持多轮讨论连贯，切换资料或知识点时准确更新讨论对象。
- 尊重学生选择：需要直接解释时及时讲清，不强制追问，不把简单附和当成已经理解。
- 完成上述场景的真实多轮对话测试，修正问题后部署并复验。
