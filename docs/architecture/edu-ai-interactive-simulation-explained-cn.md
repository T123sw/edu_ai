# Edu AI 如何实现交互模拟实验

**用户输入想学习的主题，系统自动生成一个可以动手操作的实验。学生调整参数、观察变化，并向旁边的 AI 提问。**

整体流程：输入主题 → 设计实验 → 生成页面 → 检查运行 → 动手操作与 AI 答疑。

1. **设计实验。** 系统根据主题生成学习目标、操作步骤和思考问题，并确定实验使用的公式或算法规则。

2. **生成页面。** AI 生成包含按钮、滑块、图表和计算逻辑的交互网页。例如，快速排序实验可以调整数组大小和基准策略，观察排序过程及比较次数。

3. **检查运行。** 系统自动检查页面能否运行、参数变化是否带来结果变化，发现问题时尝试修复。通过后，以“左侧步骤、中间实验、右侧问答”的形式展示。

4. **操作与答疑。** 学生的操作由浏览器中的程序实时计算，无需每次调用 AI。提问时，AI 结合实验目标、当前步骤、参数和结果进行解释，学生也可以保存观察和笔记。

目前已实现实验生成、动手操作和结合实验状态的问答。下一步计划接入完整的教学 Skills 工作流程，让 Agent 在学生完成一轮操作后，主动引导其观察结果、解释原因和继续探索。
