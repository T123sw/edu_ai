# OpenMAIC 如何实现交互模拟

OpenMAIC 的交互模拟可以理解为：**模型生成一个带操作控件的小网页，浏览器运行网页里的代码，学生调整参数后，画面实时变化。**

整体流程：用户需求和资料 → 交互场景大纲 → 模型生成 HTML、CSS 和 JavaScript → 嵌入课堂运行 → 学生操作或 AI 老师演示。

1. **规划模拟内容。** 根据用户需求和参考资料，模型在课程大纲中安排交互场景，说明要演示的概念、知识点和可调整的变量。例如，讲抛体运动时，可以让学生调整发射角度和初速度。这一步的中间产物是交互场景大纲 JSON。

2. **让模型生成网页代码。** 系统把概念说明、知识点、可调变量和交互页面规范交给模型。模型输出完整的 HTML 页面：HTML 定义按钮、滑块和展示区域，CSS 控制样式，JavaScript 实现参数变化、模拟计算和动画，并用 Canvas 或 SVG 绘图。页面还内嵌一份配置 JSON，记录变量名称、范围、默认值和预设场景。

3. **把网页放进课堂。** 程序从模型返回结果中提取 HTML，补充公式显示等处理，将网页代码和配置保存到交互场景中。前端通过 iframe（页面内嵌的小窗口）加载它，并在沙箱中运行脚本。到这一步，学生就能看到并操作模拟页面。

4. **根据操作实时更新。** 学生拖动滑块或点击按钮，触发页面内的 JavaScript，更新参数、重新计算并绘制画面。例如，把发射角度从 30 度改成 60 度，代码会据此更新运动轨迹。普通的调参和动画由浏览器执行，无需每次操作都调用模型。

5. **让 AI 老师配合演示。** 系统还会让模型根据模拟配置生成讲解词和动作 JSON，例如“把角度设为 45 度”“突出显示速度滑块”。课堂播放程序通过 postMessage 向 iframe 发送指令，模拟页面接收后修改参数、高亮控件或显示提示，实现边讲边演示。

与 PPT 生成相比，交互模拟的主要产物是**可执行的网页代码**；其中的 JSON 用于描述配置和教学动作，具体交互逻辑由 JavaScript 执行。
