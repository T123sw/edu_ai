# 学习 Agent 如何理解当前 PPT

现在提问时，系统会同时提供“这一页是什么”和“刚才讲到哪里”，默认不发送截图。

1. **前端记录位置**：正在看的页、播放/暂停状态、讲解动作、当前句子的序号，以及正在强调的元素 ID。
2. **提问时固定快照**：发送后继续翻页，不改变这次问题的上下文。手动翻页会分别保留“正在看的页”和“上次讲解的页”；重新打开课件会清除旧讲解状态。
3. **后端读取原文**：根据课件 ID 和版本，提取当前页的文字、公式、代码、表格、图表数据，以及本页完整讲稿。前端只传位置，正文由后端读取。
4. **交给模型回答**：模型收到当前页、讲稿、当前句子、强调对象和整份课件的页面目录。问“这页”依据当前页，问“刚才那句”依据讲解位置；其他页可通过工具按页读取。

会去掉字体、颜色、SVG 路径和图片编码等渲染数据。当前页不会因为旧的 6,000 字符限制被截成半段；极长内容超出上下文预算时会明确报错。

图片只提供已有名称/描述，模型没有实际看图。生成音频的句子位置按进度估算，并明确标注；浏览器逐句朗读直接记录句子序号。完整讲稿不代表用户已经听完，播放位置也不代表已经掌握。

主要实现：前端 `openmaic/classroomReading.ts` 记录位置，经播放器、资料 iframe 传到学习 Agent；后端 `self_learning/classroom_context.py` 提取语义内容，`context_builder.py` 组装模型输入。

验证覆盖：暂停、重播、跨页提问、发送后翻页、重新打开课件、重复句子、旧版本读取、无效位置拒绝和完整页内容保留。使用隔离测试数据库及模型/音频替身验证数据链路，不等于真实模型回答质量或音频对齐精度评测。
