# 根角色与报告完整流程实施计划

范围仅为根角色和报告。目标是经审阅的正文，而非只有大纲或生成成功状态。

1. 根角色明确报告进入条件、阶段、继续/暂停/结束判断；完整报告以正文审阅通过为完成标准。
2. 报告 Skill 明确需求、证据、组织、大纲确认、正文、审阅、修订与交付。只要大纲是独立结束分支。
3. Harness 提交时快照结构化组织、章节及证据；后台任务生成正文并独立审阅，最多两次修订。失败不得保存为完成报告。
4. 审阅至少检查需求覆盖、事实与推理、例子与边界、教学结构、引用、正文完整性。审阅版本绑定正文 SHA256；查询时校验后才交付。
5. 隔离测试覆盖失败拦截、修订后复审、版本变化失效；运行真实正文生成与审阅并保存样例及记录。保持服务开关不变。

模型审阅不是人工或完整事实核验；交付须如实标明审阅方式。既有非 Harness 报告路径保持原行为。
