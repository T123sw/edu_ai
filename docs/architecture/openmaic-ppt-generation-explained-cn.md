# OpenMAIC 如何生成 PPT

OpenMAIC 的实现可以理解为：**模型负责设计内容和排版，程序负责把设计结果变成幻灯片。**

整体流程：用户需求和资料 → 大纲 JSON → 每页内容与布局 JSON → 幻灯片展示与 PPT 导出。

1. **整理用户输入。** 用户输入主题、教学对象、时长等要求，也可以上传 PDF 等资料。系统从资料中提取文字和图片，给图片分配编号，并记录编号对应的图片地址。

2. **让模型生成大纲。** 系统把用户需求、资料文字、图片信息和大纲生成要求交给模型。模型输出大纲 JSON，确定每页的标题、知识点、顺序，以及建议使用的图片。

3. **让模型逐页设计。** 系统再把每页大纲、可用图片和排版规则交给模型。模型输出单页 JSON，里面包含文字、图片、图形等元素，以及它们的位置、大小和样式。例如：“在左上角放标题，下面放三个知识点，右侧放图片。”这些安排都会用 JSON 字段表示。

4. **把 JSON 组装成幻灯片。** 程序解析模型输出，补充必要的默认值，把图片编号替换成实际图片地址，组装成 Slide（一页幻灯片的数据）。网页根据元素类型和坐标，调用对应组件显示文字、图片等内容。

5. **导出 PPT 文件。** 程序使用 PptxGenJS 创建 PPT 页面，遍历元素：文字调用 addText，图片调用 addImage，图形调用 addShape。再将坐标、尺寸和样式转换成 PPT 格式，最终生成 .pptx 文件，其中的文本框、表格等可以继续编辑。
