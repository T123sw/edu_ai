# 报告段落提问

课程学习页的报告现在支持两种入口：鼠标悬停在段落旁点击“问 AI”，或选中文字后点击“问 AI”。手机上可以点段落或选中文字，再打开提问。

选中的内容会保留黄色高亮，并在 Agent 输入框上方显示引用卡片；点击输入框不会丢失引用。点击“取消引用”会同时清除卡片和高亮。切换资料后不会沿用旧引用。悬停本身不调用模型，点击入口会准备问题，用户发送后才开始回答。

前端发送资料 ID、版本、选中文字和段落位置。后端按同一版本重新读取报告，核对段落位置及渲染指纹，提供对应 Markdown 原文和前后文。因此，相同文字重复出现时可以区分是哪一段，加粗、链接等格式也不会丢失原文定位。发送后固定快照，后续取消引用不影响已发送的问题。

位置按 Unicode 字符计数，兼容中文和表情。正文无法匹配时明确报错，不悄悄改为引用报告开头。渲染指纹只用于核对位置，权限仍由原来的用户、课程和资料版本校验控制。

主要代码：前端 `liveLearning/ReportReading.tsx`；后端 `self_learning/report_document.py`。部署与测试状态见 [验收记录](../acceptance/2026-10-13-report-reading/verification.json)。

修复记录：报告引用曾因上下文额度过小而误报“引用内容过长”。真实失败请求仅引用 170 个字；开启全部工具后，原先 16 KB 总额度只剩 4,884 字节供系统提示、问题与引用使用。现将报告答疑总额度调整为 64 KB，扣除工具说明并预留 8 KB 工具结果空间，完整保留问题与引用，按需缩减周边原文。原请求回放通过，50 项后端回归通过；业务后端需要重启后生效。详见[修复验证](../acceptance/2026-10-13-report-reading/context-budget-fix.json)。
