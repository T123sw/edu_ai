## 四阶段界面

桌面保留左侧教学阶段、中间实验对象与操作、右侧当前讲解和对话三栏。左侧展示四个阶段及各自目标；算法第三阶段显示“性能测试”，其他学科使用“对比探究”。

中间展示区保持优先空间，配置放在下方。原理演示和手动练习不显示完整配置面板。右侧顶部固定显示“当前发生了什么、为什么”，下方放提示和自由问答；当前讲解不能被长聊天记录挤走。手机在实验对象附近显示简短解释和错误提示，避免操作后必须切换到问答页才能看到反馈。图中高亮与文字使用相同的元素和值。

默认顺序推荐学习，阶段完成显示具体入口，如“开始手动练习”“开始性能测试”。这些入口只切换教学阶段，不执行算法操作。手动练习区域没有“下一步”“自动执行一轮”或自动替学生完成的通用按钮。

建议保留目录回看及直接进入自由探索的能力；提前进入不补齐练习进度。练习是否完成与其他阶段能否查看分别管理，不通过强制聊天控制导航。该导航细节随第一阶段交互稿确认。

## 冒泡排序样板

### 排序规则和学习目标

固定讲授升序、从左到右扫描的冒泡排序：每次比较相邻元素，左值大于右值才交换；相等时保持原顺序。一轮结束后，本轮最大元素到达未排序区间右端；下一轮从左侧重新开始，排除已经归位的后缀。明确区分“一轮完成”和“整个数组有序”。

为重复值保存元素身份和位置，选择、动画、计数及验证引用同一身份。选择元素不计比较；正确执行一次比较决策才计一次比较，实际交换才计一次交换。错误尝试单独记录，不污染算法计数。

### 第一阶段 原理演示

使用 `[5, 3, 4, 1]`。首次解释扫描起点和规则，自动高亮第一对；用户每次触发一个明确动作，如“比较这两个数”“执行交换”“保持顺序”。一次点击最多执行一次比较或交换，不播放整轮，不提供自动运行。

| 画面与用户动作 | 同步解释 |
| --- | --- |
| 高亮 5 和 3，执行比较 | 从左侧第一对相邻元素开始；5 大于 3，需要交换 |
| 执行交换，变为 `[3, 5, 4, 1]` | 较大的 5 向右移动一格；下一对是 5 和 4 |
| 比较并交换 5 和 4 | 数组变为 `[3, 4, 5, 1]`，继续向右扫描 |
| 比较并交换 5 和 1 | 数组变为 `[3, 4, 1, 5]`；本轮已到未排序区间末尾 |
| 展示轮次总结 | 最大值 5 已归位，本轮 3 次比较、3 次交换；左侧仍未完全有序 |

自动高亮表示演示的当前位置，不自动执行下一次比较。额外提供一段无需交换的演示，使用户知道“保持顺序”也是有效决策。完成条件为看过完整一轮及保持顺序的例子，标记“演示完成”，不标记“已掌握”。

### 第二阶段 手动练习

提供新的无序数组 `[5, 1, 4, 2, 8, 3]`，任务为独立完成两轮。用户点击两个数组卡片形成一对，主动选择“交换”或“保持顺序”，并用“本轮完成”表达轮次判断。支持取消选择、重选、请求提示和重新练习；首版以点击和键盘操作为主，拖拽不是前置条件。

不默认高亮正确答案或下一对，不提前提示一轮还剩几次；画面显示用户自己选中的对象。用户必须从左侧开始，按本轮扫描顺序选择相邻元素。每次操作依据动作轨迹检查，不能只看最终数组是否偶然有序。

| 操作或情况 | 处理与反馈 |
| --- | --- |
| 选中一个元素 | 显示选中状态，提示再选择一个元素，不写算法计数 |
| 选中不相邻元素 | 指出冒泡排序只比较相邻元素，保留数组并允许重选 |
| 选择相邻但不符合本轮顺序的元素 | 提醒本轮应连续向右扫描；首层提示不直接代选 |
| 本应交换却保持，或本应保持却交换 | 指出比较规则，数组、扫描位置及算法计数不推进 |
| 正确决策 | 更新数组或明确“顺序保持”；解释本次关系，下一对由用户自行选择 |
| 提前声明本轮完成 | 说明仍有相邻比较未完成，保留当前现场 |
| 正确声明本轮完成 | 核验本轮全部动作与归位结果，标记尾部已归位，再开始下一轮 |

第一轮结果为 `[1, 4, 2, 5, 3, 8]`，第二轮为 `[1, 2, 4, 3, 5, 8]`；累计 9 次比较、6 次交换。两轮任务完成时数组仍未完全有序，反馈必须指出这一点。

提示由浅入深：提醒规则 → 指出应关注的范围 → 显示下一次具体示范。用户主动请求提示，或同类错误连续两次时提供“展开更具体提示”的入口，不自动替用户操作。保存提示使用情况；完成练习和无提示完成分别记录，不用单次结果宣称长期掌握。

### 第三阶段 性能测试

默认比较 8、16、32、64 个元素，在有序、逆序、固定随机数组下的比较次数、交换次数与扫描轮数。先展示问题并允许用户预测，再执行完整排序、记录结果、比较趋势；可以跳过预测，不能将跳过记为预测正确。

实验矩阵先固定算法变体和输入分布比较规模，再固定输入比较变体。明确两种规则：固定扫描至结束；某轮无交换则提前结束。相同输入通过数组快照和随机种子复现，切换播放速度不影响计数。计数使用无动画运行，图表展示实际计算结果；动画耗时不用于推断算法性能。

固定轮数版本比较次数为 n(n−1)/2；提前结束版本在已有序输入上为 n−1。将这些关系作为独立测试依据，不在页面上伪造测量结果。性能阶段记录实验组合、预测及运行结果；完成依据是得到至少两种规模和两种初始顺序的可比记录，结论表达单独保存，不强制用户先与 Agent 聊天。

### 第四阶段 自由探索

开放数组编辑、生成数据、升降序、单步、自动运行、速度、暂停、重置和提前结束开关。小规模使用逐元素交互，大规模使用性能图表，具体上限在性能检查后确定并明确显示。

自由探索有独立数组、设置、运行记录和对话作用域，不覆盖手动练习证据。用户可随时回到原理演示或原练习位置；如希望用探索输入另开练习，必须显式创建新尝试，不能继承旧完成状态。

## Agent 的教学行为

每个动作先由程序生成即时反馈，包含选中对象、操作结果、理由代码及下一步可尝试的操作类型。Agent 使用这些事实进行解释与引导；模型不计算权威数组、不修改计数、不裁定完成，也不直接执行学生的交换或物理设置。

| 触发时机 | 教学行为 |
| --- | --- |
| 首次进入阶段 | 一次简短导学，说明目标和如何操作；优先使用准备好的讲解 |
| 普通选取与正确操作 | 更新就地解释，不每次发起模型调用或追加聊天消息 |
| 错误操作 | 规则反馈立即出现，可提供递进提示；用户仍可继续尝试 |
| 请求更多解释或主动提问 | 根据已保存的当前状态、相关动作与错误类型调用模型 |
| 完成一轮、完成练习或对照运行 | 显示程序生成的事实总结，按需补充讲解和下一项探索建议 |

解释可以在实验准备时由 Agent 编排，运行时由事实填入模板；个性化追问走现有模型接口。上下文包含实验版本、阶段、任务、尝试、状态序号、操作对象、前后状态差异、错误类型、提示层级和相关测试记录。问题与迟到回答绑定发起时的作用域；切换阶段后不串接到当前画面。

不因停留时间长或用户不回复就主动催促。模型不可用时，确定性反馈、操作和正常导航仍可用；未同步状态的深度问答应说明需要先同步，不能声称读到了服务端尚未保存的操作。

## 技术实现与复用

新增教学协议版本，建议使用 v3，明确 `phase`（教学阶段）、`task`（阶段任务）、`action`（一次操作）和 `attempt`（一次尝试），避免继续把它们都称为 step。旧 v2 的实验版本、运行包及记录保持可恢复，新旧协议显式分流。

| 层 | 职责 | 与现有代码的关系 |
| --- | --- | --- |
| 教学流程 | 四阶段、目标、提示策略、任务完成证据 | 新增独立控制器，替换新实验对旧固定 steps 规则的依赖 |
| 学科适配 | 合法动作、状态更新、结果解释依据、验证、可比较指标 | 冒泡排序与摩擦各自实现，不在共享 Model 中继续混放所有领域字段 |
| 展示交互 | 卡片选择、高亮、动画、图表、反馈、键盘与触屏 | 复用 MAIC-UI 外观和原生绘图能力；关键交互由可信组件提供 |
| Agent 辅导 | 导学、提示、追问、事实总结和答疑 | 扩展当前 ask 上下文和调用策略，复用模型网关 |
| 会话存储 | 动作、版本、尝试、测试记录、反馈与问答 | 优先复用现有三张表、批次去重和离线草稿机制 |

学科适配器最小接口为初始化、验证动作、执行动作、判断任务结果、生成事实反馈、导出指标。先针对两个样板定义有限的参数结构，不引入任意脚本规则或完整教学 DSL。

MAIC-UI 继续负责实验页面的视觉与内容组织；冒泡排序的数组卡片、可选对象和点击命中由可信组件统一提供，绘图与交互引用同一元素身份。模型生成内容不得新增绕过练习规则的自动运行按钮，也不根据通用提示词自行改写排序或物理公式。其他学科需提交已验证的适配器，才能启用四阶段模式。

状态分开保存实验模型、教学阶段/任务、提示使用和测试记录。动作携带事件 ID、协议/内容版本、阶段、尝试及预期序号；响应区分合法执行、判断错误、无变化和非法操作，并携带可解释证据。演示、练习、对比和探索分别维护状态；重试当前练习不删除其他独立阶段的记录，依赖旧结果的总结明确标为旧尝试。

保存仍采用服务端可信重放，并用独立领域断言验证结果。存储方案须确认旧 v2 会话可读取后才决定是否增加字段或迁移；本计划不提前执行新迁移。算法性能任务保存输入和可重算结果，防止一次运行写入过量逐帧事件；教学操作保存语义动作，动画帧不作为教学动作。

## 用物理实验验证扩展方式

第二个样板选择水平面恒定滑动摩擦，复用已有数值模型。明确模型假设：水平面、恒定滑动摩擦、忽略其他阻力，g = 9.8 m/s²。展示初速度、摩擦系数、速度、位移和停车距离，不能将模型简化结论无条件外推到其他实验。

| 阶段 | 用户任务与交互 | 完成证据 |
| --- | --- | --- |
| 原理演示 | 观察受力、速度和位移；按短时间片推进并解释减速过程 | 看过从运动到停止的关键状态及对应解释 |
| 手动练习 | 完成“只改变摩擦系数，研究停车距离”的任务；设置条件、可选预测、启动并等待自然停止 | 存在相同初速度、不同摩擦系数的两次有效运行与对照记录 |
| 对比探究 | 分别研究摩擦系数与初速度，选择对照组并比较图表 | 每组对照只改变指定变量，保存完整参数、结果和单位 |
| 自由探索 | 开放模型支持的全部参数和运行控制 | 无教学通关要求，记录与练习独立 |

手动练习中，学生作出实验决策，运动过程由模拟自然推进，不要求反复点击时间步。超出模型范围的输入应阻止；同时改变两个条件时提示不能形成有效单变量对照，并允许修正。合法设置得到不符合预测的结果要保留为探究材料，不能当成非法操作回滚。

扩展成功的标准：新增物理适配器和专用交互后，共享阶段控制、反馈呈现、保存、版本隔离和 Agent 上下文无需复制一套。如果仍要改共享核心才能容纳“运行后观察”，先修正抽象，再增加第三个学科。

## 验收场景和发布边界

| 范围 | 必须通过的检查 |
| --- | --- |
| 演示 | 一次只执行一个教学动作；解释和值一致；没有整轮自动执行入口 |
