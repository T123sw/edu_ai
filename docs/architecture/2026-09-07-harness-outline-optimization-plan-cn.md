# Harness 知识点大纲优化实施计划

目标：通过真实 DeepSeek Harness 调用，交付围绕具体知识点的、具有学习目标、内容递进、案例、易错点和检验方式的大纲。本轮不要求生成报告正文。

验收样例采用“二分查找的循环不变量与边界处理”，受众为掌握 Python 循环与数组的大学初学者。这个主题能检验具体知识点边界、算法适用条件、推理、案例和学习检查，避免以泛化章节冒充合格大纲。

## 实施顺序

1. 根角色：独立为始终加载的教育角色文件，明确教学目的、角色适配、需求判断、工具选择、证据边界、任务切换、交付标准。
2. 报告 Skill：补齐报告类型、澄清条件、检索策略、内容组织、大纲生成与修订、质量检查、结束条件；把知识点质量规范放入按需参考文件。
3. 网络搜索工具：保留现有搜索服务和授权边界，规范可追溯来源、去重、时间与不可信资料标记；明确搜索摘要不等于已读全文。
4. 内容组织工具：新增结构化 organize_report_content；组织范围、先修知识、学习目标、概念依赖、示例、误区、检查和证据映射。独立存储组织结果，并绑定来源策略，允许复用。
5. 大纲工具：支持消费组织结果，保留旧调用兼容；检查学习目标与章节映射、证据引用和组织结果一致性。质量失败不得保存为合格版本；保留已有版本确认和权限规则。
6. 验证：增加有意义的边界与失败回归；使用隔离存储运行真实 Harness → 原生 Skill → 网络检索 → 内容组织 → 大纲生成，不触发正文任务。审阅实际大纲，保存交付物、执行证据与验收说明。

## 完成标准

- 五项能力都在运行代码中接通；普通对话仍可直接回答。
- 大纲聚焦一个知识点，说明受众、先修、可检验目标，包含从概念到应用的顺序、具体示例、易错点和自检任务。
- 检索证据能追溯至实际返回来源，缺失或未核实的内容不伪称已验证；检索文本不能提供工具权限或用户确认。
- 真实执行记录中能看到 Skill、搜索、内容组织和大纲工具；只要大纲时没有 submit_report。
- 自动结构校验与人工语义审阅分开记录，不把结构通过称为事实已全部核验。
- 不写真实课程数据，不修改服务开关，不重启服务；现有集成回归通过。

## 执行记录

- 已完成根角色文件、扩展报告 Skill 与知识点质量参考、来源域名过滤与参考页读取、内容组织和目标覆盖检查。
- 首轮真实验证暴露内容模型空输出，改用 Harness 专用非思考内容网关；主 Harness 的规划模式保持原配置。参数依据：[DeepSeek 思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。
- 搜索重排序返回 404，域名限定检索未命中权威页面；新增支持白名单公开参考页的读取路径，不以转载替代指定来源。
- 第三轮结构通过但人工审阅未通过：混用匹配值查找与插入点契约。增加组织结果的独立模型语义审查，失败返回具体修正要求，并禁止组织失败后绕过该步骤直接生成。
- 增加结构错误字段反馈、内容输出预算和服务端修正次数上限；发现思考模式审查也可能空返回，最终使用非思考模式逐项推演，明确区分大纲与全文要求，依据整体判定和每项检查判断阻断。
- 验收请求加入人工审阅反馈（两种查找契约、不变量、空数组与末端索引），验证是经反馈修订的样例，不作为零提示一次成功或通用可靠性证明。
- 最终语义审阅和执行结果见本轮验收文档。
