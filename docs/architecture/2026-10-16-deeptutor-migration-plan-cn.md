# DeepTutor 模拟考试迁移实施计划

日期：2026-10-16。用户已授权制定计划并开始执行。依据[迁移评估](2026-10-16-deeptutor-exam-migration-assessment-cn.md)，采用固定上游版本、独立运行服务、Edu_AI 业务适配的路线。

## 目标和边界

保留上游完整源码，复用 DeepQuestionCapability、普通资料的 Explore/Plan/Quiz、参考卷模板到 Quiz、工具协议与调用、模型适配、修复、来源、历史和任务运行层。我们的变更使用可重复应用的补丁记录，不另写简化出题引擎。上游运行数据和依赖环境独立，Edu_AI 持有用户身份、考试版本与作答事实。

主工作区有其他功能的未提交开发，本次以 `services/deeptutor/`、`backend/src/app/integrations/deeptutor/` 和对应测试为新增边界；到注册考试业务时再做小范围共享文件修改。上游固定为 `6cf793bd868ba5ecbe64722936d4be8fab5a01df`，不跟随 main 自动更新。

## 执行约束

保留工具、模型和上游运行能力，不为了迁移删掉复杂路径。资源不可用时报告明确状态；不能通过无工具的替身冒充已经接好检索或执行环境。上游的格式修复不等于答案正确性验证，真实试卷样本需要独立核对。

每个里程碑更新本计划的完成项和证据路径。先完成 M1 的可运行交付，再逐步打通 M2–M5；未完成的阶段明确保留，不把服务骨架描述成已上线模拟考试。
