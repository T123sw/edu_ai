## 测试范围与结果

### 1. 运行环境

- Windows 本地标准启动脚本检查通过：Python 3.12.9、Node.js 24.11.1、pnpm 10.28.0。
- 标准三服务启动通过，浏览器启动烟雾用例 `1 passed`。
- 测试结束执行标准停止脚本；3000、8001、5173 均无监听，`.runtime/dev-processes.json` 已清除。
- 全程仅判断配置项是否存在，没有输出密码、令牌或 API Key。

### 2. 后端确定性覆盖

执行对话 V2、深度搜索服务与导入、生成可靠性矩阵、课堂服务、课堂任务和课堂问答路由测试：

```text
120 passed, 3 warnings in 18.50s
```

警告包括 `pkg_resources`/FastAPI `on_event` 弃用提示，以及 Windows 临时测试目录清理阶段的 `WinError 145` 警告；没有测试失败。

### 3. 真实浏览器链路

使用临时教师账号和隔离课程，通过 Chromium 实际进入 `/#ai?course_id=...`：

- 认证校验和受保护路由通过；
- 工作台加载 6 个当前角色允许使用的生成工具；
- AI 课堂、资源管理入口均存在；
- 从页面输入框发送真实问题，收到 49 字模型回答；
- 浏览器监听到的页面脚本错误数为 0。

### 4. 普通对话

- `/api/auth/register`：200，返回令牌；
- `/api/chat/v2/generation/tools`：200，返回 6 个工具；
- `/api/chat/v2/reply`：200，约 6.6 秒；
- 响应包含非空助手内容、会话标识，`trace.path=fast`。

结论：普通对话的认证、模型调用、会话写入、API 响应和浏览器呈现均通过。

### 5. 深度搜索

调用 `/agent/deepsearch-and-crawl`，参数为 basic、最多 3 个地址且不写入知识库。接口返回 HTTP 200，但业务结果为：

```text
ok=false
Bocha 搜索失败: missing_api_key: BOCHA_API_KEY is not configured
```

环境中 `BOCHA_API_KEY` 与 `TAVILY_API_KEY` 均未配置。此结果分类为部署配置阻塞，不能计为通过。接口使用 HTTP 200 表达业务失败，自动化验收必须同时断言 `ok=true`。

### 6. 教学资料生成

- 创建隔离课程：200；
- `/api/chat/v2/report/direct`：202；
- 任务从 `queued`、`running/generating` 进入 `succeeded/completed`；
- 资源接口返回 200，标题存在，生成正文约 1098 字。

结论：资料任务提交、后台执行、状态轮询、持久化和读取全链路通过。

### 7. AI 课堂

两次提交一页、5 分钟、不启用搜索/TTS/视觉素材的最小课堂：

- 提交均为 202；
- 均进入 `running/generating_outlines`；
- 均在三次重试后以 `INTERNAL_ERROR` 失败；
- 核心错误为连接 `api.deepseek.com:443` 的 10 秒超时。

网络对照结果：宿主机直连 DeepSeek 15 秒超时；经 `127.0.0.1:7897` 代理可立即建立连接。以 `HTTP_PROXY`/`HTTPS_PROXY` 临时重启测试栈后，OpenMAIC 仍然超时，说明其当前请求客户端没有自动采用这些代理环境变量。

结论：课堂任务编排和错误落账正常，但真实课堂内容生成当前不可用。部署前需要为 OpenMAIC 配置可生效的代理/出口网络，再重跑本节。

### 8. 旧浏览器功能用例

目标 7 个 spec 共 13 个用例全部失败。截图与页面快照显示首次运行共同回到登录页：启动脚本固定前端请求 `127.0.0.1:8001`，而夹具只拦截 `localhost:8001`。

把测试前端临时改回 `localhost` 后，认证可以通过，但生成工厂仍为空；原因是夹具尚未模拟新增的 `/api/chat/v2/generation/tools`，部分用例也仍使用旧的响应式按钮名称和布局假设。

因此这 13 个失败记录为测试资产过期，不作为 13 个独立产品缺陷；但它们必须在下一轮修复后重新纳入回归门禁。

## 部署前必须完成

1. 为深度搜索配置有效的 Bocha 密钥；若要使用 Tavily 兜底，同时配置 Tavily 密钥。
2. 为 OpenMAIC 提供能够访问 DeepSeek 的网络出口；当前仅设置通用代理环境变量不生效，需要按其 HTTP 客户端支持方式配置。
3. 更新 Playwright 教师夹具：统一 API host、补齐生成工具目录响应，并同步当前响应式布局契约。
4. 修复配置后重新执行深度搜索和 AI 课堂真实任务；二者都成功前，不应把系统标记为全功能验收通过。
