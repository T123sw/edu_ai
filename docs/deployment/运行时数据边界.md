# Edu-AI 运行时数据边界

最近更新：2026-09-01

本项目的 Git 仓库只保存源代码、迁移、配置模板和确定性的测试夹具。用户数据、生成结果、缓存、模型、日志与备份必须放在仓库之外。Linux 统一数据根目录为 `/data/edu_ai/`；Windows 现有数据在正式迁移前保持原位，不在仓库清理阶段改写。

## Linux 目录约定

| 目录 | 用途 | 备份要求 |
| --- | --- | --- |
| `/data/edu_ai/storage/` | 用户资料、个人知识库、任务文件、媒体与兼容期文件存储 | 需要备份 |
| `/data/edu_ai/course_data/` | 课程资料、课程知识库、课堂与教学资源文件 | 需要备份 |
| `/data/edu_ai/backups/postgres/` | PostgreSQL 逻辑备份 | 必须备份并限制访问权限 |
| `/data/edu_ai/models/` | Hugging Face、Docling 等可重新下载的模型与缓存 | 通常不备份 |
| `/data/edu_ai/openmaic/` | OpenMAIC 运行时数据与导出过程文件 | 按是否可重建决定 |
| `/data/edu_ai/tmp/` | 临时文件、渲染中间产物 | 不备份，可清理 |
| `/data/edu_ai/logs/` | 应用日志 | 按保留周期轮转 |
| `/data/edu_ai/backups/` | 数据库和文件数据的离线备份 | 必须限制访问权限 |

## 应用配置边界

后端部署时至少应把以下路径显式指向数据盘：

```dotenv
STORAGE_ROOT=/data/edu_ai/storage
COURSE_STORAGE_ROOT=/data/edu_ai/course_data
VECTOR_DB_PATH=/data/edu_ai/storage/vector_db
TEMP_DIR=/data/edu_ai/tmp
OPENMAIC_DATA_ROOT=/data/edu_ai/openmaic
```

`DATABASE_URL`、模型 API Key 和其他密钥只写入服务器上的受限 `.env`，不写入 Git、README、systemd 单元正文或 Nginx 配置。模型缓存目录在环境统一阶段配置到 `/data/edu_ai/models/`。

## 仓库中允许保留的数据

- 单元测试和端到端测试直接引用的最小夹具；
- 可复现的课程示例元数据和经过审核的课程知识文本；
- 数据库 schema、Alembic 迁移与无密钥配置模板。

以下内容不得提交：真实 `.env`、PostgreSQL dump、SQLite 运行库、用户上传文件、生成资源、向量库、模型权重、构建目录、测试输出和日志。

## 迁移约束

- 当前 Windows 工作区中的 `storage/`、`models/`、课程数据和数据库备份不是本轮代码清理的删除对象。
- 数据迁移必须先做只读盘点和校验备份，再复制到 `/data/edu_ai/`；不得用 Git 传输运行数据。
- 切换前后应分别核对文件数量、总大小、数据库记录数和抽样哈希；确认新服务稳定后再决定旧副本的保留周期。
