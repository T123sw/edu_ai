## Design Context

### Users
Primary users are teachers working inside a course context rather than a generic chat context. They use the system to clarify teaching needs, combine course knowledge with personal materials, generate teaching resources, iterate on outputs, and accumulate reusable course assets over time.

### Brand Personality
Professional, trustworthy, and clear. The interface should help teachers feel oriented, in control, and supported by a capable teaching copilot rather than overwhelmed by a general-purpose AI tool.

### Aesthetic Direction
Light-mode-first, structured, calm, and product-grade. The system should feel like a mature teaching workbench: clean hierarchy, clear task flow, restrained emphasis, and strong information clarity over visual spectacle.

### Design Principles
1. Course context before conversation context.
2. Make task, knowledge source, and output state explicit.
3. Reduce cognitive load through clear hierarchy and progressive disclosure.
4. Keep the main workflow inside one unified workbench instead of many disconnected pages.
5. Favor trust, clarity, and long-session usability over novelty.
