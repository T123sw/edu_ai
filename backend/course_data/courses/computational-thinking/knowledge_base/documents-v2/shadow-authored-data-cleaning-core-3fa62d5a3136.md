## 学习目标
1. 理解数据质量的四个核心维度及其对计算结果的影响。
2. 掌握缺失值与异常值的识别机制及处理策略。
3. 能够区分“原始数据”与“特征”，理解特征构造的基本逻辑。
4. 能够评估数据清洗过程中的信息损失与噪声消除之间的权衡。

## 准确概念与边界
**数据质量**指数据满足特定使用需求的程度，主要包含四个维度：准确性（数据是否真实反映现实）、完整性（是否存在缺失）、一致性（不同来源数据是否冲突）、时效性（数据是否过时）。**数据清洗**是将低质量数据转换为高质量数据的过程，其边界在于不改变数据原本的业务含义，仅修正错误或填补空缺。**特征**是用于模型输入的变量，它不同于原始字段，往往经过提取、转换或组合，旨在更好地表达数据的潜在规律。

## 机制与步骤
处理低质量数据通常遵循“检测 - 决策 - 执行”三步机制。
1. **缺失值处理**：首先判断缺失机制。若为完全随机缺失（MCAR），可直接删除；若为非随机缺失，需填补。常用填补法包括均值填补（适用于正态分布）、中位数填补（适用于偏态分布）及众数填补（适用于分类数据）。
2. **异常值检测**：常用方法有 $3\sigma$ 原则与箱线图法则。$3\sigma$ 原则基于正态分布假设，认为超出 $[\mu - 3\sigma, \mu + 3\sigma]$ 的数据为异常。箱线图法则基于四分位距（IQR），定义异常值边界为 $[Q1 - 1.5 \times IQR, Q3 + 1.5 \times IQR]$，其中 $IQR = Q3 - Q1$。
3. **特征构造**：从原始字段中提取信息。例如从“时间戳”提取“星期几”，从“文本”提取“长度”。

## 完整示例
假设某班级成绩表包含字段：`[学号，数学，英语，物理]`。其中“物理”列存在缺失，“数学”列存在极端高分（如 150 分制得了 200 分）。
1. **检测**：统计“物理”列缺失率，计算“数学”列的 $Q1, Q3$。
2. **决策**：若缺失率低于 5%，采用中位数填补；若“数学”分数超出合理范围，视为录入错误。
3. **执行**：用全班物理中位数填充空缺，将异常数学分修正为最大值或剔除该样本。

## 代码实现
以下 Python 代码演示基于 IQR 的异常值清洗与缺失值填补：
```python
import pandas as pd
import numpy as np

def clean_data(df, column):
    # 缺失值填补：使用中位数
    median_val = df[column].median()
    df[column] = df[column].fillna(median_val)
    
    # 异常值检测：IQR 方法
    Q1 = df[column].quantile(0.25)
    Q3 = df[column].quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    
    # 异常值修正：裁剪至边界
    df[column] = np.where(df[column] < lower_bound, lower_bound, df[column])
    df[column] = np.where(df[column] > upper_bound, upper_bound, df[column])
    return df
```

## 复杂度与权衡
数据清洗并非越彻底越好。**权衡点**在于“噪声消除”与“信息保留”。过度清洗（如删除所有含缺失值的行）会导致样本量急剧下降，增加模型方差，降低泛化能力；而清洗不足则引入噪声，增加模型偏差。例如，使用中位数填补虽 robust，但会低估数据的方差。计算复杂度方面，排序计算分位数的复杂度为 $O(N \log N)$，在大尺度数据下需考虑采样策略。

## 常见误区
1. **误区一**：“异常值一定是错误数据”。事实上，异常值可能代表稀有但重要的事件（如欺诈交易），直接删除可能导致关键模式丢失。
2. **误区二**：“缺失值直接填 0"。对于非零义字段（如身高、温度），填 0 会引入严重偏差，应视为缺失处理。
3. **误区三**：“特征越多越好”。无关特征会增加计算负担并导致过拟合，应注重特征的有效性而非数量。

## 自测题与答案
1. **问**：当数据呈严重偏态分布时，为何推荐使用中位数而非均值填补缺失值？
   **答**：均值受极端值影响大，偏态分布下均值不能代表中心趋势，中位数更 robust。
2. **问**：箱线图法则中，系数 1.5 能否随意调整？
   **答**：不能随意调整。1.5 是统计学经验值，调整会改变异常值的判定灵敏度，需根据业务容忍度决定。
3. **问**：特征工程是否属于数据清洗的一部分？
   **答**：不属于。清洗是恢复数据原貌，特征工程是创造新信息，二者目的不同但常顺序执行。
