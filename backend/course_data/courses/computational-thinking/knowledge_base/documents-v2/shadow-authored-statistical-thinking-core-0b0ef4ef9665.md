## 学习目标
1. 理解统计推断的基本逻辑，区分样本与总体。
2. 准确界定“相关关系”与“因果关系”的本质差异。
3. 掌握识别混淆变量的方法，避免因果谬误。
4. 能够使用皮尔逊相关系数量化线性关联强度。

## 准确概念与边界
**统计推断**是指利用样本数据对总体特征进行估计或假设检验的过程。其核心在于承认**不确定性**，即结论总是伴随一定的置信水平，而非绝对真理。

**相关关系**（Correlation）描述的是两个变量在数值变化上的同步性。若变量 $X$ 增加时变量 $Y$ 倾向于增加，称为正相关；反之则为负相关。相关系数 $r$ 的取值范围为 $[-1, 1]$。相关关系仅表明“伴随发生”，不隐含方向性。

**因果关系**（Causation）指一个事件（因）直接导致另一个事件（果）的发生。确立因果通常需要满足三个条件：关联性、时间先后性（因在前）、排除其他解释（无混淆变量）。

**边界**：相关是因果的必要非充分条件。存在相关未必有因果，有因果未必呈现线性相关（可能是非线性关系）。

## 机制与步骤
进行统计推断与因果辨析通常遵循以下步骤：
1. **提出假设**：设定零假设 $H_0$（无关联）与备择假设 $H_1$（有关联）。
2. **收集数据**：确保样本具有代表性，避免选择偏差。
3. **计算统计量**：如计算相关系数或检验统计量。
4. **评估显著性**：计算 $p$ 值。若 $p < \alpha$（通常为 0.05），则拒绝 $H_0$。
5. **因果排查**：检查是否存在第三变量（混淆变量）同时影响了 $X$ 和 $Y$。

## 完整例子：冰淇淋销量与溺水事故
夏季数据显示，冰淇淋销量与溺水事故数量呈现强正相关（$r \approx 0.8$）。
- **错误推断**：吃冰淇淋导致溺水。
- **正确推断**：存在混淆变量“气温”。气温升高导致更多人买冰淇淋，同时也导致更多人游泳，从而增加溺水概率。
- **结论**：两者相关，但无直接因果。控制气温变量后，相关性将消失。

## 必要的公式与代码
皮尔逊相关系数公式：
$$ r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \sum_{i=1}^{n}(y_i - \bar{y})^2}} $$

Python 计算示例：
```python
import numpy as np
from scipy.stats import pearsonr

x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 5, 4, 5])
corr, p_value = pearsonr(x, y)
print(f"相关系数：{corr:.3f}, p 值：{p_value:.3f}")
```

## 复杂度与权衡
- **样本量权衡**：样本越小，抽样误差越大，推断越不可靠；但大样本可能导致微小的差异也变得“统计显著”，需结合“实际显著性”判断。
- **显著性水平**：$\alpha$ 设得越低（如 0.01），犯第一类错误（假阳性）的概率越低，但犯第二类错误（漏报）的概率增加。

## 常见误区
1. **因果倒置**：误将结果当作原因（如：健康导致运动，而非运动导致健康）。
2. **忽略混淆变量**：未控制关键背景变量。
3. **数据挖掘谬误**：在大量变量中强行寻找显著相关，导致偶然性被当作规律。

## 自测题与答案
1. **问**：若 $p=0.03$，意味着零假设为真的概率是 3% 吗？
   **答**：不是。$p$ 值是在零假设为真的前提下，观察到当前数据或更极端数据的概率。
2. **问**：相关系数为 0 是否意味着两个变量独立？
   **答**：不一定。仅意味着无线性相关，可能存在非线性关系（如抛物线）。
3. **问**：如何验证因果？
   **答**：最可靠的方法是随机对照实验（RCT），控制其他变量不变，仅改变自变量。
