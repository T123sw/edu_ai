## 算法的准确概念与边界
在计算思维中，算法（Algorithm）不仅仅是一段代码或一个数学公式。算法是指解题方案的准确而完整的描述，是一系列解决问题的清晰指令。代表着用系统的方法描述解决问题的策略机制。

从边界上看，算法不同于程序（Program）。程序是算法在特定计算机系统中的实现，它可能包含无限循环（如操作系统内核），但算法必须在有限步骤内结束。算法也不同于启发式方法（Heuristic），后者可能无法保证找到最优解或在有限时间内停止，而严格意义上的算法必须保证在有穷步骤内得出结果。算法的核心在于“机械性”，即每一步都不需要智慧介入，只需按规则执行。

## 算法的五大基本性质
一个有效的算法必须具备以下五个基本性质，缺一不可：

1. **有穷性（Finiteness）**：算法必须在执行有限步之后结束，且每一步都在有限时间内完成。这是算法与无限过程（如持续运行的服务监听）的根本区别。若一个过程陷入死循环，则它不是一个算法。
2. **确定性（Determinism）**：算法的每一步骤必须有确切的定义，不会产生二义性。对于相同的输入，无论何时执行，都必须得到相同的输出。例如，“加热一会儿”不是确定性指令，而“加热 30 秒”是。
3. **可行性（Feasibility）**：算法中的所有操作必须是可执行的。这意味着操作可以通过已经实现的基本运算执行有限次来实现。例如，要求“计算所有整数的和”不可行，因为整数集无限。
4. **输入（Input）**：一个算法有 0 个或多个输入，以刻画运算对象的初始情况。
5. **输出（Output）**：一个算法有一个或多个输出，以反映对输入数据加工后的结果。

## 机制描述与示例：欧几里得算法
为了具体说明上述性质，我们以计算两个正整数最大公约数（GCD）的欧几里得算法为例。

**数学原理**：
对于两个正整数 $a$ 和 $b$（假设 $a \ge b$），它们的最大公约数等于 $b$ 和 $a \mod b$ 的最大公约数。即：
$$ gcd(a, b) = gcd(b, a \mod b) $$
当 $b = 0$ 时，$gcd(a, 0) = a$。

**伪代码描述**：
```text
算法 GCD(a, b)
    输入：正整数 a, b
    输出：a 和 b 的最大公约数
    步骤：
    1. 当 b ≠ 0 时，执行循环：
        a. 计算 r = a mod b
        b. 令 a = b
        c. 令 b = r
    2. 返回 a
```

**Python 代码实现**：
```python
def gcd(a, b):
    while b != 0:
        r = a % b
        a = b
        b = r
    return a

# 测试
print(gcd(48, 18))  # 输出应为 6
```

**性质验证**：
- **有穷性**：因为 $a \mod b$ 的结果严格小于 $b$，且为非负整数，所以 $b$ 的值会严格递减，最终必然变为 0，循环终止。
- **确定性**：取模运算和赋值操作都是确定的，无歧义。
- **可行性**：取模和赋值是计算机基本指令，完全可行。

## 常见误区辨析
1. **误区一：程序就是算法。**
   纠正：程序是算法的载体。一个包含死循环的后台服务程序，其整体不是一个算法，但它内部处理单个请求的逻辑模块可能是一个算法。
2. **误区二：算法必须很快。**
   纠正：效率（时间复杂度）是评价算法优劣的指标，但不是定义算法的必要条件。一个效率极低但能在有限步停止的方法仍然是算法。
3. **误区三：近似解法不是算法。**
   纠正：只要近似解法能在有限步内停止并给出确定结果，它也是算法（如数值分析中的迭代法）。

## 自测题与答案
1. **判断题**：一个永远运行的操作系统调度程序是一个算法。
   - 答案：错误。违反了有穷性。
2. **选择题**：下列哪项违反了算法的确定性？
   - A. 步骤描述为“如果 x>0 则加 1"
   - B. 步骤描述为“随意选择一个数”
   - C. 步骤描述为“计算 x 的平方”
   - 答案：B。 “随意选择”导致结果不可复现。
3. **简答题**：为什么“可行性”要求操作必须是基本运算？
   - 答案：因为算法最终需要由执行者（人或机器）完成，如果步骤本身无法通过有限次基本操作实现，则该步骤无法执行，算法无法落地。
