## 准确概念与边界
**算法公平（Fairness）** 指算法决策不应因个体的敏感属性（如性别、种族、年龄）而产生系统性歧视。公平性分为群体公平（如统计parity）和个体公平（相似个体得到相似对待）。边界在于：公平的定义依赖于具体场景，不存在数学上 universally 最优的公平定义。
**算法透明（Transparency）** 指利益相关者能够理解算法如何做出决策。包括过程透明（代码开源）和结果透明（可解释性）。边界在于：商业机密与完全透明之间存在张力，且高复杂度模型（如深度学习）天然难以完全解释。
**算法责任（Accountability）** 指当算法造成损害时，必须有明确主体承担后果。包括设计者、部署者及使用者。边界在于：自动化决策链条中，责任往往被分散，需确立“人机回环”机制。

## 机制与步骤
实现伦理算法的标准流程包含四步：
1. **数据审计**：检查训练数据是否存在历史偏见或采样偏差。
2. **指标选择**：根据场景选择合适的公平性指标（如机会均等、统计parity）。
3. **模型干预**：在预处理、训练中或后处理阶段引入公平性约束。
4. **持续监控**：部署后定期检测模型表现是否发生漂移。

量化群体公平性的常用公式为统计parity差（Statistical Parity Difference, SPD）：
$$ SPD = |P(\hat{Y}=1|A=0) - P(\hat{Y}=1|A=1)| $$
其中 $\hat{Y}$ 为预测结果，$A$ 为敏感属性（0 和 1 代表不同群体）。SPD 越接近 0，表示群体间通过率差异越小。

## 完整例子：贷款审批系统
假设某银行使用算法审批贷款。敏感属性为性别（0=女，1=男）。
若男性获批率 80%，女性获批率 60%，则 $SPD = |0.6 - 0.8| = 0.2$。若阈值为 0.05，则该模型存在显著不公平。

## 代码实现：偏见检测函数
以下 Python 函数用于计算 SPD，可直接用于审计流程。
```python
import numpy as np

def calculate_spd(y_pred, sensitive_attr):
    """
    计算统计parity差 (SPD)
    参数:
        y_pred: 预测结果列表 (0 或 1)
        sensitive_attr: 敏感属性列表 (0 或 1)
    返回:
        spd: 浮点数，越接近 0 越公平
    """
    y_pred = np.array(y_pred)
    sensitive_attr = np.array(sensitive_attr)
    
    # 防止除零错误
    if np.sum(sensitive_attr == 0) == 0 or np.sum(sensitive_attr == 1) == 0:
        return None
        
    rate_0 = np.mean(y_pred[sensitive_attr == 0])
    rate_1 = np.mean(y_pred[sensitive_attr == 1])
    
    spd = abs(rate_0 - rate_1)
    return spd

# 测试数据
preds = [1, 1, 0, 1, 0, 1, 1, 1]
attrs = [0, 0, 0, 0, 1, 1, 1, 1]
print(f"SPD: {calculate_spd(preds, attrs):.2f}")
```

## 复杂度与权衡
在计算思维中，必须认识到**公平性 - 准确率权衡（Fairness-Accuracy Trade-off）**。强制满足公平性约束通常会降低模型在整体数据集上的预测准确率。这是因为历史数据中的偏见可能恰好与目标变量相关。例如，若历史数据中某群体违约率确实较高，强制拉平通过率可能会增加银行的坏账风险。决策者需在伦理风险与商业利益之间寻找 Pareto 最优解，而非盲目追求单一指标最优。

## 常见误区
1. **误区一：移除敏感属性即可实现公平。**
   纠正：其他特征（如邮编、消费习惯）可能与敏感属性高度相关（代理变量），移除显性属性无法消除隐性偏见。
2. **误区二：公平性是纯数学问题。**
   纠正：公平性本质是社会规范的法律化，数学指标仅能辅助量化，不能替代伦理判断。
3. **误区三：算法比人更客观。**
   纠正：算法是历史数据的镜像，若数据包含人类偏见，算法会放大而非消除偏见。

## 自测题与答案
1. **问**：SPD 值为 0 是否意味着模型完全符合伦理？
   **答**：否。SPD 仅衡量群体通过率差异，未考虑个体资质差异（如信用评分），可能掩盖了逆向歧视。
2. **问**：在医疗诊断算法中，应优先保证准确率还是公平性？
   **答**：视情况而定。若疾病在不同群体发病率差异大，强求统计parity可能导致漏诊。通常应优先保证“机会均等”（即患病者被检出的概率一致）。
3. **问**：谁应对算法造成的歧视性后果负责？
   **答**：部署该算法的组织主体负有首要责任，设计者负有技术伦理责任，需建立问责链条。
