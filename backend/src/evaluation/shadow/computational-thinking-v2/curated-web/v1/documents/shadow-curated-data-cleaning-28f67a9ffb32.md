**数据清洗**（data cleaning）是从记录集、[数据库表](/wiki/%E6%95%B0%E6%8D%AE%E5%BA%93%E8%A1%A8 "数据库表")或[数据库](/wiki/%E6%95%B0%E6%8D%AE%E5%BA%93 "数据库")中检测和纠正（或删除）损坏或不准确的记录的过程，是指识别数据的不完整、不正确、不准确或不相关部分，然后替换、修改、或删除[脏数据](/wiki/%E8%84%8F%E6%95%B0%E6%8D%AE "脏数据")或粗数据。数据清洗可以与数据加工工具交互执行，也可以通过[脚本](/wiki/%E8%84%9A%E6%9C%AC "脚本")进行[批处理](/wiki/%E6%89%B9%E5%A4%84%E7%90%86%E4%BB%BB%E5%8A%A1 "批处理任务")。

清洗后，一个数据集应该与系统中其他类似的数据集保持一致。 检测到或删除的不一致可能最初是由用户输入错误、传输或存储中的损坏或不同存储中类似实体的不同[数据字典](/wiki/%E6%95%B0%E6%8D%AE%E5%AD%97%E5%85%B8 "数据字典")定义引起的。 数据清理与[数据确认](/wiki/%E6%95%B0%E6%8D%AE%E7%A1%AE%E8%AE%A4 "数据确认")(data validation)的不同之处在于，[数据确认](/wiki/%E6%95%B0%E6%8D%AE%E7%A1%AE%E8%AE%A4 "数据确认")几乎总是意味着数据在输入时被系统拒绝，并在输入时执行，而不是执行于批量数据。

数据清洗不仅仅更正错误，同样加强来自各个单独信息系统不同数据间的一致性。专门的数据清洗软件能够自动检测数据文件，更正错误数据，并用全企业一致的格式整合数据。
