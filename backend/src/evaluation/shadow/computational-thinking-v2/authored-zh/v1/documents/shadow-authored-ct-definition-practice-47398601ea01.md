## 学习目标
本案例旨在通过真实情境，让学生实践计算思维的定义与边界识别。完成实践后，学生应能够：
1. 在具体场景中划定计算问题的边界（哪些可自动化，哪些需人工）。
2. 将非结构化需求转化为明确的输入输出规范。
3. 评估算法方案在边界条件下的鲁棒性。

## 真实问题情境
某大学图书馆希望优化“旧书下架流程”。目前流程完全人工：管理员逐本检查书籍出版年份和破损程度，决定下架或保留。该过程耗时且标准不一。图书馆希望引入计算思维辅助决策，但预算有限，无法购买昂贵的图像识别系统，只能利用现有的条形码扫描器和简易数据库。

## 输入输出或材料
- **输入材料**：书籍条形码（ISBN）、出版年份（数据库查询）、借阅次数（数据库查询）、外观破损评分（人工输入 1-5 分）。
- **输出结果**：决策指令（“保留”、“下架”、“修复”）。
- **约束条件**：不能自动检测破损，必须有人工介入环节；系统响应时间需小于 1 秒。

## 分步任务
请学生分组完成以下任务，重点在于界定计算思维的边界：
1. **问题边界定义**：列出哪些步骤必须由计算机完成，哪些必须由人完成。说明理由。
2. **数据抽象**：设计一个数据结构来代表一本书的状态，忽略无关信息（如书名、作者颜色）。
3. **规则设计**：制定下架逻辑。例如：年份早于 2000 且借阅次数低于 5 次。
4. **异常处理**：定义当数据缺失（如数据库无年份）时的系统行为。

## 参考实现/推导
以下是基于 Python 的逻辑推导示例，展示了如何将人工规则转化为计算逻辑：

```python
class Book:
    def __init__(self, isbn, year, borrow_count, damage_score):
        self.isbn = isbn
        self.year = year
        self.borrow_count = borrow_count
        self.damage_score = damage_score # 1-5, 5 为最破损

def decide_book_status(book):
    # 边界检查：数据完整性
    if book.year is None:
        return "MANUAL_REVIEW" # 计算无法处理，边界外推给人
    
    # 计算思维核心：规则自动化
    if book.damage_score >= 4:
        return "REPAIR_OR_DISCARD"
    elif book.year < 2000 and book.borrow_count < 5:
        return "WITHDRAW"
    else:
        return "KEEP"

# 测试数据
sample_book = Book("978000000", 1998, 2, 3)
print(decide_book_status(sample_book)) # 输出：WITHDRAW
```

## 测试与边界情况
计算思维的严谨性体现在对边界情况的处理上。学生需测试以下场景：
1. **正常情况**：数据完整，符合常规逻辑。
2. **边界值**：出版年份正好是 2000 年；借阅次数正好是 5 次。需确认逻辑是包含还是排除（$ \le $ 还是 $ < $）。
3. **异常边界**：破损评分输入为 6（超出范围）；数据库连接失败。
4. **语义边界**：一本 1990 年的经典著作，借阅次数低，是否应下架？这揭示了计算思维无法完全替代人文价值判断的边界。

## 评价量规
| 评价维度 | 优秀 (5 分) | 合格 (3 分) | 待改进 (1 分) |
| :--- | :--- | :--- | :--- |
| **边界识别** | 清晰区分自动化与人工环节，理由充分 | 能区分但理由模糊 | 混淆人工与自动任务 |
| **抽象能力** | 数据模型简洁，仅包含决策必要字段 | 包含部分无关字段 | 直接复制所有数据库字段 |
| **逻辑鲁棒性** | 妥善处理空值、异常值及边界值 | 仅处理正常流程 | 未考虑异常情况 |
| **可执行性** | 规则明确，无歧义，可转化为代码 | 规则有部分歧义 | 规则模糊，无法执行 |

## 拓展问题
1. 如果图书馆希望完全去除人工评分环节，计算思维的边界需要如何扩展？（提示：涉及图像识别算法的引入与成本权衡）。
2. 若下架规则变为“动态调整”，例如根据每学期存储空间剩余量自动调整年份阈值，算法需要增加什么变量？
3. 讨论：是否存在某些书籍永远不应由算法决定下架？这反映了计算思维在哪一层面的局限性？（提示：伦理与价值判断边界）。
