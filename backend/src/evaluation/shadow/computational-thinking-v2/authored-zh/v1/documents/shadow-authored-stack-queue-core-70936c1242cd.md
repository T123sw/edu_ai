## 学习目标
1. 准确区分栈（Stack）、队列（Queue）与双端队列（Deque）的逻辑结构特征。
2. 掌握三种结构的核心操作接口及其时间复杂度。
3. 能够根据“后进先出”或“先进先出”的需求选择合适的数据结构。
4. 理解 Python 中列表与双端队列在实现队列时的性能差异。

## 准确概念与边界
栈、队列和双端队列均属于线性数据结构，其核心区别在于**操作受限的位置**不同。
- **栈（Stack）**：限定仅在表尾进行插入和删除的线性表。遵循**后进先出**（LIFO, Last In First Out）原则。最后进入的元素最先被处理。边界在于不允许随机访问中间元素，仅能访问栈顶。
- **队列（Queue）**：限定仅在表尾进行插入、在表头进行删除的线性表。遵循**先进先出**（FIFO, First In First Out）原则。最早进入的元素最先被处理。边界在于不允许直接在表头插入或表尾删除。
- **双端队列（Deque）**：两端都可以进行插入和删除的线性表。它是栈和队列的超集，既可实现 LIFO 也可实现 FIFO，灵活性最高，但语义约束最弱。

## 机制与步骤
三种结构的基本操作机制如下：
1. **栈操作**：
   - `push(x)`：将元素 $x$ 压入栈顶。
   - `pop()`：移除并返回栈顶元素。若栈空则报错。
   - `peek()`：查看栈顶元素但不移除。
2. **队列操作**：
   - `enqueue(x)`：将元素 $x$ 加入队尾。
   - `dequeue()`：移除并返回队头元素。若队空则报错。
3. **双端队列操作**：
   - `append(x)` / `appendleft(x)`：分别在右端或左端插入。
   - `pop()` / `popleft()`：分别从右端或左端移除。

## 完整例子
假设初始状态为空，执行以下混合操作序列：
1. 栈操作：`push(1)`, `push(2)`, `pop()` $\rightarrow$ 返回 2，栈剩 [1]。
2. 队列操作：`enqueue(3)`, `enqueue(4)`, `dequeue()` $\rightarrow$ 返回 3，队剩 [4]。
3. 双端队列操作：`appendleft(5)`, `append(6)`, `popleft()` $\rightarrow$ 返回 5， deque 剩 [6]。
此例展示了不同结构对同一组数据的不同处理顺序。栈吐出了最新的 2，队列吐出了最早的 3，双端队列按左端优先吐出了 5。

## 代码实现与复杂度
在 Python 中，推荐使用 `collections.deque` 实现栈和队列，而非 `list`。
```python
from collections import deque

# 栈示例
stack = deque()
stack.append(10)  # push
val = stack.pop() # pop

# 队列示例
queue = deque()
queue.append(10)      # enqueue
val = queue.popleft() # dequeue
```
时间复杂度对比表：

| 操作 | list 实现栈 | list 实现队列 | deque 实现栈/队列 |
| :--- | :---: | :---: | :---: |
| 追加/压栈 | $O(1)$ | $O(1)$ | $O(1)$ |
| 弹出栈顶 | $O(1)$ | $O(n)$ | $O(1)$ |
| 弹出队头 | $O(n)$ | $O(1)$* | $O(1)$ |

*注：list 实现队列通常用 pop(0)，复杂度为 $O(n)$，因为需要移动后续所有元素。

## 常见误区
1. **误用列表模拟队列**：许多初学者使用 `list.pop(0)` 实现出队。当数据量大时，每次操作都需要移动内存，导致整体复杂度从 $O(n)$ 退化为 $O(n^2)$。
2. **混淆访问权限**：认为队列可以像列表一样通过索引 `queue[1]` 访问中间元素。虽然底层可能支持，但这违反了队列的抽象数据类型（ADT）定义，破坏了封装性。
3. **空结构操作**：未在进行 `pop` 或 `dequeue` 前检查结构是否为空，导致程序抛出异常崩溃。

## 自测题与答案
1. **问**：若输入序列为 1, 2, 3，经过栈处理后输出序列可能是 3, 2, 1 吗？
   **答**：是。push(1), push(2), push(3), pop(), pop(), pop() 即可得到。
2. **问**：为什么 Python 的 `deque` 比 `list` 更适合做队列？
   **答**：`deque` 底层是双向链表优化结构，两端插入删除均为 $O(1)$；`list` 是动态数组，左端删除需移动元素，为 $O(n)$。
3. **问**：双端队列能否完全替代栈？
   **答**：功能上可以，但语义上不建议。使用栈结构能向阅读代码者明确表达“后进先出”的逻辑意图。
