## 概念与边界
图遍历是指从图中某一顶点出发，按照某种搜索方法沿着图中的边对图中的所有顶点访问一次且仅访问一次的过程。这是处理图结构数据的基础操作。
*   **广度优先搜索 (BFS)**：类似于水的波纹扩散。从起始点开始，先访问所有相邻节点，再访问相邻节点的相邻节点。其核心特征是“层层推进”。
*   **深度优先搜索 (DFS)**：类似于迷宫探路，不撞南墙不回头。从起始点开始，沿着一条路径一直走到底，直到无法继续为止，然后回溯到上一个节点尝试其他路径。其核心特征是“一条路走到黑”。
*   **边界条件**：遍历必须维护一个“已访问集合”（Visited Set）。若图中存在环且未记录访问状态，算法将陷入死循环。对于非连通图，需对每个未访问节点分别启动遍历才能覆盖全图。

## 机制与步骤
### BFS 机制
1.  初始化队列 $Q$，将起始节点 $s$ 入队，标记 $s$ 为已访问。
2.  当 $Q$ 不为空时，执行循环：
    *   队头节点 $u$ 出队。
    *   遍历 $u$ 的所有邻接节点 $v$。
    *   若 $v$ 未被访问，标记 $v$ 为已访问，并将 $v$ 入队。
### DFS 机制（递归版）
1.  标记当前节点 $u$ 为已访问。
2.  遍历 $u$ 的所有邻接节点 $v$。
3.  若 $v$ 未被访问，递归调用 DFS 函数处理 $v$。
    *注：非递归版需显式使用栈结构模拟递归过程。*

## 完整示例
考虑无向图 $G=(V, E)$，其中 $V=\{A, B, C, D, E\}$，边集 $E=\{(A,B), (A,C), (B,D), (C,E), (D,E)\}$。假设邻接表按字母顺序存储。
*   **BFS 过程**：
    1.  访问 A，队列：[A]。
    2.  A 出队，邻居 B、C 入队。访问顺序：A, B, C。队列：[B, C]。
    3.  B 出队，邻居 D 入队（A 已访问）。访问顺序：A, B, C, D。队列：[C, D]。
    4.  C 出队，邻居 E 入队。访问顺序：A, B, C, D, E。队列：[D, E]。
    5.  D 出队，E 已访问。队列：[E]。
    6.  E 出队，结束。
    *   最终序列：$A \rightarrow B \rightarrow C \rightarrow D \rightarrow E$。
*   **DFS 过程**：
    1.  访问 A。
    2.  深入 B，访问 B。
    3.  深入 D，访问 D。
    4.  深入 E，访问 E。
    5.  E 无未访问邻居，回溯至 D，D 无其他邻居，回溯至 B，B 无其他邻居，回溯至 A。
    6.  深入 C，但 C 的邻居 E 已访问，回溯。
    *   最终序列：$A \rightarrow B \rightarrow D \rightarrow E \rightarrow C$。

## 算法实现
以下是基于邻接表的 Python 实现核心逻辑：
```python
from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    visited.add(start)
    while queue:
        node = queue.popleft()
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return list(visited)

def dfs(graph, node, visited):
    visited.add(node)
    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)
```

## 复杂度与权衡
设顶点数为 $V$，边数为 $E$。
*   **时间复杂度**：BFS 和 DFS 均为 $O(V + E)$。因为每个顶点入队/递归一次，每条边被检查两次（无向图）。
*   **空间复杂度**：
    *   BFS：$O(V)$。最坏情况下所有节点都在队列中（如星型图中心节点扩展时）。
    *   DFS：$O(V)$。主要消耗在递归调用栈上，最坏情况为链状图，深度为 $V$。
*   **权衡**：若需寻找无权图中的最短路径（边数最少），必须使用 BFS，因为它是按距离层级扩展的。若仅需判断连通性或遍历所有节点，DFS 代码更简洁且常数项通常较小。

## 常见误区
1.  **忘记标记已访问**：在存在环的图中，这会导致无限递归或死循环。
2.  **入队时机错误**：BFS 中应在节点入队时标记为已访问，而非出队时。若出队才标记，会导致同一节点被多次入队，增加复杂度。
3.  **混淆最短路径**：DFS 找到的第一条路径不一定是最短路径，仅 BFS 能保证无权图的最短性。

## 自测题与答案
1.  **问**：在一个无权图中，若需要找到从起点到终点的最少边数路径，应选择哪种算法？
    **答**：广度优先搜索（BFS）。
2.  **问**：DFS 算法通常使用什么数据结构来隐式或显式地存储路径状态？
    **答**：栈（Stack）或系统调用栈（递归）。
3.  **问**：若图有 $V$ 个顶点，BFS 队列中最多可能同时存在多少个顶点？
    **答**：理论上最多 $V$ 个（例如星型图中心点扩展瞬间），但在一般稀疏图中远小于 $V$。
