## 学习目标
本讲义旨在帮助学生建立程序执行流程的基础认知。学习完成后，学生应能：1. 准确区分顺序、分支与循环三种基本控制结构；2. 理解控制流对程序状态变化的影响；3. 能够使用伪代码或 Python 语言实现包含嵌套逻辑的算法；4. 识别并避免常见的逻辑错误。

## 准确概念与边界
计算思维中的控制结构决定了指令执行的次序。**顺序结构**是默认模式，指令按物理存储地址依次执行，无跳转。**分支结构**（条件结构）依据布尔表达式的真假值（True/False），选择性地执行特定代码块，本质是程序计数器（PC）的条件跳转。**循环结构**则在条件满足时重复执行代码块，直至终止条件达成，本质是 PC 的条件回跳。

边界界定至关重要：控制结构仅管理执行流，不涉及数据存储结构（如数组、链表）的具体实现细节，也不涉及子程序调用（函数）。分支必须互斥或有序，循环必须具备终止可能性，否则将导致逻辑死锁。

## 机制与步骤
从计算机组成原理视角看，控制流由程序计数器（PC）驱动。
1. **顺序**：PC 自动递增，指向下一条指令地址 $Addr_{next} = Addr_{current} + \Delta$。
2. **分支**：计算条件表达式 $C$。若 $C$ 为真，PC 指向目标块地址；若为假，PC 跳过该块。
3. **循环**：在循环体末尾评估条件 $C$。若 $C$ 为真，PC 跳回循环体起始地址；若为假，PC 指向循环后地址。

执行步骤遵循“取指 - 译码 - 执行”周期。在高级语言中，缩进代表了逻辑块的归属，编译器将其转换为底层的跳转指令（如 JMP, JZ）。

## 完整示例
以下代码演示了三种结构的混合使用：计算 $1$ 到 $N$ 之间所有偶数的和，且 $N$ 必须为正整数。

```python
def sum_even_numbers(n):
    # 顺序结构：初始化
    total = 0
    current = 1
    
    # 分支结构：输入验证
    if n <= 0:
        return "Error: N must be positive"
    
    # 循环结构：遍历与累加
    while current <= n:
        if current % 2 == 0:  # 嵌套分支
            total += current
        current += 1  # 更新循环变量，防止死循环
        
    return total

# 调用示例
print(sum_even_numbers(10))  # 输出 30
```

## 复杂度与权衡
引入控制结构会增加时间复杂度的不确定性。顺序结构复杂度通常为 $O(1)$。分支结构取决于条件判断次数，通常为 $O(1)$ 但可能引发最坏情况路径。循环结构直接决定量级，上述示例中循环执行 $N$ 次，时间复杂度为 $O(N)$。

权衡在于可读性与效率。深层嵌套的循环与分支（如超过 3 层）会显著降低代码可维护性，增加认知负荷。在某些场景下，使用数学公式（如等差数列求和）替代循环可将复杂度降为 $O(1)$，但牺牲了通用逻辑的直观性。

## 常见误区
1. **赋值与混淆**：在条件判断中误用赋值运算符 `=` 而非相等运算符 `==`，导致条件恒真或语法错误。
2. **死循环**：循环体内未更新控制变量，或终止条件永远无法满足（如 `while True` 无 break）。
3. ** off-by-one 错误**：循环边界处理不当，导致多执行一次或少执行一次（如 `<` 与 `<=` 混淆）。
4. **缩进错误**：在 Python 中，错误的缩进会导致逻辑块归属错误，使循环体外的代码被纳入循环内。

## 自测题与答案
**题目 1**：以下循环执行多少次？`for i in range(1, 5): print(i)`
**答案**：4 次。`range(1, 5)` 生成序列 [1, 2, 3, 4]，不包含终点 5。

**题目 2**：若 `x = 10`，执行 `if x > 5: x = 0` 后，`x` 的值是多少？
**答案**：0。条件成立，执行赋值语句。

**题目 3**：写出一个死循环的 Python 示例。
**答案**：`while True: pass`。条件恒为真且无中断机制。
