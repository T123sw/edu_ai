## 真实问题情境
某高校图书馆希望将借阅记录开放给教育研究人员，用于分析学生阅读习惯与学业成绩的相关性。原始数据包含学生学号、姓名、借阅书籍、精确借阅时间及宿舍区。直接发布原始数据会泄露学生隐私，违反数据治理规定。你需要作为数据工程师，对数据进行脱敏处理，使其既满足研究需求，又符合隐私保护标准。

## 输入输出或材料
- **输入材料**：一份包含 5 条记录的模拟 CSV 数据片段。
  ```csv
  student_id,name,book_title,borrow_time,dorm_area
  2023001,张三，计算思维导论，2023-10-01 14:30,北区 A 栋
  2023002,李四，Python 编程基础，2023-10-01 15:00,南区 B 栋
  ...
  ```
- **输出要求**：一份脱敏后的 CSV 文件，其中直接标识符被移除，准标识符被泛化。
- **治理规则**：
  1. 移除直接标识符（学号、姓名）。
  2. 时间泛化至“日期”，隐藏具体时刻。
  3. 地点泛化至“校区”，隐藏具体楼栋。

## 分步任务
1. **识别阶段**：遍历数据字段，标记出直接标识符（Direct Identifiers）与准标识符（Quasi-Identifiers）。
2. **处理阶段**：编写脚本移除直接标识符，对准标识符进行泛化处理（Generalization）。
3. **验证阶段**：检查处理后的数据是否仍包含唯一性过高的记录，评估重识别风险。

## 参考实现/推导
以下 Python 代码使用标准库实现数据脱敏流程。

```python
import csv
import io

def anonymize_data(raw_csv_content):
    """
    对原始 CSV 内容进行脱敏处理
    """
    f_io = io.StringIO(raw_csv_content)
    reader = csv.DictReader(f_io)
    
    output_rows = []
    # 定义需要保留的字段（最小化原则）
    keep_fields = ['book_title', 'borrow_date', 'campus']
    
    for row in reader:
        new_row = {}
        # 1. 移除直接标识符 (student_id, name 不复制)
        # 2. 泛化时间 (只保留日期部分)
        if 'borrow_time' in row:
            new_row['borrow_date'] = row['borrow_time'].split(' ')[0]
        
        # 3. 泛化地点 (只保留校区前缀)
        if 'dorm_area' in row:
            area = row['dorm_area']
            new_row['campus'] = area.split(' ')[0] if ' ' in area else area
            
        # 保留书名（研究所需）
        if 'book_title' in row:
            new_row['book_title'] = row['book_title']
            
        output_rows.append(new_row)
        
    return output_rows

# 模拟输入数据
raw_data = """student_id,name,book_title,borrow_time,dorm_area
2023001,张三，计算思维导论，2023-10-01 14:30,北区 A 栋
2023002,李四，Python 编程基础，2023-10-01 15:00,南区 B 栋"""

result = anonymize_data(raw_data)
print(f"脱敏后记录数：{len(result)}")
print(f"样例字段：{result[0].keys()}")
```

## 测试与边界情况
1. **正常测试**：运行脚本，确认输出不包含“张三”、"2023001"等字符串。
2. **边界情况**：
   - **空值处理**：若 `borrow_time` 为空，脚本不应崩溃，应填入"Unknown"。
   - **唯一性风险**：若某校区某天只有一人借书，即使泛化仍可能被识别。需检查每组泛化数据的大小 $k$，若 $k < 3$，则需进一步抑制该数据行（满足 $k$-匿名性）。
3. **一致性检查**：确保脱敏后的数据格式统一，便于研究人员读取。

## 评价量规
| 维度 | 优秀 (5 分) | 合格 (3 分) | 不合格 (1 分) |
| :--- | :--- | :--- | :--- |
| **标识符移除** | 完全移除学号、姓名 | 移除学号但保留姓名 | 未移除直接标识符 |
| **泛化程度** | 时间与地点均合理泛化 | 仅泛化时间或地点 | 未进行泛化处理 |
| **代码健壮性** | 处理了空值与异常格式 | 仅能处理标准格式 | 代码无法运行 |
| **隐私风险评估** | 提及 k-匿名性检查 | 仅目测检查 | 无风险评估意识 |
