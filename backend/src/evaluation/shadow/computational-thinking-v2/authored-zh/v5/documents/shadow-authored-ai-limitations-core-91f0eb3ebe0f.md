## 学习目标
1. 理解智能系统（如机器学习模型、大语言模型）的核心能力边界。
2. 掌握泛化、幻觉、偏差与评价的准确定义及相互关系。
3. 能够运用基础指标量化系统性能，并识别常见的评价误区。

## 准确概念与边界
智能系统并非全知全能，其能力受限于训练数据与算法结构。**泛化（Generalization）** 指模型在未见过的测试数据上保持性能的能力，是衡量智能系统实用性的核心指标。若模型仅记住训练数据而无法适应新数据，称为过拟合。**幻觉（Hallucination）** 特指生成式系统输出看似合理但事实错误的内容，源于概率预测机制而非事实核查。**偏差（Bias）** 指系统输出系统性偏离真实值或表现出 unfairness，常源于数据分布不均。**评价（Evaluation）** 是通过特定指标量化系统表现的过程，分为自动评价（如准确率）与人工评价（如有用性）。

## 机制与步骤
评价智能系统通常遵循以下流程：
1. **数据划分**：将数据划分为训练集（Training Set）、验证集（Validation Set）和测试集（Test Set）。测试集必须严格隔离，用于模拟泛化能力。
2. **指标选择**：根据任务类型选择指标。分类任务常用准确率（Accuracy）、精确率（Precision）和召回率（Recall）；生成任务常用 BLEU 或人工评分。
3. **误差分析**：区分偏差（高误差）与方差（不稳定）。

## 完整例子：二分类垃圾邮件过滤
假设一个垃圾邮件过滤器在 100 封测试邮件中进行预测，其中真实垃圾邮件 20 封，正常邮件 80 封。模型预测结果如下：
- 真阳性（TP）：15 封（正确识别垃圾）
- 假阳性（FP）：5 封（正常误判为垃圾）
- 假阴性（FN）：5 封（垃圾漏判）
- 真阴性（TN）：75 封（正确识别正常）

## 公式与代码
基础评价指标计算公式如下：
$$ \text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN} $$
$$ \text{Precision} = \frac{TP}{TP + FP} $$
$$ \text{Recall} = \frac{TP}{TP + FN} $$

以下 Python 代码可运行，用于计算上述指标：
```python
def evaluate_model(tp, tn, fp, fn):
    total = tp + tn + fp + fn
    if total == 0: return 0, 0, 0
    accuracy = (tp + tn) / total
    precision = tp / (tp + fp) if (tp + fp) > 0 else 0
    recall = tp / (tp + fn) if (tp + fn) > 0 else 0
    return accuracy, precision, recall

# 示例数据
tp, tn, fp, fn = 15, 75, 5, 5
acc, pre, rec = evaluate_model(tp, tn, fp, fn)
print(f"Accuracy: {acc:.2f}, Precision: {pre:.2f}, Recall: {rec:.2f}")
```

## 复杂度与权衡
在智能系统设计中，存在**偏差 - 方差权衡（Bias-Variance Tradeoff）**。模型过于简单会导致高偏差（欠拟合），无法捕捉数据规律；模型过于复杂会导致高方差（过拟合），泛化能力下降。此外，精确率与召回率往往相互制约，提高阈值可增加精确率但降低召回率。对于生成式系统，降低幻觉可能需要牺牲生成的多样性。

## 常见误区
1. **准确率陷阱**：在不平衡数据集中（如欺诈检测），99% 的准确率可能毫无意义，需关注召回率。
2. **幻觉即撒谎**：幻觉是概率生成的副作用，并非系统主观欺骗，不能单纯通过道德约束解决。
3. **测试集污染**：若在训练过程中间接使用了测试集信息，泛化评价将失效。

## 自测题与答案
1. **问**：为什么测试集不能在训练过程中使用？
   **答**：为了保证评价的无偏性，测试集代表 unseen data，用于验证泛化能力。
2. **问**：若某医疗诊断模型召回率极低，意味着什么风险？
   **答**：意味着大量患病者被漏诊，可能导致严重后果。
3. **问**：幻觉产生的根本机制是什么？
   **答**：基于 next-token prediction 的概率最大化，而非事实数据库检索。
