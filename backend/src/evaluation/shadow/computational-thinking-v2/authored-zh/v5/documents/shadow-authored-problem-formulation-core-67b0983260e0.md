## 学习目标
本讲义旨在帮助学生建立计算思维中最基础的抽象能力。学习完成后，学生应能够：
1. 准确区分自然语言描述的问题与计算机可处理的形式化问题。
2. 明确定义问题的输入集合、输出集合及约束条件。
3. 识别并规避问题定义中的歧义与边界漏洞。

## 准确概念与边界
问题形式化（Problem Formalization）是将现实世界中的模糊需求转化为精确数学模型或逻辑结构的过程。其核心在于建立映射关系 $f: I \to O$，其中 $I$ 为输入空间，$O$ 为输出空间。

*   **输入（Input）**：指解决问题所需的所有初始数据集合。必须明确数据的类型（如整数、实数、字符串）、结构（如数组、图）及取值范围。
*   **输出（Output）**：指问题求解后期望得到的结果。必须明确结果的格式及含义。
*   **约束（Constraints）**：指输入数据必须满足的前提条件（Preconditions）以及求解过程必须遵守的限制（如时间、内存、物理规则）。约束定义了问题的可行域。

边界在于：形式化不包含具体的算法实现细节，而是定义“做什么”而非“怎么做”。但形式化必须足够精确，使得任何符合定义的算法都能产生一致的结果。

## 机制与步骤
形式化过程通常遵循以下四个步骤：
1.  **需求清洗**：去除自然语言中的情感色彩与无关信息，提取核心动词与名词。
2.  **变量定义**：为提取的名词赋予数学符号或数据类型，确定输入输出变量。
3.  **关系建模**：用公式、逻辑表达式或伪代码描述输入与输出之间的函数关系。
4.  **约束补充**：列出所有例外情况、非法输入处理规则及资源限制。

## 完整示例：一元二次方程求解
**自然语言描述**：帮我算一下这个方程的根。
**形式化定义**：
*   **输入**：三个实数 $a, b, c$。
*   **输出**：方程 $ax^2 + bx + c = 0$ 的实数根集合 $S$。
*   **约束**：
    1.  若 $a=0$ 且 $b=0$，则无解或无穷多解（视为非法输入或特殊状态）。
    2.  若判别式 $\Delta = b^2 - 4ac < 0$，则实数根集合为空。
    3.  计算精度保留小数点后 6 位。

## 代码实现
```python
import math

def solve_quadratic(a, b, c):
    # 约束检查：二次项系数不能为 0
    if a == 0:
        if b == 0:
            return "Invalid Input: Not a quadratic equation"
        else:
            # 退化为一元一次方程
            return [-c / b]
    
    delta = b**2 - 4*a*c
    
    if delta < 0:
        return []  # 无实数根
    elif delta == 0:
        x = -b / (2*a)
        return [x]
    else:
        x1 = (-b + math.sqrt(delta)) / (2*a)
        x2 = (-b - math.sqrt(delta)) / (2*a)
        return [x1, x2]

# 测试调用
print(solve_quadratic(1, -3, 2))  # 输出: [2.0, 1.0]
```

## 复杂度与权衡
在上述示例中，计算复杂度为 $O(1)$，因为仅涉及常数次算术运算。但在形式化阶段，需权衡**精度与性能**。例如，若要求极高精度，需使用任意精度算术库而非标准浮点数，这将增加时间复杂度。此外，形式化时需权衡**通用性与特异性**：定义过于通用（如支持复数）会增加实现难度，定义过于特异（如仅支持正整数）会限制适用范围。

## 常见误区
1.  **混淆输入验证与问题定义**：问题定义应说明“当输入非法时输出什么”（如报错或返回空），而不是假设输入永远合法。
2.  **忽略退化情况**：如示例中 $a=0$ 的情况，常被初学者遗漏，导致程序崩溃。
3.  **输出歧义**：未规定输出顺序（如根是大在前还是小在前），导致测试结果不一致。

## 自测题与答案
1.  **问**：在排序问题中，输入是“一堆数字”，这种描述符合形式化要求吗？为什么？
    **答**：不符合。未定义数字类型（整数/浮点）、结构（数组/链表）及大小关系定义。
2.  **问**：若约束条件相互矛盾（如要求时间小于 1 秒且内存小于 1KB 但数据量极大），形式化阶段应如何处理？
    **答**：应标记为“无解”或需调整约束条件，形式化需保证逻辑自洽。
3.  **问**：输出是否可以是“无”？
    **答**：可以。输出空间可包含空集或特定标志位表示无解。
