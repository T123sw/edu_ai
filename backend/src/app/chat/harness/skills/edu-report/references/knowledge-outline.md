# 用户可见的大纲

目的：让用户快速判断报告结构，不提前展示正文。
- 默认约 4–6 章，尊重用户指定的章节数。
- 每章一个具体标题、1–3 个小节标题；每个标题尽量不超过 20 个汉字。用“容量增长策略”“扩容的均摊分析”等名词性标题，不用“倍增扩容，单次 O(n)”等摘要或结论。
- 只呈现章节结构，不附加长范围说明、教学目标列表、概念解释、代码、例题答案或自检题。
- 用户要求修改时更新同一大纲版本；是否继续生成由模型结合用户意图决定，不要求固定确认用语。

内部 organization 仍保留范围、先修、目标、概念依赖、例子、误区、自检与证据，用于正文生成和审阅。对外简洁不等于丢弃正文所需信息。
