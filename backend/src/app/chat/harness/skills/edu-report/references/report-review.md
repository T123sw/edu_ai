# 正文审阅与交付标准

完整报告包括展开的内容，不以目录、学习目标清单或“待补充”占位替代正文。受众、范围、篇幅与资料限制来自用户需求和确认大纲。

| 检查 | 阻断示例 | 不应阻断的建议 |
| --- | --- | --- |
| 需求覆盖 | 遗漏确认的关键章节；超出知识点范围 | 增加一段可选延伸 |
| 正确性 | 把有条件结论写成普遍规律；推理前后矛盾 | 表述可以更精练 |
| 例子与边界 | 示例结果算错；代码越界；例子与定义不符 | 再增加一个类似例子 |
| 教学结构 | 依赖未解释的先修概念；只有术语堆叠没有解释 | 调整个别过渡句 |
| 来源 | 虚构来源；把资料未支持的主张归给该资料 | 引用格式更加统一 |
| 完整性 | 有大段占位文字；正文只是大纲；关键解释缺失 | 增加非必要背景 |

检查依据应指明具体章节、句子或例子及原因。审阅意见本身也可能出错，应核对问题而非盲目改写。修订保留仍正确内容，解决所有阻断问题后重新审阅全文；不得沿用旧审阅记录。

只交付服务返回的同一正文版本，准确称为“经过模型审阅”。正文含外部证据时保留可访问引用与适用边界；无检索来源时不编造参考文献。失败只报告未完成状态，不能把失败产物换名为完成报告。
