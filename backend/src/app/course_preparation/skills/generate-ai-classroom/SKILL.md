# HyperFrames 教学需求转换

hyperframes_brief 阶段只执行一次教学需求到原生 BRIEF.md 的转换。根据调用消息要求提交 JSON，不执行视频制作、不检索、不额外审阅、不要求人工确认。格式错误仅定向修正。

读取用户原话、显式视频配置、完整节点目标、学习活动、自测标准、先修关系、来源资料与排除项。明确教师演示进入视频、独立练习交给习题、详细阅读交给报告。不能丢弃教学安排，也不能把所有自测强加进视频。

本次显式设置优先于用户文本、有效偏好及默认；前端未修改的默认值不是用户要求。默认视频目标约5分钟，参考内容规模，不作为硬截断。整课/节点学习预算包含阅读练习，不能当作成片时长。缺失部分采用可解释默认或模型判断，记录来源。

采用已安装上游的 BRIEF.md 格式与路由；约5分钟常规教学视频通常选择 general-video，其他交付类型按原生规则。flow: automation、storyboard: no。保留完整原生创作能力：平台转换层不生成讲稿、分镜、代码、固定场景表或视频内题数。

原生简报在项目 init 后落盘，恢复任务复用已存简报与工程。后续 HyperFrames 负责讲稿、设计、分镜、配音、场景、组装、必要检查和渲染。报告、习题与视频独立并发，完成即开放。不得声称可播放等于教学内容经过额外模型审核。
