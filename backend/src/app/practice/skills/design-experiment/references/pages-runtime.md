# 三个独立页面的接入约定

当前新生成只使用 demonstrate / explore 两阶段：先完整探索页，再制作演示页。guided 接口仅兼容历史产物，不为新实验生成任务、评分或第三个页面。

同时遵循 [状态含义与结束依据](state-evidence.md)：snapshot 中用可选 `_teaching` 保存关键字段语义、重置前事实和本次结束原因。该约定随页面生成指令一起提供，不新增运行时请求或生成门槛。

宿主已提供 `window.EduStage`、Tailwind 4 和 KaTeX。只输出完整 HTML，内联 CSS/JavaScript，使用原生 canvas/SVG/DOM；不下载资源、不重复声明 EduStage。正文至少16px，canvas按DPR绘制，缩放只重绘。页面只包含实验图形和本阶段实际控件；宿主显示阶段导航、任务、讲解和演示按钮。

页面排布：按嵌入区域的实际宽度设计单列内容，不把整个浏览器宽度当作可用空间。图形放最前面，接着是简洁的状态与实际操作，参数配置放在图形下方；公式、背景等辅助内容用原生 details/summary 默认收起。不要重复实验标题、阶段标题、长篇原理介绍或宿主的下一步按钮。建议用同一个父容器的直接子块标记 `data-experiment-region="visual"`、`"controls"`、`"metrics"`、`"reference"`，便于统一展示；标记是展示建议，不作为生成失败条件。统一系统无衬线字体、浅色背景、少量细分隔线与间距，避免多层卡片、阴影和每个按钮一种颜色；图形中表示不同对象/状态的颜色与图例保持一致。宽度缩小时控件自然换行，保留足够触摸区域，页面高度随内容伸展，不使用固定全屏高度裁切图形或操作。所有布局变化只重绘，不修改实验状态。

每个页面在 DOM 就绪后调用一次：

```js
EduStage.register({
  initialize(index) { /* 设置本阶段初始状态；练习按index初始化本题；绘图 */ },
  snapshot() { return { /* 可序列化的完整学科状态、参数、计数和选中对象 */ }; },
  restore(state) { /* 恢复所有变量、控件并绘图，取消旧动画，不报告操作 */ },
  next(index) { /* 仅演示页：执行一个真实动作，返回 {action_id, done, facts}；可返回Promise */ }
});
```

宿主注入 `window.__stagePage.phase` 和 `.spec`（本阶段配置），`EduStage.index` 返回当前步骤/任务索引，`EduStage.busy` 表示初始化或操作中。demo_initial、task.initial 是供生成页面理解的自然语言说明，不是运行时的数组或参数；根据说明在页面内定义明确类型的初始数据，不把说明文本传给输入解析器。探索页使用自身的初始参数，不读取 demo_initial 或练习任务；探索阶段不提供这些教学字段。只在 initialize/restore 中设初始数据，不要在 register 后再自动重置。snapshot/restore必须能往返恢复，不能只记录显示文字。所有初始化和恢复不调用 perform。

新生成页面使用 `edu-actions/1` 动作协议。此时只实现动作，不生成教学解释、下一步提示或具体对错原因；可以显示当前数组、索引、计数等客观状态和必要控件标签。讲解将在页面完成后另一次模型调用中生成。不要依赖 spec.demo_steps 的长度或 before/after 文本决定执行路径，最终讲解会替换这些字段。

演示 next 每次返回 `{action_id:'compare-0-1', done:false, facts:{left:3,right:1}}`，action_id 描述本次真实操作并在重播中稳定；facts 是该动作实际比较对象、交换值、边界变化等 JSON 事实，记录操作前的值，不能取已推进后的索引冒充本次对象。done 仅在实际算法/目标完成时为 true。从确定初始条件按内部状态机推进直到 done，不按计划步骤数量提前停止；同类型动作可以重复。snapshot 包含算法内部状态、索引和完成标志。

练习 register 额外提供 `actions:[{id:'choose-swap',label:'选择交换',rule:'用户确认交换；按当前相邻数值判对错，排序结束才pass',facts:['left','right','nextLeft','nextRight']}]`。目录描述真实代码分支语义与事实字段，不是教学讲解。不同语义需要不同 id。每个 perform 的回调返回 `{action_id:'choose-swap',verdict:'pending',facts:{left:3,right:1}}`；错误分支同样返回实际 action_id 和 facts。事实字段按适用分支提供，避免用已推进的对象覆盖本次对象；可增加 expected、reason 等客观判据。后续模板使用这些事实字段，不调用模型即时判题。不返回长篇 feedback。

演示页：隐藏全部自由操作控件和对象点击修改，只实现 next(index)，一调用对应一步；index从0开始。回看和重播由宿主恢复初始状态并重放，不要自行维护另一套步骤计数。initialize始终使用demo_initial，不按index跳步。next完成后snapshot要反映实际状态，异步动画返回完成的Promise。

next 的“一步”是一次学科操作，不是一段自动流程。算法页一次调用至多比较一对元素并完成本次必要交换，或仅推进一个轮次边界；不在 next 或其辅助函数里反复调用 step，不用 while/for/递归/定时器推进至某轮结束或整体完成。绘图遍历不受此限制。最终一步也保持相同粒度，演示执行到 done:true 时整个算法必须真实完成，快照记录最终结果与完成状态；不要偷偷运行未列出的操作、改换初始数据或强制写入完成结果。

连续物理过程不同于离散算法：next 推进到下一个有教学意义的观察时刻，依据相同方程或数值求解器实际计算时间区间的状态。可以合并内部动画/积分帧，不能要求学生逐帧点击。整段演示只跑一组初始条件，用少量观察点解释过程并到达实际停止或预定观察终点，facts 明确本次时间区间与状态变化，不增加参数切换或重复对照实验。

练习页：initialize(index)设置该任务独立初始条件和控件；index达到任务数时清空/禁用操作，不越界访问。不提供下一步按钮，用户直接操作对象或必要控件。每个语义操作通过perform执行：

```js
button.onclick = () => EduStage.perform('选择相邻元素', {index: selectedIndex}, () => {
  // 真正修改状态、绘图；错误操作也需要记录。
  if (/*错误*/) return {action_id:'select-pair',verdict:'fail',facts:{expectedIndex}};
  if (/*本题已完成*/) return {action_id:'select-pair',verdict:'pass',facts:{}};
  return {action_id:'select-pair',verdict:'pending',facts:{}}; // 本题还有必要的操作
});
```

perform接收中文动作名称、JSON参数、执行函数。宿主根据结果显示预生成success/retry，pass自动初始化下一任务，fail恢复本次操作前的状态并允许重试，pending保留进度继续本题。一个任务可以有任意多个必要操作：正确中间操作返回 pending、action_id 和具体 facts（本次对象、判据和状态变化），整个任务真实达到 completion 才返回 pass。每次操作及时重绘当前对象；教学反馈由宿主的后生成模板显示。不要因一次选择正确就 pass。算法任务必须由用户完成所有必要步骤与终止判断，不能自动跑完剩余过程或仅检查数组已排序而跳过必要遍历。多操作任务可以有“确认结果”按钮，但不能绕过判断。

练习的每个执行函数必须直接 return 判定对象，或返回最终 resolve 为判定对象的 Promise；仅选择对象等中间操作返回 pending。所有学科状态修改都在 perform 的执行函数内进行，确保失败能回到本次操作前。不要只在 setTimeout/回调函数内部 return，而让外层函数返回 undefined。不在页面内自行推进题号或提前回滚；这些由宿主在记录操作结果后完成。snapshot必须包含恢复判断所需的辅助变量。index达到任务数时只禁用操作，保留完成结果，不重置最后一个任务的数据。重置由宿主提供。

探索页：保留完整实验的参数和相关操作，用perform包裹每个操作（参数改变、单步、运行、暂停、重置等），不返回pass/fail。不要禁用自由控件。运行动画时在关键状态变化后调用 `EduStage.observe('运行一步')` 上报，不每帧上报。暂停/重置也调用perform；持续动画不要使perform的Promise永远等待，否则会阻塞暂停。restore必须取消旧定时器；仅当快照正在运行时转为暂停，不自动续跑。原本静止或暂停的快照必须原样恢复所有字段（包括 paused、状态文字和控件值），不能无条件设 paused=true 把初始就绪状态改成暂停。

首次生成完整探索页时就提供与核心机制有关的可编辑初始条件，不能只有单步/运行/暂停/重置。按学科选择有意义的参数：排序页提供有标签的数组输入与“应用数组”按钮（支持自定义乱序、已排序、逆序及重复值）；物理页提供相关初始量和单位；连接实验允许改变连接关系。参数必须进入实际计算，不能仅改变显示文字。应用新条件时停止旧动画，更新当前实验及其重置基准，清零相应过程计数并重绘；不合法输入给出可见提示且保留原实验状态。snapshot/restore 包含实际参数、已应用的初始条件和控件值，重置返回最近应用的初始条件。预设例子可以辅助选择，不能替代主要初始条件的自由设置。

输入错误使用页面内可见文字反馈，禁止 alert/confirm/prompt：沙箱不允许这些弹窗。页面负责本地实验行为与判定；宿主只管理阶段、步骤、事件与保存，不请求模型即时判题。上报是浏览器观察，不是独立科学认证。任何操作均不得自行调用父页接口、改变宿主步骤或伪造用户历史。
