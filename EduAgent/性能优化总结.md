# 深度搜索性能优化总结

## 当前性能问题

**测试结果**: 690.65秒（约11.5分钟）

### 主要耗时原因

1. **SearxNG返回403** ⚠️
   - SearxNG容器运行但返回403错误
   - 导致web_search回退到Bing/DDG HTML解析
   - HTML解析比SearxNG API慢5-10倍

2. **结构化输出频繁失败** ⚠️
   - 每次thought节点都失败，重试5次
   - 每次重试5-10秒
   - **已优化**: 减少到2次重试

3. **Agent执行步骤** ⚠️
   - 虽然只执行3步，但每步耗时较长
   - **已优化**: 递归限制从49改为20

## 已实施的优化

### ✅ 1. 减少结构化输出重试次数
- **文件**: `o_agent/base_agent.py`
- **修改**: `max_tries = 5` → `max_tries = 2`
- **预期效果**: 节省50-100秒

### ✅ 2. 减少Agent递归限制
- **文件**: `deepsearch.py`
- **修改**: `recursion_limit: 49` → `recursion_limit: 20`
- **预期效果**: 节省20-40秒

### ✅ 3. 改进SearxNG请求headers
- **文件**: `tools/search/websearch.py`
- **修改**: 使用更完整的浏览器headers
- **预期效果**: 提高SearxNG访问成功率

### ✅ 4. 优化SearxNG配置
- **文件**: `searxng/settings.yml`
- **修改**: 禁用bot detection (`limiter: false`)
- **状态**: 已更新配置，需要重启容器
