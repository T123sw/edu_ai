## 完整流程

1. **用户输入搜索关键词** → 前端页面
2. **提交搜索请求** → `POST /agent/deepsearch-and-crawl`
3. **后端深度搜索** → 获取相关URL
4. **后端爬取URL** → 爬取内容
5. **后端清洗内容** → 格式化处理
6. **后端保存结果** → 返回批次ID
7. **前端获取结果** → `GET /agent/crawl-results/{batch_id}`
8. **前端展示结果** → 链接列表、内容预览、元数据

## API端点详情

### POST /agent/deepsearch-and-crawl

**请求**:
```json
{
  "query": "搜索关键词",
  "max_urls": 5,
  "crawl_timeout": 30
}
```

**响应**:
```json
{
  "ok": true,
  "query": "搜索关键词",
  "batch_id": "批次ID",
  "total_urls": 5,
  "success_count": 3,
  "failed_count": 2,
  "links": ["url1", "url2", ...],
  "created_at": "2024-01-01T00:00:00",
  "results": [...]
}
```

### GET /agent/crawl-results/{batch_id}

**响应**:
```json
{
  "ok": true,
  "batch_id": "批次ID",
  "query": "搜索关键词",
  "total_urls": 5,
  "success_count": 3,
  "failed_count": 2,
  "created_at": "2024-01-01T00:00:00",
  "results": [
    {
      "url": "url",
      "title": "标题",
      "content": "内容",
      "content_type": "text",
      "status": "success",
      "metadata": {}
    }
  ]
}
```

### GET /agent/crawl-history?limit=20

**响应**:
```json
{
  "ok": true,
  "batches": [
    {
      "batch_id": "批次ID",
      "query": "搜索关键词",
      "total_urls": 5,
      "success_count": 3,
      "failed_count": 2,
      "created_at": "2024-01-01T00:00:00"
    }
  ]
}
```
