# 修复websearch.py编码问题

## 问题

文件 `tools/search/websearch.py` 中有编码问题，导致Python无法解析：
```
SyntaxError: invalid character '（' (U+FF08)
```

## 解决方案

文件中有一些乱码字符（显示为 `?`），需要修复。

### 快速修复方法

1. **使用文本编辑器重新保存文件为UTF-8编码**
   - 打开 `tools/search/websearch.py`
   - 另存为，选择UTF-8编码
   - 保存

2. **或者使用Python脚本修复**

```python
# 修复编码问题
with open('tools/search/websearch.py', 'r', encoding='utf-8', errors='replace') as f:
    content = f.read()

# 替换常见的乱码字符
content = content.replace('?', '和')  # 或其他合适的字符
content = content.replace('', '')  # 删除无法识别的字符

with open('tools/search/websearch.py', 'w', encoding='utf-8') as f:
    f.write(content)
```

### 关键修复点

需要修复的行：
- 第14行: `"""?SerpAPI 响应里抽?url + title?"""`
- 第29行: `使用谷歌搜索引擎（SerpAPI）搜索，返回指定数量的搜索结果列表，搜索结果包含 url?title?`

应该改为：
- 第14行: `"""从SerpAPI响应里提取url + title"""`
- 第29行: `使用谷歌搜索引擎（SerpAPI）搜索，返回指定数量的搜索结果列表，搜索结果包含 url 和 title`

## 验证修复


应该能正常导入和运行。
