## 功能流程

### 完整流程

1. **用户输入搜索关键词**
   - 在搜索表单中输入关键词
   - 设置最大URL数量（默认5个）

2. **提交搜索请求**
   - 调用 `deepSearchAndCrawl()` API
   - 显示加载状态
   - 提示用户等待（可能需要几分钟）

3. **后端处理**
   - 深度搜索获取相关URL
   - 爬取URL内容
   - 清洗和格式化内容
   - 保存结果并返回批次ID

4. **获取结果详情**
   - 使用批次ID调用 `getCrawlResults()`
   - 获取详细的爬取结果

5. **展示结果**
   - 显示搜索到的链接列表
   - 显示每个URL的爬取结果
   - 展示内容预览（可展开）
   - 显示元数据信息
   - 显示成功/失败状态

6. **刷新结果**（可选）
   - 用户可以点击刷新按钮
   - 重新获取最新的爬取结果

## API端点

### 后端API端点

1. **POST /agent/deepsearch-and-crawl**
   - 请求体: `{ query: string, max_urls?: number, crawl_timeout?: number }`
   - 响应: `{ ok: boolean, batch_id?: string, links?: string[], ... }`

2. **GET /agent/crawl-results/{batch_id}**
   - 响应: `{ ok: boolean, results?: CrawlResult[], ... }`

3. **GET /agent/crawl-history?limit=20**
   - 响应: `{ ok: boolean, batches?: CrawlHistoryItem[] }`

## 使用说明

### 访问页面

1. 以教师身份登录系统
2. 在左侧导航菜单中点击"深度搜索"
3. 或直接访问 `/deep-search` 路由

### 使用步骤

1. **输入搜索关键词**
   - 例如："计算思维 课程大纲 PDF"
   - 支持中文和英文关键词

2. **设置URL数量**
   - 建议5-10个（默认5个）
   - 过多可能耗时较长

3. **点击"开始搜索并爬取"**
   - 系统开始深度搜索
   - 显示加载状态
   - 等待完成（可能需要几分钟）

4. **查看结果**
   - 搜索到的链接列表
   - 每个URL的爬取结果
   - 内容预览和元数据

5. **刷新结果**（可选）
   - 如果爬取还在进行中
   - 可以点击刷新按钮获取最新状态

## 注意事项

1. **API地址配置**
   - 默认: `http://127.0.0.1:8848`
   - 可通过环境变量 `VITE_API_BASE_URL` 配置

2. **超时设置**
   - 默认爬取超时: 30秒/URL
   - 可在请求中自定义

3. **权限控制**
   - 仅教师角色可访问
   - 学生角色无法看到此功能

4. **性能考虑**
   - 搜索和爬取可能需要较长时间
   - 建议设置合理的URL数量限制
   - 使用异步请求避免阻塞
