# 修复websearch.py编码问题 - 最终方案

## 问题

文件 `tools/search/websearch.py` 第14行和第29行有编码问题，导致Python无法解析：
- 第14行: 有乱码字符 `?`
- 第29行: 有全角括号 `（` 和乱码字符 `?`

## 解决方案

### 方法1: 手动修复（推荐）

1. 打开 `tools/search/websearch.py`
2. 找到第14行，将：
   ```python
   """?SerpAPI 响应里抽?url + title?"""
   ```
   改为：
   ```python
   """从SerpAPI响应里提取url + title"""
   ```

3. 找到第29行，将：
   ```python
   使用谷歌搜索引擎（SerpAPI）搜索，返回指定数量的搜索结果列表，搜索结果包含 url?title?
   ```
   改为：
   ```python
   使用谷歌搜索引擎（SerpAPI）搜索，返回指定数量的搜索结果列表，搜索结果包含 url 和 title
   ```

4. 保存文件为UTF-8编码

### 方法2: 使用Python脚本修复

创建并运行以下脚本：

```python
# fix_encoding.py
import re

with open('tools/search/websearch.py', 'r', encoding='utf-8', errors='replace') as f:
    lines = f.readlines()

# 修复第14行（索引13）
if '?' in lines[13] or '' in lines[13]:
    lines[13] = '    """从SerpAPI响应里提取url + title"""\n'

# 修复第29行（索引28）
if '?' in lines[28] or '（' in lines[28]:
    # 找到docstring的开始
    for i in range(27, 35):
        if '使用谷歌搜索引擎' in lines[i]:
            # 替换整行
            lines[i] = '    使用谷歌搜索引擎（SerpAPI）搜索，返回指定数量的搜索结果列表，搜索结果包含 url 和 title\n'
            break

with open('tools/search/websearch.py', 'w', encoding='utf-8') as f:
    f.writelines(lines)

print("修复完成！")
```

运行：
```powershell
cd D:\Edu_AI_1\EduAgent
python fix_encoding.py
```

2. **第29行**: `使用谷歌搜索引擎（SerpAPI）搜索，返回指定数量的搜索结果列表，搜索结果包含 url?title?` → `使用谷歌搜索引擎（SerpAPI）搜索，返回指定数量的搜索结果列表，搜索结果包含 url 和 title`
