# 前后端集成配置说明

## 后端配置

### API端点

**服务地址**: `http://127.0.0.1:8848`

**主要端点**:
1. `POST /agent/deepsearch-and-crawl` - 深度搜索并爬取
2. `GET /agent/crawl-results/{batch_id}` - 获取爬取结果
3. `GET /agent/crawl-history?limit=20` - 获取爬取历史

### CORS配置

后端已配置CORS，允许以下来源：
- `http://localhost:5173` (Vite默认端口)
- `http://127.0.0.1:5173`
- `http://localhost:3000`
- `http://127.0.0.1:3000`

### 请求格式

**深度搜索并爬取**:
```json
{
  "query": "搜索关键词",
  "max_urls": 5,
  "crawl_timeout": 30
}
```

**响应格式**:
```json
{
  "ok": true,
  "batch_id": "批次ID",
  "query": "搜索关键词",
  "total_urls": 5,
  "success_count": 3,
  "failed_count": 2,
  "links": ["url1", "url2", ...],
  "created_at": "2024-01-01T00:00:00"
}
```

## 前端配置

### API服务地址

**默认地址**: `http://127.0.0.1:8848`

**配置方式**:
1. 环境变量: `VITE_API_BASE_URL=http://127.0.0.1:8848`
2. 代码默认值: `import.meta.env.VITE_API_BASE_URL || 'http://127.0.0.1:8848'`

### 前端文件

1. **API服务**: `src/services/deepsearch.ts`
   - `deepSearchAndCrawl()` - 调用搜索API
   - `getCrawlResults()` - 获取结果详情
   - `getCrawlHistory()` - 获取历史记录

2. **页面组件**: `src/pages/DeepSearchPage.tsx`
   - 搜索表单
   - 结果展示
   - 错误处理

3. **路由配置**: `src/routes/AppRoutes.tsx`
   - 路由: `/deep-search`
   - 权限: 仅教师角色

4. **导航菜单**: `src/layout/GlobalLayout.tsx`
   - 菜单项: "深度搜索"
   - 图标: SearchOutlined

## 常见问题

### 1. CORS错误

**症状**: `Access to fetch at '...' from origin '...' has been blocked by CORS policy`

**解决**:
- 检查后端CORS配置是否包含前端地址
- 确认前端运行在5173端口
- 检查后端是否正常运行

### 2. 连接失败

**症状**: `无法连接到服务器`

**解决**:
- 确认后端服务已启动
- 检查端口8848是否被占用
- 检查防火墙设置
- 验证API地址配置

### 3. 请求超时

**症状**: `请求超时`

**解决**:
- 搜索和爬取可能需要较长时间（5-10分钟）
- 检查后端日志查看进度
- 可以适当增加超时时间

### 4. 404错误

**症状**: `404 Not Found`

**解决**:
- 检查API端点路径是否正确
- 确认后端路由已注册
- 检查请求方法（POST/GET）
