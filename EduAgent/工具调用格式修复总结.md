# 工具调用格式修复总结

## 问题诊断

### 错误信息分析

从错误信息看：
```
KeyError: 'scan_page<tool_sep>{"url": "https://max.book118.com/html/2025/0829/8057042001007126.shtm"}<tool_call_end><tool_call_begin>scan_page<tool_sep>{"url": "http://cs.hust.edu.cn/info/1395/2919.htm"}<tool_call_end>...'
```

**问题原因**:
1. LLM返回的`tool_calls`格式不正确
2. `tool_name`不是简单的工具名（如`scan_page`），而是包含了整个工具调用字符串
3. 包含特殊标记如`<tool_sep>`、`<tool_call_end>`等
4. 这导致`self.TOOLS_MAP[tool_name]`查找失败

## 已实施的修复

### ✅ 1. 在action_node中验证tool_calls格式

**修改**: `o_agent/base_agent.py` action_node函数

**改进**:
- ✅ 验证tool_calls是否为列表
- ✅ 验证每个tool_call是否为字典格式
- ✅ 验证工具名是否在TOOLS_MAP中
- ✅ 过滤无效的tool_call

### ✅ 2. 在tool_node中增强错误处理

**修改**: `o_agent/base_agent.py` tool_node函数

**改进**:
- ✅ 验证tool_calls格式（列表、非空）
- ✅ 验证每个tool_call格式（字典、包含name字段）
- ✅ 清理tool_name，移除特殊标记
- ✅ 使用正则表达式提取实际的工具名
- ✅ 验证工具名是否在TOOLS_MAP中
- ✅ 验证args格式（字典）

### ✅ 3. 工具名提取逻辑

**策略**:
- 如果tool_name包含特殊标记（`<tool_sep>`、`<tool_call`等）
- 使用正则表达式提取第一个有效的工具名
- 格式：`^([a-zA-Z_][a-zA-Z0-9_]*)`

## 代码改进

### 关键修改点

1. **action_node验证**:
   ```python
   # 验证tool_calls格式
   if tool_calls:
       if not isinstance(tool_calls, list):
           tool_calls = []
       else:
           valid_tool_calls = []
           for tc in tool_calls:
               if isinstance(tc, dict) and 'name' in tc:
                   tool_name = tc.get('name', '')
                   if tool_name and tool_name in self.TOOLS_MAP:
                       valid_tool_calls.append(tc)
           tool_calls = valid_tool_calls
   ```

2. **tool_node错误处理**:
   ```python
   # 清理tool_name
   if tool_name not in self.TOOLS_MAP:
       if '<tool_sep>' in tool_name or '<tool_call' in tool_name:
           match = re.search(r'^([a-zA-Z_][a-zA-Z0-9_]*)', tool_name)
           if match:
               tool_name = match.group(1)
   ```
