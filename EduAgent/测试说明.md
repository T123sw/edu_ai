## 🔍 API端点说明

### 1. 深度搜索并爬取

**端点**: `POST /agent/deepsearch-and-crawl`

**请求体**:
```json
{
    "query": "计算思维 课程大纲 PDF",
    "max_urls": 5,
    "crawl_timeout": 30
}
```

**响应**:
```json
{
    "ok": true,
    "query": "计算思维 课程大纲 PDF",
    "batch_id": "20250123_143022_a1b2c3d4",
    "search_results": {
        "total_urls": 8,
        "urls": ["url1", "url2", ...]
    },
    "crawl_results": {
        "total_urls": 5,
        "success_count": 3,
        "failed_count": 2,
        "results": [...]
    }
}
```

### 2. 获取爬取结果

**端点**: `GET /agent/crawl-results/{batch_id}`

**示例**:
```powershell
# 使用Python脚本中的函数
python -c "from test_deepsearch_and_crawl import test_get_crawl_results; test_get_crawl_results('20250123_143022_a1b2c3d4')"
```

### 3. 获取爬取历史

**端点**: `GET /agent/crawl-history?limit=20`

**示例**:
```powershell
# 使用Python脚本中的函数
python -c "from test_deepsearch_and_crawl import test_get_crawl_history; test_get_crawl_history(5)"
```

## ⚠️ 注意事项

1. **服务必须先启动**
   - 确保FastAPI服务在 `http://127.0.0.1:8848` 运行
   - 如果连接失败，检查服务是否启动

2. **爬取时间较长**
   - 深度搜索可能需要1-2分钟
   - 爬取每个URL可能需要10-30秒
   - 建议测试时使用较小的 `max_urls` (如3-5)

3. **依赖检查**
   - 确保 `自动化爬虫` 模块可正常导入
   - 确保 ChromeDriver 可用
   - 确保主线 MinerU 导入配置可用

4. **错误处理**
   - 如果爬取失败，检查网络连接
   - 检查目标URL是否可访问
   - 查看服务端日志获取详细错误信息

## 🐛 常见问题

### 问题1: 连接失败

**错误**: `ConnectionError` 或 `无法连接到服务器`

**解决**:
- 确保FastAPI服务已启动
- 检查端口8848是否被占用
- 确认服务地址为 `http://127.0.0.1:8848`

### 问题2: 爬虫模块导入失败

**错误**: `无法导入爬虫模块`

**解决**:
- 检查 `自动化爬虫/src/selenium_way/crawle_url.py` 是否存在
- 确认路径配置正确
- 检查依赖包是否安装

### 问题3: 爬取超时

**错误**: `请求超时`

**解决**:
- 增加 `crawl_timeout` 参数
- 减少 `max_urls` 数量
- 检查网络连接
