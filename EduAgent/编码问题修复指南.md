# websearch.py 编码问题修复指南

## 问题

文件 `tools/search/websearch.py` 有多处编码问题，导致Python无法解析。主要问题：
1. 第14行: 有乱码字符
2. 第29行: 有全角括号和乱码字符
3. 第60-105行: 多处logger.info中有乱码字符

## 解决方案

### 推荐方法：手动修复

由于文件编码问题复杂，建议手动修复：

1. **打开文件** `tools/search/websearch.py`

2. **修复以下行**：

   - **第14行**:
     ```python
     # 原: """?SerpAPI 响应里抽?url + title?"""
     # 改: """从SerpAPI响应里提取url + title"""
     ```

   - **第29行**:
     ```python
     # 原: 使用谷歌搜索引擎（SerpAPI）搜索，返回指定数量的搜索结果列表，搜索结果包含 url?title?
     # 改: 使用谷歌搜索引擎（SerpAPI）搜索，返回指定数量的搜索结果列表，搜索结果包含 url 和 title
     ```

   - **第60行**:
     ```python
     # 原: # ---------- ?1 ?----------
     # 改: # ---------- 第1 页----------
     ```

   - **第62行**:
     ```python
     # 原: logger.info("正在谷歌搜索?1 页内?")
     # 改: logger.info("正在谷歌搜索第1 页内容")
     ```

   - **第88行**:
     ```python
     # 原: logger.info("没有更多分页结果，提前结束?")
     # 改: logger.info("没有更多分页结果，提前结束")
     ```

   - **第92行**:
     ```python
     # 原: logger.info(f"正在谷歌搜索?{current_page} 页内?")
     # 改: logger.info(f"正在谷歌搜索第{current_page} 页内容")
     ```

   - **第105行**:
     ```python
     # 原: logger.info(f"?{current_page} 页没有有效结果，提前结束?")
     # 改: logger.info(f"第{current_page} 页没有有效结果，提前结束")
     ```

3. **保存文件为UTF-8编码**

### 验证修复

修复后运行：
```powershell
cd D:\Edu_AI_1\EduAgent
python test_websearch_fix.py
```

## 关键点

- 所有 `?` 字符需要替换为正确的中文字符
- 保留全角括号 `（` 和 `）`
- 确保文件保存为UTF-8编码
