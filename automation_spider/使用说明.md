# 自动化爬虫模块使用说明

## 📋 模块概述

这是一个基于 Selenium 的自动化爬虫模块，支持多种数据抓取场景：
- **PDF文件抓取**：通过关键词搜索并下载PDF文件
- **网页文本抓取**：提取网页正文内容保存为TXT
- **CNKI知网爬取**：登录知网并批量下载论文PDF
- **指定URL抓取**：直接抓取指定URL的内容
- **代理IP管理**：自动获取和验证免费代理IP

## 🚀 快速开始

### 1. 安装依赖

```bash
cd 自动化爬虫/src/selenium_way
pip install -r requirement.txt
```

主要依赖包：
- `selenium==4.15.0` - 浏览器自动化
- `undetected-chromedriver==3.5.5` - 反检测Chrome驱动
- `webdriver-manager==4.0.1` - 自动管理ChromeDriver版本
- `requests==2.31.0` - HTTP请求
- `beautifulsoup4==4.12.3` - HTML解析
- `trafilatura==1.7.0` - 智能文本提取
- `ddddocr>=1.5.6` - 验证码识别（支持Python 3.12+）

### 2. 配置设置

配置文件位于 `automation_spider/config.py`，可通过环境变量或直接修改配置：

**环境变量配置（推荐）：**
```bash
# Windows PowerShell
$env:SPIDER_KEYWORDS="材料力学"
$env:SPIDER_PAGES="2"
$env:SAVE_ROOT_DIR="D:\output"
$env:CNKI_USERNAME="你的学号"
$env:CNKI_PASSWORD="你的密码"
$env:CNKI_COLLEGE="哈尔滨工程大学"
```

**直接修改 config.py：**
```python
@dataclass
class Settings:
    keywords: str = "线性规划"          # 默认关键词
    pages: int = 1                     # 默认页数
    save_root_dir: str = "./output"    # 输出目录
    username: str = "2024------"       # CNKI账号
    password: str = "##########"        # CNKI密码
    college: str = "哈尔滨工程大学"     # 学校名称
```

## 📖 使用方法

### 方法一：使用命令行接口（推荐）

模块提供了统一的CLI接口，使用更方便：

#### 1. 抓取PDF文件

```bash
# 通过关键词搜索并下载PDF
python -m automation_spider pdf --keywords "材料力学" --pages 2 --output "./output"
```

**功能说明：**
- 使用Bing搜索指定关键词的PDF文件
- 自动提取真实下载链接
- 多线程并发下载（默认10线程）
- 自动去重，避免重复下载

**输出位置：** `output/关键词/collect/pdf/`

#### 2. 抓取网页文本

```bash
# 通过关键词搜索网页并提取正文
python -m automation_spider txt --keywords "深度学习" --pages 3 --output "./output"
```

**功能说明：**
- 使用Bing学术搜索相关网页
- 使用trafilatura智能提取正文内容
- 自动清理特殊字符和格式
- 保存为UTF-8编码的TXT文件

**输出位置：** `output/关键词/collect/text/`

#### 3. 抓取CNKI知网论文

```bash
# 登录知网并下载论文PDF
python -m automation_spider cnki --keywords "机器人视觉" --pages 1 --output "./output"
```

**功能说明：**
- 自动登录CARSI（需要配置学校账号）
- 搜索知网论文并提取详情页链接
- 自动识别验证码（使用ddddocr）
- 批量下载PDF文件（默认3线程）

**前置条件：**
- 需要配置有效的学校账号和密码
- 需要配置正确的学校名称
- 需要能够访问CARSI登录页面

**输出位置：** `output/关键词/CNKI/`

#### 4. 抓取指定URL

```bash
# 抓取指定的URL（支持PDF和网页）
python -m automation_spider url --urls "https://example.com/a.pdf
https://example.com/article" --output "./output"
```

**功能说明：**
- 自动识别URL类型（PDF或网页）
- PDF直接下载
- 网页提取正文并保存为TXT

**输出位置：**
- PDF: `output/urls/pdf/`
- 文本: `output/urls/text/`

```python
ip_source.save_proxies("valid_proxies.csv")
```

## ⚠️ 注意事项

1. **网络访问**
   - 部分功能需要访问外网，建议使用代理IP
   - CNKI功能需要校园网或VPN访问

2. **关键词限制**
   - 关键词不要使用多个，建议一次只用一个
   - 如需多个关键词，可用逗号分隔（部分功能支持）

3. **URL格式**
   - 指定URL时，多个URL用换行符（`\n`）分隔
   - 支持PDF和普通网页，自动识别类型

4. **ChromeDriver版本**
   - 代码中硬编码了Chrome版本142，如版本不匹配需要修改
   - 使用 `webdriver-manager` 可自动管理版本

5. **验证码识别**
   - CNKI登录使用ddddocr识别验证码
   - 识别失败会自动重试（最多3次）

6. **文件命名**
   - 自动清理文件名中的非法字符
   - 重复文件名会自动添加序号

## 🔧 故障排查

### 问题1：ChromeDriver版本不匹配

**解决方案：**
```python
# 在相关文件中修改版本号
ChromeDriverManager(version_main=142)  # 改为你的Chrome版本
```

### 问题2：CNKI登录失败

**检查项：**
- 账号密码是否正确
- 学校名称是否匹配
- 网络是否可访问CARSI
- 验证码识别是否正常

### 问题3：下载失败

**可能原因：**
- 网络连接问题
- 目标链接失效
- 需要登录或验证
- 文件过大超时

### 问题4：代理IP无效

**解决方案：**
- 增加验证线程数：`multi_thread_check(thread_num=20)`
- 更换代理IP来源网站
- 手动添加有效代理到 `valid_proxies.csv`
